# 回测与实盘的差距

一份漂亮的回测报告距离一个能赚钱的实盘策略，中间隔着若干系统性差距。这些差距不是噪声，而是**方向一致的偏差**：回测几乎总是比实盘更乐观。本篇逐条列出，并给出上线前的 checklist。

## 一、容量与冲击

回测默认"想买多少就能买多少"。实盘上，你的下单本身会推动价格（[撮合滑点与成交假设](../06-回测/06-02-撮合滑点与成交假设.md)）。

容量估算的核心约束是**流动性最差的持仓**，而非平均水平：

$$ A_{\max} \approx \frac{p \cdot \text{ADV}_{\min} \cdot d}{w_{\text{typ}}} $$

其中 $p$ 是可接受的日均参与率（常见 5%~20%，视流动性与执行能力而定），$d$ 是允许的建仓天数，$w_{\text{typ}}$ 是单只股票的典型权重。

举例（方法演示）：若组合单票典型权重 2%、流动性最差标的的 ADV 为 2000 万元、参与率上限 10%、允许 3 天建仓，则单票可投 $2000万 \times 0.10 \times 3 = 600$ 万元，对应总规模 $600万 / 0.02 = 3$ 亿元。这就是该策略的量级上限。

随着规模增长，冲击成本按 $\sqrt{Q/\text{ADV}}$ 上升，而 alpha 大致不变，因此**存在一个规模最优值**——超过它，边际容量带来的成本超过边际 alpha。

## 二、成交可行性

回测按close价成交，实盘有四类"想交易却交易不了"的情形：

| 情形 | 实盘后果 | 回测中的处理 |
| --- | --- | --- |
| 涨停 | 买单排队，可能完全买不到 | 标记不可买入，顺延或跳过 |
| 跌停 | 卖单排队，止损无法执行 | 标记不可卖出，累积风险 |
| 停牌 | 完全无法交易 | 持仓冻结，权重被动漂移 |
| 熔断/极端行情 | 全市场流动性枯竭 | 需专门的压力测试 |

最危险的是**跌停时的止损失效**：回测里止损把亏损限制在 8%，实盘连续跌停可能亏 30%。这正是实盘尾部风险远大于回测的主因（[绩效指标全家桶](../06-回测/06-04-绩效指标全家桶.md)）。

## 三、延迟

回测假设信号生成后立刻成交。实盘链路包含：行情接收 → 计算 → 下单 → 交易所撮合 → 回报确认。这段延迟在日频策略上影响不大，但对分钟级策略是致命的：若信号基于收盘前 1 分钟的价格，而你的下单延迟 3 秒，成交价可能已经变化。

日频策略虽不受秒级延迟困扰，但仍需注意**数据到达时间**：财报、公告、指数成分调整的实际可得时间常晚于名义时间（[前视偏差的十种来源](../06-回测/06-03-前视偏差的十种来源.md)）。

## 四、资金成本

回测常忽略的成本项：

- **融资利率**：杠杆策略的利息支出；
- **融券成本**：做空策略的券源稀缺性与费率，A 股融券成本显著高于融资；
- **保证金占用**：期货、期权策略的资金效率远低于名义敞口；
- **现金拖累**：未投资部分的无风险收益在回测中常被漏算。

对多空策略而言，**券源不可得**往往比成本更致命：回测里能空的股票，实盘可能根本无券可融。

## 五、市场结构变化

回测隐含假设"未来的市场与历史统计特性相同"。实际会发生：

- **因子拥挤**：随着同类资金涌入，因子溢价被压缩，甚至反向；
- **交易规则变化**：涨跌停幅度、T+0/T+1、印花税、融券规则的调整会直接改变策略可行性；
- **参与者结构变化**：机构占比提升会削弱散户驱动的反转与情绪效应。

这类变化无法通过更好的回测解决，只能通过**持续监控**：跟踪策略的实时 IC、换手、拥挤度，并在指标显著恶化时主动降仓或下线。

## 六、心态与人工干预

这一条无法量化，但往往是实盘亏损的最大来源：

- **回撤期擅自停掉策略**：恰好在策略将要恢复前退出，把"账面回撤"变成"实际亏损"；
- **盈利期擅自加杠杆**：在策略最好的时候放大风险；
- **手动覆盖信号**：凭直觉否决模型的判断，保留了主观偏见却失去了系统一致性。

防御手段是**制度化**：事先书面约定策略的开关条件、最大回撤阈值、干预权限，并严格执行。任何"这次不一样"的判断都应触发复核而非直接操作。

## 七、上线前 checklist

| # | 检查项 | 通过标准 |
| --- | --- | --- |
| 1 | 成本压力测试 | 在 2~3 倍假设成本下策略仍有正收益 |
| 2 | 容量检查 | 目标规模下单票不超过参与率上限 |
| 3 | 极端行情 | 涨停/跌停/停牌/熔断均显式处理 |
| 4 | 成交价假设 | 与实盘下单方式一致（开盘/收盘/VWAP） |
| 5 | 样本外验证 | 滚动前推各段样本外绩效稳定 |
| 6 | 前视偏差 | 通过十项自查清单 |
| 7 | 数据源可靠性 | 有备份源与异常值告警 |
| 8 | 监控指标 | 实时 IC、换手、持仓集中度、偏离基准 |
| 9 | 干预规则 | 书面约定降仓/停牌条件与权限 |
| 10 | 小资金试跑 | 先以 1/10 规模运行 1~3 个月再逐步放大 |

## 八、代码：成本与规模压力测试

```python
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import factor_long_only
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
strategy = factor_long_only(factors=["mom_12_1", "bp"], top_k=10, rebalance=20)

# 成本压力测试：把滑点放大到 3 倍，看策略是否还活着
for mult in (1, 2, 3):
    cfg = BacktestConfig(
        initial_cash=1_000_000,
        commission=0.0003 * mult,      # 视具体交易所/数据源而定
        slippage=0.0005 * mult,
        exec_price="next_open",
        max_participation=0.10,
    )
    res = Backtest(md, strategy, cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"成本倍数={mult}: 年化={rep['annual_return']:.3f} "
          f"Sharpe={rep['sharpe']:.2f} 最大回撤={rep['max_drawdown']:.3f}")
```

## 常见坑

1. **回测通过就上线**：跳过小资金试跑，等于用全部本金去检验回测的可靠性。
2. **用平均流动性估算容量**：组合容量由最差的持仓决定。
3. **忽略券源**：多空策略未确认融券可得性，实盘变成"只多不空"，风险完全改变。
4. **不加成本倍数测试**：只测一组成本参数，无法知道策略对成本的敏感度。
5. **没有监控与下线标准**：策略失效时没有明确的处置流程，靠人工判断必然滞后。
6. **把回测的确定性当承诺**：回测给出的是历史统计规律，不是未来收益保证。
