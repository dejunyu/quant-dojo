# 样本内外与滚动前推

[过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)说明了问题，本篇给出工程解法：**如何切分数据，才能让回测结论对未来有参考价值**。

## 一、为什么随机切分无效

金融数据的两个特性让标准机器学习的做法失效：

1. **时序相关**：相邻交易日的价格高度相关，随机切分会让训练集包含与测试集几乎相同的样本；
2. **重叠标签**：若预测目标是未来 20 日收益，则第 $t$ 与第 $t+1$ 个样本的标签区间重叠 19 天，即使日期不同，标签也几乎相同。

后果：随机 K 折下模型只需"记住"邻近几天的价格就能拿到高分，交叉验证分数虚高，上线即失效。

## 二、三段式切分

最基础的做法是时间顺序切分：

| 段 | 用途 | 典型占比 |
| --- | --- | --- |
| 训练集 | 估计参数、因子权重 | 50%~60% |
| 验证集 | 选择模型/参数 | 20%~25% |
| 测试集（样本外） | 最终一次性评估 | 20%~25% |

关键纪律：

- **只能按时间顺序切**，不能随机；
- **测试集只能用一次**：一旦用它调参，它就变成了验证集，不再提供无偏估计；
- **训练与验证之间留 embargo**：若标签是未来 $h$ 日收益，训练集的最后 $h$ 个样本的标签会延伸到验证期，必须删除。

$$ \text{Train} = [t_0, t_1 - h],\quad \text{Test} = [t_1, t_2] $$

## 三、净化 K 折（purged k-fold）

当数据量不足以留出独立测试集时，用 K 折更充分，但必须做两件事：

**Purge（净化）**：删除训练集中标签区间与测试期重叠的样本。具体地，若测试期起点为 $T_s$，标签持有期为 $h$，则训练集中所有 $t > T_s - h$ 的样本都要删除。

**Embargo（禁运）**：在测试期之后额外屏蔽一小段训练样本（通常为 $h$ 的量级），防止测试期末端的信息通过序列相关（如波动率聚集）回渗到训练期。

$$ \text{Train}_k = [t_0,\ T_s - h] \cup [T_e + \text{embargo},\ t_n] $$

漏掉 embargo 是一个常见疏漏：净化只处理了标签重叠，而序列相关（尤其是波动率、成交量的持续性）仍会造成泄漏。

## 四、滚动前推（walk-forward）

滚动前推模拟的是真实的策略研发过程：站在历史的每一个时点，只用当时可得的数据选参数，再在下一段上检验。

流程：

```
for i in range(n_splits):
    用 [t0, t_i]          训练，选参数 θ_i
    用 [t_i, t_{i+1}]     检验，记录样本外绩效
```

两种实现：

- **滚动窗口（rolling）**：训练窗口长度固定，起点与终点同时前移，能自适应市场状态变化，但训练样本数固定；
- **扩展窗口（expanding）**：起点固定、终点前移，训练样本越来越多，参数更稳定，但对状态变化反应慢。

一般建议训练窗口**至少覆盖一个完整市场周期**（A 股约 3~5 年），否则训练期可能全在牛市，选出的参数在熊市失效。

滚动前推的输出应当看**各段样本外绩效的分布**，而不是平均值：若 5 段中有 1 段贡献了全部收益、其余 4 段亏损，说明策略不稳定；若 5 段 Sharpe 都在 0.3~0.6 之间，虽不惊艳但可信度更高。

## 五、代码：walk-forward 与 purged k-fold

```python
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.optimize import walk_forward, purged_kfold, grid_search
from qd.metrics.perf import sharpe

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission=0.0003, slippage=0.0005)

# 1) 简单三段切分
train = md.slice("2018-01-01", "2021-12-31")
valid = md.slice("2022-01-01", "2022-12-31")
test = md.slice("2023-01-01", "2024-12-31")

best = grid_search(train, sma_cross,
                   {"fast": [5, 10, 20, 30], "slow": [60, 120, 180]},
                   metric="sharpe")
print("训练期最优参数:", best["params"])

for name, seg in [("验证", valid), ("测试", test)]:
    res = Backtest(seg, sma_cross(**best["params"]), cfg).run()
    print(f"{name}期 Sharpe:", sharpe(res.equity, rf=0.02))

# 2) 滚动前推：5 段，训练窗口 3 年、检验窗口 6 个月
wf = walk_forward(
    md, sma_cross,
    {"fast": [5, 10, 20, 30], "slow": [60, 120, 180]},
    n_splits=5, train_window=756, test_window=126, metric="sharpe",
)
print("各段样本外 Sharpe:", [round(s, 3) for s in wf["scores"]])
print("各段选中参数:", wf["params"])

# 3) 净化 K 折（机器学习模型必须用它，而非随机 K 折）
folds = purged_kfold(md, n_splits=5, embargo=20)
print("折数:", len(folds))
```

## 六、结果怎么解读

| 观察 | 判断 |
| --- | --- |
| 样本内远好于样本外 | 过拟合，需减少参数或加正则 |
| 各段样本外绩效方差极大 | 策略不稳定，对市场状态敏感 |
| 样本外系统性低于样本内，但仍为正 | 正常，关键是稳定性 |
| 滚动前推各段参数频繁跳变 | 参数不可识别，应改用固定/等权方案 |
| 样本外收益集中在某一两段 | 偶然性大，需延长样本 |

一条务实经验：**接受样本外比样本内差**。它是常态而非异常。真正该警惕的是差距过大（如样本内 Sharpe 2.5、样本外 0.2），以及样本外绩效的不稳定。

## 常见坑

1. **测试集反复使用**：看了样本外结果又回去调参，样本外估计失效。
2. **忘记 embargo**：只做 purge 不做 embargo，序列相关仍会造成泄漏。
3. **训练窗口过短**：训练期全在单一市场状态，参数无法泛化。
4. **窗口切分与调仓频率冲突**：测试段起点恰好在调仓日之间，会产生不等长的持有期。
5. **只报平均样本外绩效**：应同时报告各段分布与最差段。
6. **用全部历史确定股票池**：股票池定义（如"剔除 ST"）若用当前状态回看历史，属于[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)。
