# 过拟合与多重检验

回测里最危险的事情不是 bug，而是**一个没有 bug 却依然无效的策略**。它通过了所有检查、在历史上表现完美，然后上线就亏钱。本篇解释这是为什么，以及怎么用统计工具把"运气"量化出来。

## 一、为什么参数搜索必然过拟合

假设你在纯随机数据上测试一个策略的 $N$ 组参数。这些参数的真实 Sharpe 都是 0，但**样本内估计的 Sharpe 是随机变量**，围绕 0 波动。取 $N$ 组参数的最大值，你得到的是 $N$ 个随机变量的最大值，它必然大于 0。

对于近似正态的估计量，最大值的期望有一个经典上界：

$$ \mathbb{E}\big[\max_{1\le k \le N} \widehat{SR}_k\big] \approx \sigma_{SR}\Big(\sqrt{2\ln N} + \frac{\gamma}{\sqrt{2\ln N}}\Big) $$

其中 $\sigma_{SR}$ 是 Sharpe 估计量的标准差，$\gamma\approx 0.5772$ 是欧拉常数。主导项是 $\sqrt{2\ln N}$——**试验次数每翻 100 倍，最高 Sharpe 大约增加 $\sigma_{SR}\times 3$**。

举例：若 $\sigma_{SR} \approx 0.5$（几年日频数据的典型量级），试 1000 组参数，即使策略完全无效，你也能期望看到 $\approx 0.5 \times \sqrt{2\ln 1000} \approx 1.86$ 的"最优"Sharpe。这就是**选择偏差（selection bias）**，也叫多重检验问题。

它解释了三个常见现象：

1. 参数扫描出的最优参数往往是个"孤峰"（23/57 表现好，22/57 和 24/57 就崩了）；
2. 策略越复杂、可调参数越多，样本内越漂亮、样本外越差；
3. 多人独立研究同一个策略时，第一个发表的结果往往最好——因为它是多次尝试的最大值。

## 二、Sharpe 估计量的误差

Sharpe 不是精确测量的量，它有标准误。对 iid 正态收益：

$$ \mathrm{SE}(\widehat{SR}) \approx \sqrt{\frac{1 + SR^2/2}{n}} $$

其中 $n$ 是观测数（不是天数对应的年数，而是独立收益观测数）。若收益有自相关或厚尾，标准误更大。

这意味着：**同样是 Sharpe = 1.0**，20 年数据上是高度显著的，2 年数据上则可能与 0 无显著差异。

## 三、Probabilistic Sharpe Ratio（PSR）

PSR 回答的问题是："给定观测到的 $\widehat{SR}$ 与样本量，**真实 SR 超过某个阈值 $SR^*$ 的概率**是多少？"

$$ \mathrm{PSR}(SR^*) = \Phi\left[\frac{(\widehat{SR} - SR^*)\sqrt{n-1}}{\sqrt{1 - \hat\gamma_3 \widehat{SR} + \frac{\hat\gamma_4 - 1}{4}\widehat{SR}^2}}\right] $$

其中 $\hat\gamma_3$ 是偏度、$\hat\gamma_4$ 是峰度，$\Phi$ 是标准正态 CDF。分母修正了非正态性：**负偏、厚尾的收益分布会降低 PSR**，这正是卖尾部风险策略会被 PSR 识破的原因。

用法：取 $SR^* = 0$ 检验"是否真的赚钱"；取 $SR^* = 0.5$ 或 1.0 检验"是否达到可投资标准"。通常要求 $\mathrm{PSR} > 0.95$ 才认为证据充分。

## 四、Deflated Sharpe Ratio（DSR）

PSR 只修正了样本量与分布形状，没有修正"你试了多少次"。DSR 补上了这一点：它先算出在 $N$ 次独立试验下**纯粹由运气产生的 Sharpe 期望** $\widehat{SR}_0$，再检验观测 Sharpe 是否显著超过它。

$$ \widehat{SR}_0 = \sigma_{SR}\Big((1-\gamma)Z^{-1}\big(1 - \tfrac{1}{N}\big) + \gamma\, Z^{-1}\big(1 - \tfrac{1}{Ne}\big)\Big) $$

$$ \mathrm{DSR} = \mathrm{PSR}(\widehat{SR}_0) $$

即：把"运气基准"当作阈值代入 PSR。若 $\mathrm{DSR} < 0.95$，则观测到的 Sharpe 完全可以由多次试验的运气解释。

关键难点是 **$N$ 的诚实计数**：它不是你最后留下的参数组数，而是你在整个研究过程中**试过的所有变体**——包括被放弃的因子、被换掉的窗口、被删掉的过滤条件。诚实估计时 $N$ 常常是几百甚至上千，这会让 DSR 大幅下降。这也是为什么 DSR 在实践中"不受欢迎"：它经常给出否定的答案，而那个答案是对的。

## 五、白噪声实验：量化你自己的运气基准

最直观的方法是**在你自己的搜索流程上跑随机数据**：

```python
import numpy as np
import pandas as pd
from qd.data import MarketData
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.metrics.perf import sharpe, probabilistic_sharpe, deflated_sharpe
from qd.optimize import grid_search

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

# 1) 真实数据上的网格搜索
best_real = grid_search(
    md, sma_cross, {"fast": range(5, 61, 5), "slow": range(20, 241, 20)},
    metric="sharpe",
)
print("真实数据最优:", best_real["params"], "Sharpe=", best_real["score"])

# 2) 白噪声对照：把收益率随机打乱，破坏任何真实结构
rng = np.random.default_rng(0)
close = md.close()
ret = close.pct_change()
shuffled = pd.DataFrame(
    rng.normal(0, float(ret.stack().std()), size=ret.shape),
    index=ret.index, columns=ret.columns,
)
fake_close = (1 + shuffled.fillna(0)).cumprod()
md_noise = MarketData.from_dataframes({"close": fake_close})

best_noise = grid_search(
    md_noise, sma_cross, {"fast": range(5, 61, 5), "slow": range(20, 241, 20)},
    metric="sharpe",
)
print("白噪声最优:", best_noise["params"], "Sharpe=", best_noise["score"])

# 3) 统计修正：N 必须诚实计数（含所有被放弃的变体）
grid = {"fast": list(range(5, 61, 5)), "slow": list(range(20, 241, 20))}
n_trials = len(grid["fast"]) * len(grid["slow"])

eq = Backtest(md, sma_cross(**best_real["params"]),
              BacktestConfig(initial_cash=1_000_000)).run().equity
print("PSR(SR*>0):", probabilistic_sharpe(eq, sr_benchmark=0.0, rf=0.02))
print(f"DSR(N={n_trials}):", deflated_sharpe(eq, n_trials=n_trials, rf=0.02))
```

**白噪声最优 Sharpe 就是你的运气基准**：若真实数据的最优值只比它高一点点，说明你的搜索流程几乎什么都没找到。这个实验比任何理论论证都有说服力，而且实现成本极低。

## 六、防御清单

| 手段 | 作用 | 局限 |
| --- | --- | --- |
| 减少参数 | 降低 $N$ | 不总能做到 |
| 参数平台区而非峰值 | 避免孤峰 | 需额外扫描 |
| [样本内外切分](../06-回测/06-06-样本内外与滚动前推.md) | 最直接的验证 | 只能用一次，用完即失效 |
| 滚动前推（walk-forward） | 多次模拟真实过程 | 计算成本高 |
| PSR / DSR | 统计修正 | 依赖 $N$ 的诚实估计 |
| 白噪声实验 | 直观给出运气基准 | 只是基准，不是证明 |
| 经济逻辑先验 | 减少无效搜索 | 主观 |

最重要的原则是：**样本外数据只能用一次**。反复用样本外调参，样本外就变成了样本内。

## 常见坑

1. **低估试验次数 $N$**：只算最终参数的组合数，漏掉被放弃的因子与过滤条件，DSR 被高估。
2. **样本外反复调参**：每次"看一眼"样本外就调整，等价于把样本外信息泄漏进样本内。
3. **用 Sharpe 最高点做决策**：应选择参数平台区的中心。
4. **忽略分布形状**：负偏策略的标准 PSR 会高估，必须用含偏度峰度的版本。
5. **把 DSR 当证明**：DSR 高只说明"不太像运气"，不等于"未来会有效"。
6. **样本量 $n$ 用错**：用天数而非独立观测数，重叠持有期会高估 $n$。
