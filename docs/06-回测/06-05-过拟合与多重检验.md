# 过拟合与多重检验

## 学完这一篇，你能做到

- 说清为什么"调参数调出好夏普"**几乎必然是假的**
- 理解 PSR 与 DSR 在修什么，以及为什么 DSR 把"努力"变成惩罚
- 会做**白噪声实验**：给自己的搜索流程测一次"运气基准"
- 建立一份防御清单，知道什么情况下不能相信回测

## 本篇要点

- 夏普比率是**随机变量**，不是一个确定的"成绩"
- 试 N 次挑最好的 = 主动制造选择偏差；**N 越大，门槛越高**
- **DSR 把试验次数折进公式**：试得越多，同一个夏普越不值钱
- 白噪声实验是成本最低、说服力最强的自检

---

## 一、从"试得越多，门槛越高"说起

2012 年，**David Bailey** 与 **Marcos López de Prado** 在《风险杂志》发表《夏普比率有效前沿》，提出 **PSR（Probabilistic Sharpe Ratio，概率化夏普）**：夏普比率不是一个确定值，而是一个**统计量**，它有标准误、有置信区间。所以正确的问题不是"我的夏普是多少"，而是"**我的夏普显著大于 0 的概率有多大**"。（*Journal of Risk* 15(2): 3–44）

两年后，他们在《组合管理杂志》发表《折减夏普比率》（*The Deflated Sharpe Ratio*，*JPM* 40(5): 94–107，2014），提出了一个更狠的问题：

> **"如果你试了 N 次，那最好的那次夏普，天生就带选择偏差——你怎么修正它？"**

答案是一个让人很不舒服的方向：

> **把"你试了多少次"直接放进公式，变成一个惩罚项。**
> **试得越多，同一个夏普就越不值钱。**

（同一年，Bailey、Borwein、López de Prado、Zhu 还在《美国数学学会通报》发表《伪数学与金融江湖骗术》，用的正是这个逻辑——01-03 从"这是骗术"的角度讲过，这一篇从"怎么修"的角度讲。）

> 这条思路彻底反转了一个直觉。
> 我们习惯认为"多试几次总能找到好的"——
> **在统计上，多试几次总能找到"看起来好"的，而且这是数学必然。**
> 所以 DSR 真正惩罚的不是"你不努力"，而是"**你不诚实**"。

---

## 二、为什么参数搜索必然过拟合（讲透）

设你要在 **144 组**参数里挑夏普最高的那一个。

**关键问题**：就算这些参数**全都是纯噪声**（真实夏普都是 0），会不会也有一组"看起来不错"？

> **会，而且几乎一定有。**
> 因为每一组的回测夏普都是一个**带噪声的估计**，
> 144 个估计里，总有几个因为运气好而偏高。
> **你挑的正是偏得最厉害的那个。**

这就是**多重检验**（multiple testing）问题，用 05-10 那个式子最直观：

$$E[\text{假阳性个数}] \approx N \times \alpha$$

$N$ 是你试的次数，$\alpha$ 是单次误判率。**144 组 × 5% ≈ 7 个"显著"结果**——而它们全是噪声。

> 所以"我在 144 组里找到了一组夏普 0.55 的"这句话，**本身不构成任何证据**。
> 它和"我抛了 144 次硬币，找到了连续 5 次正面"是同一类陈述。

## 三、PSR 与 DSR：两级递进（逐个讲透）

| | 回答的问题 | 出处 |
| --- | --- | --- |
| **PSR** | 夏普 > 基准的**概率**是多少？ | Bailey & LdP，*J. Risk* 15(2), 2012 |
| **DSR** | **在试过 N 次之后**，夏普 > 该门槛的概率是多少？ | Bailey & LdP，*JPM* 40(5), 2014 |

**PSR 的核心**（概念式，不必背细节）：

$$\mathrm{PSR} = \Phi\!\left(\frac{(\hat{SR} - SR^*)\sqrt{T-1}}{\sqrt{1 - \gamma_3 \hat{SR} + \frac{\gamma_4-1}{4}\hat{SR}^2}}\right)$$

逐个拆（知道每一项在管什么就够）：

| 符号 | 白话 |
| --- | --- |
| $\hat{SR}$ | 你算出来的夏普 |
| $SR^*$ | 要对比的门槛（如 0） |
| $T$ | 样本长度（期数） |
| $\gamma_3,\ \gamma_4$ | **偏度、峰度**——修正非正态（04-02 讲过厚尾！） |
| $\Phi$ | 标准正态累积分布 |

> **注意分母里那两项**：PSR 没有天真地假设"夏普的标准误 = $1/\sqrt{T}$"，
> 而是用偏度峰度做了修正。**这直接接上了 04-02**：
> 金融收益厚尾、负偏，所以夏普的误差比正态假设下更大，**显著性更难拿到**。

**DSR 在 PSR 之上多做了两件事**：

1. 用 $N$ 次独立试验下**最大夏普的期望值**作为门槛 $SR^*$（而不是 0）；
2. 再套用 PSR 的修正。

> **所以 DSR 的读法很朴素：**
> **"扣掉'我试了 N 次只为了挑最好的'这件事之后，还剩下多少真本事？"**
> 取值 0~1，**接近 0 表示这点收益完全可以由"试得多"解释掉**。

## 四、白噪声实验：给自己的流程测"运气基准"（最重要的一节）

理论上讲一万句，不如亲手做一次。方法极其简单：

> **把收益率随机打乱**（破坏所有真实结构），**用同一套搜索流程**再跑一遍，
> 看它能"找到"多好的夏普。**那个数字，就是你的运气基准。**

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import numpy as np
import pandas as pd
from qd.data import MarketData
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.metrics.perf import probabilistic_sharpe, deflated_sharpe
from qd.optimize import grid_search

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
grid = {"fast": list(range(5, 61, 5)), "slow": list(range(20, 241, 20))}
n_trials = len(grid["fast"]) * len(grid["slow"])

# 1) 真实数据上的网格搜索
best_real = grid_search(md, sma_cross, grid, metric="sharpe", verbose=False)
print("真实数据最优:", best_real["params"], "Sharpe=", round(best_real["score"], 4))

# 2) 白噪声对照：收益率随机打乱，破坏真实结构
rng = np.random.default_rng(0)
ret = md.close().pct_change()
shuffled = pd.DataFrame(
    rng.normal(0, float(ret.stack().std()), size=ret.shape),
    index=ret.index, columns=ret.columns,
)
fake_close = (1 + shuffled.fillna(0)).cumprod()
md_noise = MarketData.from_dataframes({"close": fake_close})
best_noise = grid_search(md_noise, sma_cross, grid, metric="sharpe", verbose=False)
print("白噪声最优 Sharpe:", best_noise["score"])

# 3) 把 N 诚实计入
eq = Backtest(md, sma_cross(**best_real["params"]),
              BacktestConfig(initial_cash=1_000_000)).run().equity
print("试验次数 N =", n_trials)
print("PSR(SR*>0):", round(probabilistic_sharpe(eq, sr_benchmark=0.0, rf=0.02), 4))
print("DSR(N=%d):" % n_trials, deflated_sharpe(eq, n_trials=n_trials, rf=0.02))
```

我实跑的结果：

```
真实数据最优: {'fast': 30, 'slow': 160} Sharpe= 0.5474
白噪声最优 Sharpe: nan
试验次数 N = 144
PSR(SR*>0): 1.0
DSR(N=144): 1.0356e-139
```

**三个数字，三种心情：**

1. **PSR = 1.0**：看起来完美——"夏普显著大于 0 的概率是 100%"。
2. **DSR = 1.04e-139**：几乎为零。
3. **白噪声最优 = nan**：随机数据上根本搜不出像样的结果。

> **PSR 1.0 与 DSR ≈ 0 的落差，就是这一篇的全部意义。**
> 同一个策略、同一条净值曲线：
> **只问"夏普显著吗"，答案是漂亮的 100%；
> 把"你试了 144 次"算进去，答案是"这基本等于没有"。**
>
> **而这两句话描述的是同一件事**——区别只在于：你愿不愿意承认自己试了 144 次。

> ⚠️ 白噪声那行出现 `nan`，是因为随机数据生成的价格序列可能不满足回测的成交前提（或某些参数组合无有效成交）。**这不影响结论**——它反而更清楚：
> 真实数据上那个 0.5474 **不是随便造点数据就能复现的**，但也**没有强到能扛住 144 次搜索的折扣**。

## 五、防御清单（抄下来）

| 手段 | 具体做法 |
| --- | --- |
| **记录 N** | 每次试验都记，包括放弃的变体（01-03 研究日志） |
| **提前写证伪条件** | 看到结果前就定"什么算输"（01-03） |
| **减少自由参数** | 参数越少，N 越小，过拟合空间越小 |
| **做白噪声实验** | 给自己的流程测运气基准（本篇） |
| **样本外验证** | 滚动前推，别用普通 K 折（06-06） |
| **报告 DSR 而非只报夏普** | 让读者看到你已经折过价 |
| **成本压力测试** | 2~3 倍成本（06-07） |

> **其中最便宜、最容易被跳过的是"记录 N"。**
> 因为它不需要任何技术，只需要一点诚实的习惯——
> 而在这一行，**诚实恰好是最稀缺的技术**。

---

## 六、把这一篇串起来

回到 DSR 那个反直觉的设计：**试得越多，门槛越高。**

它其实在说一件更大的事。整个 06 章讲的是"如何诚实地评估"：
06-02 的成交假设、06-03 的前视偏差、06-06 的样本外，都在防"你的数字太好看了"。
而这一篇指出了最根深蒂固的那一个：**你并不是被骗，你是自己想看到好消息。**

> 这跟 01-03 西蒙斯"停机重构"、02-04 的时间旅行测试、05-10 的因子动物园，
> 是同一条线的不同站点：
> **这个行业最贵的错误，几乎都是"把没验证的东西当成确定的事"，而且往往是自愿的。**

> 一句话收尾：
> **过拟合不是技术缺陷，是一种心理倾向——它让你爱上自己的结果。**
> 而 DSR 的全部作用，就是把这份爱打个折，看看还剩多少。
