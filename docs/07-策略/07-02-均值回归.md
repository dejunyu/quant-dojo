# 均值回归

均值回归是与[趋势跟踪](../07-策略/07-01-趋势跟踪.md)镜像的策略：它假设价格偏离均衡后会被拉回，因此**跌了买、涨了卖**。它的收益分布与趋势策略恰好相反——胜率高、盈亏比低、负偏。

## 一、为什么价格会均值回归

三条机制：

1. **流动性冲击**：大额被动卖出会把价格压低，但这是暂时的流动性折价，做市商与套利者会把价格拉回（Grossman & Miller 的做市商理论）。
2. **过度反应**：投资者对新闻的短期反应过度，之后随着信息消化而修正。
3. **微观结构噪声**：买卖价差跳动造成的 bid-ask bounce，在高频尺度上形成短期反转。

注意机制 1、2 都是**暂时性**的偏离。如果价格变动反映的是**基本面的永久性变化**，均值回归就会失效——这正是策略的核心风险。

## 二、OU 过程与半衰期

用 Ornstein-Uhlenbeck 过程刻画均值回归：

$$ dx_t = \theta(\mu - x_t)\,dt + \sigma\,dW_t $$

其中 $\theta > 0$ 是回归速度，$\mu$ 是长期均值，$\sigma$ 是波动率。离散化后可写成 AR(1) 形式：

$$ x_t - x_{t-1} = a + b\,x_{t-1} + \varepsilon_t $$

由回归系数可推出连续时间参数：

$$ \theta = -\frac{\ln(1 + b)}{\Delta t},\qquad h_{1/2} = \frac{\ln 2}{\theta} $$

**半衰期 $h_{1/2}$** 是偏离被消化一半所需的期望时间，它是均值回归策略最重要的参数：

- 决定持仓周期：持仓时间应大致等于半衰期，太短赚不到回归，太长则承受基本面漂移风险；
- 决定止损：若价格偏离后超过 2~3 个半衰期仍未回归，应怀疑均衡已改变。

经验上，$b < 0$（即 $\theta > 0$）是均值回归存在的必要条件，可用 ADF 检验判断其显著性（[配对交易与统计套利](../07-策略/07-05-配对交易与统计套利.md)中会详述协整检验）。

## 三、两类经典信号

### 布林带

$$ z_t = \frac{P_t - \mathrm{MA}_t(n)}{\sigma_t(n)} $$

当 $z_t < -k$ 时买入（价格显著低于均线），当 $z_t > k$ 时卖出，回到均线附近平仓。常用 $n = 20$、$k = 2$。

布林带的缺陷是 $\sigma$ 用简单标准差估计，对厚尾与波动聚集反应滞后。改进方式是改用 ATR 或 GARCH 估计的条件波动率。

### RSI2

用 2 日 RSI：

$$ \mathrm{RSI} = 100 - \frac{100}{1 + \frac{\overline{\text{上涨幅度}}}{\overline{\text{下跌幅度}}}} $$

RSI2 < 10 买入、> 90 卖出，且通常要求价格处于 200 日均线之上（只在大趋势向上时做回调买入）。这个过滤条件很关键：**它把"均值回归"限定在"上升趋势中的回调"，避开了下跌趋势中的接飞刀**。

## 四、收益分布特征

| 维度 | 趋势跟踪 | 均值回归 |
| --- | --- | --- |
| 胜率 | 30%~40% | 60%~75% |
| 盈亏比 | 高（>2） | 低（<1） |
| 收益偏度 | 正偏 | 负偏 |
| 主要风险 | 长期震荡 | 单次巨亏 |
| 容量 | 大 | 小（需逆向接盘） |

均值回归策略的"高胜率"很容易让人误以为风险低，实际上它是**卖保险**：大多数时候小赚，偶尔一次大亏（负偏）。因此必须用止损、分散与仓位上限来控制尾部。

## 五、价值陷阱：核心风险

均值回归最大的风险不是波动，而是**"便宜的东西可以更便宜"**——价格下跌若源于基本面的永久性恶化（业绩暴雷、行业衰退、财务造假），价格不会回归，只会一路向下。

识别与应对：

1. **基本面过滤**：只在盈利、现金流、行业地位未恶化的标的上做回归；
2. **止损而非扛单**：设定最大持有期（如 2 个半衰期）与最大亏损，到点无条件离场；
3. **分散**：单标的上限权重，避免一次暴雷打穿组合；
4. **监控回归速度**：滚动估计的 $\theta$ 若持续下降，说明回归机制正在消失，应降仓；
5. **警惕极端偏离**：偏离越大越可能是基本面变化而非噪声，超过 3~4 倍标准差应视为"结构性变化"而非"回归机会"。

## 六、代码：布林带回归与参数对比

```python
import numpy as np
import pandas as pd
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import bollinger_reversion
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report, max_drawdown

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission=0.0003, slippage=0.0005)

# 1) 布林带参数对比：n_std 越小信号越多、换手越高
for n_std in (1.5, 2.0, 2.5):
    res = Backtest(md, bollinger_reversion(window=20, n_std=n_std), cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"n_std={n_std}: 年化={rep['annual_return']:.3f} "
          f"Sharpe={rep['sharpe']:.2f} 最大回撤={max_drawdown(res.equity):.3f}")

# 2) 手工估计 OU 半衰期（以某只股票相对自身均线的偏离为例）
close = md.close()
sym = md.symbols[0]
dev = close[sym] - close[sym].rolling(60).mean()
lag = dev.shift(1)
df = pd.DataFrame({"y": dev.diff(), "x": lag}).dropna()
b = np.polyfit(df["x"], df["y"], 1)[0]
theta = -np.log(1 + b)
print(f"回归系数 b={b:.4f}  theta={theta:.4f}  半衰期={np.log(2)/theta:.1f} 个交易日")
```

半衰期的滚动估计是很好的监控指标：若某段时期 $b$ 由负转正（$\theta < 0$），说明序列已变成趋势/发散过程，均值回归策略应当停用。

## 常见坑

1. **不加趋势过滤**：在下跌趋势中做回调买入，是"接飞刀"的典型形式。
2. **把低估值当均值回归信号**：估值低不等于价格会回归，可能只是基本面恶化。
3. **扛单不止损**：均值回归策略亏大钱的唯一方式就是不止损。
4. **用全样本估计 $\mu$ 与 $\theta$**：均衡水平会漂移，必须用滚动窗口，否则是[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)。
5. **忽略交易成本**：均值回归换手高，成本敏感度远高于趋势策略。
6. **容量估计过于乐观**：逆向接盘意味着你提供流动性，规模一大就会自己把价格推走。
