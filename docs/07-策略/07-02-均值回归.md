# 均值回归

## 学完这一篇，你能做到

- 说清"均值回归"这个词是谁、在什么场合下第一次说出来的
- 用 OU 过程刻画均值回归，并**亲手估一次半衰期**
- 实现布林带信号，理解"跌破下轨才买"里的门槛在管什么
- 说出这个策略最致命的风险（价值陷阱），以及怎么防

## 本篇要点

- 均值回归赚的是**流动性冲击 + 过度反应**后的回弹
- **半衰期**（$h=\ln 2/\theta$）决定持仓周期，回归变慢是失效的早期信号
- 收益分布**负偏**：胜率高、盈亏比低、尾部很危险（与趋势策略恰好相反）
- 最怕"**接下落的刀**"——基本面真恶化时，回归永远不来

## 一、从一个"把高个子儿子拉回平均"说起

1886 年，**弗朗西斯·高尔顿**（Francis Galton）向《英国及爱尔兰人类学研究所杂志》提交了一篇论文，标题直译过来是**《遗传身高向平庸的回归》**（*Regression towards Mediocrity in Hereditary Stature*）。

他测量了约 205 对父母（他称之为"中亲"）所生的**逾 900 名**成年子女的身高，发现了一个奇怪的现象：

> **高个子父母的子女，平均而言仍然高，但比父母矮一些；**
> **矮个子父母的子女，平均而言仍然矮，但比父母高一些。**

换句话说，**极端值会向中间靠拢**。他算出的比例大约是 **2/3**——子代偏离父代的程度，只有父代偏离平均值的三分之二。

"回归"（regression）这个词，就是从这来的。它**最初是个生物学/统计学的词，跟股票毫无关系**。有意思的是，高尔顿更早（1877 年）是先拿**甜豌豆种子**做的实验，之后才用人类身高验证。（[原文全文](https://www.york.ac.uk/depts/maths/histstat/galton_reg.htm)、[Wikipedia: Regression toward the mean](https://en.wikipedia.org/wiki/Regression_toward_the_mean)）

> ⚠️ 引用时注意：原文摘要说"930 名"子女，但同篇表格与图注写"928 名"。**写"逾 900 名"最稳妥**。

> **这个来历特别值得记住，因为它提醒你：**
> **"回归"是一个统计现象，不是一个交易信号。**
>
> 高尔顿说的是"**在没有任何外力的情况下，极端值天然会向均值靠拢**"。
> 而市场里，价格之所以会回归，需要一个**具体机制**：
> 流动性冲击退去、过度反应被修正、套利者把价差磨平。
>
> **如果没有这个机制，价格不会"自己回来"——它会一直待在你不敢想的地方。**
> 这就是本篇后半段要讲的"价值陷阱"。

> 1985 年，**De Bondt 与 Thaler** 发表《股票市场反应过度了吗？》（*Journal of Finance* 40(3): 793–805，1985 年 7 月），把"过度反应后回归"变成了一个可检验的市场假说——这也成了"反转因子"的理论起点（05 章见过这条线）。

## 二、用 OU 过程描述回归（逐个讲透）

描述均值回归最常用的模型是 **OU 过程**（Ornstein-Uhlenbeck）：

$$ dx_t = \theta(\mu - x_t)\,dt + \sigma\, dW_t $$

| 符号 | 白话 |
| --- | --- |
| $x_t$ | 当前的偏离量（比如价格减均线） |
| $\mu$ | 它长期会回到的那个中心 |
| $\theta$ | **回归速度**：越大，回得越快 |
| $\sigma$ | 随机扰动的强度 |
| $dW_t$ | 布朗运动的微小增量（噪声） |

**关键在 $\theta(\mu - x_t)$ 这一项**：$x_t$ 离 $\mu$ 越远，这一项越大，往回拉的力越强。**就像一根橡皮筋。**

由此推出最有用的一个量——**半衰期**：

$$ h = \frac{\ln 2}{\theta} $$

| 符号 | 白话 |
| --- | --- |
| $\ln 2 \approx 0.693$ | 常数：要走完"一半距离"需要的相对量 |
| $\theta$ | 回归速度 |
| $h$ | **偏离量衰减到一半，需要多少个交易日** |

> **半衰期是整个均值回归策略的"心跳频率"：**
> 半衰期 5 天，你就该五六天一个周期；**半衰期 60 天，你却天天调仓，就是白交手续费**（03-04、05-07）。
>
> 更重要的是：**回归速度变慢，往往是策略失效的第一个信号**。
> 如果半衰期从 10 天变成 40 天，说明"橡皮筋松了"——不是因为市场变了，而是那个让你赚钱的机制正在消失。

## 三、两类经典信号

| 信号 | 怎么算 | 逻辑 |
| --- | --- | --- |
| **布林带** | $z = (P_t - \text{MA}_{20})/\sigma_{20}$，跌破 $-n$ 倍标准差买入 | 偏离太远就该弹回来 |
| **RSI2** | 2 日相对强弱极低时买入 | 极短期超卖 |

布林带那个式子里，$z$ 就是"**当前价偏离均线几个标准差**"。而 $n$ **就是阈值**：

> **$n$ 越大 → 门槛越高 → 交易越少 → 越保守。**
> 这个直觉听起来像废话，但**它恰恰是我在写这一篇时发现的一个真 bug 的判据**（见下一节）。

## 四、一个"参数不生效"的真 bug（值得所有人看一眼）

我实跑这篇课文代码时，发现了一件怪事：`n_std` 从 1.5 调到 2.5，**三个结果一模一样**。

继续挖，发现引擎里 `bollinger_reversion` 的实现是这样的：

```text
z = (arr[i] - ma) / sd          # 算了偏离度
return long_top_weights(-z, top_k)   # 只按 z 排序取前 top_k
```

**`n_std` 算了却没用上**——它只影响"叫法"，不影响任何成交。

> **为什么这个 bug 比"参数调错"更危险？**
> 因为你去扫参数，会得到**一排完全相同的数字**。
> 而人的第一反应不是"参数没生效"，而是"**市场对这个参数不敏感**"——
> 于是你写下了一条错误的结论，还觉得很有道理。
>
> **参数不生效，是"安静地骗你"；参数调错，是"吵着让你发现"。**

修复后的实现加了一行门槛：**只有 $z < -n\_std$ 的标的才进候选池**。修完再跑，立刻显出差别。

## 五、用平台跑一次（修复后的真实数字）

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
import pandas as pd
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import bollinger_reversion
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report, max_drawdown

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003, slippage_bp=5.0)

# 1) n_std 越大，门槛越高，成交越少
for n_std in (1.5, 2.0, 2.5):
    res = Backtest(md, bollinger_reversion(window=20, n_std=n_std), cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"n_std={n_std}: 年化={rep['annual_return']:.3f} "
          f"Sharpe={rep['sharpe']:.2f} 回撤={max_drawdown(res.equity):.3f} "
          f"成交={len(res.trades)}")

# 2) 手工估 OU 半衰期
close = md.close()
sym = md.symbols[0]
dev = close[sym] - close[sym].rolling(60).mean()
df = pd.DataFrame({"y": dev.diff(), "x": dev.shift(1)}).dropna()
b = np.polyfit(df["x"], df["y"], 1)[0]
theta = -np.log(1 + b)
print(f"b={b:.4f} theta={theta:.4f} 半衰期={np.log(2)/theta:.1f} 个交易日")
```

我实跑的结果：

```
n_std=1.5: 年化=-0.552 Sharpe=-4.12 回撤=-0.997 成交=4815
n_std=2.0: 年化=-0.517 Sharpe=-3.82 回撤=-0.995 成交=2850
n_std=2.5: 年化=-0.317 Sharpe=-2.77 回撤=-0.939 成交=599
b=-0.0664 theta=0.0687 半衰期=10.1 个交易日
```

**两个读点：**

**第一，门槛确实在起作用。** 从 1.5 → 2.5，成交从 **4815 笔** 降到 **599 笔**，回撤从 -99.7% 收窄到 -93.9%。**"只买跌破下轨的"比"买最超卖的十个"更保守**——这正是 $n$ 该有的效果。

**第二，半衰期 10.1 个交易日。** 这只股票的偏离量大约两周消散一半。**所以它的合理调仓周期就是周到两周**——比这更频繁是浪费手续费，比这更慢则错过回归。

> ⚠️ 但请注意：**这三个 n_std 全都是亏的，而且回撤接近 -94% 以上。**
> 这意味着在**这份合成数据**上，布林带均值回归是个灾难级策略
> （合成数据里埋的是弱动量 + 短期反转，20 日尺度的均值回归并不被奖励）。
>
> **重点不是"这个策略好不好"，而是：**
> **你现在能通过 n_std 这个旋钮，把"保守程度"调到可见的差别了。**
> 在此之前，那个旋钮是坏的——而你可能永远以为它是对的。

## 六、最致命的风险：价值陷阱（单独讲透）

均值回归有一个所有量化人都听过的绰号——**"接下落的刀"**。

| 情况 | 价格为什么跌 | 会不会回归 |
| --- | --- | --- |
| 流动性冲击、情绪过度反应 | 有人急着卖，与基本面无关 | ✅ **会**，这是你赚钱的地方 |
| 基本面真实恶化 | 公司确实不行了 | ❌ **不会**，你会一路亏到底 |

> **区分这两种情况，是整个策略生死所在。**
> 而麻烦在于：**事后来看它们天差地别，事前看起来几乎一样**——
> 都是一根往下走的曲线。

三条防线：

1. **基本面过滤**：财务、公告、行业景气度明显恶化的，直接排除；
2. **强制止损**：不设止损的均值回归，迟早遇到一个不回来的（03-01 提过跌停卖不出的问题）；
3. **限制单票权重**：因为负偏分布意味着"少数几次巨亏"会吃掉全部利润。

> 补个术语：**价值陷阱（value trap）** 原本指"看起来便宜的股票其实有基本面问题"，
> 在均值回归语境里泛指"**你以为是偏离，其实是趋势**"。
> 它跟 01-04 讲的"均值回归遇到基本面真实恶化"是同一条。

## 七、把这一篇串起来

回到高尔顿 1886 年那批身高数据。

他发现的是一个**统计规律**：极端值天然向中间靠。但他从没说过"你可以靠这个赚钱"——因为**身高回归靠的是遗传机制，价格回归靠的是市场机制**，而后者**可能不在**。

> 这就是均值回归和趋势跟踪（07-01）的镜像关系：
> **趋势策略赌"机制还在延续"，均值回归赌"机制马上回来"。**
> 两者的收益分布恰好相反：趋势是低胜率高盈亏比，均值回归是高胜率低盈亏比。
> **这也意味着：均值回归的亏损会很集中、很难看（负偏）。**

> 一句话收尾：
> **均值回归的敌人不是波动，是"这次真的不一样"。**
> 而你没发在事前分辨它——**所以你唯一能做的，是让"错了"这件事变得便宜**（止损、限权、过滤）。
