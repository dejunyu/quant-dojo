# 配对交易与统计套利

配对交易是[均值回归](../07-策略/07-02-均值回归.md)思想在**两个资产**上的应用：找到一对走势长期相关的资产，当它们的价差偏离历史均衡时做多低估的一方、做空高估的一方，等待回归。

## 一、相关 ≠ 协整

这是配对交易最基础、也最常被搞错的一点：

| 概念 | 定义 | 价差性质 |
| --- | --- | --- |
| 相关 | 收益率同向变动的程度 | 价格可以任意发散（两条平行上升的线，相关性高但价差发散） |
| 协整 | 价格序列的某个线性组合是平稳的 | 价差均值回归，不发散 |

**高相关但非协整**是危险的：两个都长期上涨的资产收益率高度相关，但价差持续扩大，做空强势方会一直亏。

## 二、协整检验（Engle-Granger 两步法）

**第一步**：对价格序列做回归，得到对冲比率 $\beta$ 与价差：

$$ P^A_t = \alpha + \beta P^B_t + \varepsilon_t,\qquad s_t = P^A_t - \beta P^B_t $$

实践中常用对数价格：$\ln P^A_t = \alpha + \beta \ln P^B_t + \varepsilon_t$，此时 $\beta$ 是弹性，对价格尺度不敏感。

**第二步**：对残差序列 $s_t$ 做 ADF（Augmented Dickey-Fuller）检验，检验回归式

$$ \Delta s_t = a + b s_{t-1} + \sum_{j=1}^{p} c_j \Delta s_{t-j} + \varepsilon_t $$

若 $b$ 显著为负（ADF 统计量小于临界值），则拒绝"存在单位根"的原假设，认为 $s_t$ 平稳，即 $P^A$ 与 $P^B$ 协整。

检验的注意事项：

- 临界值与标准的 ADF 临界值**不同**（因为 $\beta$ 是估计出来的），Engle-Granger 有其专用临界值表；
- 若无法确认二者中谁是因变量，应双向检验取更显著者；
- 小样本下 ADF 检验功效很低，容易接受错误的原假设。

## 三、从价差到交易信号

把价差标准化为 z-score：

$$ z_t = \frac{s_t - \mathrm{MA}(s_t, n)}{\sigma(s_t, n)} $$

经典开平仓规则：

| 条件 | 动作 |
| --- | --- |
| $z_t < -z_{\text{entry}}$ | 价差过低 → 做多 A、做空 B |
| $z_t > +z_{\text{entry}}$ | 价差过高 → 做空 A、做多 B |
| $\vert z_t \vert < z_{\text{exit}}$ | 回归均衡 → 平仓 |
| $\vert z_t \vert > z_{\text{stop}}$ | 疑似结构性破裂 → 强制止损 |

常用参数：$n = 60$，$z_{\text{entry}} = 2$，$z_{\text{exit}} = 0.5$，$z_{\text{stop}} = 3.5\sim4$。

**仓位应按波动率缩放**（[波动率目标](../07-策略/07-06-波动率目标与风险平价.md)），因为价差的波动率本身时变：高波动期若维持名义仓位，风险敞口会成倍放大。

## 四、止损为什么必须硬

配对交易的收益分布是典型的**负偏**：大多数交易小赚，少数交易巨亏。巨亏来自"协整关系破裂"——两个资产的基本面关系发生了永久性变化（如一方被并购、一方业务转型）。

因此止损是必须的，且应是**无条件执行**的硬止损。三条并用的风控：

1. **z-score 止损**：$|z| > z_{\text{stop}}$ 立即平仓；
2. **时间止损**：持有超过 2~3 个半衰期仍未回归即平仓（半衰期估计见[均值回归](../07-策略/07-02-均值回归.md)）；
3. **单对损失上限**：单笔亏损不超过组合的固定比例。

## 五、协整不稳定的问题

这是配对交易最根本的困难：**历史协整不保证未来协整**。成因包括：

- 基本面关系变化（一方业务结构改变、行业逻辑变化）；
- 监管、技术、竞争格局的结构性变化；
- 市场微观结构改变（一方流动性下降）。

检测方法：

1. **滚动协整检验**：每期用过去 $n$ 天重做 Engle-Granger，统计"显著月份占比"；占比低于 50% 说明关系脆弱；
2. **监控半衰期**：滚动估计的半衰期若持续上升，说明回归变慢，关系正在瓦解；
3. **价差的方差漂移**：$\sigma(s)$ 持续上升是破裂的前兆；
4. **基本面复核**：定期对配对做基本面检查，确认业务关系依然存在。

应对策略：**多配对分散**。单对配对交易的 Sharpe 可能只有 0.3~0.6，且存在破裂风险；持有 20~50 对低相关配对后，个别破裂的损失被稀释，组合 Sharpe 可显著提升。这也是统计套利（statistical arbitrage）从"配对"走向"篮子"的原因。

## 六、代码：滚动协整与配对回测

```python
import numpy as np
import pandas as pd
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import pairs_trading
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission=0.0003, slippage=0.0005)

# 1) 内置配对策略：不同入场阈值的对比
for entry_z in (1.5, 2.0, 2.5):
    res = Backtest(md, pairs_trading(window=60, entry_z=entry_z, exit_z=0.5), cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"entry_z={entry_z}: 年化={rep['annual_return']:.3f} "
          f"Sharpe={rep['sharpe']:.2f} 交易笔数={len(res.trades)}")

# 2) 手工做滚动协整诊断（ADF 的简化版：看 AR(1) 系数是否显著为负）
close = md.close()
a, b_sym = md.symbols[0], md.symbols[1]
la, lb = np.log(close[a]), np.log(close[b_sym])

half_lives, sig_flags = [], []
for end in range(120, len(close)):
    seg_a, seg_b = la.iloc[end-120:end], lb.iloc[end-120:end]
    beta = np.polyfit(seg_b, seg_a, 1)[0]
    spread = seg_a - beta * seg_b
    ds = spread.diff().dropna()
    sl = spread.shift(1).dropna().reindex(ds.index)
    coef = np.polyfit(sl, ds, 1)[0]
    sig_flags.append(coef < 0)
    if coef < 0:
        half_lives.append(np.log(2) / -np.log(1 + coef))

print("滚动协整显著比例:", np.mean(sig_flags))
print("半衰期中位数(日):", np.median(half_lives) if half_lives else None)
```

若"显著比例"低于半数，说明这对资产的均衡关系时断时续，策略应降低仓位或直接放弃。

## 常见坑

1. **用相关系数选配对**：高相关不等于协整，这是配对交易最大的选股错误。
2. **用固定 $\beta$**：对冲比率会漂移，应滚动估计，全样本 $\beta$ 是前视偏差。
3. **忽略做空成本与券源**：配对交易一半的腿是做空，融券不可得时策略无法执行。
4. **不止损**：协整破裂时价差会持续扩大，单次亏损可以吞掉数年收益。
5. **样本内选最优配对**：在全部股票对中挑历史上表现最好的几对，是严重的多重检验问题（[过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)）。
6. **单对重仓**：应当分散到多对，且控制单对风险预算。
