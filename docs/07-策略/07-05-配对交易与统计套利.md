# 配对交易与统计套利

## 学完这一篇，你能做到

- 分清"相关"和"协整"，知道为什么前者不能直接拿来做配对
- 说清统计套利的原始形态，以及它和"两只股票价差回归"的区别
- 理解为什么配对交易的止损必须硬
- 用平台跑配对回测，并做一次滚动协整诊断

## 本篇要点

- **相关 ≠ 协整**：两个东西一起动，不代表价差会回来
- 配对交易的生死线是**协整关系是否还成立**
- 统计套利的本质是"**同一个东西被标了两个价**"
- 协整会**永久破裂**，所以必须持续监控 + 硬止损

---

## 一、从"同一家公司，两个价格"说起

1969 年 11 月，一个叫**爱德华·索普**（Edward Thorp）的数学教授，在加州长滩和合伙人 Jay Regan 创立了一只叫 **Convertible Hedge Associates（可转债对冲）** 的基金。

**他后来自称这是第一只"市场中性"对冲基金。** 1974 年，它改名为 **Princeton/Newport Partners（PNP）**。

（01-01 讲过索普在赌场用 IBM 704 算牌的故事，那是他的前半生；这里是他把同一套思维搬进华尔街的部分。）

索普做的**不是**"找两只走势像的股票去赌价差"，而是更本质的东西：

> **同一家公司，它的股票和它的可转债，本质上是同一种东西的两种"包装"。**
> 如果可转债便宜了、股票贵了，那就买入便宜的那个、卖空贵的那个——
> **你不需要预测公司好坏，你只需要赌"两种包装迟早会对齐"。**

（据《华尔街日报》2008 年的回顾报道，PNP 在二十多年里实现了费后年化约 20%，且没有一个亏损季度。这个数字**来自二手转述，引用时请带上"据《华尔街日报》报道"**。）

**故事的结局很有戏剧性**：1980 年代末，PNP 被卷入 Milken / Drexel 垃圾债案，依 RICO 被起诉；**1991 年 6 月，上诉法院推翻了定罪**，索普等人被证明清白——但诉讼负担已迫使基金清盘。（[1991-06-29 LA Times 报道](https://www.latimes.com/archives/la-xpm-1991-06-29-fi-1259-story.html)、[Princeton Newport Partners 条目](https://en.wikipedia.org/wiki/Princeton_Newport_Partners)）

> **这个故事给本篇最重要的一个启示，藏在它的定义里：**
> **统计套利的第一步，不是"找规律"，是"确认这两个东西真的是同一个东西"。**
>
> 可转债和股票，是真的同一家公司的两种索取权——这才让"价差必收敛"有了依据。
> 而如果你只是"看图形觉得它们很像"，那你手里**没有任何经济学理由**，
> 只有一个统计巧合。**巧合是会破的。**

> 补个区分：01-06 讲过的配对交易起源（摩根士丹利 1980 年代的量化小组）是**另一条线**，
> 那条线更偏"统计上的配对"；索普这条更早，且更偏"**同一资产的不同形式**"。
> 两条线到今天都还在用。

## 二、相关 ≠ 协整（本篇最重要的一节）

这是配对交易里最容易搞错、也最致命的一点。

| | 相关（correlation） | 协整（cointegration） |
| --- | --- | --- |
| 问的问题 | **它们是不是一起动？** | **它们的差会不会回来？** |
| 数学上 | 收益率的线性相关 | 价差的线性组合是**平稳**的 |
| 会不会失效 | 会，但价差可能一直扩大 | **会永久破裂** |
| 能不能交易 | ❌ 不能直接交易 | ✅ 才有交易基础 |

**一个能记住的反例**：两只股票都在稳定上涨（比如每年都涨 10%），它们的**收益率高度相关**，但它们的**价差会一路扩大**——因为涨的绝对值不同。**你按价差做空，会一直亏。**

> **所以"相关"只告诉你"它们同向"，"协整"才告诉你"它们的距离会回来"。**
> 前者是必要条件，后者才是交易依据。

补个常识：**平稳（stationary）** 是时间序列里的一个性质，粗略理解就是"均值不变、波动幅度不随时间漂移"。**协整的定义就是：两个不平稳的序列，存在某个线性组合是平稳的。**

## 三、协整检验： Engle-Granger 两步法

最常用的做法只有两步：

1. **回归**：用 $A$ 对 $B$ 回归，得到对冲比例 $\beta$：

$$ A_t = \alpha + \beta B_t + \varepsilon_t $$

2. **检验残差**：看 $\varepsilon_t$（也就是价差）是不是平稳的。
   实操中常用一个简化判据：**看 $\varepsilon_t$ 的 AR(1) 系数是否显著为负**（负得越多，回归越快）。

| 符号 | 白话 |
| --- | --- |
| $A_t$、$B_t$ | 两只（对数）价格 |
| $\beta$ | **对冲比例**：1 份 A 对应多少份 B |
| $\varepsilon_t$ | **价差**：扣掉 B 的影响后，A 还剩多少 |
| 残差平稳 | 价差会回到均值 → **可以交易** |

**从价差到信号**，就是熟悉的 z-score：

$$ z_t = \frac{\varepsilon_t - \mu_\varepsilon}{\sigma_\varepsilon} $$

$z$ 就是"当前价差偏离历史均值几个标准差"。`entry_z=2.0` 意思是"**偏离到 2 个标准差才动手**"。

> 这和 07-02 的布林带是同一个数学结构，只是对象从"价格 vs 均线"换成了"价差 vs 均值"。
> **所以 07-02 那个"接下落的刀"的风险，在这里以"协整破裂"的形式重演。**

## 四、为什么止损必须硬（单独讲透）

07-02 说过均值回归要"强制止损"。配对交易里，这条要求**更硬**。

| 情况 | 价差为什么扩大 | 会回来吗 |
| --- | --- | --- |
| 流动性冲击、短期错价 | 有人急着成交 | ✅ 会 |
| **协整关系破裂** | 两家公司基本面永久分化 | ❌ **不会，永远** |

> **关键区别在于：均值回归赌的是"价格会回到均线"，而配对交易赌的是"两个资产的关系还在"。**
> 前者是价格问题，后者是**结构问题**。
>
> 一家公司被收购、退市、爆出造假、行业逻辑变了——
> 你和它配对的那只股票**从此和它没有关系了**。
> 而你的模型还在一遍遍告诉你"价差已经 4 个标准差，应该加仓"。

> 所以配对交易的止损不是"防波动"，是**"防关系断裂"**。
> 这也是 01-04 里 LTCM 的教训之一：**它们赌的"价差会收敛"，是一个关于世界结构的假设**，
> 而结构可以被事件打断（01-04 讲过这个故事的细节）。

## 五、用平台跑一次配对回测

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import pairs_trading
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003, slippage_bp=5.0)

# 1) 不同入场阈值
for entry_z in (1.5, 2.0, 2.5):
    res = Backtest(md, pairs_trading(window=60, entry_z=entry_z, exit_z=0.5), cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"entry_z={entry_z}: 年化={rep['annual_return']:.3f} "
          f"Sharpe={rep['sharpe']:.2f} 交易={len(res.trades)}")

# 2) 滚动协整诊断：看这对资产的"关系"稳不稳
close = md.close()
a, b_sym = md.symbols[0], md.symbols[1]
la, lb = np.log(close[a]), np.log(close[b_sym])

half_lives, sig_flags = [], []
for end in range(120, len(close)):
    seg_a, seg_b = la.iloc[end-120:end], lb.iloc[end-120:end]
    beta = np.polyfit(seg_b, seg_a, 1)[0]
    spread = seg_a - beta * seg_b
    ds = spread.diff().dropna()
    sl = spread.shift(1).dropna().reindex(ds.index)
    coef = np.polyfit(sl, ds, 1)[0]
    sig_flags.append(coef < 0)
    if coef < 0:
        half_lives.append(np.log(2) / -np.log(1 + coef))

print("滚动协整显著比例:", round(float(np.mean(sig_flags)), 4))
print("半衰期中位数(日):", round(float(np.median(half_lives)), 2))
```

我实跑的结果：

```
entry_z=1.5: 年化=-0.119 Sharpe=-1.32 交易=348
entry_z=2.0: 年化=-0.080 Sharpe=-1.42 交易=197
entry_z=2.5: 年化=-0.045 Sharpe=-1.83 交易=70

滚动协整显著比例: 0.9971
半衰期中位数(日): 4.11
```

**两个读点：**

**第一，门槛越高，交易越少、但夏普没变好。** 从 `entry_z=1.5` 到 `2.5`，交易从 348 笔降到 70 笔，年化亏损收窄（-11.9% → -4.5%），但**夏普反而变差**（-1.32 → -1.83）。这说明：**交易少不代表风险调整后更好**，你可能只是"少做了几笔同样差的交易"。

**第二，滚动协整显著比例 0.9971** —— 接近 100% 的时间，这对资产的"关系"在统计上都成立。**但策略仍然亏钱。**

> **这又是一个"技术指标很好看、但不赚钱"的例子。**
> 协整成立（价差统计上会回归），不等于**扣完成本后还能赚**（03-04、05-07）。
> 半衰期 **4.11 个交易日**意味着你大约每 4 天就要换一次仓——
> **这么高的换手，成本几乎必然吃掉全部价差收益。**

> ⚠️ 另外提醒：**合成数据里的"股票"之间本来就没有真实的经济关系**，
> 所以这里的协整 0.9971 更接近于"随机序列偶然表现出的平稳性"。
> **真实配对交易必须建立在"这两个东西真的是同一个东西"的基础上**（索普那句话）。

## 六、把这一篇串起来

回到索普那句"同一家公司的两种包装"。

它把统计套利从"图形有点像"提升到了"结构上必然"。而这个转变，正是这一篇全部方法论的根：

> **先有经济学理由（它们为什么应该一样），再有统计检验（它们现在是不是还一样），最后才是交易信号（差多少该动手）。**
> 顺序反了，你就只是在拟合历史巧合。

> 而它的失败模式也特别清晰：
> **不是价差没回来，是"关系"没了。**
> 均值回归（07-02）怕"基本面真恶化"，配对交易怕"关联真断裂"——
> **两者都怕同一件事：你以为是波动，其实是结构变了。**

> 一句话收尾：
> **配对交易赚的是"两种包装对齐"的钱，亏的是"两个世界分开"的钱。**
> 而你只能在事后，才确定自己遇到的是哪一种。
