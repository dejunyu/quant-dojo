# 波动率目标与风险平价

前面几篇解决的是"买什么"，本篇解决"买多少"。仓位管理是量化策略中**最容易被低估、却对风险调整后收益影响最大**的一环。

## 一、波动率目标（vol targeting）

原理极其简单：让组合始终维持一个恒定的目标波动率。在第 $t$ 期，用历史数据估计组合波动率 $\hat\sigma_t$，然后设定杠杆：

$$ L_t = \frac{\sigma_{\text{target}}}{\hat\sigma_t} $$

实际持仓则为 $L_t \times$ 策略原始信号。若当前波动率是目标的两倍，则仓位减半；若波动率只有目标的一半，则加杠杆到两倍。

实现细节：

1. **估计窗口**：常用 20~60 日，或指数加权（EWMA）以更快反应：

$$ \hat\sigma^2_t = (1-\lambda)\sum_{k} \lambda^{k-1} r_{t-k}^2 $$

RiskMetrics 常用 $\lambda = 0.94$。EWMA 比等权窗口对近期变化更敏感。

2. **杠杆上限**：必须设上限（如 2~3 倍），否则低波动期会给出荒谬的高杠杆。A 股融资受限，实际杠杆上限受合规约束。
3. **调整频率与缓冲**：每期都调会导致频繁换仓，实务中常设"死区"（只在杠杆偏离超过某比例时才调整）。

## 二、为什么它改善 Sharpe

关键是**波动率聚集**：金融资产的波动率具有显著的持续性（今天波动大，明天大概率还是大）。这意味着波动率在一定程度上是**可预测的**，于是可以做"波动率择时"——在高波动期降低敞口、低波动期提高敞口。

效果是双向的：

- **降低回撤**：极端回撤往往发生在波动率飙升期，此时仓位已经自动降低；
- **提高资金效率**：低波动期不必浪费风险预算。

实证上，波动率目标通常能在**几乎不降低年化收益**的前提下显著降低最大回撤与波动率，从而提升 Sharpe 与 Calmar（[绩效指标全家桶](../06-回测/06-04-绩效指标全家桶.md)）。对[趋势跟踪](../07-策略/07-01-趋势跟踪.md)、[配对交易](../07-策略/07-05-配对交易与统计套利.md)这类收益受波动率驱动的策略，改善尤为明显。

## 三、风险平价（risk parity）

传统 60/40 组合看似分散，实际上**风险高度集中于股票**：股票波动率远高于债券，90% 以上的组合风险来自股票端。风险平价的目标是让每个资产贡献相等的风险。

定义资产 $i$ 的**风险贡献**：

$$ RC_i = w_i \cdot \frac{(\Sigma w)_i}{\sigma_p},\qquad \sigma_p = \sqrt{w^\top \Sigma w} $$

风险贡献满足 $\sum_i RC_i = \sigma_p$。风险平价要求

$$ RC_i = \frac{\sigma_p}{n},\quad \forall i $$

即每个资产贡献 $1/n$ 的总风险。求解没有闭式解（除非只有两类资产），通常用数值优化：

$$ \min_w \sum_{i=1}^n \Big(RC_i - \frac{\sigma_p}{n}\Big)^2 \quad \text{s.t.} \quad w_i \ge 0,\ \sum_i w_i = 1 $$

两资产情形下的经典结果：若两资产不相关，风险平价权重与波动率成反比

$$ \frac{w_1}{w_2} = \frac{\sigma_2}{\sigma_1} $$

**等风险贡献（ERC）**是风险平价在相关情形下的推广，同样要求 $RC_i$ 相等，但允许资产间有相关性。

## 四、风险平价的实际效果与代价

| 优点 | 代价 |
| --- | --- |
| 真正分散风险，而非分散资金 | 低波动资产（债券）需加杠杆才能达到目标风险 |
| 回撤显著低于传统股债组合 | 依赖杠杆与融资成本，利率上升时受损 |
| 不依赖收益预测，只需协方差 | 对协方差估计敏感 |
| 长期 Sharpe 通常优于市值加权 | 在单一资产长期牛市中跑输（如债券牛市中的股债组合） |

风险平价最著名的实践是桥水的"全天候"策略。它在 2008 年等系统性危机中表现稳健，但在持续的低波动 + 单边牛市环境中会跑输简单的股票多头。

## 五、共同局限

两类方法都建立在"用历史波动率预测未来风险"之上，因此有共同的软肋：

1. **波动率估计滞后**：历史窗口的估计无法预测突发事件。2008、2020 年的波动率跳升是在几天内发生的，等 EWMA 反应过来，损失已经造成。
2. **低波动滋生高杠杆**：长期低波动会给出极高的目标杠杆，恰恰在风险最被低估时敞口最大（"波动率悖论"）。
3. **相关性在危机中趋同**：风险平价依赖分散化，但危机中资产相关性趋向 1，分散失效。
4. **相关性上升本身就是风险信号**：应监控组合的平均相关性，在相关性快速上升时主动降仓。

缓解手段：结合**前瞻性风险指标**（信用利差、波动率期货期限结构、流动性指标）而非纯历史波动率；设置杠杆硬上限；在相关性突破阈值时强制降仓。

## 六、代码：波动率目标与风险平价

```python
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import vol_target, risk_parity, dual_momentum
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report, max_drawdown, sharpe

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission=0.0003, slippage=0.0005)

# 1) 波动率目标：不同目标波动率下的表现
for tv in (0.08, 0.12, 0.20):
    res = Backtest(md, vol_target(target_vol=tv, lookback=60), cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"目标波动={tv:.0%}: 年化={rep['annual_return']:.3f} "
          f"Sharpe={rep['sharpe']:.2f} 最大回撤={max_drawdown(res.equity):.3f}")

# 2) 风险平价 vs 等权：对比风险调整后收益
for name, strat in [("risk_parity", risk_parity(lookback=120)),
                    ("dual_momentum", dual_momentum(lookback=120, top_k=5))]:
    res = Backtest(md, strat, cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"{name}: 年化={rep['annual_return']:.3f} Sharpe={sharpe(res.equity, rf=0.02):.2f} "
          f"最大回撤={max_drawdown(res.equity):.3f}")
```

对比时应当重点看 **Sharpe 与最大回撤**，而非年化收益——波动率目标通常会降低名义收益（因为高波动期仓位低），但换来的是更好的风险调整表现。

## 常见坑

1. **不加杠杆上限**：低波动期给出 5 倍杠杆，一次跳空就爆仓。
2. **估计窗口过长**：250 日窗口反应太慢，等于没做择时；20 日又容易被单日异常值带偏。
3. **忽略融资成本**：杠杆不是免费的，融资利率会侵蚀低波动期的加杠杆收益。
4. **风险平价假设相关性稳定**：危机中相关性趋同，分散失效，需监控。
5. **把风险平价当收益策略**：它优化的是风险分配，不是收益；单资产牛市中必然跑输。
6. **用全样本协方差**：$\Sigma$ 必须滚动估计，用全样本属于[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)。
