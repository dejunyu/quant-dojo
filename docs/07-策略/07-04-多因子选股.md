# 多因子选股

前面几篇分别解决了[因子构造](../05-因子/05-02-因子构造.md)、[检验](../05-因子/05-05-单因子检验IC与ICIR.md)、[合成](../05-因子/05-09-因子合成.md)。本篇把它们组装成一个可运行的策略：**多因子选股**，并延伸到指数增强产品的实践。

## 一、完整流程

```
1. 选股域（universe）    —— 哪些股票可买
2. 因子计算与预处理      —— 去极值、中性化、标准化
3. 因子合成              —— 得到一个综合打分
4. 打分排序与选股        —— 取前 N 只
5. 组合优化              —— 确定权重，加约束
6. 交易执行与再平衡      —— 换手控制、成本
7. 归因与监控            —— 收益来自哪里
```

每一环都会显著影响最终结果。实务中，**选股域与组合优化对结果的影响常常不亚于因子本身**。

## 二、选股域

选股域定义了"可交易范围"，常见过滤条件：

| 过滤项 | 目的 | 典型阈值 |
| --- | --- | --- |
| 剔除 ST / *ST | 规避退市与异常波动风险 | 必须剔除 |
| 上市天数 | 剔除次新股的异常换手 | > 60~180 日 |
| 停牌 | 不可交易 | 当期剔除 |
| 市值下限 | 保证容量 | 视策略规模而定 |
| 流动性下限 | 保证可成交 | ADV > 目标持仓 |
| 涨跌停 | 无法成交 | 调仓日剔除 |

选股域必须**逐期动态**确定：用当前是否 ST 去过滤 2015 年的数据，属于典型的[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)。

## 三、从打分到权重

合成后的因子打分只给出排序，权重还需要单独确定。四种常见方式：

1. **等权**：最简单、最稳健，适合股票数量较多时（30 只以上）。
2. **打分加权**：$w_i \propto \max(z_i, 0)$，打分越高权重越大，但会集中于少数高分股。
3. **市值加权**：$w_i \propto \text{MktCap}_i$，容量大、接近基准，但削弱了因子暴露。
4. **组合优化**：求解带约束的最优权重：

$$ \max_w\ w^\top \alpha - \frac{\lambda}{2} w^\top \Sigma w - \gamma \cdot \text{Cost}(w - w_0) $$

三项分别是预期收益（由因子打分给出）、风险惩罚（协方差 $\Sigma$）与换手惩罚。$\lambda$ 与 $\gamma$ 控制激进程度。

## 四、约束：行业与市值

绝大多数实盘产品都有约束：

- **行业中性**：$\sum_{i \in k} w_i = \sum_{i \in k} w_i^{\text{bench}}$，即各行业权重与基准一致；
- **市值中性**：组合加权市值与基准相当；
- **个股上限**：$w_i \leq w_{\max}$（常见 3%~10%），防止集中于单票；
- **行业偏离上限**：$|w_k - w_k^{\text{bench}}| \leq \delta$（常见 1%~3%）；
- **换手上限**：单次调仓换手不超过某比例。

这些约束会**降低因子收益**（因为限制了暴露），但换来的是**可预测的风险**。对指增产品而言，这是必须接受的取舍——产品的目标不是最大收益，而是**在给定跟踪误差下的最大超额收益**。

## 五、指数增强实践

指数增强（index enhancement）的运作方式：

1. 以某指数（如沪深 300、中证 500）为基准；
2. 在基准成分内（或成分内为主）用多因子模型选股与加权；
3. 目标是稳定获取年化超额（IR 通常在 1~3 之间，视市场与能力而定）；
4. 风险控制以**跟踪误差（TE）**为核心：

$$ \mathrm{TE} = \sqrt{\frac{252}{n}\sum_t (r_{p,t} - r_{b,t})^2} $$

常见 TE 上限为 3%~8%，视产品合同约定。

关键实务要点：

- **超额收益的稳定性比高低更重要**：年化超额 8% 但年度波动 6% 的产品，实际上会在某些年份跑输；
- **成分股内选股比例**：完全在成分内选股约束最强、超额最低，允许 20%~30% 成分外会显著提高超额但增加风险；
- **行业暴露管理**：即便合同中无约束，主动行业暴露也是超额波动的最大来源；
- **换手与成本**：指增产品换手常在年 3~10 倍，成本控制直接决定净超额。

## 六、归因

三层归因缺一不可：

1. **因子归因**：超额中有多少来自价值、动量、质量等各因子（用因子暴露 × 因子收益计算）；
2. **行业归因**：$\sum_k (w_k - w_k^b) \cdot r_k$，行业配置贡献；
3. **个股归因**：残差部分，即真正的选股 alpha。

若超额全部来自某一年的某个行业押注，那么这个策略实盘上很难持续。

## 七、代码：构建多因子组合

```python
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import factor_long_only, rotation
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission=0.0003, slippage=0.0005)

# 1) 多因子多头选股：月度调仓，每期持有打分最高的 10 只
strategy = factor_long_only(factors=["mom_12_1", "bp", "roe_q"], top_k=10, rebalance=20)
res = Backtest(md, strategy, cfg).run()
rep = perf_report(res.equity, rf=0.02)
print(f"top_k=10: 年化={rep['annual_return']:.3f} Sharpe={rep['sharpe']:.2f} "
      f"最大回撤={rep['max_drawdown']:.3f} 交易笔数={len(res.trades)}")

# 2) 集中度对比：top_k 越小越集中，因子暴露越强但风险越高
for k in (5, 10, 20, 30):
    r = Backtest(md, factor_long_only(factors=["mom_12_1", "bp", "roe_q"],
                                      top_k=k, rebalance=20), cfg).run()
    print(f"top_k={k}: Sharpe={perf_report(r.equity, rf=0.02)['sharpe']:.2f}")

# 3) 调仓频率对比：换手与成本的直接权衡
for reb in (5, 10, 20, 60):
    r = Backtest(md, factor_long_only(factors=["mom_12_1", "bp", "roe_q"],
                                      top_k=10, rebalance=reb), cfg).run()
    print(f"调仓={reb}日: Sharpe={perf_report(r.equity, rf=0.02)['sharpe']:.2f}")
```

## 常见坑

1. **只优化因子不管理组合**：因子再好，若权重集中于 3 只股票、行业偏离 20%，实盘不可接受。
2. **忽略换手成本**：月度调仓 10 只股票的组合，年换手可能超过 5 倍，成本占比显著。
3. **选股域静态化**：用当前成分股、当前 ST 状态回看历史，收益虚高。
4. **协方差矩阵估计误差**：优化器对 $\Sigma$ 极度敏感，样本外常失效，应加约束或用收缩估计。
5. **过度约束导致因子失效**：行业完全中性 + 市值完全中性 + 个股上限 2%，最终组合几乎等于基准，超额趋近于零。
6. **用合成数据调参数**：`generate_demo_market` 只适合验证代码，不适合得出策略结论。
