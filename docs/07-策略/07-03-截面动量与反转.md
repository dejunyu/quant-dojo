# 截面动量与反转

## 学完这一篇，你能做到

- 分清**截面动量**与**时序动量**，知道它们不是一回事
- 说清动量为什么会**崩溃**，以及崩溃在什么条件下可预测
- 理解"波动率调整动量"为什么能降低崩溃幅度
- 用平台对比动量族四个因子，并手造一个调整版

## 本篇要点

- 截面动量比"谁涨得多"，时序动量比"它自己过去涨没涨"
- **动量崩溃**发生在"大跌之后突然反弹"时，做空的高波动输家弹得最猛
- 调整动量（除以波动率）能**削平尾部**，代价是牺牲一点平均收益
- **反转**是动量的反面，A 股的短期反转尤其明显（05 章铺垫过）

---

## 一、从"跌完之后最猛的反弹"说起

2016 年，**Kent Daniel** 与 **Tobias Moskowitz** 在《金融经济学杂志》发表《动量崩溃》（*JFE* 122(2): 221–247）。

他们研究了动量策略最惨的一种处境，结论非常反直觉：

> **动量最危险的时刻，不是市场大跌的时候，而是"大跌之后突然反弹"的时候。**

机制是这样的（NBER 摘要原话）：崩溃发生在市场处于 **"panic"（恐慌）状态**——大跌之后、波动率高涨之时，并且**与市场反弹同时发生**。原因是：**过去那些输家（高波动的垃圾股）带有类似期权的收益特征，在恐慌状态下，市场要求极高的溢价才肯持有它们**。一旦恐慌退去、市场反弹，这批股票弹得最猛——而你的动量策略**正好做空了它们**。

（工作论文见 [NBER w20439](https://www.nber.org/papers/w20439)。2009 年那次是史上最剧烈的动量崩溃之一——**具体幅度不同来源口径不一，别写死数字**。）

> **这个发现的价值在于：它把"因子会失效"变成了"因子在特定条件下会失效"。**
> 05-07 讲过 McLean & Pontiff 的"发表后衰减 58%"，那是一种**慢性的**衰减；
> 而动量崩溃是一种**急性的、可事前估计的**尾部风险。
>
> **换句话说：动量不是"永远有效"，也不是"随机失效"，
> 而是在"高波动 + 刚反弹"这个特定路口，特别容易出事。**

> 这也是 04-02 讲过的负偏/厚尾在因子层面的具体体现：
> **动量策略的净值曲线，往往是一条缓慢爬升、然后突然断崖的线。**

## 二、截面动量 vs 时序动量（先分清）

| | 截面动量（cross-sectional） | 时序动量（time-series） |
| --- | --- | --- |
| 比什么 | **同一天里，谁涨得多** | **它自己过去涨没涨** |
| 输出 | 排序 → 买前 20%、卖后 20% | 方向 → 做多或空仓 |
| 典型 | `mom_12_1`、`rev_20` | CTA 趋势、`dual_momentum` |
| 需要多少标的 | 越多越好 | **1 个就够**（单合约也能做） |

> 05-01 给过一个判据：**"如果股票池只剩 1 只，这个因子还算得出来吗？"**
> 能 → 时序；不能 → 截面。**动量这两类都有，别混。**

本篇主要讲**截面**这一支（因为它的崩溃机制被研究得最透），但两者的直觉是相通的。

---

## 三、12-1 动量：为什么跳过最近一个月

05-02 讲过这个细节，这里补完整：

用 t-12 到 t-1 的收益算动量，**故意跳过最近一个月**。因为：

- **最近一个月住着短期反转**（过度反应后的回吐）；
- 如果把最近一个月算进去，它含的**反转噪声会把中期动量信号对冲掉**。

> 所以 12-1 动量不是"随便切个窗口"，而是**在构造阶段就承认了"短期会反转"这件事**。
> 这也解释了：**动量和反转不是两个策略，是同一个现象的两种时间尺度。**
> 短期（周/月）反转，中期（3~12 月）动量，长期（3~5 年）又反转（De Bondt & Thaler 1985）。

---

## 四、波动率调整：把尾部的刀磨钝

最直接的改进：**不要比"过去涨了多少"，而是比"过去涨了多少 ÷ 它自己的波动"**。

$$ \text{mom\_adj} = \frac{\text{过去 12 个月的收益}}{\text{同期年化波动率}} $$

| 符号 | 白话 |
| --- | --- |
| 分子 | 涨了多少 |
| 分母 | **一路上抖得多厉害** |
| 整个比值 | **"每单位波动换来的涨幅"**——类似夏普的想法 |

> **为什么它有用？** 因为它天然地**压制了高波动股票**。
> 而动量崩溃的元凶，正是"高波动的输家突然反弹"。
> **你把高波动股票的权重降下来，尾部就钝了。**

代价也很清楚：**平均收益会略降**（因为高波动股票在平时涨得也猛）。这就是典型的"**用收益换尾部**"。

## 五、用平台对比动量族

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import winsorize, zscore
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

# 1) 动量族横向对比
for name in ("mom_12_1", "mom_6_1", "rev_20", "rev_5"):
    print(f"{name}: IC={lab.mean_ic(name, horizon=20):.4f} "
          f"年化换手={lab.turnover(name)['annual_turnover']:.1f}x")

# 2) 手工构造波动率调整动量
close, ret = md.close(), md.returns()
mom = close.shift(21) / close.shift(252) - 1          # 12-1 动量
vol = ret.rolling(252).std().shift(21) * np.sqrt(252)
mom_adj = mom / vol.clip(lower=0.05)                  # sigma 设下限，避免除零

# 3) 对比调整前后
for label, panel in [("mom_raw", mom), ("mom_adj", mom_adj)]:
    lab.register(label, zscore(winsorize(panel, limits=0.01)))
    ic = lab.mean_ic(label, horizon=20)
    ls = lab.quantile_backtest(label, n_quantiles=5)["long_short"]
    print(f"{label}: IC={ic:+.4f} 多空夏普={ls['sharpe']:+.2f} "
          f"多空回撤={ls['max_drawdown']:.2%}")
```

我实跑的结果：

```
mom_12_1: IC=0.0287 年化换手=33.5x
mom_6_1:  IC=0.0451 年化换手=44.0x
rev_20:   IC=-0.0476 年化换手=120.0x
rev_5:    IC=0.0022 年化换手=217.2x

mom_raw: IC=+0.0291 多空夏普=+1.14 多空回撤=-8.90%
mom_adj: IC=+0.0313 多空夏普=+1.05 多空回撤=-14.29%
```

**这组数字有两个反直觉，都值得记：**

**第一，`rev_5` 的 IC 几乎为 0，但换手高达 217 倍。** 05-07 的净 IC 公式会告诉你：毛 IC 0.0022 减去 217×成本，**净 IC 是个大负数**。**短线反转在合成数据里根本赚不到钱**，纯粹是给券商打工。

**第二，波动率调整在这里"没帮上忙"**：`mom_adj` 的 IC 略高（0.0313 vs 0.0291），但**多空夏普反而降了**（1.05 vs 1.14），**回撤还扩大了**（-14.29% vs -8.90%）。

> **为什么？因为这份合成数据里根本没发生过"动量崩溃"。**
> 00-01 讲过：合成数据只被埋了弱动量，而**没有人为植入 2009 年那种"恐慌后暴力反弹"的极端场景**。
> 所以"削平尾部"的价值在这里体现不出来——**你付出的代价（牺牲收益）倒是实打实发生了**。
>
> **这恰恰是量化里最难的一课：**
> **一个"理论上更好"的改进，在没遇到它要防的那种灾难时，看起来就是纯粹的损失。**
> 而人性会让你在这个时刻把它砍掉——**然后在下一次灾难里，彻底明白它为什么存在。**

## 六、动量和反转的使用要点

| 要点 | 说明 |
| --- | --- |
| **别混时间尺度** | 短期反转、中期动量、长期反转，用错尺度会互相抵消 |
| **换手是命门** | 反转族换手极高（`rev_5` 217x），净 IC 必为负（05-07） |
| **警惕崩溃** | 大跌后反弹期，动量最容易断崖 |
| **考虑波动率调整** | 用一点平均收益换更薄的尾部 |
| **A 股要本地验证** | 文献里的方向来自美股，A 股不总一致（05-01） |

## 七、把这一篇串起来

回到 Daniel 和 Moskowitz 那个发现。

它之所以重要，是因为它把"因子失效"从一个模糊的担忧，变成了一个**具体的、可事前估计的场景**：**恐慌之后、反弹之时、做空的输家弹得最猛。**

> 而这一篇的整个结构，其实是在说一件更大的事：
> **动量这个"简单到一行代码"的因子，背后有三层时间尺度、一种可预测的崩溃、和一套调整方法。**
> 05 章教你"怎么检验它有效"，
> 这一篇教你"**它会在什么时候突然失效**"——
> **后者比前者更值钱，因为前者你迟早会在回测里看到，后者不会出现在回测里。**

> 一句话收尾：
> **动量赚的是"趋势延续"的钱，亏的是"趋势突然回头"的钱。**
> 而这两件事，往往发生在同一个月里。
