# 截面动量与反转

[趋势跟踪](../07-策略/07-01-趋势跟踪.md)是时间序列上的动量，本篇讨论**横截面动量**：在每个调仓日把所有股票放在一起排序，买入过去涨得最好的一批、卖出涨得最差的一批。同一时间尺度上还存在一个相反的现象——短期反转。两者共同构成了价格类因子最核心的矛盾。

## 一、截面动量 vs 时序动量

| 维度 | 截面动量 | 时序动量 |
| --- | --- | --- |
| 比较对象 | 股票之间横向比 | 资产与自身历史比 |
| 信号 | 排序取前 K 名 | $\mathrm{sign}(P_t - P_{t-n})$ |
| 是否需要多标的 | 是，需横截面 | 否，单品种可做 |
| 是否对冲市场 | 多空组合天然对冲 | 需额外处理仓位 |
| 典型应用 | 股票多因子、指增 | CTA、资产配置 |

截面动量的优势是**自动剔除市场因素**：即使全市场上涨，只要涨的幅度不同，排序依然有意义。

## 二、12-1 动量：为什么跳过最近一个月

标准动量定义：

$$ mom_{12,1} = \frac{P_{t-21}}{P_{t-252}} - 1 $$

即"过去 12 个月的收益，但跳过最近 1 个月"。跳过最近 21 个交易日有两个原因：

1. **短期反转效应**：最近一个月的收益与未来收益常呈负相关（流动性冲击、过度反应），纳入它会稀释动量信号；
2. **微观结构噪声**：买卖价差跳动（bid-ask bounce）会让最近一期的收益率带有负自相关，属于纯噪声而非真实信息。

Jegadeesh & Titman (1993) 的原始设定就采用了跳过最近一周或一月的做法，后来 12-1 成为文献标准。

## 三、市场差异：A 股的短期反转

实证上，不同市场的动量/反转结构差异显著：

- **美股**：12-1 动量长期显著为正，月度反转也显著但换手成本高。
- **A 股**：由于散户交易占比高、波动率高，**短期反转（1 个月）效应往往强于 12-1 动量**；而年度动量在很多样本期内并不显著，甚至为负。

因此直接照搬美股的 12-1 动量到 A 股常常失望。务实做法是**让数据说话**：在同一股票池上同时检验 mom_12_1、mom_6_1、rev_5、rev_20，比较它们的 IC 与[分层回测](../05-因子/05-06-分层回测.md)单调性，再决定用哪个。

另一个重要现象是**行业动量**：剔除行业内个股动量后，剩余部分常常较弱。这意味着个股动量有相当部分其实是行业动量的体现，做行业中性化后的动量 IC 会下降（[中性化](../05-因子/05-04-中性化.md)）。

## 四、动量崩溃

动量策略最危险的时刻不是熊市，而是**熊市结束、牛市开始的拐点**。

机制：熊市中输家（高 beta、垃圾股）跌幅巨大；当市场反转时，这些前期的输家反弹最猛。此时动量组合持有的是"做多前期赢家（防御股）+ 做空前期输家（高 beta 股）"，两个方向同时亏损，造成**极端集中回撤**。历史上动量因子曾在短时间内损失数年累计收益。

减缓手段：

1. **波动率调整**（见下节）——这是最有效的单一手段；
2. **在市场反转信号出现时降低动量暴露**：如市场从下跌趋势转为上涨时；
3. **限制空头端**：只做多头动量（做多赢家、不做空输家），可以规避一部分崩溃风险，代价是失去一半 alpha；
4. **与价值因子组合**：动量崩溃时价值因子往往表现良好，二者负相关，合成后更平稳。

## 五、波动率调整动量

高波动股票在动量排序中占据两端，它们的收益波动极大，主导了组合的风险。波动率调整的定义：

$$ mom^{\text{adj}}_{i,t} = \frac{mom_{i,t}}{\sigma_{i,t}} $$

其中 $\sigma_{i,t}$ 是过去一段时间（常与动量窗口匹配）的已实现波动率。

效果与原理：

- 等价于对每只股票按其波动率缩放暴露，高波动股票的动量值被压缩；
- 组合层面近似于**风险加权**而非等权，显著改善 Sharpe 与最大回撤；
- 对动量崩溃的缓解尤为明显——因为崩溃时输家端正是高波动股票，缩放后其空头权重被压低。

实施细节：$\sigma$ 的估计窗口也应跳过最近一个月（与动量保持一致），且需对 $\sigma$ 设下限（如不低于 5% 年化），否则低波动股票会被无限放大。

## 六、代码：动量族对比与波动率调整

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import winsorize, zscore
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

# 1) 动量族横向对比
for name in ("mom_12_1", "mom_6_1", "rev_20", "rev_5"):
    print(f"{name}: IC={lab.ic(name, horizon=20):.4f} "
          f"年化换手={lab.turnover(name)['annual_turnover']:.1f}x")

# 2) 手工构造波动率调整动量
close = md.close()
ret = md.returns()
mom = close.shift(21) / close.shift(252) - 1        # 12-1 动量
vol = ret.rolling(252).std().shift(21) * np.sqrt(252)
mom_adj = mom / vol.clip(lower=0.05)                # 波动率调整，sigma 设下限

# 3) 对比调整前后：IC、ICIR、多空收益
#    先注册成因子，再用与内置因子完全相同的流程检验
for label, panel in [("mom_raw", mom), ("mom_adj", mom_adj)]:
    lab.register(label, zscore(winsorize(panel, limits=0.01)), description="12-1 动量对比")
    ic = lab.ic(label, horizon=20)
    ls = lab.quantile_backtest(label, n_quantiles=5)["long_short"]
    print(f"{label}: IC={ic.mean():+.4f} ICIR={ic.mean()/ic.std():+.3f} "
          f"多空夏普={ls['sharpe']:+.2f} 多空回撤={ls['max_drawdown']:.2%}")
```

解读要点：波动率调整后 IC 均值未必提高（它改变的是风险而非信息），但**多空组合的 Sharpe 与最大回撤通常明显改善**。因此评价它应看风险调整指标，而非 IC 本身。

## 常见坑

1. **动量窗口含最近一月**：未跳过会导致 IC 显著下降甚至反号。
2. **未剔除涨跌停与停牌**：涨停板的连续一字板会制造"超强动量"，但实盘买不进去。
3. **只做多头端的动量**：多头动量在熊市中同样大幅回撤，需配合市场状态判断。
4. **忽略交易成本**：反转因子换手极高，成本可能吞掉全部毛收益（[因子衰减与换手](../05-因子/05-07-因子衰减与换手.md)）。
5. **把动量崩溃当成随机回撤**：它是结构性的、可预期的（熊市末期），可以主动管理。
6. **波动率调整时用全样本波动率**：必须用滚动估计且跳过相应窗口，否则是前视偏差。
