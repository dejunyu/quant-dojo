# 趋势跟踪

## 学完这一篇，你能做到

- 说清趋势跟踪为什么"胜率低却可能赚钱"
- 认出三大经典构造：均线交叉、通道突破、ATR 止损
- 理解为什么突破策略特别怕滑点，以及"参数平台"比"参数最优点"重要
- 用平台跑趋势回测，并做一次参数敏感性扫描

## 本篇要点

- 趋势跟踪赚的是"**方向持续性 + 被迫平仓**"的钱，收益分布**正偏**
- 胜率通常只有 **30%~40%**，靠盈亏比取胜
- 主要亏损来自**震荡市的反复假突破**
- 判断参数好坏看"**平台**"，不看"最高点"（01-03 的过拟合）

---

## 一、从"教会了规则，然后呢"说起

01-04 讲过那场著名的实验：1983 年底，**理查德·丹尼斯**（Richard Dennis）和搭档埃克哈特打赌"交易能不能教"，招了 21 男 2 女，用两周教了他们一套极简的趋势规则（突破近期区间就买/卖），并给每人一笔真钱去跑。这批人后来被称为"**海龟**"。

**那个故事在 01-04 里讲的是"策略有适用环境"**。这一篇要讲的是它更冷的下半场。

丹尼斯本人，那个号称"场内王子"、从 400 美元本金做到亿万身家的人，**后来在 1987 年黑色星期一亏了约 1000 万美元**，1987–88 两年合计约 5000 万；**1990 年，他因为"没有遵守自己定的规则"以超过 250 万美元和解**。（[Wikipedia: Richard Dennis](https://en.wikipedia.org/wiki/Richard_Dennis)）

> **一个教别人守规则的人，自己栽在了不守规则上。**
> 这件事对趋势跟踪这一族来说，几乎是量身定做的注脚：
> **这一族的规则简单到两周就能教完，但执行它需要的心理强度，二十年也未必练得出来。**

同时补一句 01-04 说过的措辞提醒：**海龟"合计赚了约 1.75 亿美元"是"据报道"，没有审计公开来源**，引用时务必带上"据报道"。

## 二、趋势跟踪赚的是什么钱

核心假设：价格会**延续**。背后的机制大概有三类：

| 机制 | 说的是什么 |
| --- | --- |
| **信息扩散慢** | 坏消息不是一天被所有人消化的，价格会慢慢走 |
| **机构分批建仓** | 大资金买不满，只能分几天/几周买，形成持续买压 |
| **被迫平仓的连锁** | 止损、追保、强平会沿着同一方向推价格（03-06 的轧空是最极端版） |

> **注意这三条都是"别人不得不做某件事"。**
> 趋势跟踪赚的，很大程度上是**"别人被迫在同一方向行动"**的钱。
> 这也是为什么它在**危机**里往往表现特别好：那正是所有人被迫平仓的时候。

### 收益形态：低胜率 + 高盈亏比

$$ \mathbb{E}[\text{pnl}] = p\,W - (1-p)\,L $$

| 符号 | 白话 | 趋势策略的典型值 |
| --- | --- | --- |
| $p$ | 胜率 | **只有 30%~40%** |
| $W$ | 平均赚多少 | 大（少数几波趋势） |
| $L$ | 平均亏多少 | 小（震荡市反复小亏） |

**代入感受一下**：胜率 35%、平均赚 3、平均亏 1：

$$0.35 \times 3 - 0.65 \times 1 = 0.40 > 0$$

> **这就是趋势跟踪"反人性"的地方：它会让你连续亏八次，然后靠第九次赚回来。**
> 而那八次小亏，恰恰是最容易让人放弃、改参数、甚至放弃策略的时刻。
> **01-04 说过：海龟"两周教会"的规则，难的从来不是规则，是连亏时还照着做。**

补个术语：收益分布**正偏**（右偏）——大部分时候小亏，少数时候大赚。这和 07-02 均值回归的**负偏**恰好相反（04-02 讲偏度时见过）。

## 三、三大经典构造

| 构造 | 怎么算 | 参数含义 |
| --- | --- | --- |
| **均线交叉** | 快线上穿慢线做多，下穿平仓 | `fast` / `slow`：快慢两条均线长度 |
| **通道突破** | 价格突破过去 n 日最高/最低就进出 | `entry` / `exit`：突破窗口、退出窗口 |
| **ATR 止损** | 用平均真实波幅的倍数设止损 | `n_atr`：放宽几倍波动空间 |

> **为什么趋势策略必须"宽"止损？**
> 因为它靠的是"撑到趋势来"。止损设太紧，会被正常波动扫出去，
> **而且是"刚被扫出、趋势就来了"那种最难受的扫出**。
>
> 这与 07-02 均值回归正好相反：那边必须**强制止损**（接下落的刀），
> 这边必须**留呼吸空间**。**同一套风控思路，两个策略的用法完全相反**——
> 因为你赌的东西不一样：一个赌"会回来"，一个赌"会继续走"。

## 四、用平台跑一次趋势回测

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross, turtle_breakout
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report, max_drawdown

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003, slippage_bp=5.0)

# 1) 两类趋势信号对比
for name, strat in [("sma_20_60", sma_cross(fast=20, slow=60)),
                    ("turtle_20_10", turtle_breakout(entry=20, exit=10))]:
    res = Backtest(md, strat, cfg).run()
    rep = perf_report(res.equity, rf=0.02)
    print(f"{name}: 年化={rep['annual_return']:.3f} Sharpe={rep['sharpe']:.2f} "
          f"回撤={max_drawdown(res.equity):.3f} 交易={len(res.trades)}")

# 2) 参数敏感性：看平台，不找最高点
for entry in (20, 40, 60, 90, 120):
    res = Backtest(md, turtle_breakout(entry=entry, exit=max(entry // 2, 5)), cfg).run()
    print(f"突破窗口={entry}: Sharpe={perf_report(res.equity, rf=0.02)['sharpe']:.2f}")
```

我实跑的结果：

```
sma_20_60:     年化=0.047  Sharpe=0.23  回撤=-0.429 交易=8527
turtle_20_10:  年化=-0.565 Sharpe=-4.64 回撤=-0.998 交易=4432
突破窗口=20:  Sharpe=-4.64
突破窗口=40:  Sharpe=-3.79
突破窗口=60:  Sharpe=-3.61
突破窗口=90:  Sharpe=-3.36
突破窗口=120: Sharpe=-3.40
```

**这张表要横着看，也要竖着看：**

**横着看两个策略**：`sma_20_60` 夏普 0.23（微赚），`turtle_20_10` 夏普 **-4.64**、回撤 **-99.8%**（几乎归零）。同一份数据、同一个家族，结果天差地别。

> **这不是"趋势跟踪不行"，而是"这份合成数据里没有趋势"。**
> 00-01 讲过：合成数据只被埋入了弱动量、短期反转、价值、低波、质量——
> **没有人为它植入"中长期趋势"**。
> 所以任何纯做突破的策略，在这里都会一路被假突破打脸。
> **这恰恰是趋势策略最真实的处境：它在没有趋势的市场里，就是这个样子。**

**竖着看参数扫描**：突破窗口从 20 拉到 120，夏普从 -4.64 升到 -3.36 再回到 -3.40。

> **注意这个形状——它不是"某个窗口特别神"，而是一整片都很差、只是差得少一点。**
> 这正是 01-03 讲的"看平台不看最高点"的实操版：
> **如果一个参数的邻域全都很差，那这个"最优点"就是噪声。**
>
> 反过来，假若你扫出一条"窗口 87 时夏普 2.3、周边全是 0.3"的曲线，
> 那不是发现了金矿，那是发现了**过拟合**。

## 五、趋势策略最容易死在哪

| 死法 | 表现 | 对策 |
| --- | --- | --- |
| **震荡市反复假突破** | 连续小亏，磨到人放弃 | 波动率过滤、降低频率 |
| **止损太紧** | 被正常波动扫出，错过趋势 | 用 ATR 放宽 |
| **滑点** | 突破点往往波动最大，实际滑点远超均值 | 03-05 冲击模型 |
| **参数取孤峰** | 邻域很差 | 看参数平台 |
| **不控仓位** | 波动放大时敞口被动变大 | 接 07-06 波动率目标 |

> **第一条是这一族的宿命。** 趋势跟踪在 70%~80% 的时间里是无聊甚至难受的，
> 因为它赌的就是"少数几次极端行情"。
> 而人在连续小亏之后，几乎一定会做两件事：**改参数** 或 **停策略**。
> **丹尼斯 1990 年那次和解，就是这件事最贵的注脚。**

## 六、把这一篇串起来

回到那个"教别人守规则的人"。

趋势跟踪这一族的规则简单得惊人——突破就买，跌破就卖。**它的全部难度不在智力，在耐受**：耐受连亏、耐受无聊、耐受"改了会更好"的诱惑。

> 而且它和 07-02 均值回归构成一对镜像：
> **趋势赌"机制延续"，回归赌"机制回来"；**
> **趋势低胜率高盈亏比、正偏，回归高胜率低盈亏比、负偏。**
> 两者常常互补（01-04 提过），因为它们的坏年份通常不是同一年。

> 一句话收尾：
> **趋势跟踪不是一场"预测"的游戏，是一场"熬"的游戏。**
> 你不需要每次都猜对——**你只需要在猜错八次之后，还在场上。**
