# 因子衰减与换手

## 学完这一篇，你能做到

- 说清为什么"论文里很赚钱的因子，发表后就不太赚了"
- 读懂 **IC 衰减曲线**与**半衰期**，据此选调仓周期
- 算清**换手 → 成本 → 净 IC** 这笔账
- 理解为什么"信号半衰期"和"换手率"必须一起看

## 本篇要点

- 因子收益会随**被发表、被交易**而衰减：回测天然高估未来
- IC 衰减曲线告诉你"信号能管多久"，半衰期决定调仓频率
- **净 IC = 毛 IC − 单边成本 × 年化换手**：很多因子毛 IC 为正、净 IC 为负
- 衰减、换手、容量是同一件事的三个侧面

---

## 一、从"论文发表之后，因子就不灵了"说起

2016 年，**R. David McLean** 与 **Jeffrey Pontiff** 在《金融学杂志》发表了一篇题目就很扎心的论文：《学术研究是否摧毁了股票收益的可预测性？》（*JF* 71(1): 5–32）。

他们做了一件费力但极有说服力的事：把 **97 个**已在学术期刊发表的收益预测变量，逐一拿到**样本外**、以及**论文发表之后**的年份去检验。结果（[AFA 官方摘要](https://afajof.org/issue/volume-71-issue-1/)）：

| 阶段 | 组合收益相对原论文 |
| --- | --- |
| 样本外（原样本之外） | **低 26%** |
| 论文发表之后 | **低 58%** |
| 其中可归因于"发表后被交易" | 约 **32%**（= 58% − 26%） |

> **请把这两行数读慢一点。**
> 一部分衰减是"原样本内过拟合"（01-03 的 AMS 论文、06 章多重检验）；
> 但**还有一截，是论文发表之后才发生的**——
> 因为大家读到了、开始照着做、资金涌进来，**错误定价被修正掉了**。
>
> 这正是 01-02 讲过的 alpha 衰减链条的现实版：
> **规律被发现 → 资金涌入 → 拥挤 → 收益下降。**
> 只不过这里多了一个精确的触发时点：**论文发表日**。

其实 Jegadeesh 与 Titman 1993 年的动量论文摘要里早就写过："组合形成后第一年的超额收益，会在随后两年消散"；他们 2001 年的续篇进一步发现反转出现在形成后 4~5 年（[NBER w7159](https://www.nber.org/papers/w7159)）。

> **一个因子不是静态矿藏，是有保质期的。**
> 所以评估它，不能只问"IC 有多高"，还必须问：**"它能管多久？"**

---

## 二、IC 衰减曲线与半衰期（逐个讲透）

做法很直接：**把预测期 h 从 1 天、5 天、10 天、20 天……一路拉长，每个 h 各算一次 IC**，画成一条曲线。

- 若 IC 在短 h 高、长 h 迅速掉到 0 → **短命信号**，必须快进快出（换手高）；
- 若 IC 在很长 h 仍维持 → **慢信号**，可以低频调仓（换手低、容量大）。

**半衰期**就是"IC 掉到峰值一半时所对应的预测期"。它是选调仓周期最实用的依据：

> **调仓周期应该和信号半衰期匹配。**
> 半衰期只有 5 天，却按月调仓 → 信号早凉了；
> 半衰期有半年，却天天调仓 → **白交手续费**（03-04）。

补个常识：**IC 衰减**（ic decay）与 01-02 说的"因子有周期性"不是一回事——
前者是**同一个信号随预测期拉长而变弱**（时间维度），
后者是**同一个因子在不同年份忽强忽弱**（截面随时间的稳定性）。**两个都要查。**

---

## 三、换手率：安静吃掉利润的那只手（单独讲透）

**换手率**定义：一段时间里买入 + 卖出的总金额 ÷ 组合市值。年化后常用"倍"表示（如 33.5x = 一年把整个组合换 33.5 遍）。

它和成本的关系，是本篇最该背下来的一笔账：

$$\text{净 IC} = \text{毛 IC} - c \times T$$

| 符号 | 白话 |
| --- | --- |
| 毛 IC | 因子本身的预测准头（05-05） |
| $c$ | 单边综合成本（03-04，含佣金 + 价差 + 冲击） |
| $T$ | 年化换手倍数 |
| **净 IC** | **扣完成本之后，真正剩下的东西** |

> **这个式子和 03-04 的 $\alpha_{net} = \alpha_g - T\cdot c$ 是同一个东西**，
> 只是把"超额收益"换成了"IC 口径"。**成本从来不看你 IC 多高，只看你换了多少次手。**

三种典型结局：

| 毛 IC | 换手 | 净 IC | 结论 |
| --- | --- | --- | --- |
| 0.03 | 5x | 0.02 | 可做 |
| 0.03 | 33x | -0.036 | **白忙** |
| 0.03 | 125x | -0.22 | 越努力越亏 |

> ⚠️ **最阴险的是第二行**：毛 IC 看着挺健康，回测曲线也漂亮，
> 一扣成本直接变负。**而多数人只报毛 IC。**

---

## 四、容量：换手的另一个约束

03-05 讲过：规模越大，参与率越高，冲击成本按平方根上升。把它和换手放一起看：

$$\text{单票日交易额} = \frac{A \cdot T}{252 \cdot N}$$

$A$ 是规模、$T$ 是换手、$N$ 是持仓数。**换手翻倍 = 每天要买卖的钱翻倍 = 容量减半**。

> 所以"高频 + 大资金"几乎不可能兼得：
> 要么降换手（等信号半衰期长的因子），要么缩规模，要么换流动性更好的标的。

## 五、用平台算清三个因子的账

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

# 1) IC 衰减：峰值、最佳预测期、半衰期
for name in ("mom_12_1", "bp", "vol_60"):
    decay = lab.ic_decay(name)
    print(f"{name}: IC峰值={decay.peak_ic():.4f} "
          f"峰值horizon={decay.best_horizon()} 半衰期={decay.half_life()}")

# 2) 换手率
for name in ("mom_12_1", "bp", "vol_60"):
    print(name, "日均换手:", f"{lab.turnover(name)['avg_daily_turnover']:.2%}")

# 3) 净 IC：毛 IC 减去换手成本
cost_one_way = 0.002        # 单边成本 20 bp（示意，视交易所而定）
for name in ("mom_12_1", "bp", "vol_60"):
    ic = lab.mean_ic(name, horizon=20)
    to = float(lab.turnover(name)["annual_turnover"])
    net = ic - cost_one_way * to
    print(f"{name}: IC={ic:.4f} 年化换手={to:.1f}x 净IC={net:.4f}")
```

我实跑的结果（关键三行）：

```
mom_12_1: IC=0.0287 年化换手=33.5x 净IC=-0.0382
bp:       IC=-0.0105 年化换手=124.9x 净IC=-0.2604
vol_60:   IC=-0.0013 年化换手=33.7x 净IC=-0.0688
```

**请注意 `mom_12_1` 这一行：毛 IC +0.0287（05-05 说过 0.03 已算不错），
年化换手 33.5 倍，扣 20 bp 单边成本后，净 IC 变成 -0.0382。**

> **一个"统计上有效"的因子，扣完成本后是负的。**
> 这就是本篇最想让你亲眼看到的事：
> **IC 检验通过 ≠ 策略能用。** 中间还隔着换手和成本两道闸。

再看 `bp`：换手 **124.9 倍**（一年把组合换 125 遍），净 IC **-0.26**。
03-04 那张"策略成本承受力"表里，日度均值回归可承受单边成本只有 0.5~2 bp，
而这里假设了 20 bp——**bp 这类高换手因子，在这种成本假设下必然死**。

衰减那几行也值得读：`bp` 的 IC 峰值出现在 horizon=1、半衰期=1（**当天就凉**），
而 `mom_12_1` 峰值在 horizon=120、半衰期 None（长信号）。**两者的合理调仓频率天差地别。**

> ⚠️ **成本假设 20 bp 是示意值**，实际取决于市场、规模、流动性（03-04/03-05）。
> 换手越大，这个假设越该被认真核对——**别用一个拍脑袋的 c 去否决策略，也别用它去放行策略。**

## 六、把这一篇串起来

回到 McLean 与 Pontiff 那 97 个因子。

样本外低 26%、发表后低 58%——这两个数字合起来，讲的不只是"过拟合"，而是一个更冷的事实：

> **一个因子被越多的人知道、越多资金照着做，它就越接近失效。**
> 所以回测里那条漂亮曲线，从诞生的那天起就在**倒计时**。

而换手与净 IC 是它的另一半：**就算信号还没衰减，你为了抓住它而频繁交易，也会把利润亲手交出去。**

> 一句话收尾：
> **因子有两道保质期——一道是"别人也发现了"（衰减），一道是"你自己交易太勤"（换手）。**
> 优秀的因子研究，不是找最亮的信号，
> **是找一个"够亮、够久、还能安静地拿着"的信号。**
