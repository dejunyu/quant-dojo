# 中性化

在做完[去极值与标准化](../05-因子/05-03-去极值与标准化.md)之后，因子值仍然携带大量**已知的风险暴露**。BP 高的股票往往是银行、地产，换手率高的股票往往是小盘股。如果不加控制，你以为自己在买"便宜"，实际上可能只是买了"银行股 + 小盘股"。中性化就是要把这部分已知暴露剥离出去。

## 一、为什么要中性化

中性化的三个实际用途：

1. **提纯 alpha**：把因子中已经由市值、行业解释掉的部分去掉，剩下的才是真正新增的信息。
2. **避免暴露叠加**：多因子合成时，若每个因子都隐含小市值暴露，合成结果的规模暴露会被放大，风险集中。
3. **满足产品约束**：指数增强与中性产品对行业、市值偏离有严格限制，中性化后的因子天然降低主动暴露。

## 二、回归做法

标准做法是**逐期横截面回归**，对每个交易日 $t$ 独立估计：

$$x_{i,t} = a_t + b_t \cdot \ln(\text{MktCap}_{i,t}) + \sum_{k=1}^{K} c_{k,t} \cdot D_{i,k} + \varepsilon_{i,t}$$

其中：

- $x_{i,t}$ 是股票 $i$ 在第 $t$ 期的因子暴露；
- $\ln(\text{MktCap}_{i,t})$ 是市值对数，取对数是因为市值本身高度右偏；
- $D_{i,k}$ 是行业哑变量，股票属于第 $k$ 个行业则为 1，否则为 0；
- **残差 $\varepsilon_{i,t}$ 就是中性化后的因子**。

回归系数 $b_t$、$c_{k,t}$ 的经济含义是"因子值中有多少被市值和行业解释了"，残差则是"剔除这些解释后，该股票在同行同规模公司中的相对位置"。

### 行业哑变量与共线性

若同时使用截距 $a_t$ 与全部 $K$ 个行业哑变量，会触发**哑变量陷阱**——$\sum_k D_{i,k} = 1$ 与截距列完全共线，设计矩阵不满秩。两种标准解法：

- **去掉截距**，保留全部 $K$ 个行业哑变量，此时每个 $c_k$ 表示行业均值，残差自然以行业为基准去均值；
- **保留截距，删掉一个行业**作为基准组，其余系数表示相对基准的差异。

两种做法得到的残差完全相同，只是系数解释不同。实践中第一种更方便解读。

### 市值用对数还是排名

- **$\ln(\text{MktCap})$**：假设因子与市值对数近似线性，是文献中的标准做法。
- **市值分位排名**：更稳健，不受极值影响，适合小市值极端分布的市场。
- **市值分组哑变量**：允许非线性，代价是自由度消耗大。

若因子与市值的关系明显非线性（例如 U 型），线性对数项无法剔除干净，此时用分组哑变量更合适。

## 三、什么时候不该中性化

中性化不是无条件正确的默认动作，以下情况应当谨慎或不做：

1. **行业/市值本身就是策略的收益来源**。小市值因子、行业轮动策略如果被中性化，alpha 会被自己洗掉。
2. **因子本就是行业内定义的**。例如"行业内 ROE 排名"已经是相对量，再中性化一次等于重复处理，只会引入噪声。
3. **行业分类太粗或太少**。若只有 3~5 个行业且每个行业样本很少，回归自由度消耗大而收益有限，残差会严重过拟合。
4. **样本量太小**。横截面回归需要每个行业有足够样本，少于 10 只股票的行业分组，其行业均值估计不可靠。
5. **因子与市值高度共线无法分离**。例如"总市值"本身，中性化后残差几乎为 0。

判断的经验法则：**问自己"我希望这个因子的持仓在行业/市值上偏离中性吗？"** 若答案是"希望"（如行业轮动），则不做；若答案是"不希望"（如纯选股 alpha），则做。

## 四、中性化改变了什么

中性化后因子的经济含义发生了实质变化：

| 维度 | 中性化前 | 中性化后 |
| --- | --- | --- |
| 含义 | 全市场绝对排序 | 同行业内、同规模下的相对排序 |
| 高暴露组特征 | 可能是某行业集中 | 行业分散，但行业内偏贵/偏便宜 |
| IC | 包含市值行业的贡献 | 只含纯选股能力 |
| 组合风险 | 可能有大幅行业/规模偏离 | 暴露更中性，跟踪误差更低 |

因此**中性化后 IC 下降是正常且预期内的**，不应据此判断"因子变差了"。真正该看的是：

- 下降幅度是否过大（IC 从 0.05 掉到 0.005，说明因子几乎全部是市值行业的代理）；
- 中性化后 IC 的 t 值是否仍然显著；
- 分组收益的**单调性**是否保持（[分层回测](../05-因子/05-06-分层回测.md)）。

一个实用的诊断表：分别算"原始 IC"、"仅中性化市值后的 IC"、"仅中性化行业后的 IC"、"双重中性化后的 IC"，即可拆出因子收益的行业贡献、规模贡献与纯净部分。

## 五、代码：市值 + 行业中性化

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import neutralize, winsorize, zscore
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

# 原始因子：先去极值
raw = winsorize(get_factor("roe_q").compute(md), lower=0.01, upper=0.99)

# 风格暴露：市值对数（取对数是文献标准做法）。
# 合成数据集自带 fundamentals（pe/pb/roe/mktcap），具体取用方式以数据对象为准：
lncap = np.log(mktcap_panel)          # dates × symbols 的市值面板

# 行业分类：这里用固定的模拟分类演示，实盘应替换为真实行业标签
industries = pd.DataFrame(
    np.random.default_rng(0).integers(0, 5, size=(len(md.dates), len(md.symbols))),
    index=md.dates, columns=md.symbols,
)

# 1) 仅对市值中性化
neu_cap = neutralize(raw, lncap)

# 2) 对市值 + 行业同时中性化（行业以哑变量形式进入）
neu_both = neutralize(raw, lncap, group=industries)

# 3) 中性化后重新标准化，保证量纲统一
neu_z = zscore(neu_both)

print("原始      IC:", lab.ic("roe_q"))
print("市值中性  IC:", lab.ic("roe_q_neu_cap"))
print("双重中性  IC:", lab.ic("roe_q_neu_both"))
print(lab.quantile_backtest("roe_q_neu_both", n_quantiles=5))
```

`neutralize(x, style, group=...)` 的语义是：对 `style`（连续变量，如 $\ln$ 市值）与 `group`（类别变量，如行业）做横截面回归并取残差。若只想对行业中性化，只传 `group` 即可。

## 常见坑

1. **哑变量陷阱**：截距加全行业哑变量导致矩阵不满秩，回归解不稳定。必须去截距或删基准组。
2. **逐期回归、不可跨期**：中性化必须在每个横截面上独立做，用全样本统一回归等于把未来行业均值引入过去，属于[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)。
3. **行业分类变更**：公司主营业务变更或行业分类标准调整（如 GICS 与申万切换）会造成历史断层，需按当期有效分类逐期映射。
4. **ST、次新股污染**：极端样本会主导行业均值，应在中性化前剔除或单独分组。
5. **把中性化当万金油**：中性化只能剔除你**已知并指定**的暴露。若因子隐含流动性、beta 暴露而未指定，中性化后依然存在。
6. **中性化后再标准化**：回归残差的尺度每期不同，直接加权会有偏，务必补一次 z-score。
