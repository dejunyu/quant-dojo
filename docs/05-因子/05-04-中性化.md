# 中性化

## 学完这一篇，你能做到

- 用一句话说清"中性化"到底在剥掉什么
- 解释为什么**不做中性化，你的 alpha 很可能只是市值或行业**
- 知道什么时候**不该**中性化（这比会做更重要）
- 会在平台上做市值 + 行业双重中性化，并对比前后 IC

## 本篇要点

- 中性化 = 把因子对**不想押注的暴露**做回归，取**残差**
- 最常见要剥的两样：**市值**、**行业**
- 剥完之后剩下的，才更接近"这个因子自己的信息"
- **别过度中性化**：把真信号一起剥掉，比不剥更糟

---

## 一、从一个人把"公司特征"写进风险模型说起

1974 年，**巴尔·罗森伯格**（Barr Rosenberg）在《金融与定量分析杂志》发表《证券收益中市场外的协方差成分》（*JFQA* 9(2): 263–274）。

他问了一个在当时很超前的问题：**两只股票为什么会一起动？**

传统答案只有"它们都跟着大盘"（beta）。罗森伯格说不止——他在论文摘要里写得直白：个股在因子上的载荷，**"由公司可观测的特征决定：损益表与资产负债表数据、行业归属、以及历史收益行为"**。（[EconPapers 论文页](https://econpapers.repec.org/article/cupjfinqa/v_3a9_3ay_3a1974_3ai_3a02_3ap_3a263-274_5f01.htm)）

> **这个想法后来长成了整个业界的风险模型体系**：1970 年代中期他创立了 Barr Rosenberg Associates（后发展为 **BARRA**），把"行业 + 风格"写成一张可操作的暴露矩阵；MSCI 于 2004 年收购 BARRA（[MSCI 官方新闻稿](https://www.msci.com/eqb/pressreleases/archive/20040406_pr.pdf)）。**BARRA 具体创立年份有 1974 / 1975 两说，别写死。**

> **这篇论文给中性化的启示，一句话就够：**
> **如果"行业 + 市值 + 财务特征"本来就解释了股票之间大部分共同波动，
> 那么一个因子若不先把这些剥掉，你根本分不清自己赚的是"选股本事"还是"押对了行业/市值"。**

这正是 01-05 讲收益分解时那句"**不剥干净 beta 和风格，你没资格谈 alpha**"的具体做法。

## 二、中性化到底在做什么（逐个讲透）

一句话：**把因子里"能由不想押注的暴露解释掉"的那部分减掉，只留残差。**

写成横截面回归（每个交易日 t 各做一次）：

$$x_{i,t} = a_t + \sum_k b_{k,t}\, E_{k,i,t} + \varepsilon_{i,t}$$

| 符号 | 白话 |
| --- | --- |
| $x_{i,t}$ | 原始因子值（股票 i、第 t 天） |
| $E_{k,i,t}$ | 第 k 个**想剥掉的暴露**：市值对数、行业哑变量等 |
| $b_{k,t}$ | 回归系数：因子值里有多少来自这个暴露 |
| $a_t$ | 当天截距 |
| $\varepsilon_{i,t}$ | **残差 = 中性化后的因子值** |

> **残差的意思很朴素：**
> **"扣掉市值和行业能解释的部分之后，这只股票还剩下多少'说不清'的因子值？"**
> 我们要的就是这份"说不清"——因为它更可能是因子自己的信息，
> 而不是"小盘股整体贵""银行股整体便宜"这类风格效应。

### 一个能感受到的例子

假设你的因子是"ROE 高不高"。不做中性化直接选前 20%，结果很可能**一水儿的大银行、大消费**——因为大公司 ROE 天然稳定。

这时回测赚了钱，你以为是"选到了好公司"，其实是**押了市值 + 押了行业**。风格一反转，钱原样吐回去（01-05 那个"2021 年满仓小市值股赚 30%"就是反过来的同一件事）。

> 中性化做的事，就是把"因为它大 / 因为它属于这个行业"这两层先扣掉，
> 再问：**在同一规模、同一行业里，它的 ROE 还突出吗？**

补两个常识：

- **哑变量（dummy）**：把"属于哪个行业"这种类别，转成 0/1 的列（是银行=1，否则=0）。回归只能吃数字，所以要这么转。
- **取对数**：市值跨度能到几千倍，取 $\ln$ 后差异被压缩，回归更稳（02-03 也见过类似"用对数换尺度"的思路）。

## 三、什么时候**不该**中性化（比会做更重要）

这是最容易被跳过的一节。中性化是减法，**减过头会把真信号一起减掉**。

| 情况 | 该不该剥 | 为什么 |
| --- | --- | --- |
| 市值/行业本身就是你的**投资逻辑** | ❌ 别剥 | 比如"就做小盘股"，剥掉等于把主题删了 |
| 想要的正是**风格轮动收益** | ❌ 别剥 | 剥完就没收益来源了 |
| 因子与暴露高度相关（如估值与市值） | ⚠️ 谨慎 | 可能把大半信号一起剥没，需用 05-08 的正交化思路先诊断 |
| 只想赚**纯选股 alpha** | ✅ 该剥 | 这正是中性化的主场 |

> **判断标准只有一条：**
> **"这个暴露，是我打算靠它赚钱，还是我怕它混进来？"**
> 前者保留，后者剥掉。**先回答这句，再写代码。**

还有个坑：**中性化用的暴露数据本身必须干净且 point-in-time**。
若行业分类用了"今天"的标签去回测历史，又是 02-04 的前视偏差；
若市值用了未复权价格算，又是 02-03。**中性化不会自动帮你修上游。**

## 四、中性化改变了什么（讲透）

剥完之后的因子，三件事会变：

1. **均值约为 0、与暴露不再相关**：这是定义决定的，不是"变好了"；
2. **IC 可能升，也可能降**：升说明原来被风格噪声稀释了；降说明原来赚的本来就是风格；
3. **分层单调性可能变化**：因为排序依据变了。

> ⚠️ **千万别把"中性化后 IC 变高"当成功劳**。
> 它只说明"剔除的风格恰好是干扰"。**如果 IC 变低了，反而是更有价值的发现**——
> 它告诉你：你以为的 alpha，其实一直是 beta（01-05）。

## 五、用平台做一次市值 + 行业中性化

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import neutralize, winsorize, zscore
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

raw = winsorize(get_factor("roe_q").compute(md), lower=0.01, upper=0.99)
lncap = np.log(md.fundamentals["mktcap"])      # 平台自带的市值面板
print("市值面板形状:", lncap.shape)

# 1) 仅对市值中性化
neu_cap = neutralize(raw, exposures=[lncap])
# 2) 市值 + 行业双重中性化（industry/size 用平台内置标签）
neu_both = neutralize(raw, md=md, industry=True, size=True)

lab.register("roe_q_neu_cap", zscore(neu_cap))
lab.register("roe_q_neu_both", zscore(neu_both))
print("原始      IC:", round(lab.mean_ic("roe_q", horizon=20), 4))
print("市值中性  IC:", round(lab.mean_ic("roe_q_neu_cap", horizon=20), 4))
print("双重中性  IC:", round(lab.mean_ic("roe_q_neu_both", horizon=20), 4))
```

我实跑的结果：

```
市值面板形状: (1827, 50)
原始      IC: 0.0195
市值中性  IC: 0.0207
双重中性  IC: 0.0205
```

**IC 从 0.0195 微升到 0.0207，再回到 0.0205，几乎没变。**

> 这又是合成数据的一个诚实结果：`roe_q` 里本来就没埋多少市值/行业暴露，
> 所以剥与不剥差别很小。**别据此得出"中性化没用"**——
> 换一份真实数据（大公司 ROE 系统性更高）差异会立刻显现。
>
> 正确的读法是：**中性化是"体检"，不是"美容"。**
> 体检结果正常，不代表体检没意义；它只是告诉你"这次没有隐藏的风格暴露"。
> 而一旦发现 IC 大幅下降，那才是它最值钱的时刻——**它替你挡下了一个伪 alpha**。

`neutralize(x, md=..., exposures=..., industry=True, size=True)` 的语义就是：
对连续暴露（市值）与类别暴露（行业哑变量）做**横截面回归取残差**。只想剥行业，只开 `industry=True` 即可。

## 六、把这一篇串起来

回到 1974 年罗森伯格那句"载荷由公司特征决定"。

它听起来像一句技术描述，其实是一个很锋利的提醒：

> **你看到的任何一个"因子"，都可能只是若干更基础暴露的投影。**
> 不把这些投影一层层剥开，你永远不知道自己到底在赚谁的钱。

这和 01-05 的收益分解、05-02 的 Novy-Marx（"控制盈利后价值策略更强"）、05-08 的共线性，是同一条线：**因子的价值，往往在"控制住别的东西之后"才看得清。**

> 一句话收尾：
> **中性化不改数据，改的是"你允许自己赚哪份钱"。**
> 剥掉的从来不是噪声，是**你不打算承担、却不小心承担了的风险**。
