# 分层回测

IC 告诉你因子和收益"有没有关系"，分层回测（quantile backtest）告诉你这个关系"能不能用来赚钱"。它是单因子检验的第二个必备环节，与 [IC/ICIR 检验](../05-因子/05-05-单因子检验IC与ICIR.md)互补而非替代。

## 一、分组构造流程

标准的分层回测是一个循环：

1. **每期排序**：在第 $t$ 个调仓日，把股票池内全部股票按因子暴露 $x_{i,t}$ 升序排列。
2. **切分 N 组**：按分位数切成 $Q_1, Q_2, \ldots, Q_N$ 组（$Q_1$ 为暴露最低组）。
3. **组内等权**：组内每只股票权重 $1/N_q$，也可改为市值加权。
4. **持有至下期**：持有 $h$ 期后重新排序调仓。
5. **记录收益**：得到每组的收益序列 $r_{Q_q,t}$，进而得到累计净值曲线。

多空组合（long-short）定义为最高组减最低组：

$$r_{LS,t} = r_{Q_N,t} - r_{Q_1,t}$$

（若因子方向为负，则反过来做多 $Q_1$、做空 $Q_N$，或用 $-r_{LS}$。）

## 二、为什么多空组合比 IC 更严格

| 检验 | 回答的问题 | 剔除的东西 |
| --- | --- | --- |
| 因子多头组收益 | 能不能靠它赚钱 | 未剔除市场涨跌 |
| IC | 暴露与收益是否相关 | 剔除了个股特质噪声 |
| **多空组合** | 能否稳定获取组间差异 | 剔除了市场 beta、无风险利率 |

多空组合的核心价值在于**它把市场因素对冲掉了**。若某因子多头组年化 15%，但同期市场年化 14%，那这个因子几乎毫无价值；IC 可能因为横截面相关而依然为正，多空组合却会暴露它的真实能力。

此外，分层回测是**可执行的**：它的输出就是一组可交易的组合，能直接接上换手率、交易成本、容量约束的计算（[因子衰减与换手](../05-因子/05-07-因子衰减与换手.md)），而 IC 只是一个抽象的相关系数。

## 三、单调性判断

理想的有效因子，各组收益应随组序单调变化。定量做法是计算组序与组收益的秩相关：

$$\rho = \mathrm{Spearman}\big((1,2,\ldots,N),\ (\bar r_{Q_1},\ldots,\bar r_{Q_N})\big)$$

$\rho$ 接近 $\pm 1$ 说明单调性好。实践中更直接的做法是：

- 看各组年化收益柱状图是否阶梯状；
- 看是否只有首尾两组极端、中间三组几乎无差异（尾部驱动）；
- 看是否出现 U 型或倒 U 型（非线性，IC 会低估因子价值）。

## 四、分组数怎么选

分组数是一个偏差-方差权衡：

| 分组数 | 每组样本 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 3 | 多 | 稳健、统计噪声小 | 只看粗略的三分位，尾部信息被稀释 |
| 5 | 中等 | 业界标准，兼顾稳健与分辨率 | 尾部信息部分稀释 |
| 10 | 少 | 能刻画尾部（decile spread 是文献常用口径） | 样本少时噪声大，组内偏离等权假设严重 |

选择原则：**每组至少 30~50 只股票**。若股票池只有 100 只，分 10 组就毫无意义。A 股全市场（4000+ 只）分 10 组很常见，沪深 300 内通常只分 5 组。

另外注意，文献中常说的 "decile spread"（第 10 组减第 1 组）与 5 分组的多空收益不可直接比较——前者只用了 20% 的样本，收益更高但换手也更大。

## 五、统计显著性

多空组合的收益序列可以做标准 t 检验：

$$t = \frac{\bar r_{LS}}{\sigma(r_{LS})/\sqrt{n}}$$

其中 $\bar r_{LS}$ 是每期多空收益的均值。经验上多空组合的年化 Sharpe 大于 1 已属优秀，大于 0.5 可考虑纳入多因子体系；若月度多空收益的 t 值小于 2，通常认为证据不足。

注意：多空组合的**名义收益不等于可实现收益**。它假设两端都能无成本成交，而现实中做空成本高、小市值股票容量小、涨停无法买入。因此多空 Sharpe 应视为"因子信息含量的上界"，多头端的超额收益才是多数产品真正能拿到的部分。

## 六、与 IC 结果矛盾时怎么解释

| 现象 | 可能成因 | 处理方式 |
| --- | --- | --- |
| IC 显著，多空不显著 | IC 由中间组贡献，首尾无差异；或换手成本吞噬收益 | 看分组柱状图；加成本后重算 |
| 多空显著，IC 不显著 | 非线性（U 型）关系；或 IC 被极端值干扰 | 用 RankIC；做二次项或分段检验 |
| 分组不单调但两端差大 | 尾部驱动，中间无区分度 | 改用分位阈值选股而非连续加权 |
| 单调但第一组亏损 | 因子方向为负（如低波、反转） | 反转方向后重新解释 |
| 样本内单调、样本外消失 | 过拟合或因子拥挤 | 做[样本内外与滚动前推](../06-回测/06-06-样本内外与滚动前推.md) |

一个常被忽略的成因是**行业集中**：若第 5 组恰好全是某行业股票，多空收益可能只是行业收益。解决办法是先做[中性化](../05-因子/05-04-中性化.md)再分组，或分组时做行业内分层。

## 七、代码：5 分组 + 绩效评估

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab
from qd.metrics.perf import perf_report, sharpe, max_drawdown

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

name = "mom_12_1"
# 各组的"周期收益"时间序列（列为 Q1..Q5）。
# 默认按 horizon 步长采样，保证收益**不重叠**，可以直接累乘成净值。
bt = lab.quantile_returns(name, n_quantiles=5, horizon=20)

for q in bt.columns:
    nav = (1 + bt[q]).cumprod()
    rep = perf_report(nav, rf=0.02)
    print(f"{q}: 年化={rep['annual_return']:.3f} Sharpe={rep['sharpe']:.2f} "
          f"最大回撤={rep['max_drawdown']:.3f}")

# 多空组合：Q1（因子值最高组）- Q5
ls = bt["Q1"] - bt["Q5"]
nav_ls = (1 + ls).cumprod()
print("多空年化:", perf_report(nav_ls, rf=0.0)["annual_return"])
print("多空Sharpe:", sharpe(nav_ls))
print("多空最大回撤:", max_drawdown(nav_ls))

# 单调性：组序与组均值收益的秩相关
means = bt.mean()
order = pd.Series(range(1, len(means) + 1), index=means.index)
print("单调性(Spearman):", means.corr(order, method="spearman"))
# 多空收益 t 检验
t_stat = ls.mean() / (ls.std() / np.sqrt(len(ls)))
print("多空 t 值:", round(t_stat, 2))

# 想要一步到位的汇总（含年化、夏普、多空、单调性判定）：
summary = lab.quantile_backtest(name, n_quantiles=5)
print(summary["long_short"], summary["monotonicity"])
```

读结果时的顺序应当是：**先看单调性 → 再看多空 t 值 → 最后看多头端是否能跑赢基准**。多数实盘产品只能做多头，若多头组相对基准没有超额，多空组合再漂亮也无法落地。

## 常见坑

1. **分组边界由极端值决定**：不做[去极值](../05-因子/05-03-去极值与标准化.md)就分组，第 1、第 5 组会被少数极端样本占满。
2. **忽略交易成本**：特别是 10 分组的 decile spread，换手极高，毛收益漂亮但净收益可能为负。
3. **等权假设不可实现**：组内等权意味着小市值股票与大市值股票权重相同，实盘会有容量问题，可改用市值加权重测。
4. **涨跌停无法成交**：A 股涨停板股票在分组中常出现在高动量组，实际买不到，回测会高估。
5. **幸存者偏差**：只用现存股票做历史分组，退市股的极端负收益被剔除，第 1 组收益被系统性高估。
6. **把多空收益当可实现收益**：做空受限、融券成本高的市场里，多空收益只是理论上界。
