# 因子共线性和正交化

## 学完这一篇，你能做到

- 说清为什么"多加一个因子"可能什么都没加
- 会用相关矩阵诊断共线性，并读懂它
- 理解**正交化**在剥什么、以及为什么它**顺序敏感**
- 明白为什么"该合成而不是堆叠"，为 05-09 铺路

## 本篇要点

- 两个高度相关的因子，提供的**不是两份独立信息**
- 正交化 = 把一个因子里"能由另一个解释"的部分减掉（与 05-04 中性化同构）
- **施密特正交化顺序敏感**：谁在前，谁保留原貌
- 先诊断冗余，再决定加不加因子——**别把换标签当成发现新因子**

---

## 一、从"价值因子突然变多余了"说起

2015 年，Fama 与 French 在《金融经济学杂志》发表《五因子资产定价模型》（*JFE* 116(1): 1–22），在原来的市场、规模、价值三因子之外，又加入了**盈利能力（RMW）**与**投资风格（CMA）**两个因子。

然后摘要里出现了一句让整个行业讨论很久的话：

> **"加入了盈利与投资因子之后，三因子模型里的价值因子（HML），在描述平均收益时变得冗余了。"**
> （"the value factor of the FF three-factor model becomes **redundant**"，[EconPapers 摘要](https://econpapers.repec.org/scripts/a/abstract.pf?h=RePEc:eee:jfinec:v:116:y:2015:i:1:p:1-22)）

⚠️ **措辞必须说准**：原文限定为"**在他们的样本里、对描述平均收益而言**冗余"，
**不是**"HML 无效"的普遍结论，后续仍有争议。

> **这个"冗余"是什么意思？**
> 说白了：新加的两个因子，把原来 HML 能解释的那部分收益**接管了**。
> 它们和 HML 高度相关——**你以为加了两份新信息，其实很大程度上是同一个东西换了个标签**。
>
> 这就是本篇的主题：**共线性**。
> 因子不是越多越好，**关键是它们彼此有多独立**（01-05 的"广度 BR = 独立下注次数"还记得吗？
> 高度相关的两个因子，BR 只算 1 次，不算 2 次）。

---

## 二、怎么诊断（逐个讲透）

最直接的工具是**因子相关矩阵**：两两算相关系数，看哪些格子接近 ±1。

$$\rho_{ij} = \mathrm{corr}(f_i,\ f_j)$$

| $\rho$ 的绝对值 | 意味着 |
| --- | --- |
| < 0.3 | 基本独立，可以放心一起用 |
| 0.3 ~ 0.7 | 有重叠，需留意 |
| **> 0.7** | **高度共线，加进来多半是换标签** |

> 补个常识：**VIF（方差膨胀因子）** 是诊断多重共线性的通用统计工具（值越大共线性越严重）。
> 但它的**提出者与年份本轮未核实**，别写成"某某于某年提出"——
> 会用它、知道它测什么就够了。

还有一个更本质的诊断：**正交化之后，这个因子还剩多少 IC？**
如果剥掉与老因子共享的部分后 IC 归零，那它就没提供增量信息（下一节）。

---

## 三、正交化在做什么（单独讲透）

**正交化 = 把因子 A 里"能由因子 B 解释"的那部分减掉，只留残差。**

$$f_A^{\perp} = f_A - \beta\, f_B, \qquad \beta = \frac{\mathrm{Cov}(f_A, f_B)}{\mathrm{Var}(f_B)}$$

| 符号 | 白话 |
| --- | --- |
| $f_A$、$f_B$ | 两个因子值 |
| $\beta$ | A 里有多少成分可以写成 B 的倍数 |
| $f_A^{\perp}$ | **减完之后，A 独有的那部分** |

> **这跟 05-04 的中性化是同一个动作**，只是对象不同：
> - 中性化：剥掉**风格暴露**（市值、行业）；
> - 正交化：剥掉**另一个因子**。
>
> 两者都是"回归取残差"，都是**把不想要的共同成分减掉**。

### 施密特（Gram-Schmidt）正交化：顺序敏感

> ⚠️ **这是最容易踩的坑**：`orthogonalize(["bp", "ep"])` 与 `orthogonalize(["ep", "bp"])` **结果不同**。
> **排在前面的因子保留原貌，后面的被剥离。**
>
> 所以顺序不是技术细节，是**一次表态**："我认定谁是主信息、谁是从属信息"。
> 这个决定必须有经济理由（比如"BP 是更基础的价值度量"），**不能为了减少共线性随手排**。

### PCA 降维（另一条路）

若不想指定谁主谁从，可以用**主成分分析（PCA）**：把一组相关因子重组成若干**彼此正交**的主成分，按解释方差大小排序。

> 代价是**主成分不好解释**：第一主成分可能是"0.4×价值 + 0.3×质量 + 0.3×动量"，
> 你没法向客户说"我买的是便宜股"。**可解释性换正交性**，这是取舍，不是免费午餐。

## 四、为什么要"合成"而不是"堆叠"（伏笔）

若五个因子两两相关 0.9，直接等权相加，本质上等于**把同一个信号加了五遍**——
权重看着分散，风险却全押在一个方向。

> **Grinold 基本定律里的 BR 是"独立下注次数"**：
> 相关 0.9 的五个因子，BR 接近 1，不是 5。
> **所以 05-09 的合成，前提是先在这里把相关性降下来。**

## 五、用平台看相关矩阵与正交化

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab
from qd.factors import get_factor
from qd.factors.pipeline import orthogonalize, zscore, combine

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)
names = ["bp", "ep", "mom_12_1", "vol_60", "roe_q"]

# 1) 相关矩阵
corr = lab.correlation(names)
print(corr.round(2))
cm = corr.where(~np.eye(len(corr), dtype=bool)).abs().stack()
print("最高相关:", cm.sort_values(ascending=False).head(2).round(3).to_dict())

# 2) 把 ep 中与 bp 共享的部分剥掉（bp 在前，保留原貌）
bp = zscore(get_factor("bp").compute(md))
ep = zscore(get_factor("ep").compute(md))
ep_orth = orthogonalize(ep, against=[bp], md=md)
lab.register("ep_orth", ep_orth)
print("正交前 ep 的 IC:", round(lab.mean_ic("ep", horizon=20), 4))
print("正交后 ep 的 IC:", round(lab.mean_ic("ep_orth", horizon=20), 4))

# 3) 正交化后再合成
combined = combine([zscore(get_factor(n).compute(md)) for n in names], method="equal")
lab.register("combo", combined)
print("等权合成 IC:", round(lab.mean_ic("combo", horizon=20), 4))
```

我实跑的结果：

```
     bp    ep  mom_12_1  vol_60  roe_q
bp   1.00  0.73    -0.16   -0.18   0.57
ep   0.73  1.00    -0.31   -0.21   0.04
...
最高相关: {'bp ep': 0.728, 'ep bp': 0.728}
正交前 ep 的 IC: -0.0261
正交后 ep 的 IC: -0.0278
等权合成 IC: 0.0049
```

**`bp` 与 `ep` 相关 0.73，超过 0.7 的警戒线**——它们都是"便宜程度"的度量，本来就该一起动。**再加一个同类因子，BR 几乎不增加。**

> 正交后 `ep` 的 IC 从 -0.0261 变成 -0.0278，**几乎没变**。
> 两种读法都可以，但都指向同一件事：
> 在这个合成数据里，ep 的预测力**并不来自与 bp 共享的那部分**。
> 换成真实数据，若正交后 IC 大幅归零，你就该果断把它从因子库里删掉——**它没有提供增量信息**。

> 顺带看最后一行：五个因子等权合成，IC 只有 **0.0049**，比单独最好的 `mom_12_1`（0.0287）还低。
> **堆得多不等于合成得好**——这正是 05-09 要解决的问题。

## 六、把这一篇串起来

回到 2015 年那句"HML 变得冗余"。

它不是在宣布价值因子死了，而是在提醒所有人：**因子库是一个有结构的系统，不是一串名字**。每加一个新成员，都得先问：

> **"它带来的信息，是原有因子给不了的，还是只是换了个说法？"**

这和 05-04 的中性化（剥风格）、05-02 的 Novy-Marx（控制盈利后价值更强）、05-09 的合成（加权之前先降相关），是同一条线的四站：**因子的价值，只在"控制住别的东西之后"才看得清。**

> 一句话收尾：
> **共线性的本质，是"你以为自己分散了，其实只是把同一注下了五遍"。**
> 而正交化，就是逼每个因子交代：**"扣掉别人之后，你自己还剩什么？"**
