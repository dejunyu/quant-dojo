# 因子共线性和正交化

当你手上有了 10 个因子，直觉是"全部加进去应该更好"。现实往往相反：这些因子之间高度相关，直接加权会重复计入同一信息、放大噪声、让权重失去可解释性。本篇处理这个问题，**下一篇（[因子合成](../05-因子/05-09-因子合成.md)）才真正把它们合起来**。

## 一、为什么要看相关性

三个具体后果：

1. **加权系数不稳定**：若两个因子相关 0.9，回归或均值-方差优化求出的权重会在两者之间剧烈摆动，样本内完美、样本外崩塌。
2. **重复计入**：价值类的 BP 与 EP 高度相关，等权相加等于给"价值"这一信息分配了两倍权重，而它并非两倍可信。
3. **多重检验**：每多试一个因子，就多一次"偶然显著"的机会（[过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)）。若 10 个因子里其实只有 3 个独立信息源，你实际承担的是 10 次检验的风险而非 3 次。

## 二、如何诊断

**相关矩阵**是最直接的起点。经验阈值：

| 相关系数绝对值 | 判断 | 处理建议 |
| --- | --- | --- |
| < 0.3 | 基本独立 | 可直接合成 |
| 0.3 ~ 0.7 | 中度相关 | 可合成，但注意权重稳定性 |
| > 0.7 | 高度相关 | 先正交化或合并为一个 |
| > 0.9 | 近似重复 | 保留一个，或做主成分 |

**Pearson 与 Spearman 的差异**值得注意：因子间若存在单调非线性关系（如市值与流动性），Spearman 相关会显著高于 Pearson。因子研究通常用 Spearman（或先做[排名变换](../05-因子/05-03-去极值与标准化.md)再算 Pearson），因为它刻画的是"排序是否一致"，而这正是选股关心的东西。

**VIF（方差膨胀因子）** 是多元回归场景下的标准诊断：

$$ \mathrm{VIF}_k = \frac{1}{1 - R_k^2} $$

其中 $R_k^2$ 是用其余因子对第 $k$ 个因子做回归的决定系数。$\mathrm{VIF} > 10$ 通常认为共线性严重。此外还可看设计矩阵的**条件数**（最大特征值与最小特征值之比），条件数大于 30 提示数值不稳。

## 三、施密特（Gram-Schmidt）正交化

给定一组因子向量 $f_1, f_2, \ldots, f_K$，施密特正交化逐步剥离：

$$ \tilde f_1 = f_1 $$

$$ \tilde f_k = f_k - \sum_{j<k} \frac{\langle f_k, \tilde f_j\rangle}{\langle \tilde f_j, \tilde f_j\rangle}\,\tilde f_j $$

内积 $\langle a,b\rangle$ 在每期横截面上计算（等价于对标准化后的因子做回归取残差）。得到的 $\tilde f_k$ 与所有 $\tilde f_j (j<k)$ 正交。

这与[中性化](../05-因子/05-04-中性化.md)是同一个数学操作——中性化就是"把因子对市值、行业做正交化"，只是这里被剥离的对象换成了另一个因子。

### 顺序依赖问题

**施密特正交化最重要的性质是顺序依赖**：$f_1$ 保持原样，$f_2$ 被剥离掉与 $f_1$ 共享的部分，因此**排在第一位的因子拿走了全部共享信息**。

举例：若先用 BP 对动量做正交化，得到的"纯净动量"将不含任何价值成分，而 BP 仍保留它俩共享的那部分。交换顺序，结论完全相反。

实践建议：**按因子的可信度排序**——IC 更稳定、经济逻辑更强、文献支持更充分的因子排前面。或者干脆避免顺序依赖，改用下面的对称正交化。

### 对称正交化

对因子协方差（或相关）矩阵 $S$ 做变换：

$$ \tilde F = F S^{-1/2} $$

其中 $S^{-1/2}$ 由特征分解 $S = U\Lambda U^{\top}$ 得到 $S^{-1/2} = U\Lambda^{-1/2}U^{\top}$。结果是所有因子两两正交且**不依赖输入顺序**，代价是原始因子被整体混合，单个因子的经济含义更难解释。

| 方法 | 顺序依赖 | 可解释性 | 适用场景 |
| --- | --- | --- | --- |
| 施密特 | 有 | 较好（保留第一个因子原貌） | 有明确主次关系的因子 |
| 对称正交化 | 无 | 差 | 因子地位平等、追求稳定性 |
| 对风格因子回归取残差 | 有（取决于回归哪些） | 好 | 只需剔除市值/行业 |

## 四、PCA 降维

主成分分析把 $K$ 个相关因子变成 $K$ 个不相关的线性组合：

$$ PC_j = F \cdot v_j $$

其中 $v_j$ 是协方差矩阵的第 $j$ 大特征向量。看**方差解释率** $\lambda_j / \sum_k \lambda_k$，通常前 2~3 个主成分就能解释 70% 以上的共同变动。

PCA 在因子研究中的典型现象：**第一主成分几乎总是"市场/规模/价值"的混合体**，即所有因子共同的方向。这意味着第一主成分未必是你想要的 alpha，它可能只是最大的风险暴露。

PCA 的优缺点：

| 优点 | 缺点 |
| --- | --- |
| 彻底消除共线性 | 主成分无经济含义 |
| 降维后权重稳定 | 特征向量由历史样本决定，样本外不稳定 |
| 可自动决定保留几个成分 | 对输入因子的尺度敏感（必须先标准化） |

因此 PCA 更适合作为**诊断工具**（判断究竟有几个独立信息源），而不是最终的组合构造工具。若一定要用，建议只保留前 2~3 个成分，并在样本外检验其稳定性。

## 五、为什么要合成而不是堆叠

"把 20 个因子都放进模型"的诱惑来自误以为信息可以线性累加。实际约束是：

- **自由度有限**：估计 20 个因子的最优权重需要大量样本，样本不足时估计误差主导；
- **多重检验**：检验 20 个因子，即使全部无效，按 5% 显著性也期望有 1 个"显著"；
- **可解释性与可维护性**：20 个因子中某个数据源出错，排查成本极高。

正确路径是：**先用相关性诊断把 20 个归成若干簇 → 每簇合成一个代表因子 → 再用少数几个代表因子做最终合成**。这既是统计要求，也是工程要求。

## 六、代码：相关矩阵与正交化

```python
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab
from qd.factors.pipeline import orthogonalize, zscore, combine

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

names = ["bp", "ep", "mom_12_1", "vol_60", "roe_q"]

# 1) 相关矩阵：找出高度相关的因子对
corr = lab.correlation(names)
print(corr.round(2))
print("最高相关的两对:")
cm = corr.where(~np.eye(len(corr), dtype=bool)).abs().stack().sort_values(ascending=False)
print(cm.head(4))

# 2) 施密特正交化：把 ep 中对 bp 的共享部分剥离
orth = orthogonalize(["bp", "ep"], md=md)   # 顺序敏感：bp 在前，保留原貌
print("正交前 ep 的 IC:", lab.ic("ep"))
print("正交后 ep 的 IC:", lab.ic("ep_orth"))

# 3) 交换顺序，观察 IC 归属的变化
orth_rev = orthogonalize(["ep", "bp"], md=md)
print("反向正交后 bp 的 IC:", lab.ic("bp_orth"))

# 4) 正交化后再合成，权重更稳定
from qd.factors import get_factor
combined = combine([zscore(get_factor(n).compute(md)) for n in names], method="equal")
```

解读要点：正交后 `ep` 的 IC 下降，说明它原本的预测力有相当部分与 `bp` 共享；若下降后仍显著，则它确实提供了价值之外的增量信息，值得保留。

## 常见坑

1. **忘记先标准化就正交化**：量纲不同的因子做内积，结果被尺度大的因子主导。必须先 `zscore`。
2. **忽略顺序依赖**：施密特正交化后直接比较各因子 IC，会得出"第一个因子最重要"的错误结论——那只是排序造成的。
3. **逐期正交化 vs 全样本正交化**：必须在每个横截面上独立做；用全样本协方差一次性变换会把未来信息带入过去。
4. **过度正交化**：把所有因子两两正交一遍，剩下的残差可能只是噪声，IC 全部归零。
5. **把 PCA 第一主成分当 alpha**：它往往是最大的风险因子，实盘会带来巨大的集中暴露。
6. **相关矩阵不稳定**：用全样本估计的单一相关矩阵掩盖了时变性，应分年度检查相关矩阵是否漂移。
