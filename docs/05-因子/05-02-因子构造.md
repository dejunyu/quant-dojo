# 因子构造

## 学完这一篇，你能做到

- 说清"从原始行情到因子值"的四步链路，知道每一步最容易错在哪
- 理解"12-1 动量"为什么**故意跳过最近一个月**（这是本篇最该记住的一件事）
- 会手写几个常见因子，并把自定义面板交给平台检验
- 明白为什么"造出来的因子，大多数是没用的"

## 本篇要点

- 因子的起点不是公式，是**数据**；清洗比公式更决定成败
- 窗口选择是**偏差-方差权衡**：太短全是噪声，太迟钝抓不到变化
- 财报必须按**披露日**对齐，不是报告期（否则前视偏差）
- 造因子很容易，**证明它有用才是难的**

---

## 一、从"为什么跳过最近一个月"说起

1993 年，Narasimhan Jegadeesh 与 Sheridan Titman 在《金融学杂志》发表《买入赢家、卖出输家的收益》，把**动量效应**写成了可检验的规律：过去一段时间涨得多的股票，接下来一段时间平均还会继续跑赢。

但真正内行看这篇论文，会注意一个很奇怪的细节：他们算"过去涨了多少"时，**不是从昨天往回数 12 个月，而是从一个月前往回数 12 个月**——也就是**故意跳过最近一个月**。

这就是量化里鼎鼎大名的 **12-1 动量**（`mom_12_1`）：用 t-12 到 t-1 的收益，不用 t 最近那一段。

> **为什么要跳过？** 因为**短期是反转的**：最近一周、一个月涨太猛的股票，往往因为流动性冲击和过度反应而回调。
> 如果把最近一个月算进去，它含有的"反转噪声"会把中期动量信号**对冲掉**。
>
> 于是研究者做了个很朴素的处理：**把最吵的那一段丢掉，只留中段。**
>
> **这个动作，就是"因子构造"最好的缩影：**
> 因子不是"把数据代进公式"，
> **而是先想清楚"我要捕捉哪个机制、要避开哪个干扰"，再决定怎么切窗口、怎么清洗。**

Jegadeesh 与 Titman 的论文摘要里就写得很清楚：买入赢家、卖出输家在**形成后 3~12 个月**产生显著正收益，而"**组合形成后第一年的超额收益，会在随后两年消散**"——这已经是"因子衰减"的一手证据（05-07 会专门讲）。1993 年那篇的官方书目是 *JF* 48(1): 65–91（[AFA 官方目录](https://afajof.org/issue/volume-48-issue-1/)）。

另一个把"构造"讲得更透的例子是 **Robert Novy-Marx 2013 年的毛利润因子**：他用"毛利润 / 总资产"这**一个会计变量**排序，发现高盈利公司平均收益显著更高，而且**控制住盈利之后，价值策略反而更强**（*JFE* 108(1): 1–28，[NBER w15940](https://www.nber.org/papers/w15940)）。

> **一个变量的加入，改变了另一个因子的表现**——这正是后面 05-04 中性化、05-08 共线性要处理的问题。
> **一个因子的经济含义，从它怎么被构造出来的那一刻就定了。**

## 二、四步链路（逐个讲透）

标准构造链路：

| 步 | 干什么 | 最容易错在哪 |
| --- | --- | --- |
| **1. 取原始数据** | 收盘价、成交量、复权因子、财报科目、行业、市值 | 用了**不复权价**（02-03）；单位不统一（02-01） |
| **2. 算中间量** | 收益率、滚动和、滚动标准差、财务比率 | 窗口选错、`shift(-1)` 混进特征（02-04） |
| **3. 清洗** | 停牌、缺失、新股、极端值、中性化 | **最常被跳过，也最致命** |
| **4. 映射为暴露** | z-score、排名、行业内分位 | 全样本标准化泄漏未来（02-04） |

> **很多"因子失效"，其实根本不是想法错了，是第 3 步偷懒。**
> 比如没剔除停牌日：一只股票停牌三个月，复牌后补涨，
> 你的动量因子会把这段**按日历算出来的涨幅**当成"趋势强劲"，
> 于是买入一批刚复牌的股票——**回测很漂亮，实盘买不进**（03-01 讲过复牌涨停）。

补两个常识：

- **滚动（rolling）**：只用一个固定长度的近期窗口算，窗口往前滑；**扩展（expanding）**：从第一天算到当天，窗口越来越长。02-04 讲过，两者都只用历史，都合法。
- **`shift(1)` 是你的朋友**：信号里出现它，意味着"t 日用 t-1 日信息"，安全；`shift(-1)` 只能出现在标签里（02-04、02-07）。

## 三、窗口怎么选（单独讲透）

滚动窗口长度是典型的**偏差-方差权衡**：

| 窗口 | 交易日含义 | 典型用途 |
| --- | --- | --- |
| 5 / 10 | 周 / 双周 | 短期反转、情绪 |
| 20 | 一个月 | 短期动量、实现波动率、换手率 |
| 60 | 一个季度 | 中期反转、流动性 |
| 120 | 半年 | 波动率、beta |
| 250 | 一年 | **12-1 动量**、长期反转、盈利稳定性 |

> **窗口太长**：反应迟钝，抓不到状态切换；
> **窗口太短**：估计被噪声主导，换手率飙升（03-04 讲过换手是成本放大器）。

一个常被忽略的点：**因子的"保质期"和窗口是配套的**。
12-1 动量用一年数据构造，它捕捉的是"中期反应不足"，所以持有期通常也是周~月，不是日内。**用一年窗口造出的信号，别拿去做分钟级交易。**

> 波动率类因子的估计误差大致随 $\sqrt{T}$ 缩小——所以 20 日与 60 日波动率的差别，
> 主要来自**反应速度**，而不是"谁算得更准"。**别把"更稳定"误当成"更正确"。**

## 四、三类常见因子模板

| 类别 | 例子 | 构造要点 |
| --- | --- | --- |
| **价格类** | 动量 `mom_12_1`、反转 `rev_20`、波动 `vol_60` | 用复权价；注意符号方向 |
| **基本面类** | BP（市净率倒数）、ROE、毛利率 | **按披露日对齐**，用 point-in-time 快照 |
| **量能类** | 换手率、成交量比、Amihud 非流动性 | 用成交额而非成交量（跨所口径一致） |

> ⚠️ **基本面因子最大的坑**：财报的**报告期**（2023-12-31）与**披露日**（2024-04-10）差好几个月。
> 用报告期对齐，等于让模型在 1 月就"知道"了 4 月才公布的利润——**这是最标准的前视偏差**（02-04）。
> 正确做法是用 **point-in-time 快照**：站在历史上每个时点，只取当时已经公开的那一版数据。

> 补个常识：**BP** = Book-to-Price，账面价值 ÷ 市值，是"便宜程度"最经典的度量（01-05 的 HML 就靠它构造）。
> 名字里带 **P**（Price）的比率都要小心：**价格是每天变的，账面值一季才更新一次**——分子分母的时间口径必须对齐。

## 五、用平台手写四个因子并检验

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次。它手写 4 个因子、清洗、注册进因子库，然后统一算 IC：

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, volume, ret = md.close(), md.volume(), md.returns()

# 1) 5 日 / 60 日成交量比（短期放量）
vr = volume.rolling(5).mean() / volume.rolling(60).mean().replace(0, np.nan)

# 2) Amihud 非流动性：|r| / 成交额，取 20 日均值（03-05 讲过）
amount = volume * close
illiq = (ret.abs() / amount.replace(0, np.nan)).rolling(20).mean()

# 3) 60 日已实现波动率（年化）
vol60 = ret.rolling(60).std() * np.sqrt(252)

# 4) 60 日反转（符号取负：过去跌得多 → 因子值大）
rev60 = -close.pct_change(60)

# 清洗：上市不足 60 日、停牌过多的样本置为 NaN
for df in (vr, illiq, vol60, rev60):
    df[close.rolling(60).count() < 40] = np.nan

# 注册进因子库，之后就能像内置因子一样检验
lab = FactorLab(md)
lab.register("vr_5_60", vr, category="情绪", description="5/60 日成交量比")
lab.register("illiq_amihud", illiq, category="流动性", description="Amihud 非流动性")
lab.register("vol60", vol60, category="波动", direction=-1, description="60 日波动（反向）")
lab.register("rev60", rev60, category="反转", description="60 日反转")
for name in ("vr_5_60", "illiq_amihud", "vol60", "rev60"):
    print(name, round(lab.mean_ic(name, horizon=20), 4))
```

我实跑的结果：

```
vr_5_60      -0.0076
illiq_amihud -0.0214
vol60        -0.0024
rev60        -0.0734
```

**四个因子，IC 全是负的、而且都接近 0。**

> 请先别急着说"我造的因子没用"——**这恰恰是本篇最诚实、也最重要的一课。**
> 合成数据里只被**故意埋进**了弱动量、短期反转、价值、低波、质量等少量效应（00-01），
> 而这四个是我临时凑的：成交量比、Amihud、60 日波动、60 日反转。
> **它们没撞上被埋的规律，所以 IC 自然接近 0。**
>
> 换成真实数据，结果也大抵如此：**随手造出来的因子，绝大多数是没用的。**
> 这不是失败，是常态。01-03 讲流程时说过——
> **单因子检验阶段就否掉，成本是几小时；留到实盘才发现，成本是真金白银。**

`lab.register(name, panel)` 把自定义面板登记进因子库，之后 `FactorLab` 的全部工具（IC、分层回测、换手）都能直接用——**自定义因子和内置因子在分析上没有任何区别**，这也是平台刻意做的解耦（02-02 讲过）。

`rolling(60).count() < 40` 这类清洗是必要的：否则因子表开头一堆 NaN 行，会让 IC 的前若干期样本量极小、均值失真。

## 六、把这一篇串起来

回到那个"跳过最近一个月"的决定。

Jegadeesh 和 Titman 完全可以简单地算"过去 12 个月涨幅"，少一行代码。但他们知道**最近一个月里住着反转噪声**，所以主动把它剔掉。这个小小的取舍，比任何复杂的数学都更能说明什么是因子构造：

> **造因子不是"把数据代进公式"，是"想清楚要捕捉哪个机制、要躲开哪个干扰"。**
> 窗口、清洗、对齐、方向，每一步都是对机制的一次表态。

> 一句话收尾，也是 05-01 那句的续集：
> **造因子是容易的，造出"有理由成立"的因子才难。**
> 而下一组课文（05-03 到 05-06），讲的就是怎么把这四个近零的 IC，
> 逼到承认自己到底是不是巧合。
