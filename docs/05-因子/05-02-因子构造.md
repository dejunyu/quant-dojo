# 因子构造

因子的起点不是公式，而是数据。[什么是因子](../05-因子/05-01-什么是因子.md)给出了定义，本篇解决"怎么把一堆原始行情变成一张 `dates × symbols` 的因子暴露表"。

## 一、从原始数据到因子值的四步

标准的构造链路如下：

1. **取原始数据**：收盘价、成交量、复权因子、财报科目、行业分类、市值。
2. **算中间量**：收益率、对数收益率、滚动和、滚动标准差、滚动均值、财务比率。
3. **清洗**：处理停牌、缺失、新股上市不足 N 日、极端值（[去极值与标准化](../05-因子/05-03-去极值与标准化.md)）、市值行业[中性化](../05-因子/05-04-中性化.md)。
4. **映射为暴露**：z-score、排名、或行业内分位，得到可直接进入模型的因子值。

第 2 步决定因子的经济含义，第 3 步决定它的统计可用性，第 4 步决定它与后续加权方式的兼容性。很多"因子失效"问题其实出在第 3 步——比如没有剔除停牌日，导致复牌后的暴涨被误算成动量。

## 二、窗口（lookback）怎么选

滚动窗口长度是典型的偏差-方差权衡。窗口太长，因子反应迟钝，捕捉不到状态切换；窗口太短，估计被噪声主导，换手率飙升。

| 窗口 | 交易日含义 | 典型用途 |
| --- | --- | --- |
| 5 / 10 | 周 / 双周 | 短期反转、情绪类因子 |
| 20 | 一个月 | 短期动量、实现波动率、换手率 |
| 60 | 一个季度 | 中期反转、流动性 |
| 120 | 半年 | 波动率、beta 估计、技术分析指标 |
| 250 | 一年 | 动量 12-1、长期反转、盈利稳定性 |

经验规则：窗口内应至少包含 60 个以上的有效观测才能让矩估计相对稳定；对于波动率类因子，估计误差大致随 $\sqrt{T}$ 缩小，因此 20 日与 60 日波动率的差异主要来自"反应速度"而非"精度"。

实证上常见的做法是**用 IC 对窗口做敏感性扫描**：同一个因子在 20/40/60/120/250 下分别算 IC 均值，选 plateau（平台区）的中心，而不是选最高点——最高点几乎总是过拟合的产物（[过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)）。

## 三、价格类因子模板

价格是最容易获得的数据，动量、反转、波动类都出自这里。

**动量（跳过最近一个月）**：

$$mom_{12,1} = \frac{P_{t-21}}{P_{t-252}} - 1$$

跳过最近 21 个交易日是为了避开短期反转效应与买卖价差造成的虚假动量。

**短期反转**：

$$rev_{20} = -\Big(\frac{P_t}{P_{t-20}} - 1\Big)$$

**已实现波动率**（用日收益率序列）：

$$\sigma_{t}^{(T)} = \sqrt{\frac{252}{T}\sum_{k=0}^{T-1}\big(r_{t-k} - \bar r\big)^2}$$

**Amihud 非流动性**：

$$illiq_{t} = \frac{1}{T}\sum_{k=0}^{T-1}\frac{|r_{t-k}|}{\text{Amount}_{t-k}}$$

分子是收益率绝对值，分母是成交额，值越大表示单位成交额引起的价格冲击越大，即流动性越差。注意分母要用成交额（价格 × 成交量）而非成交量，否则高价股会被系统性低估非流动性。

## 四、基本面类因子模板

基本面因子的核心是**比率化**。绝对量指标（如净利润）会被市值主导，几乎等价于规模因子，因此必须除以市值或总资产。

| 因子 | 定义式 | 说明 |
| --- | --- | --- |
| EP | $\frac{\text{净利润}}{\text{总市值}}$ | 盈利收益率，价值因子 |
| BP | $\frac{\text{净资产}}{\text{总市值}}$ | 账面市值比，最经典的价值因子 |
| SP | $\frac{\text{营业收入}}{\text{总市值}}$ | 对小市值、低盈利公司更稳健 |
| ROE | $\frac{\text{净利润}}{\text{净资产}}$ | 质量因子核心 |
| 毛利率 | $\frac{\text{营收} - \text{营业成本}}{\text{营收}}$ | Novy-Marx 认为其预测力强于 ROE |
| 应计项目 | $\frac{\Delta \text{经营性应收} - \Delta \text{经营性应付}}{\text{总资产}}$ | 低应计为正向 |
| 营收增速 | $\frac{\text{营收}_t}{\text{营收}_{t-4}} - 1$ | 同比口径，避开季节性 |

使用财报数据时的铁律：**按披露日（announcement date）而非报告期（period end）对齐**。一季报的报告期是 3 月 31 日，但多数公司在 4 月中下旬才披露；若按 3 月 31 日入库，则引入了约三周的未来信息。这是[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)最重要的来源之一。

## 五、量能类因子模板

成交量数据提供的是"关注度"与"分歧度"信息。

- **成交量均值比**：$vr = \frac{\text{Vol}_5}{\text{Vol}_{60}}$，短期放量，常作为情绪因子。
- **换手率**：$turn = \frac{\text{Vol}}{\text{流通股本}}$，高换手在 A 股通常对应短期反转（负向）。
- **换手率变化**：$\Delta turn = turn_{20} - turn_{120}$，剥离了个股固有换手水平后的异常关注度。
- **资金流**：用逐笔成交方向（主动买/主动卖）加权的成交额净额，视数据源而定。

量能类因子的普遍问题是自相关强、换手率高，单独使用时需要检查交易成本是否吞掉边际收益（[因子衰减与换手](../05-因子/05-07-因子衰减与换手.md)）。

## 六、代码：手写因子并与内置因子对比

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close = md.close()
volume = md.volume()
ret = md.returns()

# 1) 60 日成交量均值比：短期放量 / 长期放量
vr = volume.rolling(5).mean() / volume.rolling(60).mean().replace(0, np.nan)

# 2) Amihud 非流动性：|r| / 成交额，取 20 日均值
amount = volume * close
illiq = (ret.abs() / amount.replace(0, np.nan)).rolling(20).mean()

# 3) 60 日已实现波动率
vol60 = ret.rolling(60).std() * np.sqrt(252)

# 4) 60 日反转（注意符号：过去跌得多 → 因子值大）
rev60 = -close.pct_change(60)

# 清洗：剔除上市不足 60 日与全样本停牌的样本
for df in (vr, illiq, vol60, rev60):
    df[close.rolling(60).count() < 40] = np.nan

# 组装成新的 MarketData 面板，交给 FactorLab 检验
from qd.data import MarketData
# 2) 把自定义面板注册进因子库，之后就能像内置因子一样检验
lab = FactorLab(md)
lab.register("vr_5_60", vr, category="情绪", description="5 日/60 日成交量比")
lab.register("illiq_amihud", illiq, category="流动性", description="Amihud 非流动性")
lab.register("vol60", vol60, category="波动", direction=-1, description="60 日已实现波动（反向）")
lab.register("rev60", rev60, category="反转", description="60 日反转")
for name in ("vr_5_60", "illiq_amihud", "vol60", "rev60"):
    print(name, round(lab.mean_ic(name, horizon=20), 4))
```

说明：`lab.register(name, panel)` 把自定义面板登记进因子库，之后 `FactorLab` 的全部检验工具（IC、分层回测、换手）都能直接用在它身上——自定义因子和内置因子在分析上没有任何区别。`rolling(60).count() < 40` 这类条件清洗是必要的——否则因子表开头的 NaN 行会让 IC 的前若干期样本量极小，均值失真。

## 常见坑

1. **报告期对齐**：财报按 period end 入库，是最隐蔽也最致命的前视偏差。必须按实际披露日映射。
2. **除权除息未复权**：用未复权价算动量，除权日会出现假的暴跌与假的反弹。务必使用后复权或复权因子还原的价格。
3. **停牌期填充**：停牌期间成交量记 0，会让 Amihud 等指标的分母为 0 产生 inf；停牌期间价格常用前值填充，会让收益率为 0，低估真实波动。
4. **新股与次新股**：上市初期涨停板导致收益率失真、换手率极高，应设 60~180 日的上市天数过滤。
5. **分母为负或接近 0**：PE 为负时 EP 会变成"更大的负数"，把亏损公司排成"最便宜"。处理方式是把负 PE 与正 PE 分开处理，或直接用 BP、SP 规避。
6. **窗口扫描选最高点**：选 IC 最高的窗口几乎必然踩到噪声，应选平台区。
