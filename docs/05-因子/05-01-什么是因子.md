# 什么是因子

## 学完这一篇，你能做到

- 用一句话说清"因子"到底是什么，并向不懂的人解释清楚
- 分清**特征、因子、信号**这三个天天被混用的词
- 说清因子收益从哪来，以及为什么它会有"保质期"
- 在平台上算出第一个因子，并做一次单因子检验

## 本篇要点

- 因子 = **横截面上可排序、能解释未来收益差异的共同特征**
- 因子是"暴露"，信号是"暴露 + 方向 + 阈值"的可执行判断
- 因子收益三类解释：风险补偿、行为偏差、套利限制
- 单因子检验三步：构造 → IC 检验 → 分层回测

---

## 一、从"便宜的股票更赚钱吗"说起

1992 年，芝加哥大学的**尤金·法马**（Eugene Fama）和**肯尼斯·弗伦奇**（Kenneth French）在《金融学杂志》发表《股票预期收益的横截面》（*JF* 47(2): 427–465），做了件看起来很朴素的事：把全市场股票按**市值**和**账面市值比**（通俗说"便宜还是贵"）分组，比较它们的长期收益。

结论震动了学界：只用 CAPM 的市场 beta 去解释横截面收益时，关系是**"平的"**（几乎无效）；而加入**规模**与**账面市值比**这两个容易测量的变量后，差异就被抓住了。二人在 1993 年《金融经济学杂志》的《股票与债券收益中的共同风险因子》里，才正式把 SMB / HML 构造成**三因子模型**。（01-05 讲收益分解时见过这条线，[AFA 官方目录](https://afajof.org/issue/volume-47-issue-2/)）

> ⚠️ **一个常被写错的细节**：**1992 年是"横截面证据 / beta 失效"，1993 年才是"三因子模型正式构造"**。
> 把两篇混成"1992 年提出三因子"，是这行最常见的以讹传讹。法马后来与 Lars Hansen、Robert Shiller 共获 **2013 年诺贝尔经济学奖**（[诺奖官网](https://www.nobelprize.org/prizes/economic-sciences/2013/press-release/)）。

> **这篇论文真正开创的，不是"价值股能赚钱"这个结论，而是一种提问方式：**
> **不去问"哪只股票会涨"，而是问"具备什么特征的股票，长期平均涨得更多"。**
>
> 这个转向，就是整个因子投资的起点。
> 从此研究的对象从**一只只公司**，变成了**一组组可排序的特征**——
> 市值、估值、动量、质量、低波动……每一个这样的特征，就是一个**因子**。

差不多同时，1993 年 **Jegadeesh 与 Titman** 发表《买入赢家、卖出输家的收益》（*JF* 48(1): 65–91），把"过去涨得多的股票短期还会继续涨"（**动量**）写成可检验的规律。此后三十年，学术界陆续"发现"了几百个这样的特征——多到 Campbell Harvey、Yan Liu、Heqing Zhu 在 2016 年《金融研究评论》那篇《……与预期收益的横截面》里，直接主张**新因子的 t 值门槛应该提高到 3.0 以上**，并说"多数已发表的发现很可能是假的"（*RFS* 29(1): 5–68）。这个局面被圈内叫作**"因子动物园"（Factor Zoo）**。

> ⚠️ **别把"316 个已发表因子"当成 2016 年那篇论文的结论**：精确数字出自作者 2014 年的工作论文，原文是"**至少 316 个因子被检验过**"，而且作者自己强调"这个数肯定偏低"。10 篇会专门讲这段。

> **但请先记住本篇最重要的一个警告：**
> **"被写进论文的因子"不等于"真能赚钱的因子"。**
> 试的次数够多，噪声里总能挑出几个看着显著的（这正是 01-03 那篇 AMS 论文说的）。
> 所以这一整章，讲的不只是"怎么造因子"，更是"**怎么诚实地检验一个因子**"。

## 二、因子的定义（逐个讲透）

> **因子 = 横截面上可排序、能解释未来收益差异的共同特征。**

三个关键词，缺一不可：

| 关键词 | 排除了什么 | 例子 |
| --- | --- | --- |
| **可排序** | 类别型标签 | "属于医药行业"不是因子，"行业内 ROE 排名"才是 |
| **解释未来收益差异** | 纯会计指标 | 营收数字本身不是因子，除非它能区分谁涨得多 |
| **共同** | 个股特有事件 | 某家公司中标大单不是因子，一批公司共有的属性才是 |

形式化地说，若第 t 期股票 i 的因子暴露为 $x_{i,t}$、未来一期收益为 $r_{i,t+1}$：

$$r_{i,t+1} = \alpha_t + \beta_t x_{i,t} + \varepsilon_{i,t}$$

| 符号 | 白话 |
| --- | --- |
| $x_{i,t}$ | 这只股票的因子值（比如 BP 排第几） |
| $r_{i,t+1}$ | 它下一段的收益 |
| $\beta_t$ | **斜率**：因子每高一点，收益平均多多少 |
| $\alpha_t$ | 与因子无关的基础收益 |
| $\varepsilon_{i,t}$ | 剩下的、解释不了的部分（残差） |

**$\beta_t$ 的符号决定因子方向**：为正说明"暴露越高、未来收益越高"（正向因子），为负则反过来。所谓**因子溢价**，就是长期持有高暴露组、做空低暴露组获得的那部分收益：

$$\text{Factor Return} = \bar r_{\text{high}} - \bar r_{\text{low}}$$

> 补个常识：**横截面（cross-section）** 是"同一时刻、所有股票"的那一刀（02-07 见过）。
> 因子天生是横截面的——它比较的是**同一天里谁排前面**，而不是某只股票自己的历史。
> 这也解释了 01-01 里那句：**因子是"相对"的，全市场一起涨，排名照样能分高下。**

## 三、三个天天被混用的词（单独讲透）

| 概念 | 回答的问题 | 能直接交易吗 | 例子 |
| --- | --- | --- | --- |
| **特征（feature）** | "它是什么样" | ❌ | 所属行业、上市地 |
| **因子（factor）** | "它排第几" | ❌，只是暴露 | BP、ROE、20 日动量 |
| **信号（signal）** | "买不买、买多少" | ✅ | "BP 最高的 100 只，等权月度调仓" |

> **一句话：特征回答"是什么"，因子回答"排第几"，信号回答"怎么下单"。**
> 因子是**原材料**，信号是**菜谱**。

这个区分有实际意义：同一个 BP 因子，可以映射成完全不同的信号——取前 10% 等权、行业内取前 3 名、或与动量相加后再排序。**混为一谈，回测亏钱时你就分不清该换因子还是换映射。**

补个常识：机器学习里常说 **feature（特征）**，量化里常说 **factor（因子）**。两者不完全等价，但"特征比因子宽泛"这层关系是通用的。

## 四、横截面因子 vs 时序因子

| | 横截面因子 | 时序因子 |
| --- | --- | --- |
| 比较对象 | 同一天、所有股票 | 同一资产、跨时间 |
| 回答 | "买哪只" | "现在该不该持有" |
| 典型 | 价值、质量、动量（截面）、低波 | 时间序列动量、CTA 趋势 |
| 剩下 1 只股票还成立吗 | ❌ | ✅ |

> **一个实用判据：如果股票池只剩 1 只标的，这个因子还算得出来吗？**
> 能 → 时序因子；不能 → 横截面因子。

时序因子常见于 [07-01 趋势跟踪](../07-策略/07-01-趋势跟踪.md) 与资产配置；它不要求横截面有足够多标的，单个期货合约也能做，但**无法自动剔除市场涨跌**，所以常配合波动率目标等仓位管理。

## 五、因子收益从哪里来（判断"保质期"的关键）

学术界对**因子溢价**有三种主流解释，并不互斥：

| 解释 | 说的是什么 | 保质期 |
| --- | --- | --- |
| **风险补偿** | 高收益是承担了无法分散的系统性风险 | 长期存在，但会周期性大幅回撤 |
| **行为偏差** | 投资者系统性犯错（反应不足 / 过度反应）造成错误定价 | 随市场结构变化而**衰减甚至反向** |
| **套利限制** | 卖空难、成本高、噪声交易者风险，使错误定价无法被消除 | 天然绑定小市值、高成本，**容量受限** |

> **为什么这一节值得记？** 因为它能回答 01-02 留下的问题：**"这钱凭什么轮到我赚？"**
> 一个因子如果没有任何机制解释，只是"历史上统计显著"，
> 那它大概率是数据挖掘的产物——**衰减最快、也最不该重仓**。

举两个对照：
- **价值因子**常被解释为风险补偿 + 行为偏差（便宜股被嫌弃），所以长期存在但能连亏好几年；
- **小市值、高波动、低流动性**上的异象，更多来自套利限制——它们难套利，所以效应强，但**装不下大钱**（03-05 讲过容量）。

## 六、经典因子家族总览

| 家族 | 代表因子 | 经济含义 | 经验方向 |
| --- | --- | --- | --- |
| 价值 | BP、EP、SP | 便宜的公司长期回报更高 | 正向 |
| 动量 | mom_12_1 | 过去赢家短期继续跑赢 | 正向 |
| 反转 | rev_1、rev_20 | 短期跌幅大者反弹 | 负向（短期） |
| 质量 | roe_q、毛利率 | 盈利能力强且可持续 | 正向 |
| 规模 | ln_mktcap | 小市值风险高、流动性差 | 负向 |
| 低波 | vol_60 | 低波动股票收益风险比更好 | 负向 |
| 流动性 | illiq（Amihud） | 流动性差的资产要求溢价 | 负向 |
| 情绪 | 预期修正、研报覆盖 | 情绪推动短期定价偏离 | 短期正、长期反 |

完整九大类清单见 [05-10 因子库总览](./05-10-因子库总览.md)。**表中"经验方向"来自文献，必须在本市场重新验证**——A 股与美股并不总是一致（01-05 讲过 A 股短期反转更强）。

## 七、因子投资 vs 主动选股

| | 主动选股 | 因子投资 |
| --- | --- | --- |
| 依赖 | 少数深度研究的标的 | 大量标的的统计规律 |
| 仓位 | 集中 | 分散 |
| 单笔优势 | 高，但样本极少 | 微弱，但样本极多 |

> **把微弱优势叠加成稳定优势，正是 [05-09 因子合成](./05-09-因子合成.md) 存在的理由。**
> 这也呼应 01-05 的 Grinold 基本定律：成绩 ≈ 准头 × √广度——
> **因子投资不追求看得准，追求"看的次数足够多"。**

## 八、用平台算第一个因子

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor, list_factors
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
print("股票数:", len(md.symbols), "日期:", md.dates[0].date(), "~", md.dates[-1].date())

# 1) 算因子暴露：一张 dates × symbols 的表
f = get_factor("mom_12_1")
expo = f.compute(md)
print("最后一日因子分布:\n", expo.iloc[-1].describe().round(3))

# 2) 单因子检验：IC + 分层回测
lab = FactorLab(md)
print("IC:", lab.ic("mom_12_1", horizon=20))
print("检验结论:", lab.report("mom_12_1")["verdict"])
```

我实跑的关键结果：

```
IC: ICSeries(mean=0.0287, n=1557)
检验结论: 通过：可以考虑进入组合（仍需样本外验证）
```

**`IC = 0.0287`** 读作"信息系数 0.0287"——因子值与未来收益的相关性。0.03 左右已经算不错（01-02 讲过）。**但请特别注意"通过"两个字后面的那句"（仍需样本外验证）"**：

> 平台说"通过"，只是说**在这份合成数据上**通过了它设的几道门槛。
> 合成数据是**故意埋了弱动量的**（00-01 讲过），所以这个结果几乎是设计出来的。
> **它证明的是"你的流程跑通了"，不是"动量因子在 A 股能赚钱"。**
> 真实结论必须换真实数据、做样本外检验（06 章）才能下。

`get_factor` 返回的因子对象只需 `md` 一个入参，输出标准的 `dates × symbols` 面板；后续 [05-03 去极值](./05-03-去极值与标准化.md)、[05-04 中性化](./05-04-中性化.md) 都在这张面板上进行。

## 九、把这一篇串起来

回到 1992 年那 6 个组合。

Fama 和 French 做的事，用今天的话说就是：**把"选股票"变成"给股票打分"**。这一转，让研究可以规模化、可以检验、可以复现——02-07 讲的向量化、01-03 讲的流程纪律，全都能用上了。

> 但规模化的代价也在这里：**当你能一天造出几百个因子，"挑出显著的"就变得太容易了**。
> 这就是 Factor Zoo 这个略带自嘲的名字提醒我们的事。

> 一句话收尾，也当整章的座右铭：
> **造因子是容易的，证明它不是巧合才是难的。**
> 所以 05-03 到 05-09 这七篇，讲的都是同一件事：**怎么把一个"看着有用"的因子，逼到承认自己到底有没有用。**
