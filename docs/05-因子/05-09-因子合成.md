# 因子合成

单因子的 IC 通常只有 0.02~0.05，单独使用很难撑起一个产品。合成的目的是把若干个**弱相关**的弱因子叠加成一个信息比率更高的复合因子。前提是：候选因子已经做过[去极值标准化](../05-因子/05-03-去极值与标准化.md)、[中性化](../05-因子/05-04-中性化.md)，且共线性已按[因子共线性和正交化](../05-因子/05-08-因子共线性和正交化.md)处理过。

## 一、五类合成方法对比

| 方法 | 公式 | 优点 | 缺点 | 数据需求 |
| --- | --- | --- | --- | --- |
| 等权 | $z = \frac{1}{K}\sum_k z_k$ | 无参数、最稳健、无过拟合 | 忽略因子强弱差异 | 无 |
| IC 加权 | $z = \sum_k \overline{IC}_k \cdot z_k$ | 强因子权重高，实现简单 | 忽略因子间相关 | IC 序列 |
| ICIR 加权 | $w \propto \Sigma^{-1}\mu$ | 理论最优 IR，考虑相关性 | 协方差估计误差大 | IC 协方差矩阵 |
| 最大化 IC | 广义特征向量解 | 直接优化目标 | 对协方差极敏感、易过拟合 | 因子协方差 + IC 向量 |
| 回归法 | Fama-MacBeth 估计因子收益 $f_{k,t}$ | 有经济含义，可做风险归因 | 需两阶段估计，误差累积 | 面板回归 |

### 1. 等权

把所有因子标准化后直接平均。它的理论依据是：当你对因子的相对强弱**没有可靠信息**时，等权是最小 regret 的选择。实务中，多个结构不同的因子（价值 + 动量 + 质量 + 低波）等权组合往往是很难被打败的基准。

### 2. IC 加权

$$ z_{i,t} = \sum_{k=1}^{K} \overline{IC}_k \cdot z_{i,t}^{(k)} $$

用各因子的历史 IC 均值作为权重。直觉上 IC 高的因子贡献更大。局限是完全忽略了因子间相关性：两个高度相关的因子会被重复加权，等效于给它俩共同的信息源双倍权重。

### 3. ICIR 加权（均值-方差解）

把每个因子的 IC 序列看作一个"资产"，我们想在它们之间分配权重以最大化合成 IC 的信息比率：

$$ \max_w \frac{w^\top \mu}{\sqrt{w^\top \Sigma w}} $$

其中 $\mu_k = \overline{IC}_k$，$\Sigma$ 是 IC 序列的协方差矩阵。解析解为

$$ w \propto \Sigma^{-1}\mu $$

这正是均值-方差优化的形式，因此继承了它的全部问题：**$\Sigma^{-1}$ 对估计误差极度放大**，尤其当因子高度相关时 $\Sigma$ 接近奇异，解出的权重会出现极端正负对冲。实践中必须加约束（权重非负、上限）、收缩估计（shrinkage）或降维。

### 4. 最大化 IC

直接求解使合成因子 IC 最大的权重，最终化为广义特征值问题：

$$ \max_w \frac{w^\top \mu}{\sqrt{w^\top V w}} $$

其中 $V$ 是因子暴露的横截面协方差矩阵（不同于 IC 协方差 $\Sigma$）。解为 $w \propto V^{-1}\mu$。方法优雅但对 $V$ 的估计误差同样敏感，样本外表现常不如等权。

### 5. 回归法（Fama-MacBeth）

两阶段估计：

1. 每期横截面回归 $r_{i,t} = \sum_k \beta_{k,t} x_{i,t}^{(k)} + \varepsilon_{i,t}$，得到当期的**因子收益** $f_{k,t} = \beta_{k,t}$；
2. 对 $\{f_{k,t}\}$ 求均值与协方差，按 ICIR 加权的方式确定长期权重。

优点是因子收益有明确经济含义（每单位暴露带来多少收益），且天然可分解归因；缺点是两阶段误差叠加，且需要先验地确定"哪些是风险因子、哪些是 alpha 因子"。

## 二、权重估计必须用滚动窗口

这是合成中最容易犯错、后果最严重的一点：**权重只能用截止到 $t$ 期的信息估计**。

$$ \hat w_t = f\big(\{\mathrm{IC}_s\}_{s \le t-\text{gap}}\big) $$

常见的做法是用过去 250 个交易日的 IC 均值滚动估计，并在估计期与持有期之间留出 **gap**（至少等于持有期 $h$），否则 IC 的计算窗口会与持仓期重叠，构成泄漏。

用全样本 IC 均值作为固定权重回测，是最典型的[前视偏差](../06-回测/06-03-前视偏差的十种来源.md)：它让 2018 年的组合用上了 2024 年才知道的因子强弱信息。

## 三、权重不稳定问题

即使滚动估计，权重也可能大幅摆动，带来两个后果：

- **换手激增**：权重变化直接导致持仓变化，成本上升（[因子衰减与换手](../05-因子/05-07-因子衰减与换手.md)）；
- **样本外失效**：权重的高频变化往往是在追逐噪声。

缓解手段：

1. 对权重做时间平滑（$\hat w_t = \lambda \hat w_{t-1} + (1-\lambda)\hat w_t^{\text{raw}}$）；
2. 加权重上限/下限约束；
3. 用更长的估计窗口（牺牲反应速度换稳定性）；
4. 直接用等权——在很多实证中，等权的样本外表现不输复杂加权。

## 四、机器学习合成的注意事项

用 GBDT、随机森林或神经网络把因子映射成收益预测，是当前的主流做法之一，但有三个必须守住的红线：

1. **时序泄漏**：标准的随机 K 折会把相邻交易日分到训练与验证集，模型只需"记住"邻近几天的价格就能拿高分。必须用**净化 K 折（purged k-fold）**并加 **embargo**（[样本内外与滚动前推](../06-回测/06-06-样本内外与滚动前推.md)）。平台提供 `purged_kfold`。
2. **样本量不足**：日频 × 几千只股票看似样本很多，但**独立样本数**远小于行数。按"每年独立预测次数"估算，十年日频数据也只有约 2500 个独立时间点。特征数一旦上百，过拟合几乎不可避免（[过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)）。
3. **可解释性缺失**：黑箱模型在亏损时无法归因，难以判断是否该下线。建议至少做特征重要性分析、分组单调性检查与因子暴露归因。

此外，机器学习模型的输出仍应回到标准检验流程：**合成因子算 IC → 分层回测 → 换手与成本评估**。任何跳过检验直接使用模型输出的流程都不可靠。

## 五、合成后的检验

合成不是终点，复合因子必须重新走一遍单因子检验：

- IC、ICIR 与 t 值是否优于最好的单因子；
- 5 分组收益是否单调；
- 换手率是否可控（合成常降低换手，因为各因子噪声相互抵消）；
- 分年度表现是否稳定，是否存在某一年贡献了全部收益。

若合成后的 IC 反而不如最好的单因子，说明合成过程引入了噪声（通常是协方差估计误差），应退回等权。

## 六、代码：IC 加权与等权对比

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import zscore, winsorize, combine
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

names = ["bp", "ep", "mom_12_1", "vol_60", "roe_q"]

# 1) 统一预处理：去极值 + 标准化
panels = {}
for n in names:
    panels[n] = zscore(winsorize(get_factor(n).compute(md), limits=(0.01, 0.99)))

# 2) 等权合成
equal = combine(list(panels.values()), method="equal")

# 3) IC 加权：权重 = 各因子 IC 均值（示意；实盘必须改用滚动窗口，否则是前视）
ic_mean = {n: lab.mean_ic(n, horizon=20) for n in names}
icw = combine(list(panels.values()), method="ic", weights=[ic_mean[n] for n in names])

# 4) 注册成因子后再对比检验（与内置因子的分析方式完全一致）
lab.register("combo_equal", equal, description="等权合成因子")
lab.register("combo_icw", icw, description="IC 加权合成因子")

print("单因子 IC:", {n: round(lab.mean_ic(n, horizon=20), 4) for n in names})
print("等权合成 IC:", round(lab.mean_ic("combo_equal", horizon=20), 4))
print("IC加权合成 IC:", round(lab.mean_ic("combo_icw", horizon=20), 4))
print("等权 5 分组（多空）:", lab.quantile_backtest("combo_equal", n_quantiles=5)["long_short"])
print("合成因子年化换手:", round(lab.turnover("combo_equal")["annual_turnover"], 1))
```

## 常见坑

1. **全样本权重**：用整段历史的 IC 均值定权重再回测，是最常见也最致命的前视偏差。
2. **忘记留 gap**：滚动 IC 的估计窗口与持仓窗口重叠，同样构成泄漏。
3. **协方差估计误差**：ICIR 加权解出极端权重（如 +3.5 与 -2.8），样本外必然崩。必须加非负与上限约束。
4. **合成前不做去极值标准化**：量纲不一致导致合成结果被某一因子主导。
5. **合成后不再检验**：直接上实盘，等于放弃了最后一道防线。
6. **机器学习用随机 K 折**：时序数据必须用 `purged_kfold` 并加 embargo。
