# 去极值与标准化

[因子构造](../05-因子/05-02-因子构造.md)产出的原始因子值往往量纲混乱、分布厚尾，直接拿去做 IC 检验或加权合成会得到误导性结果。预处理的目标只有一个：**让因子值在横截面上可比、可加、且不被个别观测支配**。

## 一、为什么要去极值

金融数据的分布远比正态厚尾。以 BP 为例，净资产为负的公司算出的 BP 会跑到极端负值；以换手率为例，重组复牌股的换手率可能是正常水平的数十倍。

不处理会引发三类问题：

1. **回归被支配**：最小二乘对残差平方最小化，一个离群点可以把横截面回归的斜率整体拉偏，进而污染[中性化](../05-因子/05-04-中性化.md)的结果。
2. **分组边界失真**：分 5 组时，若 99.5% 分位处有一个极端值，第 5 组的组间差异会被这个单一样本拉大，回测出的多空收益其实来自一只股票。
3. **标准化尺度被撑大**：极端值让横截面标准差虚高，导致绝大多数正常样本的 z-score 被压缩到接近 0，因子实际失去区分度。

## 二、三种去极值方法

### 1. 分位数法（winsorize）

把小于 $q_\alpha$ 的值替换为 $q_\alpha$，大于 $q_{1-\alpha}$ 的替换为 $q_{1-\alpha}$：

$$\tilde x = \min\big(\max(x, q_{\alpha}),\ q_{1-\alpha}\big)$$

常用 $\alpha = 0.01$ 或 $0.025$。优点是直观、与分布无关；缺点是把尾部信息整体丢弃，且阈值是分位数本身，样本量小时不稳定。

### 2. MAD 法（中位数绝对偏差）

先算中位数绝对偏差：

$$\mathrm{MAD} = \mathrm{median}\big(|x - \mathrm{median}(x)|\big)$$

再以中位数为中心截断：

$$\tilde x = \mathrm{clip}\Big(x,\ x_{med} - n \cdot 1.4826 \cdot \mathrm{MAD},\ x_{med} + n \cdot 1.4826 \cdot \mathrm{MAD}\Big)$$

常数 $1.4826$ 的作用是让 $1.4826 \cdot \mathrm{MAD}$ 在正态分布下成为 $\sigma$ 的一致估计（因为此时 $\mathrm{MAD} \approx 0.6745\sigma$）。通常取 $n = 5$（对应约 5 倍标准差）。优点是中位数与 MAD 本身对离群点免疫（击穿点高达 50%），比均值-标准差法稳健得多；缺点是对偏态分布的处理不对称性不敏感。

### 3. 均值 ± nσ 法

$$\tilde x = \mathrm{clip}\big(x,\ \mu - n\sigma,\ \mu + n\sigma\big),\quad n \approx 3$$

最简单，但 $\mu$ 与 $\sigma$ 自身已被离群点污染，厚尾分布下阈值会被撑得很宽，**实践中不推荐作为默认方法**。

| 方法 | 阈值 | 对分布的影响 | 适用场景 |
| --- | --- | --- | --- |
| 分位数 | 1%/99% | 直接削平两端 | 通用默认，分布未知时 |
| MAD | 中位数 ± 5×1.4826×MAD | 依中位数定位，较为对称 | 厚尾、偏态严重的基本面比率 |
| 均值 ± 3σ | $\mu \pm 3\sigma$ | 阈值易被离群点撑大 | 分布近似正态时 |

## 三、横截面标准化

标准化的目的是量纲统一。最常用的是每期横截面 z-score：

$$z_{i,t} = \frac{x_{i,t} - \mu_t}{\sigma_t}$$

其中 $\mu_t$、$\sigma_t$ 是第 $t$ 期所有股票因子值的均值与标准差。这是**逐期**做的，不做全样本统一——因为因子值的绝对水平会随市场状态漂移（例如牛市中 PE 普遍抬升），跨期统一尺度会引入伪时序变化。

两种变体值得了解：

- **市值加权标准化**：用市值加权的均值与标准差，避免大量小市值股票主导分布。A 股实践中很常见。
- **中位数/MAD 标准化**：$z = (x - \text{median}) / (1.4826 \cdot \text{MAD})$，与 MAD 去极值配套使用更自洽。

标准化之后的因子值大致在 $[-3, 3]$ 之间，量纲一致，这是多因子能够直接相加的前提（[因子合成](../05-因子/05-09-因子合成.md)）。

## 四、排名变换与正态变换

更激进的做法是**排名变换**：把因子值换成它在横截面上的百分位排名

$$u_{i,t} = \frac{\mathrm{rank}(x_{i,t}) - 0.5}{N_t} \in (0,1)$$

优点是完全免疫离群点、分布恒为均匀；代价是**丢失了强度信息**——第一名和第二名被压成相邻，而原本可能相差 10 倍。对于尾部驱动型因子（如反转），这会造成损失。

**正态分数变换**在排名基础上再做一次映射：

$$\tilde z_{i,t} = \Phi^{-1}(u_{i,t})$$

其中 $\Phi^{-1}$ 是标准正态的分位函数。它得到一个严格正态、且比 z-score 稳健的暴露，常用于需要正态假设的[因子合成](../05-因子/05-09-因子合成.md)方法（如最大化 ICIR 的均值-方差解）。

经验建议：分布严重偏态的基本面比率（ROE、应计）适合排名或正态变换；本来就比较对称的价格类因子（动量、波动率）用 z-score 即可。

## 五、处理顺序

顺序错了会得到不同的结果，标准流程是：

1. **去极值**（削平物理上不合理的值）→
2. **中性化**（回归剔除市值、行业，见[中性化](../05-因子/05-04-中性化.md)）→
3. **标准化 / 排名**（统一量纲）→
4. 合成或检验。

原因：若先标准化再去极值，极端值已经把 $\sigma$ 撑大，去极值阈值失去意义；若先标准化再中性化，回归残差的尺度不再统一，需重新标准化一遍。中性化本质是回归，回归对离群点敏感，所以去极值必须在它之前。

## 六、代码：完整预处理流水线

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import winsorize, zscore, rank
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

raw = get_factor("bp").compute(md)          # 账面市值比，厚尾典型
lab.register("bp_rank", raw.rank(axis=1, pct=True) - 0.5, description="BP 截面排名")
print("原始偏度:", float(raw.stack().skew()))

# 1) 去极值：分位数 1%/99%
w1 = winsorize(raw, lower=0.01, upper=0.99)

# 手工实现 MAD 法，便于理解公式
med = raw.median(axis=1)
mad = (raw.sub(med, axis=0)).abs().median(axis=1)
w2 = raw.clip(lower=med - 5 * 1.4826 * mad, upper=med + 5 * 1.4826 * mad, axis=0)

# 2) 标准化
z1 = zscore(w1)                              # 均值-标准差 z-score
r1 = rank(w1)                                # 横截面百分位排名

# 3) 对比：预处理前后 IC 均值
print("raw IC  :", lab.ic("bp"))
print("winsor  :", lab.ic("bp_w1"))
print("rank    :", lab.ic("bp"))
print("处理后偏度:", float(w1.stack().skew()))
```

流水线函数都是 `DataFrame` 进、`DataFrame` 出的纯函数，可以任意组合；注意它们默认按**行（横截面）**操作，因此每期独立，不会引入跨期信息。

## 注意事项

1. **先清洗再去极值**：若未剔除停牌、新股与 NaN，极端值本身可能是脏数据产生的（如分母为 0 的 inf），去极值只能掩盖而不能修复。
2. **不要把去极值当万能**：去极值只改变分布形状，不改变排序的中段。若因子本身无效，去极值救不回来。
3. **阈值也是参数**：1%/99% 与 5 倍 MAD 是行业惯例而非最优解，扫描多个阈值取最高 IC 会引入过拟合（[过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)）。
4. **负值与零的处理**：BP 为负、PE 为负时，去极值会把它们截断到同一边界，形成"并列"的大样本，需检查并列比例是否过高。
5. **标准化不是中性化**：z-score 只统一量纲，不剔除市值行业暴露。认为"标准化过就等于中性化了"是常见误解。
6. **排名变换会削弱尾部因子**：反转、低波这类收益集中在极端的因子，用排名变换后分组收益可能明显下降。
