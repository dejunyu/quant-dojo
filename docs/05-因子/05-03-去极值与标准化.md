# 去极值与标准化

## 学完这一篇，你能做到

- 说清"去极值"为什么是**替换**而不是**删除**
- 分清 winsorize / z-score / 排名变换各自解决什么问题
- 理解为什么这些看似无害的预处理，也会**泄漏未来信息**
- 会按顺序搭一条完整的因子预处理流水线

## 本篇要点

- 去极值不是删数据，是把极端值**拉回边界**，样本数不变
- 标准化让不同量纲的因子能比较；**必须逐横截面做，且只用历史参数**
- 处理顺序有讲究：先去极值 → 再标准化 → 再中性化
- 阈值（1% / 5% / 3 倍 MAD）是**人为选择**，必须写进因子定义

---

## 一、从一个工程师的名字说起

**查尔斯·温莎**（Charles P. Winsor，1895–1951）本来是工程师，后来成了生物统计学家。他没炒过股，但今天每一个做量化的人都在用他名字命名的操作：**winsorization（缩尾 / 去极值）**。

这个方法的想法特别朴素：数据里总会有几个离谱的值——可能真是极端行情，也可能只是录入错误。直接删掉会丢样本，留着又会带偏均值。于是温莎一派的做法是：

> **不删，把超出边界的值"拉回"到边界上。**

比如 90% 缩尾：小于 5% 分位的值，一律设成 5% 分位；大于 95% 分位的，一律设成 95% 分位。数据源自 1947 年 Hastings、Mosteller、Tukey 与 Winsor 合写的《小样本低阶矩：次序统计量的比较研究》，后经 Tukey 1962 年《数据分析的未来》系统化（[Wikipedia: Winsorizing](https://en.wikipedia.org/wiki/Winsorizing)）。今天 MSCI 编制价值/成长指数时，方法论文档里仍有一节就叫 "Winsorizing the Variable"（[MSCI 指数方法论](https://www.msci.com/eqb/methodology/meth_docs/MSCI_GIMIVGMethod_Feb2021.pdf)）。

> **这个故事里最该记住的一点：**
> **去极值不是量化行业发明的，是稳健统计的老传统。**
> 而它给你的第一个提醒是——**阈值是人为选的**。
> 1% 还是 5%、分位数还是"中位数 ± 3 倍 MAD"，没有标准答案，
> **所以必须把它写进因子定义里，否则别人无法复现你**（00-01、02-06 都强调过）。

---

## 二、为什么必须去极值（讲透）

因子面板里一个离谱的值，能同时毁掉三件事：

| 被毁的东西 | 怎么毁的 |
| --- | --- |
| 均值 / 标准差 | 一个极端值就能把 z-score 的分母撑大，让所有正常股票都被压成接近 0 |
| 回归 / 相关性 | 最小二乘对离群点极敏感，IC 会被一两只股票主导 |
| 分层回测 | 极端股全挤进 Q1 或 Q5，分组单调性变成假象 |

> 02-01 讲过"数据质量比数量重要"，05-01 讲过"因子是可排序的共同特征"——
> **一个极端值既不是"共同特征"，也不该有那么大的投票权。**

### 三种方法逐个说清

| 方法 | 怎么做 | 保留样本吗 | 适合 |
| --- | --- | --- | --- |
| **缩尾 winsorize** | 超界值拉回边界 | ✅ 保留 | 默认选择 |
| **截断 trimming** | 超界值直接丢弃 | ❌ 变少 | 一般不用（会改变样本） |
| **MAD 法** | 以中位数 ± n×MAD 为界 | ✅ | 比均值/标准差更抗极端值 |

**MAD**（Median Absolute Deviation，中位数绝对偏差）听着唬人，其实就是：
先找中位数，再看每个值离中位数有多远，取这些距离的**中位数**。它用中位数而不是均值，所以**极端值自己影响不了边界**——这正是"稳健统计"的核心思路（04-02 讲厚尾时见过同样的精神）。

> ⚠️ **别把 winsorize 写成"删除异常值"**：它替换、不删除，样本数 N 不变。
> 这两个词混用，回测里的样本量会悄悄对不上。

## 三、标准化：让不同因子能一起说话（逐个讲透）

BP 是 0~2 的小数，市值是对数后 20 多的数，动量是百分之几十——**量纲不同，没法直接相加**。标准化就是把它们都换算成"偏离均值几个标准差"：

$$z_{i,t} = \frac{x_{i,t} - \mu_t}{\sigma_t}$$

| 符号 | 白话 |
| --- | --- |
| $x_{i,t}$ | 股票 i 在 t 日的原始因子值 |
| $\mu_t$、$\sigma_t$ | **t 日横截面上**所有股票的均值、标准差 |
| $z_{i,t}$ | 标准化后："它比当天平均高几个标准差" |

> ⚠️ **两个致命细节**：
> ① **必须逐横截面（每行内部）做**，也就是 02-07 说的 `axis=1` 方向——
> 比较的是"今天谁排前面"，不是"这只股票比自己历史高多少"；
> ② **$\mu_t$、$\sigma_t$ 只能用截至 t 日的数据估计**。用全样本均值/标准差，
> 2018 年的 z 值里就混进了 2024 年的信息——**这是 02-04 讲过的前视偏差**。
> 看似只是"预处理"，照样能作弊。

### 排名变换（更稳，但会丢信息）

把因子值换成**百分位排名**，天然不受极端值影响，也不要求分布对称：

$$\text{rank}_{i,t} = \text{percentile}(x_{i,t}) \in [0, 1]$$

代价是**丢掉了"差多少"**：第一名比第二名强一点点，还是强十倍，排名里看不出来。所以：
- 数据脏、厚尾明显（04-02）→ 用排名更稳；
- 想保留强度差异、做加权合成（05-09）→ 用 z-score 更合适。

## 四、处理顺序：为什么不能乱

标准顺序：

```
去极值 → 标准化 → 中性化 → （可选）排名
```

> **为什么去极值要在标准化之前？**
> 因为 z-score 的分母是标准差，**极端值会先把标准差撑大**，
> 再标准化就等于"让离群点自己把尺子改了"，正常股票全被压扁。
> **先把尺子上的坏刻度修好，再量。**

> **为什么中性化放最后？**
> 中性化是对风格暴露做回归取残差（05-04），回归对量纲和离群点敏感，
> 所以要先有一份干净、同尺度的输入。

## 五、用平台跑一条完整流水线

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import winsorize, zscore
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

raw = get_factor("bp").compute(md)
print("原始偏度:", round(float(raw.stack().skew()), 4))

# 1) 缩尾去极值（分位数口径）
w = winsorize(raw, lower=0.01, upper=0.99)
# 2) 横截面标准化
z = zscore(w)
# 3) 排名变换（对照）
r = w.rank(axis=1, pct=True) - 0.5

lab.register("bp_raw", raw)
lab.register("bp_wins", w)
lab.register("bp_rank", r)
for name in ("bp_raw", "bp_wins", "bp_rank"):
    print(name, "IC:", round(lab.mean_ic(name, horizon=20), 4))
print("处理后偏度:", round(float(w.stack().skew()), 4))
```

我实跑的结果：

```
原始偏度: 1.5223
处理后偏度: 1.4086
bp_raw  IC: -0.0105
bp_wins IC: -0.0105
bp_rank IC: -0.0105
```

**三个 IC 一模一样（-0.0105），偏度只从 1.52 降到 1.41。**

> 请先别失望——**这恰恰是本篇最诚实的一课**：
> 这份合成数据里 `bp` 本来就没被埋入很强的价值效应，而且极端值不算多，
> 所以去极值 / 标准化 / 排名**几乎不改变结论**。
>
> **预处理不是"提升因子"的魔法，它是"防止因子被数据缺陷骗到"的保险。**
> 数据干净时你看不出它干了什么；数据一脏，没做和做了会差出一条回测曲线。
> 这和 03-01 那段"约束打开反而变好"是同一个道理：**保险的价值，要在出事那天才看得见。**

## 六、把这一篇串起来

回到温莎。

他当年处理的是生物统计里的小样本，今天我们在 3000 只股票的面板上做同样的事。工具变了，判断没变：**极端值不该被无条件相信，也不该被随便丢掉**。

> 这一整章有个隐藏主线：05-02 造因子 → 本篇洗因子 → 05-04 剥离不想要的暴露 →
> 05-05 / 05-06 检验它。**每一步都不增加信息，只是不让信息被污染。**

> 一句话收尾：
> **去极值改的是"刻度"，标准化改的是"尺子"，
> 而它们共同守住的，是"别让一只异常股票替全市场做决定"。**
