# 美股与港股规则

## 一、美股：交易与结算

| 项目 | 美股 | 说明 |
| --- | --- | --- |
| 交易时间（美东） | 盘前 04:00–09:30，常规 09:30–16:00，盘后 16:00–20:00 | 不同券商开放时段不同 |
| T+0 | 支持 | 当日买入可当日卖出 |
| 结算周期 | **T+1**（2024 年 5 月起由 T+2 缩短） | 现金账户卖出后需 1 个交易日资金才到账 |
| 涨跌幅限制 | 无个股涨跌幅限制；有全市场熔断机制 | 熔断规则视交易所规则而定 |
| 最小变动价位 | $0.01 | 报价也可能以更小单位显示 |
| 碎股 | 多数券商支持部分券商的分股（fractional shares） | 视券商而定 |
| 交易单位 | 无"手"的概念，1 股起 | 部分低价股与期权有差异 |

### T+0 不等于无限制：PDT 规则

美股的保证金账户受 **Pattern Day Trader（PDT）** 规则约束：若 5 个交易日内进行 4 次及以上日内交易（day trade），账户需维持最低净值门槛（通常为 $25,000），否则会被限制买入（具体以监管机构与券商规定为准）。对策略的意义：

- **小资金账户无法实现高频日内策略**。要么提高资金量，要么降低日内交易频率，要么使用现金账户（现金账户无 PDT，但受"结算前不可再卖出"的良币规则约束，即 free-riding 限制）。
- 因此，**日内策略的实际门槛是资金规模，不是技术**。

### 盘前盘后的陷阱

盘前盘后时段流动性极差：**买卖价差可能是常规时段的 5~10 倍**，成交量集中在少数几只股票上。用盘前价格做信号、用常规时段成交，或者用盘后数据做回测，都会产生严重偏差。建议：**研究和回测只用常规时段数据**。

## 二、港股：交易与结算

| 项目 | 港股 |
| --- | --- |
| 交易时段 | 早市 09:30–12:00，午市 13:00–16:00（含收市竞价时段，具体时段以交易所规则为准） |
| T+0 | 支持 |
| 结算 | **T+2** |
| 涨跌幅 | 无个股涨跌幅限制；有市场波动调节机制（冷静期） |
| 交易单位 | **每手股数不固定**（由发行人决定，可能是 100、500、2000 股等） |
| 价位 | 按股价分档，tick size 随价格区间变化 |

港股的"每手股数不固定"是回测中最容易出错的地方：**必须按标的单独取整**，不能用统一的 100 股。忽略这一点会让你在某些标的上系统性买入过多（资金不足）或过少（权重偏低）。

## 三、三地市场对比

| 维度 | A 股 | 美股 | 港股 |
| --- | --- | --- | --- |
| T+0 交易 | 否（T+1） | 是 | 是 |
| 结算 | T+1 | T+1 | T+2 |
| 涨跌幅限制 | 有（10%/20%/30%） | 无（有熔断） | 无（有调节机制） |
| 交易单位 | 100 股 | 1 股 | 每手不固定 |
| 卖空难度 | 高 | 中（需 locate） | 中（有指定证券名单） |
| 印花税 | 卖出 0.1% | 无 | 双边（另有多项交易费用） |
| 股息税 | 按持股期限差异化（A 股个人投资者规则视税收规定而定） | 预扣（非居民通常 30%，税收协定可降低） | 视情况（港股通有特定规则） |

## 四、做空：locate 与保证金

美股做空的流程是：

1. **Locate（找券）**：券商必须确认能借到股票才能执行卖单。若股票"hard to borrow"（难借），可能无法做空。
2. **借券利息**：按年化利率按日计息，热门做空标的的年化借券成本可能很高（视供需而定，部分标的极高）。
3. **保证金**：做空需缴纳保证金（通常为市值的一定比例），且股价上涨时保证金要求上升。
4. **股息责任**：做空方在除息日**需要支付**股息给借出方。
5. **轧空风险（short squeeze）**：若股价快速上涨且借券供给枯竭，券商可能强制召回（recall），你被迫在高位平仓。理论上做空的损失**无上限**（股价可以无限上涨），而多头损失最多为 100%。

对策略的意义：**做空不是"多头镜像"**。它的成本更高、风险不对称、且容量受借券供给限制。一个多空策略的"空头腿"往往比"多头腿"难实现得多，很多机构因此只做多头（long-only）或多头 + 期货对冲。

## 五、税务要点

- **美股股息预扣税**：非美国税务居民的美股股息通常被预扣（法定税率 30%，税收协定下可降至更低，具体取决于居民国与券商处理）。预扣发生在派息时，对长期持有高股息股票的组合影响显著。
- **资本利得税**：非居民通常不就美股资本利得缴美国税（具体视税务身份与协定而定），但居民国可能有纳税义务。
- **港股**：港股通渠道下的股息与资本利得处理有特定规则（视内地与香港相关安排而定）。
- **实践建议**：税务规则复杂且随政策变化，**回测中应保守估计股息税**，且不要把它当作可优化项——靠税务套利赚钱通常需要专业结构与合规支持。

## 六、在回测中表达这些差异

```python
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import dual_momentum
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
strategy = dual_momentum(lookback=120)

# A 股口径：T+1 + 涨跌停 + 印花税（卖出）+ 佣金
a_cfg = BacktestConfig(
    initial_cash=1_000_000, commission_rate=0.00025, stamp_duty=0.001,
    lot_size=100, price_limit=0.10, t_plus_one=True,
)

# 美股口径示意：T+0、无涨跌幅、无印花税、1 股起、点差成本
us_cfg = BacktestConfig(
    initial_cash=1_000_000, commission_rate=0.0, stamp_duty=0.0,
    lot_size=1, price_limit=None, t_plus_one=False,
)

for name, cfg in [("A-share", a_cfg), ("US-style", us_cfg)]:
    res = Backtest(md, strategy, cfg).run()
    m = perf_report(res.equity, rf=0.02)
    print(name, {k: round(v, 4) for k, v in m.flat().items() if k in ("sharpe", "annual_return")})
```

这个对比的目的不是得出"哪个市场更好"，而是让你看到：**同一个策略在不同交易制度下的表现差异，可能远大于策略参数调整带来的差异**。做跨市场策略时，规则适配是第一步。

## 常见坑

- **用 A 股规则回测美股**（或反之）。最典型的错误是把 T+1 约束套到美股上，或者给美股加涨跌幅限制。
- **忽略结算周期**。T+2 结算下，卖出资金不能立即用于买入（现金账户），这会让高换手策略无法执行。
- **假设做空总能成交**。没有 locate 就没有空单，这是硬约束。
- **用盘前盘后价格做信号**。流动性极差，价差极大，回测结果不可信。
- **忽略港股每手股数不固定**，导致权重系统性偏差。
- **忘记做空要付股息**。做空高股息股票时，除息日会有一笔现金流出，长期做空的成本被显著低估。
