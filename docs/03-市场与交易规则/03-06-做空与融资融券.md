# 做空与融资融券

## 一、做空的机制

做空（short selling）的完整流程是五步：

1. **借券（locate / borrow）**：从券商或证券出借方借入股票。必须先确认"有券可借"才能下单。
2. **卖出**：在市场上卖出借来的股票，收到现金（但这笔现金通常被冻结为保证金）。
3. **维持保证金**：账户中必须维持一定比例的保证金（初始保证金与维持保证金，比例视券商与市场规定而定）。
4. **买回（cover / buy to cover）**：日后在市场中买回同样数量的股票。
5. **还券**：把股票归还给借出方，了结交易。

净利润为：

$$\Pi = (P_{\text{sell}} - P_{\text{buy}}) \times Q - \text{借券利息} - \text{交易成本} - \text{股息支付}$$

**三个必须记住的不对称性**：

1. **损失无上限**：股价可以无限上涨，做空理论上亏损无限；而多头最多亏 100%。
2. **收益上限 100%**：股价最多跌到 0，所以做空最多赚 100%（加上杠杆则是倍数关系）。
3. **时间不站在你这边**：借券利息按日计息，持有越久成本越高；而多头没有持有成本。

第 3 点是最容易被忽略的：**做空是一个负 carry 的头寸**。长期做空需要持续的理由，而长期做多不需要。

## 二、融券成本

A 股的融资融券（两融）业务中，融券成本主要包括：

| 项目 | 说明 |
| --- | --- |
| 融券费率 | 按年化计息，按实际占用天数收取。不同标的费率不同，具体以券商公布为准 |
| 融资利率 | 借入资金买入（加杠杆）的年化利率 |
| 保证金比例 | 需缴纳的保证金占市值比例，视券商规定而定 |
| 交易费用 | 与普通交易相同的佣金、印花税等 |
| 权益补偿 | 除息时需向出借方支付相应股息；送转时需调整数量 |

一个完整的成本估算（示意性，假设年化融券费率 8%，市值 100 万，持有 60 天）：

$$\text{利息} = 1{,}000{,}000 \times 8\% \times \frac{60}{365} \approx 13{,}151 \text{ 元} \approx 1.3\%$$

即 60 天的持有成本是 1.3%。**对市场中性策略，这意味着空头腿的毛 alpha 至少要超过 1.3% 才能盈亏平衡**——而多空两侧的 alpha 通常是同一量级的，所以融券成本常常吃掉中性策略一半以上的收益。

## 三、为什么 A 股做空难

| 障碍 | 具体表现 |
| --- | --- |
| 券源稀缺 | 可融券的标的数量远少于可买标的；热门做空标的常常无券 |
| 券源不稳定 | 借到的券可能被出借方随时召回（recall），被迫平仓 |
| 费率较高 | 融券年化费率通常显著高于融资利率，部分标的更高（视市场供需而定） |
| 标的限制 | 部分标的被调出融券标的名单，或暂停融券卖出 |
| 制度约束 | 融券卖出有价格限制（如不得低于最近成交价，视交易所规则而定） |
| 折算率与保证金 | 保证金比例与担保物折算率随市场波动调整 |
| T+1 | 当日融券卖出后当日不能买券还券（相关规定视交易所规则而定），日内做空受限 |

综合结果是：**A 股的多空策略在实盘中往往只能实现"多头腿"，空头腿要么放弃，要么用股指期货替代**。这也是 A 股市场中性产品普遍使用 IC/IF/IM 期货对冲的原因——期货做空没有券源问题，代价是承担基差风险（见 [03-07-指数ETF与期货基础](./03-07-指数ETF与期货基础.md)）。

## 四、轧空（Short Squeeze）

轧空的机制链条：

$$\text{股价上涨} \rightarrow \text{空头浮亏} \rightarrow \text{保证金不足} \rightarrow \text{被迫买回} \rightarrow \text{进一步推高股价}$$

触发条件通常是：

1. 该股票的**做空比例（short interest）高**，即空头持仓占流通股的比例大。
2. 流通盘小、可借券数量少（供给刚性）。
3. 出现利好催化（业绩超预期、题材炒作）。
4. 股价上涨触发连锁强平。

常用的观测指标：

- **Short Interest / 流通股**：空头持仓占比。
- **Days to Cover** = 空头持仓量 / 日均成交量：表示空头全部平仓需要多少天的成交量。值越大，轧空潜力越大。

$$\text{Days to Cover} = \frac{\text{Short Interest}}{ADV}$$

对策略的意义：**做空高 short interest 的小盘股是危险的**，无论你的模型说它应该跌多少。历史上有多起著名的轧空事件，参与的空头在几天内损失惨重，而基本面判断事后看是对的——**方向对了，但时间上被强制出局**。

## 五、融资（加杠杆）的另一面

融资买入（margin buying）是做多的杠杆，机制不同但风险同源：

| 风险 | 说明 |
| --- | --- |
| 强制平仓 | 维持担保比例低于平仓线时，券商强制卖出，且通常在最差的价格 |
| 杠杆放大回撤 | 2 倍杠杆下，标的跌 30% 则账户跌 60%（未计利息） |
| 利率成本 | 融资利率按日计息，长期持有成本高 |
| 集中度限制 | 单一标的的融资比例通常受限 |

**关键认识**：杠杆不提高夏普比率，只放大收益与风险。真正的杠杆应该来自"波动率目标"（见 `vol_target` 策略）——在波动率低时加仓、波动率高时减仓，而不是恒定加杠杆。

## 六、在回测中表达做空约束

```python
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import pairs_trading
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

# 配对交易：多一个、空一个，天然依赖做空能力
strategy = pairs_trading(lookback=120, entry_z=2.0, exit_z=0.5)

# 无融券成本（乐观，仅作对照）
optimistic = Backtest(md, strategy, BacktestConfig(
    initial_cash=1_000_000, allow_short=True, borrow_rate=0.0)).run()

# 含融券成本（示意年化 8%）与保证金占用
realistic = Backtest(md, strategy, BacktestConfig(
    initial_cash=1_000_000, allow_short=True, borrow_rate=0.08,
    margin_ratio=0.5)).run()

for name, res in [("无融券成本", optimistic), ("融券 8%", realistic)]:
    m = perf_report(res.equity, rf=0.02)
    print(name, {k: round(v, 4) for k, v in m.flat().items() if k in ("sharpe", "annual_return")})

# 空头腿占比：占比越高，融券成本影响越大
short_notional = res.weights.clip(upper=0).abs().sum(axis=1)   # 逐日空头敞口
print("空头名义占比均值:", round(short_notional.mean(), 4))
```

对比两条曲线，你会直接看到融券成本对市场中性策略的杀伤力。**如果差距大到让策略从"可用"变成"不可用"，那么正确结论不是调参，而是换用期货对冲或减少空头暴露**。

## 常见坑

- **回测假设随时可以做空、无限券源、零成本**。这是市场中性策略回测虚高的首要原因。
- **忽略召回风险**。券被召回时你必须在最差的时点平仓，这不是成本项而是强制的时点风险。
- **认为做空只是"负的多头"**。二者的成本结构、风险形状、容量约束完全不同。
- **做空高 short interest 的小盘股**，轧空风险无法用止损控制（跳空时止损失效）。
- **忽略做空要付股息**。做空高股息标的，除息日会有一笔现金流出，长期持有成本被低估。
- **用恒定杠杆而不做波动率目标**。恒定杠杆在波动率上升时会放大回撤，而波动率目标会自动降仓。
