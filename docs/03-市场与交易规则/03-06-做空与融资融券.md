# 做空与融资融券

## 学完这一篇，你能做到

- 用一句话说清"做空"到底在做什么，以及为什么它的风险和做多**不对称**
- 讲明白融券成本、保证金、强制平仓分别是什么
- 用 2021 年 GameStop 事件解释什么叫"轧空"，以及"方向对了却亏光"
- 知道在回测里怎么把做空约束表达出来

## 本篇要点

- 做多最多亏 100%（跌到 0），**做空理论上亏损没有上限**（股价可以一直涨）
- 融券不是免费的：借券要付息、要占保证金、还可能被随时要求归还
- **轧空** = 股价上涨 → 空头被迫买回 → 进一步推高股价，自我强化的死亡螺旋
- 杠杆不提高夏普，只放大收益与风险

---

## 一、从一群散户逼退对冲基金说起

2021 年 1 月，美国一家叫 GameStop 的游戏零售商成了全球焦点。

它是一家被普遍看衰的公司——线下卖游戏光盘，面对数字下载的冲击，机构大举做空。**据当时报道，被做空的股数一度达到流通盘的约 140%**（超过 100% 意味着同一股被借出、再被卖空了不止一次）。（[Wikipedia: GameStop short squeeze](https://en.wikipedia.org/wiki/GameStop_short_squeeze)）

Reddit 论坛 r/wallstreetbets 上的散户发现了一件事：**空头持仓太拥挤了**。他们集体买入股票和看涨期权，把股价推高。当月 GME 一度累计上涨约 **1,625%**，1 月 29 日收于 **325 美元**。

接下来的链条是自动运转的：

> 股价涨 → 空头浮亏 → 保证金不足 → **被迫买回股票平仓** → 买盘进一步推高股价 → 更多空头被强平……

几家做空的对冲基金损失惨重。**据报道**，Melvin Capital 在 2021 年 1 月单月亏损 **53%**，资产管理规模从年初约 125 亿美元降至月末 80 多亿美元，并接受 Point72 与 Citadel 合计 27.5 亿美元注资才撑下来（WSJ 首报，Reuters / Bloomberg 转引）。**1 月 28 日**，Robinhood 等券商限制/暂停 GME 买入，引发巨大争议。（[Reuters / CGTN 全文](https://news.cgtn.com/news/2021-02-01/Melvin-Capital-loses-53-in-January-due-to-GameStop-drama-XwdvDWoBxK/index.html)、[ABC News](https://www.abc.net.au/news/2021-01-29/gamestop-stock-price-crash-as-robinhood-restricts-buying-shares/13101670)）

> ⚠️ **数字要标"据报道"**：这类基金的仓位与亏损并非公开披露，来自消息人士，不同媒体口径不一。
> 网上流传的"亏 45 亿美元""盘中最高 483 美元"等数字缺乏一手佐证，**不要当硬事实引用**。

> **这个故事最刺痛人的地方，不是散户赢了，而是：**
> **空头对公司基本面的判断，事后看很可能是对的**——GameStop 的生意确实在走下坡。
> 但他们**方向对了，却死在时间上**：在价格回归"正确"之前，保证金先撑不住了。
>
> 这就是做空最本质的一句话：
> **做多你可以扛，做空你不能扛。** 市场可以在很长时间里保持"非理性"，而你的保证金等不了那么久。

## 二、做空到底在做什么（讲透）

一句话：**先借来股票卖掉，等价格跌了再买回来还回去，赚中间的差价。**

```
借入 100 股（约定日后归还）→ 以 50 元卖出，拿到 5000 元
→ 股价跌到 30 元 → 花 3000 元买回 100 股还回去
→ 赚 2000 元（未扣融券费）
```

| | 做多 | 做空 |
| --- | --- | --- |
| 操作顺序 | 先买后卖 | **先卖后买** |
| 最大盈利 | 无上限 | 最多 100%（跌到 0） |
| **最大亏损** | **100%**（跌到 0） | **无上限**（股价可以一直涨） |
| 亏了能扛吗 | 能，最坏归零 | 不能，可能被强平在最高点 |

> ⚠️ **这个不对称是全部风险的源头。**
> 做多时，"不止损"最坏也就是归零，你还能等；
> 做空时，价格每涨一分，你的浮亏都在扩大，**而且没有天花板**。
> 所以圈内那句老话：**"做空是唯一一种你正确也可能破产的交易。"**

### 三个必须知道的成本

| 成本 | 是什么 | 为什么致命 |
| --- | --- | --- |
| **融券费（borrow rate）** | 借股票要付的年化利息 | 按天计息，**持有越久越贵**，热门做空标的费率可能极高 |
| **保证金（margin）** | 押在券商那里的抵押品 | 浮亏扩大 → 维持担保比例下降 → 补钱或被强平 |
| **召回（recall）** | 出借人随时可以要求还券 | 你可能被迫在最差的价位平仓 |

> 补个常识：**维持担保比例** = 你账户里的资产 ÷ 借来的负债。低于券商的平仓线时，
> 券商会**不问你同意就卖掉你的持仓**——这就是 GameStop 里"被迫买回"的机制。

## 三、轧空（Short Squeeze）单独讲透

轧空的机制链条：

$$\text{股价上涨} \rightarrow \text{空头浮亏} \rightarrow \text{保证金不足} \rightarrow \text{被迫买回} \rightarrow \text{进一步推高股价}$$

**注意最后一个箭头指回开头**——这是个正反馈闭环，不是一次性的下跌。所以它一旦启动，速度远超基本面变化。

触发条件通常是四条同时具备：

1. **做空比例高**（short interest 占流通股比例大）；
2. **流通盘小、可借券少**（供给刚性，想买回也买不到）；
3. 出现**利好催化**（业绩超预期、题材、论坛号召）；
4. 上涨触发连锁强平。

常用的观测指标：

$$\text{Days to Cover} = \frac{\text{Short Interest}}{ADV}$$

逐个拆：分子是**空头持仓量**，分母 $ADV$ 是**日均成交量**。整个式子的意思是——

> **"如果所有空头同时想平仓，按平时的成交量，需要多少天才能买完？"**
> 值越大，说明空头越拥挤、越买不回来，**轧空潜力越大**。GameStop 之所以极端，正是因为 140% 的做空比例配上有限的流通盘。

> 补个常识：**short interest（空头持仓）** 是公开数据，交易所/数据商会定期披露。
> **它是少数能提前观测到的"拥挤度"指标**——01-02 讲因子拥挤时说过，
> 拥挤不只让收益变少，更会让风险变大，轧空就是最暴烈的版本。

## 四、A 股为什么做空难

| 难点 | 说明 |
| --- | --- |
| **券源少** | 融券标的受名单限制，能借到的股票和数量都有限 |
| **成本高** | 融券费率普遍高于成熟市场，且借券不稳定 |
| **T+1 叠加** | 个股当日买入不可卖，融券卖出也受相应约束（见 [03-01](./03-01-A股交易规则.md)） |
| **政策变动** | 极端行情下监管可能暂停或收紧融券 |

所以 A 股常见的"市场中性"实现，往往不是真融券做空个股，而是用**股指期货对冲**把大盘 beta 减掉（见 [03-07](./03-07-指数ETF与期货基础.md)）。

> 这就解释了 01-01 里那句"市场中性 = 把 beta 对冲掉"在 A 股的具体落地：
> **不是空股票，是空指数。**

## 五、融资（加杠杆）的另一面

融资买入是"借钱做多"，机制不同但**风险同源**：

| 风险 | 说明 |
| --- | --- |
| 强制平仓 | 维持担保比例低于平仓线时，券商强制卖出，且常在**最差的价格** |
| 杠杆放大回撤 | 2 倍杠杆下，标的跌 30% → 账户跌 60%（未计利息） |
| 利率成本 | 按日计息，长期持有成本高 |
| 集中度限制 | 单一标的的融资比例通常受限 |

> **关键认识：杠杆不提高夏普比率，只放大收益与风险。**
> 真正的杠杆应该来自"**波动率目标**"（`vol_target`）——波动低时加仓、波动高时减仓，
> 而不是恒定地加 2 倍。这也是 01-04 讲 LTCM 时那个 "25:1" 最该被记住的教训：
> **杀死他们的不是模型错了，是杠杆让"暂时错了"变成"永久出局"。**

## 六、用平台算清两笔账

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次。它不依赖某个策略是否真的做空，而是把两笔最关键的账**直接算给你看**：

```python
# 账 1：融券费——借股票是要付利息的
notional = 1_000_000          # 100 万空头名义
borrow_rate = 0.08            # 年化融券利率 8%
fee = notional * borrow_rate
print("100 万空头持有一年的融券费:", int(fee), "元")

# 账 2：轧空——股价上涨时，做空的浮亏没有上限
short_price = 50.0
shares = 10_000               # 做空 1 万股，名义 50 万
for up in [0.10, 0.30, 0.50, 1.00]:
    loss = shares * short_price * up
    print(f"股价涨 {up:.0%}: 浮亏 {int(loss):,} 元")
```

我实跑的结果：

```
100 万空头持有一年的融券费: 80000 元
股价涨 10%: 浮亏 50,000 元
股价涨 30%: 浮亏 150,000 元
股价涨 50%: 浮亏 250,000 元
股价涨 100%: 浮亏 500,000 元
```

**两笔账，两个结论：**

1. **融券费是"确定性支出"**：8 万/年，不管你判对判错都要交。一个毛超额只有 5% 的市场中性策略，光融券费就吃掉一大截。**这跟 03-04 的成本是同一件事，只是换了个名字。**
2. **浮亏没有刹车**：股价翻倍，50 万本金全亏光；而现实里的轧空可以远超翻倍（GameStop 一度涨了数十倍）。**这不是"回撤"，是"归零甚至倒欠"**。

> 所以做空策略的回测里，`allow_short`、`borrow_rate`、`margin_ratio` 三个参数
> **必须显式设置**，不能依赖默认值。`BacktestConfig` 具体字段以平台实现为准。
> 而且就算设了，也要记住：**回测能算清融券费，算不清"被召回"和"流动性枯竭"**——
> GameStop 里最致命的那一下，恰恰是模型没法提前模拟的。

## 七、把这一篇串起来

回到 2021 年 1 月。

那些对冲基金不是不懂基本面，也不是模型没跑对。他们栽在两件**模型之外**的事上：**仓位太拥挤**，以及**杠杆不留余地**。

> 这和 01-04 的 LTCM、01-02 的因子拥挤、03-04 的成本，是同一条教训的不同侧面：
> **量化里最贵的风险，往往不来自"判断错"，而来自"判断对之前被迫离场"。**

> 一句话收尾，值得抄在交易台前：
> **做多亏的是钱，做空亏的是时间。**
> 市场可以非理性得比你的保证金更久——**而它不需要对，只需要比你活得久。**
