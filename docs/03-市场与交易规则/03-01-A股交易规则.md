# A股交易规则

## 一、交易时段

A 股每个交易日的交易时段（沪深交易所，视交易所最新规则而定）：

| 时段 | 时间 | 机制 |
| --- | --- | --- |
| 开盘集合竞价 | 09:15–09:25 | 09:15–09:20 可撤单，09:20–09:25 不可撤单 |
| 连续竞价 | 09:30–11:30，13:00–14:57 | 价格优先、时间优先 |
| 收盘集合竞价 | 14:57–15:00 | 不可撤单，形成收盘价 |

**集合竞价的定价原则是成交量最大化的价格**：高于该价的买单与低于该价的卖单全部成交。这对回测的意义是：**开盘价与收盘价都是竞价形成的，不能假设你能以任意价格成交**。很多回测默认"以收盘价成交"，这在集合竞价制度下是一个乐观假设——你只能"参与竞价"，是否能成交取决于排队。

## 二、T+1 制度

- **T+1**：当日买入的股票，**当日不能卖出**，最快 T+1 日卖出。
- **资金**：卖出股票所得资金当日可用于买入（T+0 可用），但**取现需 T+1**。

T+1 对策略的直接影响：

1. **日内策略无法在个股上实现**。任何"日内买入、日内卖出"的 A 股个股策略都不成立。可行的替代是"变相 T+0"：先持有底仓，当日先卖后买（前提是底仓是 T 日之前买入的）。
2. **可转债、ETF 跨境品种、部分期权**有不同的交易制度（如可转债为 T+0），具体视交易所规则而定。
3. **回测引擎必须拒绝当日卖出当日买入的持仓**，否则日内反转策略会得到完全虚假的收益。

## 三、价格限制

### 涨跌幅限制

| 板块 | 日涨跌幅限制 |
| --- | --- |
| 沪深主板 | ±10% |
| 创业板、科创板 | ±20% |
| 北交所 | ±30% |
| ST / *ST | ±5%（主板） |
| 新股上市首日 | 另有特殊规则（视交易所规则而定） |

涨停价的计算（主板，保留两位小数）：

$$\text{limit\_up} = \text{round}(P_{t-1}^{close} \times 1.10, 2)$$

回测中必须处理的两条规则：

- **涨停不可买入**：板上有大量排队买单，实际成交概率极低，回测应视当日该标的不可买入。
- **跌停不可卖出**：同理，跌停时卖出单无法成交，这会让止损失效——**这是实盘与回测差距最大的地方之一**。一个"跌 5% 就止损"的策略在连续跌停时根本无法执行。

### 价格笼子（限价申报范围）

连续竞价阶段的限价申报需在有效范围内（具体幅度与适用板块以交易所最新规则为准），典型表述是：买入申报价格不得高于买入基准价的 102%（或绝对价格差若干档），卖出申报价格不得低于卖出基准价的 98%。

对策略的意义：**不能用市价单"扫货"到任意价格**。大单必须拆分并使用限价单，这直接影响冲击成本的建模，参见 [03-05-流动性与冲击成本](./03-05-流动性与冲击成本.md)。

## 四、交易单位与最小变动价位

- **最小交易单位**：买入必须是 100 股（1 手）的整数倍；卖出时不足 100 股的部分应一次性卖出。
- **最小变动价位（tick size）**：0.01 元人民币。

对小资金账户，100 股取整会带来显著的"取整误差"：如果目标权重是 3.7%、股价 68 元、账户 10 万元，理论应买 54.4 股，实际只能买 0 股或 100 股——**低价股组合和小型账户受此约束最严重**。这也是为什么很多策略要求"单只标的的权重下限"要足够大。

## 五、交易成本

一笔 A 股交易的成本包括（具体费率以券商与交易所最新规定为准）：

| 项目 | 方向 | 典型水平 |
| --- | --- | --- |
| 佣金 | 双边 | 万分之 1~3，通常有单笔最低 5 元 |
| 印花税 | **卖出单边** | 千分之一（0.1%） |
| 过户费 | 双边 | 按成交金额的万分之零点几计（沪深口径略有差异） |

举例（示意性计算，以佣金万 2.5、印花税千 1、过户费忽略为例），一次完整的买入并卖出（金额 10 万元）：

$$\text{成本} \approx 100000 \times (0.025\% + 0.025\% + 0.1\%) = 150 \text{ 元} \approx 15 \text{ bp}$$

单边约 5 bp，双边约 15 bp。**这个数字是所有 A 股策略的"及格线"**：一个年换手 10 倍的策略，仅成本就是 1.5%/年，如果它的毛超额只有 3%，实际只剩 1.5%。详见 [03-04-交易成本分解](./03-04-交易成本分解.md)。

## 六、在回测中正确设置约束

```python
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.utils.calendar import trading_days
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
strategy = sma_cross(fast=20, slow=60)

# 基准：不做任何约束（过于乐观，仅作对照）
naive = Backtest(md, strategy, BacktestConfig(initial_cash=1_000_000)).run()

# 现实：打开 T+1、涨跌停不可成交、100 股取整与成本
realistic = Backtest(
    md, strategy,
    BacktestConfig(
        initial_cash=1_000_000,
        commission_rate=0.00025,     # 佣金（双边）
        stamp_duty=0.001,            # 印花税（卖出单边）
        min_commission=5.0,          # 单笔最低佣金
        lot_size=100,                # 最小交易单位
        price_limit=0.10,            # 涨跌幅限制
        t_plus_one=True,             # T+1
    ),
).run()

print("naive    :", {k: round(v, 4) for k, v in perf_report(naive.equity, rf=0.02).flat().items()})
print("realistic:", {k: round(v, 4) for k, v in perf_report(realistic.equity, rf=0.02).flat().items()})
print("交易日数:", len(trading_days("2024-01-01", "2024-12-31", market="A")))
```

**注意**：`BacktestConfig` 的具体字段以平台实现为准；如果某些字段不存在，应在策略层或成本模型中显式处理，而不是假设引擎已经帮你约束了。**永远不要相信"默认配置"是保守的**——多数回测框架的默认值是乐观的。

## 七、其他必须知道的规则

- **ST 与退市风险警示**：被实施风险警示的股票涨跌幅限制更小、流动性骤降，多数策略应在可选池中剔除。
- **停牌**：重组等事项会长期停牌，期间不可交易，见 [02-03-复权停牌与异常处理](../02-数据与工具/02-03-复权停牌与异常处理.md)。
- **分红除息与送转**：除权日价格跳变，必须用复权价计算信号，见同篇。
- **指数成分与新股上市**：新股上市初期波动极大且有特殊限制，通常剔除上市未满 N 日的标的。
- **科创板/创业板权限**：个人投资者需满足资产与交易经验门槛才能交易（视交易所与券商具体规定而定）。

## 常见坑

- **回测允许涨停买入**。追涨停策略的回测收益几乎全部来自这个漏洞。
- **回测允许跌停卖出**。这让止损在高波动期"完美执行"，实盘做不到。
- **假设可以按收盘价任意数量成交**。收盘是集合竞价，成交与否取决于排队。
- **忽略 100 股取整**，尤其在小账户和低价股上误差巨大。
- **把印花税算成双边**。印花税只在卖出时收取，算双边会高估成本约 10 bp，进而低估策略——这方向倒是"安全"的，但会让你错误地放弃本来可行的高频策略。
