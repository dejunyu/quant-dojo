# 加密货币市场

## 一、市场结构特点

| 维度 | 加密货币 | 与传统市场的对比 |
| --- | --- | --- |
| 交易时间 | 24/7 全年无休 | 无开盘/收盘，无隔夜跳空的概念（但仍存在"周末效应"） |
| 涨跌幅限制 | 无 | 单日 ±50% 并不罕见 |
| 熔断机制 | 无统一机制 | 各交易所自选规则 |
| 交易单位 | 无"手"，数量可任意分割 | 精度通常到小数点后 6~8 位 |
| 结算 | 现货即时；合约多为连续结算 | 无 T+1/T+2 概念 |
| 托管 | 交易所托管（有对手方风险）或自托管 | "not your keys, not your coins" |
| 监管 | 各辖区差异极大 | 同一交易所对不同地区用户规则不同 |

**"24/7"对研究的影响**：

1. **没有统一的"日"边界**。日频数据需要一个约定（通常是 UTC 00:00）。不同切分得到的日频收益序列不同，因子值也不同，必须固定并声明时区。
2. **波动率存在日内周期**。传统市场有"开盘波动大、午间平静"的模式，加密市场周期更弱但仍存在。
3. **周末效应**：传统市场的"周末停盘"效应消失，但周末流动性下降，应单独处理。

## 二、三大类交易品种

### 1. 现货（Spot）

直接买卖标的资产。成本主要是**交易手续费（maker/taker）**与**买卖价差**。多数交易所采用阶梯费率：交易量越大费率越低；挂单成交（maker）通常比吃单（taker）便宜，部分交易所对 maker 有返佣（负费率）。

### 2. 交割合约（Quarterly / Dated Futures）

有到期日，到期时按约定价格交割（多为现金交割）。价格与现货的差称为**基差**：$B = F - S$。临近到期时基差收敛到 0，这是"期现收敛"策略的收益来源。研究合约数据的最大陷阱是**换月跳变**：直接用连续合约价格序列会在换月日产生巨大假跳变，必须构造连续合约（按比例拼接或按收益率拼接），与商品期货的处理相同。

### 3. 永续合约（Perpetual / Perp）

没有到期日，靠**资金费率（funding rate）**锚定现货价格：

- 若永续价格 > 现货（多头占优），资金费率为**正**：多头支付给空头。
- 若永续价格 < 现货，资金费率为**负**：空头支付给多头。
- 支付通常每 8 小时一次（部分交易所为 1/4/8 小时，视交易所规则而定）。

资金费率的本质是由拥挤度定价的周期性持仓成本。它的两个用途：

**（1）作为成本**：持有多头一年，成本是资金费率的累计值。若平均年化费率为 10%，多头策略的毛收益必须先超过 10% 才能盈利。这是很多"看起来很赚"的加密趋势策略的真实杀手。

**（2）作为信号**：极端正的资金费率意味着多头拥挤、杠杆偏高，历史上有一定概率预示回调（高费率吸引套利者做空永续、做多现货，高杠杆多头更易被强平）。但它是弱信号，随时段变化。

$$\text{年化持有成本} \approx \bar{f} \times \frac{365 \times 24}{\Delta h}$$

其中 $\bar{f}$ 是每期平均资金费率，$\Delta h$ 是支付间隔小时数（如 8 小时，则一年约 1095 期）。

## 三、杠杆与强制平仓

- 合约支持高杠杆（部分交易所可达数十倍，视平台与用户所在地规则而定）。
- **维持保证金率**决定强平线：账户权益低于维持保证金要求时被强制平仓。
- 强平会造成**连锁反应**：大量强平单砸向市场 → 价格进一步下跌 → 触发更多强平。这解释了"插针"（瞬间极端价格）与瀑布式下跌。
- 对策略的意义：**回测必须假设杠杆会被强平**。一个"5 倍杠杆的趋势策略"回测很漂亮，实盘往往死于一次 15% 的反向波动。

## 四、交易所风险

这是加密市场最被低估的风险类别，且不可通过对冲消除：

| 风险类型 | 表现 | 缓解方式 |
| --- | --- | --- |
| 宕机 | 行情中断、无法下单 | 多交易所部署；不在单一平台持有全部仓位 |
| 提币限制 | 暂停提现 | 定期提币至自托管 |
| 破产风险 | 交易所倒闭，资产无法取回 | 分散存放；控制单平台敞口 |
| 插针与操纵 | 极端价格触发止损/强平 | 用指数价格而非单所价格；拉长采样窗口 |
| 规则变更 | 手续费、杠杆、合约规则单方面修改 | 关注公告；避免依赖特定规则套利 |

历史上有多次大型交易所倒闭/暴雷事件，导致用户资产全额损失。传统市场有托管与投资者保护机制，这类风险相对可控，因此加密市场的风险预算必须单独留出一块。

## 五、数据特点

```python
import numpy as np
import pandas as pd
from qd.data import MarketData
from qd.data.synthetic import generate_demo_market

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, vol = md.close(), md.volume()

# 1) 时区：加密数据没有"交易日"概念，必须显式声明切分规则（UTC 或其他）
print("索引时区:", close.index.tz)

# 2) 缺失段检测：交易所宕机会造成连续多期缺失，而不是随机散点
gap = close.isna().rolling(5).sum()
print("连续 5 期全缺失的时段数:", int((gap >= 5).sum().sum()))

# 3) 极端波动：加密市场单日 ±20% 并不罕见，不能用 A 股 ±11% 的阈值过滤
ret = md.returns()
print("单日 |r| > 20% 的比例:", round((ret.abs() > 0.20).mean().mean(), 5))

# 4) 流动性：用成交额而非成交量（不同交易所计价与精度不同）
amount = close * vol
adv = amount.rolling(20).mean()
print("低流动性样本占比:", round((adv < adv.quantile(0.2)).mean().mean(), 4))

# 5) 资金费率示意：年化持有成本换算（每 8 小时一期）
def annualized_funding(funding_per_period, hours=8):
    periods_per_year = 365 * 24 / hours
    return funding_per_period * periods_per_year

f = pd.Series([0.0001] * len(close.index), index=close.index)   # 每期万分之一
print("示意年化资金成本:", round(annualized_funding(f.mean()), 4))
```

## 六、策略适配要点

| 策略类型 | 适配问题 |
| --- | --- |
| 趋势/动量 | 可行，但需扣资金费率与手续费；波动大，仓位管理更关键 |
| 均值回归 | 可行，但"回归"常被打断，必须严格止损 |
| 套利（期现、跨所） | 收益明确但需承担交易所风险，容量有限 |
| 高频做市 | 竞争激烈，需要极低延迟与手续费优惠 |
| 多因子选股 | 有效标的通常几百个，广度不足，检验功效低 |

**最重要的一条**：加密市场标的数量少、历史短（多数只有几年数据），统计检验的功效远低于股票市场。在股票上敢用的因子门槛，在加密市场需要更严格，否则几年后必然失效。

## 常见坑

- **用连续合约价格序列直接算收益率**，未处理换月跳变，凭空产生巨大假涨跌幅。
- **忽略资金费率**。持有多头一年的策略，成本可能高达两位数百分比。
- **用单一交易所价格**，被插针触发止损或强平。
- **把加密市场的夏普与股票市场直接比较**。高夏普常来自短样本、高波动基数与幸存者偏差。
- **忽略交易所倒闭风险**，把全部资金放在一个平台。
- **用日频 UTC 切分却按本地时区下单**，导致信号与执行错开。

## 延伸阅读

- 各交易所（如 CME、Binance 等）发布的永续合约与资金费率规则文档——具体结算间隔、费率上限以交易所最新规则为准。
- 各国/地区监管机构关于加密资产交易与托管的投资者提示——合规要求以当地最新规定为准。
