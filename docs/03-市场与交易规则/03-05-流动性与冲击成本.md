# 流动性与冲击成本

## 一、什么是流动性

流动性有多个维度，实战中最关心三个：

1. **宽度（width）**：买卖价差。价差越小，往返成本越低。
2. **深度（depth）**：在不显著移动价格的前提下能成交的数量。看盘口挂单量。
3. **弹性（resiliency）**：价格被冲击后回复的速度。弹性差的市场，一次大单会把价格永久性推走。

还有一个时间维度——**即时性（immediacy）**：想立刻成交要付出多少代价。三者共同决定了你的"可执行价格"。

## 二、Amihud 非流动性指标

Amihud（2002）提出的指标是学术与实务中最常用的低频流动性度量：

$$ILLIQ_{i,y} = \frac{1}{D_{i,y}} \sum_{t=1}^{D_{i,y}} \frac{|r_{i,t}|}{\text{Amount}_{i,t}}$$

其中 $r_{i,t}$ 是日收益率，$\text{Amount}_{i,t}$ 是当日成交额，$D$ 是当年交易日数。直观含义是：**每单位成交额引起的价格变动幅度**。值越大，说明这只股票"用一点钱就能砸出很大的波动"，即流动性越差。

实务中常用它的对数形式（分布更接近正态）或者用"过去 20 日"滚动代替年度：

$$ILLIQ_{i,t}^{(20)} = \frac{1}{20}\sum_{\tau=t-19}^{t}\frac{|r_{i,\tau}|}{\text{Amount}_{i,\tau}}$$

Amihud 指标的另一个用途是**作为因子**：流动性差的股票要求更高的预期收益（流动性溢价），因此高 Amihud 值（低流动性）的股票长期有正超额——但这个超额恰恰是因为它难交易，大资金拿不到。

## 三、参与率与平方根冲击模型

**参与率（Percentage of Volume, POV）**：

$$\text{POV} = \frac{Q}{V_{\text{market}}}$$

经验规则：日内参与率控制在 **5%~10%** 以内通常不会造成显著冲击；超过 20% 时冲击会急剧上升。

**平方根冲击模型**（Almgren-Chriss 等经典形式）：

$$\frac{\Delta P}{P} = \eta \cdot \sigma \cdot \sqrt{\frac{Q}{ADV}}$$

其中：

- $\sigma$：日波动率（如 2%）。
- $Q$：本次交易量（股数或金额）。
- $ADV$：日均成交量（同单位）。
- $\eta$：市场常数，量级约 1（不同市场/文献估计不同，应自行校准）。

举例（示意，取 $\eta=1$、$\sigma=0.02$）：买入相当于 $ADV$ 的 5%：

$$\frac{\Delta P}{P} = 1 \times 0.02 \times \sqrt{0.05} = 0.02 \times 0.2236 = 0.447\% \approx 45 \text{ bp}$$

买入 $ADV$ 的 20%：

$$0.02 \times \sqrt{0.20} = 0.02 \times 0.447 = 0.894\% \approx 89 \text{ bp}$$

**注意关键性质**：交易量放大 4 倍，冲击只翻一倍。所以拆分订单是有意义的——但这不意味着可以无限拆，因为拆单会带来时机成本（见 [03-04-交易成本分解](./03-04-交易成本分解.md)）。二者的权衡就是执行算法要解决的问题。

## 四、容量估算

容量（capacity）的定义应该是：**当策略规模增加到使净 alpha 降到目标值以下时的规模**。一个简化的估算框架：

1. 计算策略的年双边换手 $T$ 与组合总市值 $A$。
2. 每年交易总金额 $\approx T \cdot A$。
3. 每只股票的平均单笔交易占其 $ADV$ 的比例 $\approx \frac{T \cdot A / N}{\text{平均单笔可执行量}}$，其中 $N$ 是持仓数。
4. 用平方根模型算出平均冲击成本 $c_{\text{impact}}$。
5. 净超额 $\alpha_{\text{net}} = \alpha_g - T \cdot (c_{\text{spread}} + c_{\text{impact}} + c_{\text{fee}})$。
6. 解出使 $\alpha_{\text{net}}$ 达到目标的 $A$。

一个粗略的经验结论（量级参考，非精确数字）：

| 策略类型 | 大致容量量级 |
| --- | --- |
| 高频做市 | 千万级 |
| 分钟级统计套利 | 亿级 |
| 日度均值回归 | 亿~十亿级 |
| 月度多因子（全市场） | 百亿级 |
| 低频资产配置 | 几乎无限 |

容量的核心约束不是"市场有多大"，而是"**你的 alpha 有多快衰减**"。如果一个信号的预测期是 20 天，你必须在 20 天内建完仓，这就限制了单只股票的日交易量；如果预测期是 1 年，你可以慢慢买。

## 五、用平台估算流动性与冲击

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors.pipeline import rank

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, vol, ret = md.close(), md.volume(), md.returns()
amount = close * vol                       # 成交额

# 1) 滚动 20 日 Amihud 非流动性
illiq = (ret.abs() / amount).rolling(20).mean()
print("Amihud 分位数（越大越难交易）:\n",
      illiq.iloc[-1].quantile([0.2, 0.5, 0.8, 0.95]).round(8))

# 2) ADV 与可交易金额上限（按参与率 10% 约束）
adv = amount.rolling(20).mean()
pov_cap = adv * 0.10
print("单日可执行金额上限（中位数）:", round(pov_cap.iloc[-1].median(), 0))

# 3) 平方根冲击模型：给定买入金额，估算冲击成本（bp）
def impact_bp(order_amount, adv_, vol_20d, eta=1.0):
    q_over_adv = (order_amount / adv_).clip(upper=1.0)
    return eta * vol_20d * np.sqrt(q_over_adv) * 1e4

sigma20 = ret.rolling(20).std()
for scale in [0.01, 0.05, 0.10, 0.20]:
    cost = impact_bp(adv.iloc[-1] * scale, adv.iloc[-1], sigma20.iloc[-1])
    print(f"买入 ADV 的 {scale:.0%} → 冲击中位数 {np.nanmedian(cost):.1f} bp")

# 4) 容量示意：组合规模 A、换手 T、持仓数 N 下的单笔参与率
def pov_per_name(A, T, N, trading_days_per_year=252):
    daily_trade = A * T / trading_days_per_year      # 每日双边交易总额
    return daily_trade / N                            # 每只股票日均交易金额

for A in [1e6, 1e7, 1e8, 1e9]:
    per_name = pov_per_name(A, T=10, N=50)
    print(f"规模 {A:,.0f} → 每只股票日均交易 {per_name:,.0f}, "
          f"占 ADV {np.nanmedian(per_name / adv.iloc[-1]):.2%}")
```

跑完这段代码，你会得到一个非常直接的结论：**规模每放大 10 倍，每只股票的日交易额也放大 10 倍，参与率随之放大，冲击成本按平方根上升**。当冲击成本接近毛 alpha 时，策略就到顶了。

## 六、大资金 vs 小资金

| 维度 | 小资金（<千万） | 大资金（>十亿） |
| --- | --- | --- |
| 可选策略 | 几乎全部（含高频） | 低频、大容量 |
| 主要成本 | 显性成本（佣金、最低佣金） | 隐性成本（冲击、时机） |
| 换手限制 | 宽松 | 严格（参与率约束） |
| 建仓速度 | 可即时 | 需数日至数周 |
| 关键工作 | 找 alpha | 执行优化 + 容量管理 |
| 常见失败 | 成本估计过低 | 规模扩张过快导致 alpha 被吃光 |

小资金的最大优势是"**能进别人进不去的地方**"：微盘股、低流动性标的、快速信号。这不是作弊，而是能力——大资金无法复制。因此小资金不应模仿大机构的低频策略，而应利用自己的规模优势。

## 常见坑

- **用总市值或总成交额估计容量**。真正约束你的是**你能交易的那一小部分**（如流动性最好的 20% 标的）。
- **假设可以按当日 ADV 的全部成交**。参与率超过 20% 时，模型已经失效，且会留下被识别的足迹。
- **忽略集中流动性事件**。指数成分调整日、财报日的成交量会异常放大，用平常的 ADV 建模会低估那时的可交易量（也可能高估其他时候）。
- **用平均流动性而非最差流动性**。组合里只要有一只股票买不进，就会拖累整体；应按分位数（如 20% 分位）而非均值估计。
- **规模扩大后不重算成本**。很多策略在 1000 万规模下夏普 2.0，到 10 亿规模夏普 0.3，这不是策略失效，而是成本结构变了。
