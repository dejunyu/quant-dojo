# 幸存者偏差

## 一、定义

**幸存者偏差（survivorship bias）**：研究样本只包含了"存活至今"的个体，而那些中途失败、退市、清盘的个体被系统性剔除，导致统计结论偏向乐观。

它与前视偏差的区别很重要：

| | 前视偏差 | 幸存者偏差 |
| --- | --- | --- |
| 错误性质 | 用了未来的**信息** | 用了未来的**样本选择** |
| 典型表现 | 信号里混入了未来价格 | 样本里没有失败者 |
| 检查方法 | 时间旅行测试（截断重算） | 检查样本数量随时间的曲线与退市记录 |

两者常常同时发生：用"当前 A 股全市场列表"拉 2015 年至今的数据，既没有退市股（幸存者偏差），又隐含使用了"这些公司活到了今天"这一未来信息（前视）。

## 二、三个典型的引入途径

### 1. 用当前股票列表回测历史

这是最常见也最致命的一种。A 股每年有一定数量的股票退市或暂停上市，把这些公司从历史样本中剔除，等于**只统计了赢家**。

偏差的量级有多大？取决于策略类型：

- 对**动量、质量、低波动**这类"偏好健康公司"的因子：影响 1%~3%/年（因为这些因子本来就会少买问题股）。
- 对**反转、低价股、高波动**这类"偏好困境公司"的因子：影响可达 **5%~15%/年**。因为困境股中恰好有相当比例后来退市了，剔除它们等于把最差的样本删掉，反转因子的收益会被严重高估。

这也解释了一个常见现象：**论文里的反转策略在实盘中总是做得比回测差**。

### 2. 用指数成分股做研究

用"当前沪深 300 成分股"回测过去 10 年，会同时引入两种偏差：

- 成分股是**事后筛选**的结果——现在的成分股之所以在列，正是因为它们过去表现好。
- 成分股每半年调整一次，历史上的成分与现在完全不同。

正确做法是使用**历史成分股快照**：在每个调整生效日更新成分列表，而不是用今天的列表。

### 3. 用基金净值数据评价策略

对冲基金数据库里只有"愿意上报且仍然存续"的基金。业绩差的基金会清盘并停止上报，于是数据库的平均业绩被系统性高估，而"基金收益的持续性"这类研究结论也会被扭曲。这也是评价私募/公募历史业绩时必须注意的一点。

## 三、如何构造无偏样本

四个步骤，缺一不可：

1. **获取完整的历史 universe**：包含退市、暂停上市、被 ST 的所有标的，且要保留它们退市前的全部行情。
2. **用 point-in-time 的可选池**：每天的可选池 = 当日上市且未退市、未停牌（或按需要包含停牌）、满足流动性门槛的股票。
3. **对退市做最后一段收益处理**：退市整理期后的最终价值通常按退市价或清算价值处理。若无法获得，保守做法是假设剩余价值为 0（或按最后可得价格的一定折扣）。**保守假设会让回测更难看，但更安全。**
4. **保留失败者的完整轨迹**：不要用"上市满 3 年"之类的条件过滤历史样本——这个条件本身就是未来信息（一只 2018 年上市的股票在 2019 年时不可能知道自己能活满 3 年）。

## 四、用平台检查样本完整性

```python
from qd.data.synthetic import generate_demo_market
from qd.utils.calendar import trading_days

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, vol = md.close(), md.volume()

# 1) 样本数量随时间变化：如果早期远少于近期，说明数据只覆盖了"存活者"
n_by_year = close.notna().sum(axis=1).groupby(close.index.year).mean()
print("每年平均有效标的数:\n", n_by_year.round(1))

# 2) "最后出现日"分布：集中在末尾是正常的；若大量标的在中间消失，需确认是否退市
last_valid = close.apply(lambda c: c.last_valid_index())
print("最后交易日的年份分布:\n", last_valid.dt.year.value_counts().sort_index())

# 3) 构造 point-in-time 可选池（示意）：上市且有成交，且近期有流动性
listed = close.notna()
liquid_20d = (vol.fillna(0).rolling(20).sum() > 0)
universe = listed & liquid_20d
print("可选池占比:", round(universe.mean().mean(), 4))

# 4) 检查"上市首日附近"的样本：新股上市初期波动极大，常需剔除
age = listed.cumsum()
newborn = (age > 0) & (age <= 20)
print("上市 20 日内样本占比:", round(newborn.mean().mean(), 4))
```

## 五、偏差量级的经验判断

无法给出普适数字，但可以用下面这个思路估计自己数据里的偏差量级：

$$\text{偏差} \approx P(\text{退市}) \times \mathbb{E}[r_{\text{退市股}} - r_{\text{平均}}]$$

举例（示意性计算，非真实统计）：若某类股票 5 年内退市比例为 3%，退市前一年平均跑输市场 60%，则剔除它们带来的年化高估约为：

$$\frac{3\% \times 60\%}{5} \approx 0.36\% \text{/年}$$

这个数字看起来不大，但如果你的策略年化超额只有 3%，那 0.36% 就是 12% 的相对误差；而对高换手、偏好困境股的策略，分母与分子都会显著放大。**做量级估算的价值不在于精确，而在于判断"这个偏差是否可能大到改变我的结论"。**

## 六、与其他偏差的叠加

研究表明（学术文献中的常见结论）：在存在幸存者偏差的样本上，很多"异象"的显著性会被放大。当你回测出某个因子特别强时，先问三个问题：

1. 我的样本包含了失败者吗？
2. 我的数据口径是 point-in-time 的吗？
3. 我做过多少次尝试才得到这个结果（过拟合）？

三个问题的答案共同决定了这个因子值不值得继续投入。参见 [02-04-前视偏差](./02-04-前视偏差.md) 与 [01-03-量化投研流程](../01-入门/01-03-量化投研流程.md)。

## 常见坑

- **用"当前全市场股票列表"当历史 universe**。这是幸存者偏差最标准的形态，务必从数据商获取含退市的历史列表。
- **把退市股的行情直接删除**而不是保留到最后可得价格。这样连"它亏损了多少"都没统计进去。
- **忽略基金/策略数据库的自报偏差**。即使样本完整，"谁愿意上报"本身就是选择偏差。
- **用"存续至今的产品"对比"历史平均"**。比较基准也必须是无偏的，否则对比毫无意义。
- **剔除新股时用了未来信息**。"上市满 N 年"不能用今天的状态判断历史。

## 延伸阅读

- 关于共同基金与对冲基金数据库中的幸存者偏差，金融文献中有大量实证研究；结论普遍认为偏差量级在每年 1%~4% 区间（具体取决于样本与方法）。
- 中证指数公司公布的指数成分调整规则与历史成分文件——构造无偏 A 股样本的权威依据。
- 数据商提供的含退市股票历史行情说明——实践中应向数据商确认其是否包含退市标的的退市前行情。
