# 前视偏差

## 学完这一篇，你能做到

- 用一个生活化的比喻说清"前视偏差"是什么，不需要数学背景
- 读懂本篇唯一那个公式里的每个符号，明白它为什么值得单独写一篇
- 在自己的代码里逐条排查 10 个常见来源
- 会用"时间旅行测试"给策略做一次体检

## 本篇要点

- 前视偏差 = 决策时用了**当时还不知道**的信息，就像考试偷看答案
- 它最危险的地方：**不会让回测变差，只会让回测变好**——你不会去查，反而会去配资
- 最隐蔽的来源不是未来价格，而是"未来才知道的披露日、成分股、分布参数"
- 唯一可靠的检查：把数据在某一天截断重算，看之前的结果变不变

---

## 一、从一场"稳赢"的考试说起

想象一场很奇怪的考试：发卷的时候，答案就印在卷子背面。

你考了 98 分，信心爆棚，回家跟家人说"我学得不错，下学期可以加大投入了"。直到有人提醒你：**你翻到过卷子背面**。

这时候问题来了——那 98 分里，有多少是真会，有多少是抄的？**你分不清，而且你根本不会想去查**，因为成绩太好了。

量化回测里的**前视偏差**（look-ahead bias），就是这场考试：

> 你在用历史数据"考"一个策略时，**不小心让它在做题的那一刻，看到了那一刻之后才会发生的事**。

最常见的形态，一句话就能说清：

> **用今天的收盘价算出买入信号，又假设自己能按今天的收盘价成交。**

听起来只是"差了半天"，但这是不可能的——**收盘价是收盘那一刻才确定的，而那一刻你已经买不进去了**。你等于假设自己能在"知道收盘价之后、回到收盘之前"下单。这就是时间旅行。

### 为什么它是最危险的一类错误

其他错误大多会让回测变难看：

| 错误类型 | 回测会怎样 | 你的反应 |
| --- | --- | --- |
| 因子没用 | 收益平平 | 去查、去改 |
| 成本没扣 | —— | 补上就变难看 |
| **前视偏差** | **曲线漂亮得不像话** | **高兴，然后想加大资金** |

> **这就是它致命的地方：普通缺陷会报警，前视偏差会发奖。**
> 一个让你亏钱的模型你会去修，一个"稳赚"的模型你会去借钱。
> 所以行业里有句半开玩笑的话：**回测越漂亮，越要先怀疑自己偷看了未来。**

> 费曼那句 1974 年的话，在这一篇比在任何地方都贴切：
> **"第一原则是：你不能欺骗自己——而你是最容易被自己欺骗的人。"**
> 前视偏差几乎从来不是故意作弊，而是"我没意识到这行数据当时还不存在"——**自己骗自己，往往比别人骗你更难发现。**

## 二、本篇唯一那个公式（逐个讲透）

01-01 讲"量化是什么"的时候，我们删掉了一个抽象公式，说过一句：**"它的数学留给 02-04"**。现在它该出场了——因为只有在这里，它才有真实含义。

先用人话说一遍：

> **t 时刻做决定，只能用 t 时刻已经公开的信息。**

写成式子是：

$$s_t = f(X_t), \quad \text{要求 } X_t \subseteq \mathcal{F}_t$$

别被符号吓到，逐个拆开，没有一个难：

| 符号 | 读法 | 是什么意思 | 生活化理解 |
| --- | --- | --- | --- |
| $t$ | 第 t 期 | 某一个具体的决策时刻（某一天） | "今天" |
| $s_t$ | 信号 | 今天算出来的买卖决定 | 今天写的答题卷 |
| $X_t$ | 输入数据 | 你实际拿来算信号的那堆数 | 你翻过的书、看过的资料 |
| $f$ | 规则 | 把数据变成决定的那套逻辑 | 你的解题方法 |
| $\mathcal{F}_t$ | 信息集 | **到 t 时刻为止，全世界已经公开的全部信息** | "到今天为止，你本来能知道的一切" |
| $\subseteq$ | 包含于 | 左边是右边的子集 | "只能从里面拿，不能从外面拿" |

**整句话就一个意思：$X_t$ 必须装在 $\mathcal{F}_t$ 里面——凡是当时还没公开的数，一个都不许用。**

> 这里有个特别重要的常识，叫 **信息集（information set）**，圈内常写作 $\mathcal{F}_t$（花体 F，来自 filtration，"信息流"）。
> 你可以把它想成**"到今天为止的历史档案柜"**：里面装着所有已经发生、已经公告、已经成交的事。
> 明天才公布的财报、下周才生效的指数成分，**此刻都不在柜子里**——伸手去拿，就是前视。

### 这个公式什么时候会被破坏

按定义，$s_t \not\perp$ 未来信息就违规。但"未来"远比你以为的隐蔽。它常常藏在三类地方：

1. **未来价格**：用收盘价算信号又用收盘价成交（开头的例子）。
2. **未来才知道的标签或状态**：财报的"报告期"当成"披露日"、用"现在是否 ST/退市"去过滤历史样本、用今天的指数成分回测十年前。
3. **未来的统计量**：用全样本的均值、标准差、分位数去做标准化——这个最隐蔽，下一节单独讲。

> 一句话记住区别（这是 01 章埋过的线）：
> - **前视偏差**：用了未来的**信息**（这篇）。
> - **幸存者偏差**：用了未来的**样本名单**（[02-05](./02-05-幸存者偏差.md)）。
> - **过拟合**：没用未来信息，但在同一份数据里试太多次（[01-03](../01-入门/01-03-量化投研流程.md)）。
>
> 三者症状一模一样：回测漂亮、实盘拉胯。**区分方法只有一个：一个一个排除。**

## 三、十个最常见的来源（逐条能查）

| # | 来源 | 错误做法 | 正确做法 |
| --- | --- | --- | --- |
| 1 | 未来函数 | 当日收盘价算信号、当日收盘价成交 | 用 t 日信号在 t+1 日（或开盘）成交 |
| 2 | 财报报告期 vs 披露日 | 2023 年报从 2024-01-01 就生效 | 从实际披露日（如 2024-04-10）起生效 |
| 3 | 财报重述 | 用最新更正后的数据回测历史 | 用 point-in-time 快照，保留当时版本 |
| 4 | 指数成分调整 | 用公告日更新成分 | 用调整**生效日**更新成分 |
| 5 | 全样本标准化 | 用全样本均值/标准差做 z-score | 只用截至 t 日的滚动/扩展窗口 |
| 6 | 全样本去极值 | 用全样本分位数 winsorize | 用滚动窗口分位数 |
| 7 | 标签重叠（机器学习） | 训练标签窗口跨过测试集起点 | 净化（purging）+ 禁飞区（embargo） |
| 8 | 退市 / ST 状态 | 用"现在是否退市"过滤历史 | 用当时已知的标记，否则变幸存者偏差 |
| 9 | 复权因子 | 用今天的复权因子回算历史价 | 用当时可得的复权因子 |
| 10 | 参数估计 | 用全样本最优参数回测全样本 | 参数在训练窗估计、测试窗固定 |

**第 5、6、7 条最容易被忽略**，因为它们看起来只是"预处理"，没碰任何"未来价格"，却照样泄漏。补两个常识：

- **point-in-time（时点数据）**：数据商提供的一种"历史快照"能力——能查到"在 2020 年 6 月 30 日那天，市场看到的这份财报长什么样"，包括后来被更正前的旧版本。**回测要的就是这个，而不是今天数据库里的最新值。**
- **purging / embargo（净化 / 禁飞区）**：机器学习切分训练与测试时，在两段之间**故意空出一段时间**，防止标签窗口重叠导致未来信息渗进训练。金融时间序列**绝不能用普通 K 折**。

## 四、把"全样本标准化也是前视"讲透

这是本篇最反直觉、也最值得单独讲的一节。

标准化（z-score）是因子预处理的基本动作：把每个因子值减均值、除以标准差，让不同量纲能比较。式子很朴素：

$$z_{i,t} = \frac{f_{i,t} - \mu}{\sigma}$$

- $f_{i,t}$：第 i 只股票在 t 时刻的原始因子值
- $\mu$、$\sigma$：用来标准化的**均值**和**标准差**

问题就出在这两个字母上：**如果 $\mu$ 和 $\sigma$ 是用"整段历史、包括未来"算出来的，那么 2018 年的标准化值里，就混进了 2024 年的信息。**

举个能感受到的例子：假设这个因子在 2023 年整体抬升了（比如全市场估值变贵）。用全样本算出的均值 $\mu$ 会被抬高，于是**历史那些年份的标准化值全部被系统性压低**——模型会"学到"历史上这个因子偏弱、近期偏强。可这完全是统计假象，真实的因子值根本没变。

我实跑了一次对比，数字很直观（合成数据，用来学方法）：

```
全样本标准化(错) 2019 年均值: -0.3696
扩展窗口(对)   2019 年均值: -0.0906
```

> **同一个因子、同一年，只因为"用了未来的分布参数"，值就凭空被压低了 4 倍。**
> 这就是前视偏差最阴险的形态：**它不给你看未来价格，它只是悄悄改了你手里的尺子。**

正确做法只有一个：**用滚动窗口（rolling）或扩展窗口（expanding）估计参数**——每个 t 日，只用"到今天为止"的数据算 $\mu$ 和 $\sigma$。

```python
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import zscore, winsorize

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
raw = get_factor("mom_12_1").compute(md)

# ❌ 错误：全样本标准化，用了未来的分布参数
z_wrong = zscore(winsorize(raw, limits=0.01))

# ✅ 正确：扩展窗口，只用截至当日的历史估计参数
mu = raw.expanding(min_periods=60).mean()
sd = raw.expanding(min_periods=60).std()
z_expanding = (raw - mu) / sd

# ✅ 也可以：滚动窗口，只用最近 250 个交易日
mu_r = raw.rolling(250, min_periods=60).mean()
sd_r = raw.rolling(250, min_periods=60).std()
z_rolling = (raw - mu_r) / sd_r

print(z_wrong.iloc[:5, :3].round(3))
print(z_expanding.iloc[:5, :3].round(3))
```

> 补个常识：**扩展窗口（expanding）** 是"从第一天算到今天，窗口越来越长"；**滚动窗口（rolling）** 是"只算最近 N 天，窗口长度固定"。
> 两者都只用历史，都合法；区别是前者稳定、后者对近期变化更敏感。

## 五、时间旅行测试：唯一可靠的体检

道理讲完，怎么查？答案不是"仔细检查代码"——人总会看漏。答案是**让机器替你证明没作弊**。

方法叫**时间旅行测试**（也叫截断重算），四步：

1. 选一个历史日期 t（比如 2020-06-30）；
2. 把所有数据在 t 日**截断**，假装自己就活在那天；
3. 用截断后的数据，重新算 t 日之前的全部信号与净值；
4. 和用全样本算出的、t 日之前那段对比。

> **如果两条曲线有任何不一样，说明你的计算偷看了 t 之后的东西。**
> 因为一个真正只用到 t 日为止信息的计算，**给它更多未来数据，结果也不该变**——它根本没看那些数据。

```python
from qd.data.synthetic import generate_demo_market
from qd.data import MarketData

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

def signal(md_part):
    """一个待检查的信号：20 日动量"""
    return md_part.close().pct_change(20)

full = signal(md)

# 截断到 2020-06-30 重算，只比较截断日之前的部分
truncated = signal(md.slice("2018-01-01", "2020-06-30"))
common = full.index.intersection(truncated.index)
diff = (full.loc[common] - truncated.loc[common]).abs().max().max()
print("最大差异:", diff)   # 应接近 0（浮点误差级别）
```

我实跑的结果：`最大差异: 0.0`。这个 20 日动量是干净的。

平台里甚至把这个思路做成了**自动化测试**：`tests/test_no_lookahead.py` 会把所有"未来数据"随机打乱，然后断言切点之前的净值曲线**必须完全不变**。00-01 里推荐你至少跑一次这个测试，原因就在这里——

> **它不是"我觉得我没偷看"，是"我把未来全搅乱了，之前的答案还是一模一样"。**
> 这是全书里我最喜欢的一种诚实：**用代码证明，而不是用嘴保证。**

- [ ] 信号面板的每一行，只用了该行日期及之前的数据？

- [ ] 训练 / 测试切分处设置了 embargo？
- [ ] 成交价晚于信号价至少一期？
- [ ] 复权因子在历史上与当时可得的一致？
- [ ] **通过了时间旅行测试？**
- [ ] 数据版本号已记录？

## 七、把这一篇串起来

回到开头那场"答案印在背面"的考试。

前视偏差的可怕，从来不是技术上有多难，而是**它奖励你**：给你一条漂亮曲线，让你舍不得去怀疑。所以整篇其实只教了一个动作——

> **在相信任何回测之前，先假装自己活在历史的某一天，把那天之后的数据全部藏起来，再算一遍。**

这和 01-03 西蒙斯"停机重构"、AMS 论文"披露你试了多少次"，是同一种精神：**把诚实做成流程，而不是指望自己有警惕心**。

> 塔勒布那句火鸡寓言，在这里可以换个说法：
> **一只火鸡被喂了 1000 天，每天更确信"人类爱我"；第 1001 天是感恩节。**
> 而前视偏差的版本更狠——**它不是喂了你 1000 天，它是把第 1001 天的答案，提前抄给了你。**
> 于是你连"曾经对过"都算不上。

## 动手练习

- 跑一遍时间旅行测试，把 `signal` 改成 `md_part.close().pct_change(20).shift(-1)`（故意看未来），看最大差异变成多少。**先猜，再跑。**
- 对比全样本标准化与扩展窗口标准化的 IC 差异，把数字记进研究日志。
- 在你自己的因子代码里搜一遍 `shift(-`、`.bfill(`、`iloc[i+`，逐个确认它们没有把未来值喂进特征。（注意：算"未来收益"当训练标签时用 `shift(-1)` 是正常的，问题只在于它**绝不能进入特征**。）
