# 前视偏差

## 一、定义

设 $\mathcal{F}_t$ 为 $t$ 时刻**公开可得**的信息集。一个在 $t$ 日用于生成交易决策的信号 $s_t$，如果它的计算过程使用了不属于 $\mathcal{F}_t$ 的数据，就存在**前视偏差（look-ahead bias）**。

$$s_t = f(X_t), \quad \text{要求 } X_t \subseteq \mathcal{F}_t$$

前视偏差之所以是最危险的一类错误，是因为它**不会让回测变差，只会让回测变好**。一个正常的模型缺陷会让收益下降，你会去查；而前视偏差会给你一条漂亮的曲线，你会去配资。

## 二、10 个常见来源

| # | 来源 | 错误做法 | 正确做法 |
| --- | --- | --- | --- |
| 1 | 未来函数 | 用当日收盘价算信号，当日收盘价成交 | 用 $t$ 日信号在 $t+1$ 日（或开盘）成交 |
| 2 | 财报报告期 vs 披露日 | 用 2023 年报数据从 2024-01-01 开始生效 | 从实际披露日（如 2024-04-10）起生效 |
| 3 | 财报重述 | 使用最新更正后的财务数据回测历史 | 使用 point-in-time 快照，保留当时的版本 |
| 4 | 指数成分调整 | 用公告日更新成分股 | 用调整生效日更新成分股 |
| 5 | 全样本标准化 | 用全样本的均值/标准差做 z-score | 只用截至 $t$ 日的滚动窗口估计参数 |
| 6 | 全样本去极值 | 用全样本分位数 winsorize | 用滚动窗口分位数 |
| 7 | 标签重叠（机器学习） | 训练样本的标签窗口跨越了测试集起点 | 用净化（purging）+ 禁飞区（embargo） |
| 8 | 退市/ST 信息 | 用"现在是否退市"过滤历史样本 | 用当时已知的标记，否则引入幸存者偏差 |
| 9 | 复权因子 | 用今天的复权因子回算历史价格 | 用当时可得的复权因子（或确认序列一致） |
| 10 | 参数估计 | 用全样本最优参数回测全样本 | 参数必须在训练窗内估计，测试窗内固定 |

第 5、6、7 条是最容易被忽略的，因为它们看起来只是"预处理"，不涉及"未来价格"，但同样泄漏了未来信息。

## 三、为什么全样本标准化也是前视偏差

假设你要对因子做 z-score：

$$z_{i,t} = \frac{f_{i,t} - \mu}{\sigma}$$

如果用全样本的 $\mu$ 和 $\sigma$，那么 2018 年的标准化值里包含了 2024 年的信息。这会造成什么后果？如果因子在未来整体走高（例如全市场估值抬升），全样本均值会被抬高，导致历史期的标准化值系统性偏低——于是模型会"学习"到历史上该因子偏弱，这是一种完全虚假的模式。

更严重的是**分布漂移**：如果 2020 年发生过一次极端行情，全样本标准差会被拉大，历史期的标准化值被压缩，因子在历史期几乎无区分度，而在近期区分度很高。回测结果会呈现"近期非常好"的假象。

正确做法是使用**滚动窗口或扩展窗口**估计：

```python
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import zscore, winsorize

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
raw = get_factor("mom_12_1").compute(md)

# ❌ 错误：全样本标准化（用了未来的分布参数）
z_wrong = zscore(winsorize(raw, limits=0.01))

# ✅ 正确：扩展窗口（expanding），只用截至当日的历史估计参数
mu = raw.expanding(min_periods=60).mean()
sd = raw.expanding(min_periods=60).std()
z_expanding = (raw - mu) / sd

# ✅ 也可以：滚动窗口（rolling），只用最近 250 个交易日
mu_r = raw.rolling(250, min_periods=60).mean()
sd_r = raw.rolling(250, min_periods=60).std()
z_rolling = (raw - mu_r) / sd_r

print(z_wrong.iloc[:5, :3].round(3))
print(z_expanding.iloc[:5, :3].round(3))
```

## 四、时间旅行测试（最可靠的检查方法）

这是一个可以直接落地的检查：

1. 选定一个历史日期 $t$（比如 2020-06-30）。
2. 把所有数据在 $t$ 日截断（用 `md.slice(start, t)`）。
3. 用截断后的数据重算 $t$ 日之前的全部信号与净值。
4. 与用全样本算出的 $t$ 日之前的净值对比。

如果两条曲线不一致，说明你的计算过程使用了 $t$ 日之后的信息。**任何差异都必须被解释清楚**。

```python
from qd.data.synthetic import generate_demo_market
from qd.data import MarketData

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

def signal(md_part):
    """一个待检查的信号：这里用 20 日动量"""
    return md_part.close().pct_change(20)

full = signal(md)

# 截断到 2020-06-30 重算，然后只比较截断日之前的部分
truncated = signal(md.slice("2018-01-01", "2020-06-30"))
common = full.index.intersection(truncated.index)
diff = (full.loc[common] - truncated.loc[common]).abs().max().max()
print("最大差异:", diff)      # 应接近 0（浮点误差级别）
```

## 五、检查清单

在把任何因子投入回测前，逐条打勾：

- [ ] 信号面板的每一行只用了该行日期及之前的数据？
- [ ] 所有 `shift(-k)` 已被消除？（在因子代码里搜索 `shift(-`、`iloc[i+`、`rolling(...).mean().shift(-`）
- [ ] 财务数据的生效日是披露日而非报告期？
- [ ] 指数成分/行业分类使用的是生效日版本？
- [ ] 标准化、去极值、缺失值填充都使用了滚动或扩展窗口？
- [ ] 训练/测试切分处是否设置了 embargo（标签窗口长度）？
- [ ] 回测中成交价晚于信号价至少一期？
- [ ] 复权因子在历史上是否与当时可得的一致？
- [ ] 是否通过了时间旅行测试？
- [ ] 数据版本号已记录？

## 六、与相关偏差的关系

- **前视偏差**：用了未来的信息。
- **幸存者偏差**：样本剔除了失败者（退市股），见 [02-05-幸存者偏差](./02-05-幸存者偏差.md)。
- **过拟合**：没有用未来信息，但在样本内拟合了噪声，见 [01-03-量化投研流程](../01-入门/01-03-量化投研流程.md)。

三者经常同时出现，且症状相似（回测漂亮、实盘拉胯）。区分它们的方法是：先做时间旅行测试排除前视，再检查样本完整性排除幸存者，最后用样本外检验评估过拟合。

## 常见坑

- **"我只是用了当天收盘价"**。用收盘价算信号又用收盘价成交，是最经典的前视，等价于假设你能"在收盘价成交且收盘价已知时下单"。正确信号→成交至少间隔一个 bar。
- **`.fillna(method="bfill")`**。向后填充用的是未来值，是明确的前视。
- **用 `.shift(-1)` 对齐收益**。计算未来收益做标签时必然要 shift(-1)，这没问题；但必须确保这个未来收益**只用于训练标签，不进入特征**。
- **滚动窗口的 `min_periods` 太小**。窗口未满时用少量样本估计标准差会造成早期极端值，虽不是前视但同样有害。
- **回测引擎的默认撮合假设**。有些引擎默认在信号 bar 成交，务必确认配置。
