# 复权停牌与异常处理

## 学完这一篇，你能做到

- 用自己的话说清"10 送 10 之后股价腰斩，我到底亏了没有"
- 分清前复权 / 后复权 / 不复权，知道每种该用在哪
- 解释**错误的复权怎么凭空造出一个"很赚钱"的假因子**
- 会识别并处理停牌、涨跌停、缺失值和异常跳变

## 本篇要点

- 复权的本质是保持"**持有者财富的连续性**"，不是改价格，是改口径
- 用不复权价算收益，除权日会出现巨大假跌幅 → 摧毁动量因子、制造反转假象
- 停牌期间不能成交；复牌跳空、涨跌停是回测最容易高估收益的地方
- 一条铁律：**算收益用复权价，判断能不能成交用不复权价**

---

## 一、从一次"账户没少、股价腰斩"说起

假设你持有某只股票 1000 股，股价 20 元，市值 2 万元。

某天公司公告 **"10 送 10"**：每 10 股白送你 10 股。除权日开盘，股价变成 **10 元**，你的持股变成 **2000 股**。

**你的钱一分没少**：10 元 × 2000 股 = 2 万元。

但如果你打开一个不做任何处理的行情软件，看它的"涨跌幅"，会看到触目惊心的一行：

> **-50%**

这一刻，所有依赖"过去涨跌幅"的策略集体出错：

- 动量策略（买最近涨得多的）会**立刻把这只股票踢出去**；
- 反转策略（买最近跌得最惨的）会**把它当成暴跌股重仓买入**；
- 而实际上，公司什么都没发生，你什么都没亏。

> **这就是本篇要讲的第一件事：数据里最大的假信号，常常不是市场给的，是"公司行为"制造的。**
> 分红、送股、配股都会让价格出现断层，但这个断层**不是投资收益的变化**。
> 不把它抹平，你的因子就是在对着会计分录做交易。

更麻烦的是，**这类股票不是随机的**。高送转的公司往往是前期涨幅大、股价高的股票。于是那个"反转因子"会系统性地买入一整批特定公司——回测显示效果奇好，实盘一跑就亏。**你以为发现了 alpha，其实只是买到了一筐刚除权的股票。**

---

## 二、复权到底在做什么（逐个讲透）

一句话：**复权不是改价格，是把价格换算到同一把尺子上，让"持有者的财富"连续。**

数学上引入一个**复权因子** $F_t$：

$$P_t^{\text{adj}} = P_t^{\text{raw}} \cdot F_t$$

逐个拆：

| 符号 | 意思 | 白话 |
| --- | --- | --- |
| $P_t^{raw}$ | 不复权价（原始价） | 交易所当天真实成交的那个数 |
| $F_t$ | 复权因子 | 累计了从基准日到 t 日**所有分红送转**的调整比例 |
| $P_t^{adj}$ | 复权后的价 | 抹平断层、可以放心算收益的价 |

**三种口径的差别，只在"基准点选在哪"**：

| 口径 | 基准 | 用途 | 千万别拿来做什么 |
| --- | --- | --- | --- |
| **不复权** | 无 | 判断涨跌停、确定实际成交价 | 算收益率、做技术指标 |
| **前复权** | 以**最新价**为基准，把历史价按比例下调 | 技术指标、图表、**收益率序列** | 判断涨跌停（价格可能接近 0 甚至为负） |
| **后复权** | 以**最早价**为基准，把之后的价格上调 | 长期累计财富、复利计算 | 算实际成交量、市值 |

> 补两个常识：
> - **除权 / 除息**（ex-rights / ex-dividend）：股权登记日之后，价格按规定扣掉分红或送股对应的价值，那天叫除权日。
> - **前复权价的"负值陷阱"**：长期高送转的股票，前复权后早期价格可能非常接近 0，甚至因为分红累计而为负。**这种价显然不能拿去判断 ±10% 涨跌停**——所以需要单独保留一份不复权价。

除权价怎么算？两个最常见的公司行为，式子很朴素：

$$P_{\text{ex}} = P_{\text{prev}} - D \quad\text{（现金分红，D 为每股股息）}$$

$$P_{\text{ex}} = \frac{P_{\text{prev}}}{1 + n/10} \quad\text{（每 10 股送 n 股）}$$

第二行代入开头那个例子：20 ÷ (1 + 10/10) = **10 元**，和软件显示的一样。**公式没错，错的是拿这个断层去算收益率。**

> **一条必须背下来的铁律：**
> **算收益率、做因子、画技术指标 → 用前复权；**
> **判断涨跌停、算可成交量、模拟撮合 → 用不复权（真实成交价）；**
> **算长期累计财富 → 用后复权。**
> 混用是数据清洗里最贵的一类错误。

---

## 三、错误复权怎么制造"假 alpha"（本节最重要）

把开头的例子写成收益率，就是那个 -50%：

$$r_t = \frac{10 - 20}{20} = -50\%$$

**这个 -50% 会被写进因子面板，然后被策略当真。** 三种典型后果：

| 错误做法 | 后果 |
| --- | --- |
| 用不复权价算收益率 | 除权日假暴跌 → 反转因子买入一批刚除权的股票，回测虚高 |
| 用不复权价算长期持有收益 | 每次分红都被当成"亏损"，蓝筹股每年低估 2~3 个百分点——**已经超过多数策略的年化 alpha** |
| 混用：前复权算信号 + 不复权撮合 | 前复权早期价格接近 0，技术指标完全错乱 |

> **为什么这件事值得单独一节？**
> 因为它不像前视偏差那样"偷看未来"，也不像幸存者偏差那样"少了样本"——
> **你的数据一条不少、代码一行没错，结论却完全是假的。**
> 这类错误只能靠"懂数据在说什么"来发现，测试帮不了你。

### 一个判断顺序

拿到任何一份新行情，先固定按这个顺序处理：

1. 用复权因子生成前复权价，**同时单独保留一份不复权价**用于撮合；
2. 算涨跌幅，筛出 $|r| > 11\%$（主板）的记录，**逐条核对**是除权、复牌、还是板块规则差异；
3. 用成交量生成"可交易掩码"；
4. 因子计算用**有限步长**的前向填充（如 `limit=5`），别让长期停牌的价格被无限沿用；
5. 记录每一步改了多少样本，**任何一步改动超过 1% 都要回头查原因**。

## 四、停牌：最隐蔽的是"复牌跳空"

停牌期间没有成交，数据里表现为缺失。不同用途处理方式不同：

| 场景 | 处理方式 | 理由 |
| --- | --- | --- |
| 因子计算 | 用停牌前最后一次有效值填充，但**标记**为不可用 | 避免 NaN 传播，后续要屏蔽 |
| 收益率计算 | 停牌期间设为 0 或 NaN | **不能用填充价算假收益** |
| 回测撮合 | 停牌日**不能成交**，订单顺延或失败 | 实盘确实买不到 |
| 组合权重 | 停牌股保持原权重，不计入当日可选池 | 避免换手率被虚增 |

**最隐蔽的危害是复牌后的跳空。** 重大资产重组停牌几个月，复牌可能连续涨停——这段时间你**既买不进也卖不出**。如果回测允许在复牌日按复牌价成交，收益会被系统性高估。正确做法：复牌后若涨停，当日不可买入（见 [03-01 A股交易规则](../03-市场与交易规则/03-01-A股交易规则.md)）。

> 一句话：**停牌不是"没有数据"，是"那几天你根本不在场"。**
> 把它当成 0 收益的普通交易日，等于假设自己能在停牌期间自由进出。

---

## 五、涨跌停：回测最容易白捡的钱

A 股主板日涨跌幅限制 ±10%（ST ±5%，创业板/科创板 ±20%，北交所 ±30%，**以交易所最新规则为准**）。两个要点：

- **涨停板不能买入，跌停板不能卖出**（买单排队几乎成交不了）。回测必须显式拒绝这类成交，否则任何"追涨停"策略都会得到虚高收益。
- 判断涨停应基于**前收盘价**：$\text{limit\_up} = \text{round}(P_{t-1}^{close} \times 1.10,\ 2)$。

> **行业里有个说法：追涨停策略的回测收益，几乎全部来自"允许在涨停价成交"这一个假设。**
> 实盘里你根本排不到队。这是 01-01 讲的"回测与实盘的差距"最典型的一例。

## 六、用平台做一次数据体检

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, vol, ret = md.close(), md.volume(), md.returns()

# 1) 异常跳变：主板单日涨跌应落在 ±11% 内（留 1% 给四舍五入与新规）
bad = ret.abs() > 0.11
print("异常跳变次数:", int(bad.values.sum()))

# 2) 停牌掩码：零成交或缺失视为不可交易
tradeable = (vol.fillna(0) > 0) & close.notna()
print("可交易比例:", round(tradeable.mean().mean(), 4))

# 3) 有限步长前向填充，用于因子计算；但保留掩码用于屏蔽信号
price_for_factor = close.ffill(limit=20)
signal = price_for_factor.pct_change(20).where(tradeable)

# 4) 涨停检测（示意；幅度按板块与交易所规则调整）
prev_close = close.shift(1)
limit_up = (close >= (prev_close * 1.10).round(2) - 1e-8)
print("疑似涨停占比:", round(limit_up.mean().mean(), 4))

# 5) "僵尸"标的：价格还在、但 20 日无成交
zombie = (vol.fillna(0).rolling(20).sum() == 0) & close.notna()
print("20 日无成交标的数:", int(zombie.iloc[-1].sum()))
```

我实跑的结果：

```
异常跳变次数: 364
可交易比例: 0.9963
疑似涨停占比: 0.0064
20 日无成交标的数: 0
```

**注意第 1 行：364 次"异常跳变"。** 这是合成数据里故意植入的涨跌停与停牌行为（生成器会模拟 ±10% 的涨跌停），不是脏数据。但它正好演示了这套检查的用途——**真实数据里，这 364 条必须逐条核对**：哪些是真涨跌停，哪些是复权没做对。**不核对就往下跑，等于把疑问直接埋进了因子。**

## 七、把这一篇串起来

回到那个"账户没少、股价腰斩"的瞬间。

软件没骗你，价格确实是 10 元；错的是**把一次会计调整当成了市场行为**。量化里大量"看起来很强的因子"，追到最后都是这类口径问题——不是模型不行，是**喂给模型的东西根本不是你以为的那个东西**。

> 数据工程里有句老话，值得和 02-04 那句放在一起：
> **"垃圾进，垃圾出"（Garbage in, garbage out）。**
> 但更准确的说法是：**"看似干净的错误数据进，理直气壮的错误结论出"**——
> 因为脏数据会报警，口径错的数据会给你发奖。

三篇陷阱到此凑齐了：

| 篇 | 骗你的方式 |
| --- | --- |
| [02-04 前视偏差](./02-04-前视偏差.md) | 让你**看到了**当时不该知道的数 |
| [02-05 幸存者偏差](./02-05-幸存者偏差.md) | 让你**少看了**本该在的失败者 |
| 本篇 | 数据一条不少，但**含义被改了** |

> 所以每次拿到新行情，先别急着算因子。
> **先问一句：这一列数字，到底在描述什么？** 这一问，能省掉后面几个月的弯路。

## 动手练习

- 找出你数据里单日涨跌幅超过 ±11% 的记录，**逐条判断**是真实涨跌、除权、还是复牌。把判断依据写进研究日志。
- 实现一个停牌掩码，分别应用到因子计算与回测撮合，对比前后收益差。**先猜哪个方向变化更大，再跑。**
- 用一句话向不懂股票的人解释：为什么"10 送 10 股价腰斩"不算亏钱。（讲得通，复权就算真懂了）

## 延伸阅读

- 交易所公布的交易规则与涨跌幅限制说明（上交所、深交所、北交所官方文件）——**具体幅度以最新规则为准**。
- 中证指数公司关于指数计算中公司行为处理的方法说明——复权的工业标准做法。
- 数据商提供的复权因子字段文档——实践中以数据商的具体定义为准。
