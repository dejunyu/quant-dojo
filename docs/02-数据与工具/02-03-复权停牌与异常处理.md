# 复权停牌与异常处理

## 一、复权的本质

股票分红、送股、配股会改变股价，但这种改变**不是投资收益的变化**：10 送 10 之后股价腰斩，你的持股数量翻倍，总资产不变。如果不处理，收益率序列会在除权日出现一次巨大的假跌幅。

复权的数学本质是引入一个**复权因子** $F_t$，使得：

$$P_t^{\text{adj}} = P_t^{\text{raw}} \cdot F_t$$

其中 $F_t$ 累计了从基准日到 $t$ 日所有公司行为的调整。三种口径的差别只在于基准点：

| 口径 | 基准 | 公式（$T$ 为样本最后一天） | 用途 |
| --- | --- | --- | --- |
| 不复权 | 无 | $P_t^{raw}$ | 判断涨跌停、确定实际成交价 |
| 前复权 | 最新价 | $F_t = \prod_{\tau=t}^{T-1} (1 + a_\tau)$ | 技术指标、图表、收益率序列 |
| 后复权 | 最早价 | $F_t = \prod_{\tau=0}^{t-1} (1 + a_\tau)^{-1}$ 的倒数形式 | 长期累计财富、复利计算 |

其中 $a_\tau$ 是除权除息当日的调整比例。以现金分红为例，除息日的理论除权价：

$$P_{\text{ex}} = P_{\text{prev}} - D$$

而送转股（每 10 股送 $n$ 股）的除权价为：

$$P_{\text{ex}} = \frac{P_{\text{prev}}}{1 + n/10}$$

## 二、错误复权如何制造假 alpha（本节最重要）

假设一只股票在 $t$ 日 10 送 10，价格从 20 元变为 10 元。如果你用不复权价计算：

$$r_t = \frac{10 - 20}{20} = -50\%$$

于是产生了一个 $-50\%$ 的"暴跌"。现在想象一个**反转因子**（买入过去一个月跌幅最大的股票）：这只股票会被判为"暴跌股"而买入，而它实际上什么都没发生。在整个市场上，高送转股票通常恰好是前期涨幅大、股价高的股票，于是这个假信号会系统性地买入一批特定股票——**回测会显示这个反转因子效果很好，实盘却亏钱**。

反之，动量因子会被同样的错误反向破坏：除权日的假暴跌让动量因子把这些股票排除在外，导致因子失效。

再看第二个例子：**用不复权价计算长期持有收益**。持有 5 年，期间分红 10 次，不复权算出的累计收益会系统性低估真实收益，低估幅度在 A 股蓝筹上可能每年相差 2~3 个百分点——这已经超过了多数策略的年化 alpha。

第三类错误是**混用**：用前复权价算信号、用不复权价撮合成交。前复权价在早期可能是负值或极小的数（长期高送转的股票前复权后早期价格可能接近 0），用它算出的"价格"会导致技术指标完全错乱。

**判断规则**：
- 算收益率、做因子、做技术指标 → 用**前复权**。
- 判断涨跌停、算可成交量、模拟撮合 → 用**不复权**（实际成交价）。
- 算长期累计财富 → 用**后复权**。

## 三、停牌

停牌期间没有成交，数据里表现为缺失。处理方式取决于用途：

| 场景 | 处理方式 | 理由 |
| --- | --- | --- |
| 因子计算 | 用停牌前最后一次有效值填充，但**标记**为不可用 | 避免 NaN 传播，但后续要屏蔽 |
| 收益率计算 | 停牌期间收益设为 0 或 NaN | 不能用填充价算假收益 |
| 回测撮合 | 停牌日**不能成交**，订单顺延或标记失败 | 实盘确实买不到 |
| 组合权重 | 停牌股票保持原权重，不计入当日可选池 | 避免换手率被虚增 |

停牌最隐蔽的危害是**复牌后的跳空**。长期停牌（重大资产重组）复牌时可能连续涨停，这段时间你既买不进也卖不出。如果回测里允许在复牌日以复牌价成交，就会系统性地高估收益。正确的做法是：复牌后若涨停，则当日不可买入（见 [03-01-A股交易规则](../03-市场与交易规则/03-01-A股交易规则.md)）。

## 四、涨跌停

A 股主板日涨跌幅限制为 ±10%（ST 股 ±5%，创业板/科创板 ±20%，北交所 ±30%，视交易所具体规则而定）。涨跌停的处理要点：

- **涨停板不能买入**（买单排队成交概率极低），**跌停板不能卖出**。回测必须显式拒绝这类成交，否则任何"追涨停"策略都会得到虚高的收益。
- 判断涨停应基于**前收盘价与涨跌停幅度**：$\text{limit\_up} = \text{round}(P_{t-1}^{close} \times (1 + 10\%), 2)$。
- 一字板（开盘即涨停且全天不打开）当日成交量极小，用成交量可以辅助判断真实性。

## 五、缺失值与异常跳变检测

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, vol, ret = md.close(), md.volume(), md.returns()

# 1) 缺失诊断：区分"整列缺失"（未上市/退市）与"零星缺失"（停牌）
missing_col = close.isna().mean()
print("缺失率最高的标的:\n", missing_col.sort_values(ascending=False).head(5))
print("每日缺失股票数（尾部）:\n", close.isna().sum(axis=1).tail(5))

# 2) 异常跳变：主板单日涨跌应落在 ±11% 内（留 1% 给四舍五入与新规）
bad = ret.abs() > 0.11
print("异常跳变次数:", int(bad.values.sum()))

# 3) 停牌掩码：零成交或缺失视为不可交易
tradeable = (vol.fillna(0) > 0) & close.notna()
print("可交易比例:", round(tradeable.mean().mean(), 4))

# 4) 前向填充价格用于因子计算，但保留掩码用于屏蔽信号
price_for_factor = close.ffill(limit=20)      # 限制填充长度，避免长期停牌污染
signal = price_for_factor.pct_change(20).where(tradeable)

# 5) 涨停检测（示意；幅度按板块与交易所规则调整）
prev_close = close.shift(1)
limit_up = (close >= (prev_close * 1.10).round(2) - 1e-8)
print("疑似涨停占比:", round(limit_up.mean().mean(), 4))

# 6) 零成交量与价格不变的检查：真正的"僵尸"标的
zombie = (vol.fillna(0).rolling(20).sum() == 0) & close.notna()
print("20 日无成交标的数:", int(zombie.iloc[-1].sum()))
```

## 六、处理流程建议

对任何一份新行情，按固定顺序处理：

1. 用复权因子生成前复权价，并**单独保留不复权价**用于撮合。
2. 计算涨跌幅，筛出 $|r| > 11\%$（主板）的记录，逐条核对是否为除权/停牌复牌/板块规则差异。
3. 用成交量生成可交易掩码。
4. 对因子计算使用有限步长（如 `limit=5`）的前向填充，避免长期停牌的价格被无限沿用。
5. 记录每一处修改的数量，任何一步改动超过 1% 的样本都要回头查原因。

## 常见坑

- **直接用数据源提供的"收盘价"而不确认是否已复权**。不同源默认值不同，有的是不复权，有的提供多列。这是最常见的假 alpha 来源。
- **用 `fillna(0)` 处理价格**。价格填 0 会让收益率变成 $-100\%$，制造一批"暴跌股"。
- **无限步长前向填充**。停牌半年的股票价格被沿用半年，复牌后因子值严重失真。
- **忽略 ST 股与不同板块的涨跌幅差异**，用统一的 ±10% 判断涨跌停。
- **在回测中允许涨跌停成交**。追涨停类策略的回测收益几乎全部来自这里，实盘不可复制。

## 延伸阅读

- 交易所公布的交易规则与涨跌幅限制说明（上交所、深交所、北交所官方文件），具体幅度与适用板块以最新规则为准。
- 中证指数公司关于指数计算中公司行为处理的方法说明——理解复权的工业标准做法。
- 数据商提供的复权因子字段文档——实践中应以数据商的具体定义为准。
