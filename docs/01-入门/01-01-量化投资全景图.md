# 量化投资全景图

## 一、定义：把"判断"换成"规则"

量化投资的本质不是"用电脑炒股"，而是**把投资决策中依赖主观判断的部分，尽可能替换成可计算、可检验、可重复的规则**。这句话里有三个可拆开的词：

1. **规则化**：买什么、买多少、什么时候卖，必须写成不含歧义的表达式。"我觉得这个票要涨"不是规则；"过去 12 个月剔除最近 1 个月的收益率排名前 20% 且成交额大于 1 亿元的股票，等权买入"是规则。
2. **可回测**：规则必须在历史数据上跑出可度量的结果，且这个结果要能经得起样本外检验。
3. **可复现**：同一份数据 + 同一份代码 + 同一份参数，任何人在任何时间重跑，结果必须逐笔一致。做不到可复现的研究，等于没做。

把所有策略抽象成一个统一形式，后面所有章节都会反复用到：

$$w_t = f(X_t;\theta)$$

其中 $X_t$ 是 $t$ 时刻**已经公开**的信息矩阵（行为股票、列为特征），$\theta$ 是模型参数，$w_t$ 是目标持仓权重向量。量化研究的全部工作，就是寻找一个函数 $f$ 与参数 $\theta$，使未来一段时间的组合收益在扣除成本后仍为正——同时要保证这个 $f$ 不是从噪声里硬凑出来的。

## 二、量化 vs 主观

| 维度 | 主观投资 | 量化投资 |
| --- | --- | --- |
| 决策依据 | 深度研究少数标的，重逻辑与调研 | 统计规律覆盖广度，重一致性与频率 |
| 持仓数量 | 通常 10~50 只 | 通常 100~3000 只 |
| 单票权重 | 高（可达 10%） | 低（常 0.1%~2%） |
| 调仓频率 | 低，按季度/事件 | 高，日频至月频 |
| 信息处理 | 非结构化（纪要、电话、调研） | 结构化（行情、财报、另类数据） |
| 可复制性 | 依赖人，难以传承 | 依赖代码与数据，可复制 |
| 典型失败模式 | 认知偏差、过度自信 | 过拟合、前视偏差、容量误判 |

注意这张表讲的是**典型情况**，不是绝对分界。很多机构是"量化选股 + 主观否决"的混合模式。

## 三、产业链：谁在做什么

- **卖方**：券商研究所提供研报、路演与一致预期数据；部分券商还提供因子库与算法交易服务。
- **买方公募**：指数增强基金（在跟踪误差约束下追求超额）、量化对冲基金（用股指期货对冲掉市场 beta）。
- **买方私募量化**：市场中性、CTA（管理期货）、指增、套利、高频。私募的组织形态通常是"投研团队 + 自建交易系统"。
- **基础设施**：数据商（Wind、聚源、Tushare、akshare 等）、PB 托管、券商柜台与 API、云计算。

一个关键区分：**超额收益的来源决定了你能承受的规模**。依赖越快的信号（秒级、分钟级），容量越小、越依赖交易系统；依赖越慢的信号（月度基本面），容量越大、越依赖数据与模型。

## 四、收益来源分类

任何一笔收益都应该被拆开看，否则你不知道自己到底赚的是什么钱：

$$r_p = \alpha + \sum_{k}\beta_k f_k + \varepsilon_p$$

- **beta**：随市场涨跌而来的收益，不承担额外风险也能拿到，代价是承受系统性回撤。
- **风格因子暴露**：市值、价值、动量、质量、低波等长期溢价的暴露。这部分看起来像 alpha，本质是另一种 beta，也会失效和回撤。
- **纯 alpha（残差收益）**：剔除所有已知因子暴露后剩下的部分。它才是需要真正竞争的地方。
- **交易/流动性收益**：做市、套利、执行优化赚的钱，本质是提供流动性或者信息处理的报酬。
- **结构性收益**：打新、分红、股指期货贴水带来的收益，通常与制度安排有关，容量和持续性都有限。

入门阶段最容易犯的错，是把"风格因子暴露"当成了自己的 alpha：小市值因子在 A 股长期有效，但一个满仓微盘股的组合并不需要"模型"，它的收益几乎全部来自市值因子暴露，一旦风格反转会回撤得非常彻底。

## 六、跑通第一个策略

```python
from qd.data.synthetic import generate_demo_market
from qd.strategy.builtin import sma_cross
from qd.backtest import Backtest, BacktestConfig
from qd.metrics.perf import perf_report

# 1) 数据：平台内置合成行情，离线可复现（seed 固定则数据固定）
md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
print(md.symbols[:5], len(md.dates))

# 2) 信号：双均线，快线上穿慢线做多，下穿平仓（策略工厂返回可回测对象）
strategy = sma_cross(fast=20, slow=60)

# 3) 回测
bt = Backtest(md, strategy, BacktestConfig(initial_cash=1_000_000))
res = bt.run()

# 4) 复盘：净值曲线、成交明细、绩效指标
print(res.summary())
print(perf_report(res.equity, rf=0.02))
print(res.trades.head())
```

这段代码的价值不在于策略本身（双均线在扣费后基本不赚钱），而在于它把"数据—信号—回测—评价"这条链路跑通了一次。之后所有复杂策略，都是在这条链路上替换中间环节。

## 常见坑

- **把回测收益当成绩**。一个没有扣除交易成本、没有考虑涨停买不进、没有做样本外检验的回测曲线，几乎必然漂亮。
- **用"未来函数"作弊**。最常见的形态是用当天收盘价算信号，再用当天收盘价成交。正确做法是用 $t$ 日信号在 $t+1$ 日成交，详见 [02-04-前视偏差](../02-数据与工具/02-04-前视偏差.md)。
- **混淆相关与因果**。因子与收益在历史上相关，不代表机制仍在。任何因子都要能讲出"为什么有人愿意长期为此付出代价"。
- **忽略容量**。回测里买 1 手和实盘买 1 亿是完全不同的两件事，参见 [03-05-流动性与冲击成本](../03-市场与交易规则/03-05-流动性与冲击成本.md)。

## 延伸阅读

- Burton Malkiel，《漫步华尔街》（*A Random Walk Down Wall Street*）——建立对市场有效性争论的基本认识。
- Richard Grinold & Ronald Kahn，《主动投资组合管理》（*Active Portfolio Management*）——主动管理的经典框架与信息率理论。
- 丁鹏，《量化投资：策略与技术》——中文语境下对 A 股量化策略分类较早的系统整理。
