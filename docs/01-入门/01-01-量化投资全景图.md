# 量化投资全景图

## 学完这一篇，你能做到

- 用自己的话解释量化在做什么，不需要任何数学背景
- 说出量化投资的四个环节，以及每个环节最容易出错的地方
- 分清"我真的有本事"和"我只是搭了顺风车"——这是本篇最重要的一件事
- 跑通人生第一个量化策略，看懂它为什么是一条坏策略

## 本篇要点

- 量化 = 把"我觉得"翻译成"如果……就……"，让电脑能执行、能检验
- 四环节：数据 → 想法 → 回测 → 实盘，任何一环偷懒都会让你亏真钱
- 收益要拆开看：市场给的、风格给的、你本事赚的，三者完全不同
- 一个策略"回测很好看"和"能赚钱"之间，隔着一整个陷阱场

## 一、从一位数学教授说起

1961 年的一个周末，拉斯维加斯。

一个三十岁不到的数学教授坐在 21 点牌桌前，戴着墨镜。他不是来赌运气的——他带了一台**可穿戴计算机**，藏在鞋里，用脚趾输入数据，通过藏在耳朵里的耳机接收"该下多少注"的提示音。

这台机器是他和**克劳德·香农**（信息论之父）一起在自家地下室做出来的。

这个教授叫**爱德华·索普**。

事情要从更早说起。1958 年前后，索普还在读博，他琢磨了一个别人觉得"没意义"的问题：**21 点这个游戏，庄家的优势到底有多大？如果每一张发出的牌我都记住，优势会不会翻转？**

当时的赌场界有个共识：赌场优势是数学规律，长期玩必输。索普不信这个"共识"，他去查了凯利公式，然后**用 IBM 704 计算机跑了海量模拟**——在那个计算机要占满一个房间的年代，他为了算这个，专门去学了 Fortran。

结论是：**只要记牌，在某些牌局末段，玩家的期望收益会变成正的。**

他写成书，1962 年出版，叫《击败庄家》，卖了 70 多万册，登上《纽约时报》畅销榜。赌场慌了——作为对策，它们开始**提前洗牌**，让你无法记牌。

但这个故事真正的结局不在赌场。

索普发现，同样的思维方式在股市里更值钱。1969 年他成立普林斯顿/纽波特合伙公司，做"市场中性"策略——用模型找定价错误，同时做多和做空，把大盘涨跌的影响对冲掉。

据索普本人 1998 年披露，他个人投资在 28.5 年里的年化收益率约 20%。

> **这个故事里有量化投资的三根支柱，记住这三根就够了：**
>
> 1. **先算，再下注。** 不是"我觉得能赢"，而是先用计算机跑出概率，确信期望为正才进场。
> 2. **只在有优势时下注。** 记牌到牌局末段才加大注码，其余时间下最小注。**优势不明显时，什么都不做才是对的。**
> 3. **优势消失就换战场，不是更用力。** 赌场改了洗牌规则，他没有硬刚，而是把同一套方法搬到股市。

## 二、所以量化到底是什么

如果上面那段话你只记住一件事，请记住这句：

> **量化投资，就是把"我觉得"这三个字，换成电脑能执行的规则。**

用索普的例子对照一下：

| 说法 | 能不能交给电脑 |
| --- | --- |
| "这只股票我觉得要涨" | ❌ 电脑不知道"觉得"是什么意思 |
| "我判断现在是底部" | ❌ 什么叫底部？没有定义 |
| "当过去 12 个月涨幅排在全部股票前 20%，且成交量放大时买入" | ✅ 每一个条件都能算出来 |
| "当牌局剩余牌中 10 点牌占比超过 40% 时，加大注码" | ✅ 索普的做法，可计算 |

区别不在于谁更聪明，而在于**能不能被检验**。

这一点极其重要：**不能被检验的判断，你永远不知道自己是对是错**——赚了可能是运气，亏了可能是运气，你无从改进。

### 三个必须同时成立的条件

1. **规则化**：买什么、买多少、什么时候卖，写成没有歧义的表达式。"我觉得这个票要涨"不是规则；"过去 12 个月剔除最近 1 个月、收益率排名前 20%、且日均成交额大于 1 亿元，等权买入"是规则。
2. **可回测**：规则能在历史数据上跑出结果。注意——"能跑出结果"不等于"结果可信"，第四部分会讲这里有多少坑。
3. **可复现**：同一份数据 + 同一份代码 + 同一份参数，任何人、任何时间重跑，结果必须逐笔一致。**做不到可复现，等于没做。**

第三点常被忽略，但它是一切的基础。如果你的结果依赖于"我那天心情好调了个参数"，你就永远无法判断改进来自哪里。

> 物理学家费曼在 1974 年的毕业演讲里说过一句话，是这个行业最好的座右铭：
> **"第一原则是：你不能欺骗自己——而你是最容易被自己欺骗的人。"**
>
> 这句话在量化里尤其致命，因为你的对手不是市场，是**你自己写的那段看起来很漂亮的历史回测**。

## 三、量化 vs 主观：没有高下，只有分工

新手最容易陷入的争论是"量化好还是主观好"。这是个伪问题——它们是两种不同的**工作方式**，成本和风险完全不同。

| 维度 | 主观投资 | 量化投资 |
| --- | --- | --- |
| 靠什么赚钱 | 比别人更懂某家公司/行业 | 比别人更快、更系统地处理大量数据 |
| 覆盖范围 | 深挖 10~50 只 | 广泛覆盖 100~3000 只 |
| 单只股票仓位 | 重（可达 10%） | 轻（常 0.1%~2%） |
| 决定频率 | 低，按季度/事件 | 高，日频到月频 |
| 靠什么信息 | 调研纪要、电话会、产业链 | 结构化数据：行情、财报、另类数据 |
| 最难的地方 | 判断错了很难及时认错 | 回测骗你，而你不知道 |
| 典型死法 | 认知偏差、过度自信 | 过拟合、前视偏差、容量误判 |
| 能不能传承 | 难，依赖人 | 相对容易，代码和数据都在 |

注意最后一行——**两种方式死法不同**。主观死于人性的弱点，量化死于统计的陷阱。后面你会发现，本书花了大量篇幅讲量化怎么"自己骗自己"，因为这是这个行当里最贵的教训。

再补一个常听到的词：**"市场中性"**。就是同时做多和做空，把上面说的 beta 对冲掉，只留下 alpha。索普的基金做的就是这件事——不管大盘涨跌，我只赚我判断对的那部分差价。

现实中很多机构是混合的：模型选股，人来做最后的否决。这不是骑墙，是两种能力互补。

## 四、钱的来源：这一节最容易被跳过，也最重要

假设去年你的账户赚了 20%。问你一个问题：

**这 20% 里，有多少是你"有本事"，有多少是"市场给的"？**

绝大部分新手答不上来。而这恰恰决定了你明年会不会把钱赔回去。

任何一笔收益，都可以拆成三层。这三层在行业里有正式的叫法，**记住这几个词，你跟人聊天就不会露怯**：

| 收益来源 | 专业术语 | 是什么 | 牛市结束时会怎样 |
| --- | --- | --- | --- |
| **市场给的** | **beta（贝塔）收益** | 大盘涨 20%，你跟着涨 20%。这是"搭车"，你不需要任何本事就能拿到 | 大盘跌，你跟着跌，一分不少还回去 |
| **风格给的** | **风格因子收益** | 你专买小盘股、低估值股或高股息股，这类股票这几年刚好流行 | 风格一转，回撤可能比大盘更惨 |
| **你自己赚的** | **alpha（阿尔法）收益** | 剔除上面两层之后，剩下的那部分超额收益 | 这部分才是真本事，但也最难拿到 |

> **行业里最常用的一句话是"我要赚 alpha，不是赚 beta"。**
> 意思是：我要靠本事赚钱，而不是靠大盘上涨搭顺风车。这句话是判断一个策略好坏的起点。

顺带把一个常被搞混的地方说清楚——**beta 不是"坏东西"**。指数基金就是纯粹赚 beta，而且它跑赢了绝大多数专业基金经理。beta 的问题不在于它低人一等，而在于**它不需要你，谁拿都一样**。你要证明自己有价值，就得拿出 beta 之外的东西。

### 一个真实感很强的例子

假设 2021 年你满仓买了一批小市值股，年底赚了 30%。你觉得自己有本事。

但真相很可能是：那一年小市值**风格**本身就涨了 28%，你实际只贡献了 2%——**而这 2% 可能还是运气，不是 alpha**。

这解释了行业里一个现象：很多"明星"基金经理在风格顺风期业绩惊人，**风向一转就回撤到妈都不认识**。不是他变笨了，是他从来就没拥有过 alpha，只是站在了风口上。

> ⚠️ **入门阶段最容易犯的错，就是把"风格因子收益"当成了自己的 alpha。**
> 一个满仓微盘股的组合根本不需要"模型"，它的收益几乎全部来自市值风格暴露。

这不是说风格因子不能赚钱——它长期确实有效，学术界叫它"因子溢价"。而是说：**你要知道自己赚的是什么钱，才知道这钱还能赚多久。**

> 投资大师格雷厄姆有句被引用了一百年的话：
> **"短期看，市场是一台投票机；长期看，它是一台称重机。"**
>
> 投票机比的是人气，称重机比的是分量。**量化做的事，就是别去猜人气，老老实实去称重。**

## 五、四环节流程：整本书的地图

量化从头到尾就四个环节。你现在不需要会做，只需要知道**它们是什么、各容易错在哪**。

| 环节 | 在干什么 | 最容易死在哪 |
| --- | --- | --- |
| **1. 数据**（第 02 章） | 拿到干净、不含未来信息的行情和财报 | 前视偏差：用了当时还不知道的信息；幸存者偏差：只看到活到今天的股票 |
| **2. 想法**（第 05 章） | 把"经验"变成可算的因子或信号 | 想出一个事后看来理所当然、但当时毫无依据的规律 |
| **3. 回测**（第 06 章） | 用历史数据检验这个想法 | **最常见、最致命**：参数调得太细、样本太短、成本没扣、试了 900 次才挑出最好的一次 |
| **4. 实盘**（第 07-11 章） | 小资金真实运行，边跑边监控 | 回测和实盘的差距：滑点、成交不了、容量不够 |

如果只能给一句话提醒，就是这句：

> **回测好看几乎不能说明什么，但回测难看一定说明有问题。**（方向是不对称的）

索普当年也做了这件事：在赌场真正赢钱之前，他先在 IBM 704 上把所有牌型组合跑了一遍。**计算机跑出来的结果，才是他敢下注的依据——而不是直觉。**

### 那数据从哪来？

这是新手最容易误解的一点：**课程里跑的，绝大多数不是真实行情。**

以本篇为例，代码里有一行：

```
md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
```

`generate_demo_market` 是平台内置的**假股市生成器**：它不下载任何东西，而是用随机数**当场造**出一份行情。我实际跑它的结果是：50 只编造的股票、1827 个交易日、编造的股票代码（`600000`、`600001`…），但结构完整——有开盘价/收盘价/成交量，有市盈率/净资产收益率/市值/行业分类，甚至连**停牌**（成交量归零）和**涨跌停**都模拟了。

**它最特别的地方，是里面被故意埋进了真实的规律**：中期动量、短期反转、价值、低波动。为什么？为了让你亲身感受一件事——**因子"有效"和"神奇"是两回事**。你会看到动量因子的 IC 确实为正，但正得非常微弱，扣掉交易成本就所剩无几。

这是设计者的用心，但你必须记住它的边界：

| 你想做的事 | 用合成数据行不行 |
| --- | --- |
| 学会方法、跑通流程、理解概念 | ✅ 完全可以 |
| 判断某个策略"真实能不能赚钱" | ❌ **绝对不行** |
| 跟人说"我的策略年化 X%" | ❌ 说了就是外行 |

> **合成数据是用来学方法的，不是用来选策略的。**
> 真要研究实盘，用平台里的 `AkshareFeed` 接真实 A 股行情（第 02 章会讲）。

那 `seed=7` 是什么？**随机种子**。固定它，你每次生成的都是同一份数据。这就是前面说的"可复现"——**换台电脑、换个人跑，结果也必须一模一样**。

### 第一个策略

下面这段完整复制，存成 `my_first_strategy.py`，然后按上面三步跑。

注意第一行的 `generate_demo_market`——**就是前面说的假股市生成器**。所以下面所有数字，都是在"编造但结构真实的行情"上跑出来的，用来学方法，不代表真实 A 股。

```python
from qd.data.synthetic import generate_demo_market
from qd.strategy.builtin import sma_cross
from qd.backtest import Backtest, BacktestConfig
from qd.metrics.perf import perf_report

# 1) 数据：平台内置的模拟行情，不联网也能跑（seed 固定则数据固定）
md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
print(md.symbols[:5], len(md.dates))

# 2) 信号：双均线策略，快线上穿慢线做多，下穿就平仓
strategy = sma_cross(fast=20, slow=60)

# 3) 回测
bt = Backtest(md, strategy, BacktestConfig(initial_cash=1_000_000))
res = bt.run()

# 4) 复盘：看净值、成交和完整绩效
print(res.summary())
print(perf_report(res.equity, rf=0.02))
print(res.trades.head())
```

跑完你会看到一大串数字。**别急着看收益，先看这三个：**

```
累计收益：27.06%   年化：3.36%   年化波动：17.34%
最大回撤：-46.01%
总成本 740,543 元（年均 102,144 元，≈ 初始资金 10.21%/年）
```

这三行就是一次完整的量化启蒙：

| 数字 | 它在说什么 |
| --- | --- |
| **年化 3.36%** | 7 年下来年化只有 3.36%——还不如国债。但注意它不是 0，策略**确实抓到了点什么** |
| **最大回撤 -46%** | 中间有段时间，你的 100 万变成了 54 万。**为了 3.36% 的年化，你要扛住腰斩**——这个性价比是灾难性的 |
| **成本年均 10.21%** | 最狠的一个。策略毛收益被交易成本吃掉一大半。**双均线不是不赚钱，是赚的钱全交了手续费和印花税** |

> **一个"看着还行"的收益率，配上"腰斩的回撤"和"10% 的年化成本"，是一个彻头彻尾的坏策略。**
> 而且它亏的方式极其隐蔽——你不会在某一天突然亏光，你会用七年时间慢慢发现：白忙一场。

这不是 bug，这就是真相。双均线是人类最早被发现的交易规则之一，如果它稳定赚钱，早就没人干别的了。

**但请注意第三个数字。** 如果只做一件事能让这个策略变好，不是换股票、不是调参数，而是**降低交易频率**——8418 笔交易太多了。后面第六章你会看到，同一个策略把调仓从"每天"改成"每月"，收益会从负变正。

> **这段代码真正的价值，是让你第一次走完"数据→信号→回测→评价"这条链路。**
> 之后所有复杂策略，都是在这条链上替换中间环节而已。看懂这一点，你就有了整本书的骨架。

## 七、新手的四个坑（建议抄下来）

- **坑 1：把回测收益当成绩。**
  一个没扣交易成本、没考虑涨停买不进、没做样本外检验的回测曲线，**几乎必然漂亮**。漂亮的回测是最不值得高兴的东西。

- **坑 2：用"未来函数"作弊。**
  最常见的形态：用当天收盘价算信号，再用当天收盘价成交。这相当于考试时偷看了答案——你不可能知道当天收盘价，因为那时候还没收盘。
  正确做法：用今天的信号，在明天成交。

- **坑 3：混淆相关与因果。**
  历史上"冰淇淋销量"和"游泳溺亡数"高度相关，但吃冰淇淋不会导致溺亡——两者都是"夏天"的结果。
  因子与收益在历史上相关，不代表机制还在。**任何因子你都要能讲出"为什么有人愿意长期为它付钱"**，讲不出来的，大概率是巧合。

- **坑 4：忽略容量。**
  回测里买 1 手和实盘买 1 亿，是完全不同的两件事。前者立刻成交，后者会把价格买上去。

## 八、把这一篇串起来

回到索普。

他在赌场做的三件事，和量化投资的三个环节完全对应：

| 索普在赌场 | 对应量化 |
| --- | --- |
| 用 IBM 704 算每种牌型的胜率 | **先算清楚概率**：数据 + 建模 |
| 只在牌局末段优势明显时加注 | **仓位管理**：没有优势就不下注 |
| 赌场改了洗牌规则，他转去股市 | **优势会衰减**：换战场，不是更用力 |

他后来在 1991 年就怀疑麦道夫的收益"在数学上不可能"，而麦道夫在 2008 年爆出是庞氏骗局。**"这个数字说不通"——这种判断力，就是量化训练出来的。**

> 最后送你一句塔勒布在《黑天鹅》里讲的故事：
> **一只火鸡被喂养了 1000 天，每一天它都更加确信"人类是爱我的"。第 1001 天是感恩节。**
>
> 你的回测跑 1000 次都很漂亮，不代表第 1001 次不会崩。
> **历史上没有出现过的风险，不等于不存在——它可能只是还没轮到。**

## 动手练习

- 跑一遍上面的代码，把 `fast=20, slow=60` 改成 `fast=5, slow=20`，看结果变成什么样。**先猜，再跑**，然后问自己：为什么猜错了？
- 写下你最近做过的一个投资或消费决定，试着改写成"如果……就……"的形式。你会发现自己有大量"判断"根本无法被检验——**把它们圈出来，那就是你未来要补的认知漏洞。**
- 找一只你熟悉的股票，问自己：过去三年它的涨幅里，多少是大盘给的？多少是它所在风格（大小盘、行业）给的？剩下的才是它自己的。
