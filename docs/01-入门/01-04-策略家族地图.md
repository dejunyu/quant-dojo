# 策略家族地图

## 一、用什么标准分类

很多人按"技术分析/基本面/机器学习"分类，这对研究没有帮助。更有用的三个轴是：

1. **收益来源**（赚谁的钱）：是承担风险、提供流动性、还是利用行为偏差？
2. **持有期**（秒、分钟、日、周、月）：决定了能容纳多少资金和需要什么基础设施。
3. **方向性**（有 beta 还是中性）：决定了它在熊市里的表现形态。

按这三个轴，可以把主流策略分成七大族。

## 二、七大策略家族对比

| 家族 | 收益来源 | 典型持有期 | 容量 | 方向性 | 主要失效条件 |
| --- | --- | --- | --- | --- | --- |
| 趋势/动量（CTA、Turtle） | 趋势延续的反应不足与被迫平仓 | 周~月 | 大 | 可做多空 | 震荡市反复被打脸；趋势反转时集中回撤 |
| 均值回归 | 流动性冲击后的价格回复 | 分钟~周 | 中 | 通常中性 | 遇到基本面真实恶化，"回归"变成"继续下跌" |
| 套利（期现、跨期、ETF） | 同一资产在不同场所/形式的价差 | 分钟~日 | 中 | 中性 | 价差因制度/信用而长期不收敛 |
| 多因子选股 | 长期风险溢价 + 行为偏差 | 周~月 | 很大 | 通常多头 | 风格反转；因子拥挤 |
| 指数增强 | 多因子 alpha + 严格跟踪误差约束 | 周~月 | 很大 | 多头 | 超额被成本吃掉；风格漂移被问责 |
| 统计套利（配对、协整） | 相对定价错误的修正 | 日~周 | 中 | 中性 | 协整关系破裂（基本面分化） |
| 高频/做市 | 流动性供给、微观结构预测 | 秒~分钟 | 小 | 中性 | 竞争加剧、手续费/监管变化 |

**表里最该记住的一列是"失效条件"**。任何一个策略在被采用之前，都应该先写清楚"我在什么情况下会亏钱"，否则你无法在亏损时区分"正常回撤"和"策略已死"。

## 三、逐个说明

### 趋势跟踪

核心假设是价格存在自相关（$Corr(r_t, r_{t+k}) > 0$ 在某些 k 上成立），成因包括信息扩散缓慢、机构分批建仓、以及止损触发的连锁反应。典型实现是唐奇安通道突破（Turtle）与双均线：

$$\text{信号} = \mathbf{1}\{P_t > \max(P_{t-1},\dots,P_{t-n})\}$$

趋势策略的收益分布高度右偏：大部分时间小亏（震荡期的假突破），少数时间大赚。这意味着它的胜率通常只有 35%~45%，靠盈亏比取胜。新手最容易在这里失败——因为连续 8 次小亏会让人忍不住改参数，而改完参数往往刚好错过下一波大趋势。

### 均值回归

核心假设是短期价格受流动性冲击偏离"价值中枢"，之后回复。布林带是典型实现：

$$z_t = \frac{P_t - MA_{20}(P)}{\sigma_{20}(P)}, \quad z_t < -2 \Rightarrow \text{买入}$$

它与趋势策略在数学上是相反的，因此**两者常常互补**：一个组合里同时配置趋势与均值回归，可以平滑收益曲线。它的致命风险是"接下落的刀"——当价格下跌源于基本面恶化而非流动性冲击时，回归假设不成立。因此均值回归策略必须在基本面层面做过滤，并且强制止损。

### 配对交易与统计套利

找两个价格序列存在协整关系的资产（$P_t^A - \beta P_t^B \sim I(0)$），做多价差低估的一方、做空高估的一方。关键操作是**先检验协整再交易**，而不是先看图表觉得"它们走势很像"。协整是一种统计关系，会因一方基本面变化而永久破裂，因此必须持续监控。

### 多因子与指数增强

把多个有经济逻辑的信号合成一个综合打分：

$$score_t = \sum_k \omega_k \cdot \text{zscore}(f_{k,t})$$

指数增强在此基础上叠加约束：行业偏离 < 2%、市值暴露中性、跟踪误差（TE）通常控制在 3%~8%。对新手而言，指增是最好的入门方向——因为它有明确的基准和明确的考核指标（超额收益、信息比率），不容易自欺。

### 高频与做市

依赖队列位置、订单簿预测、极低延迟。它对个人投资者基本不开放：需要托管机房、极快的行情与柜台、以及规模化的技术投入。个人能做的"类高频"通常是分钟级的短周期动量或做市型挂单，容量很小。

## 四、横向对比：三类起步策略

```python
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import (
    sma_cross, bollinger_reversion, dual_momentum, turtle_breakout,
    pairs_trading, rotation, buy_and_hold,
)
from qd.metrics.perf import perf_report, max_drawdown

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

candidates = {
    "sma_cross":        sma_cross(fast=20, slow=60),
    "bollinger":        bollinger_reversion(window=20, n_std=2.0),
    "dual_momentum":    dual_momentum(lookback=120),
    "turtle":           turtle_breakout(entry=20, exit=10),
    "buy_and_hold":     buy_and_hold(),
}

rows = []
for name, strat in candidates.items():
    res = Backtest(md, strat, BacktestConfig(initial_cash=1_000_000)).run()
    m = perf_report(res.equity, rf=0.02)
    rows.append({
        "strategy": name,
        "sharpe": round(m["sharpe"], 2),
        "ann_ret": round(m["annual_return"], 4),
        "mdd": round(max_drawdown(res.equity), 4),
        "n_trades": len(res.trades),
    })

import pandas as pd
print(pd.DataFrame(rows).set_index("strategy"))
```

看这份对比表时要同时看四列：夏普（风险调整后收益）、年化（绝对收益）、最大回撤（痛苦程度）、成交笔数（换手与成本压力）。**一个夏普高但成交 8000 次的策略，在真实成本下大概率会归零**；而 `buy_and_hold` 作为对照基准，是所有策略都必须跑赢的门槛。

## 五、如何选择起步方向

| 你的情况 | 建议起步方向 |
| --- | --- |
| 个人、资金小、无特殊权限 | 日频多因子选股 / ETF 轮动 |
| 有期货账户、能承受回撤 | CTA 趋势（Turtle、双均线） |
| 有融券或期货对冲能力 | 市场中性、配对交易 |
| 有编程与低延迟能力、资金较大 | 分钟级统计套利 |
| 时间有限、追求稳健 | 风险平价 / 波动率目标配置 |

## 常见坑

- **只看收益不看容量**。回测里 3000% 的收益如果只能容纳 10 万元，毫无意义。
- **把不同家族的策略简单相加**。趋势 + 均值回归在同一标的上会互相抵消信号；正确做法是在不同标的或不同周期上组合。
- **用同一段历史评价所有策略**。每个策略都有自己的"好年份"和"坏年份"，单点对比容易产生错误结论，应该看全周期与分年度表现。
- **忽视交易规则约束**。A 股 T+1 使得日内均值回归策略无法在当天卖出，详见 [03-01-A股交易规则](../03-市场与交易规则/03-01-A股交易规则.md)。

## 延伸阅读

- 柯蒂斯·费思（Curtis Faith），《海龟交易法则》——趋势跟踪最著名的公开实验与系统描述。
- John Bollinger, *Bollinger on Bollinger*——布林带指标作者本人的说明与用法限制。
- Ernie Chan，《量化交易：如何建立自己的算法交易业务》（*Quantitative Trading*）——面向个人投资者，涵盖均值回归与配对交易的实现细节。
