# 收益分解与风险因子

## 一、为什么必须做分解

假设你的策略去年赚了 40%，沪深 300 涨了 15%。你很容易得出"我的 alpha 是 25%"这个结论。但真实情况可能是：你的组合平均市值只有基准的 1/5，而去年小盘风格大涨——你的"alpha"其实是市值因子暴露，它会在风格反转的年份原样吐回去。

收益分解唯一的目的，就是**把这两件事分开**。没有分解，你无法回答"这个策略明年还会赚吗"。

## 二、分解的层级

$$r_p - r_f = \underbrace{\alpha}_{\text{选股能力}} + \underbrace{\beta_m (r_m - r_f)}_{\text{市场暴露}} + \underbrace{\sum_k \beta_k f_k}_{\text{风格暴露}} + \underbrace{\varepsilon}_{\text{残差}}$$

| 成分 | 来源 | 是否可持续 | 是否需要主动管理 |
| --- | --- | --- | --- |
| 无风险利率 $r_f$ | 货币市场 | 是 | 否 |
| 市场 beta | 承受系统性风险 | 长期为正但波动大 | 否（买 ETF 即可） |
| 风格因子暴露 | 市值、价值、动量、质量、低波等 | 长期存在但周期性很强 | 部分 |
| alpha | 错误定价、信息处理、流动性供给 | 会衰减 | 是 |
| 残差 | 运气 | 否 | — |

这张表说明了量化行业的商业模式：**客户付高费率买的是 alpha，而 beta 部分应该便宜地获得**。如果你的策略大部分收益来自 beta，客户应该买指数基金而不是付你 2/20 的费率。

## 三、CAPM：最简单的分解

CAPM 只有一个因子：

$$\mathbb{E}[r_i] - r_f = \beta_i (\mathbb{E}[r_m] - r_f), \quad \beta_i = \frac{Cov(r_i, r_m)}{Var(r_m)}$$

它的经济学含义是：**只有无法通过分散化消除的风险（系统性风险）才能获得风险补偿**，个股特有的风险不该有溢价，因为投资者可以免费分散掉。

CAPM 在实践中被大量实证反驳：低 beta 股票的收益高于模型预测，高 beta 股票的收益低于预测（即"低波动异象"）。但这不妨碍它作为第一层分解工具——它至少能告诉你"这个策略的收益里有多少是单纯靠市场上涨赚来的"。

## 四、Fama-French：加入风格因子

Fama-French 三因子模型在 market 之外加入：

- **SMB**（Small Minus Big）：做多小市值、做空大市值的收益差，捕捉规模溢价。
- **HML**（High Minus Low）：做多高账面市值比（价值股）、做空低账面市值比（成长股），捕捉价值溢价。

五因子再加入 **RMW**（盈利能力强减弱）与 **CMA**（投资保守减激进）。回归形式：

$$r_i - r_f = \alpha_i + \beta_m(r_m-r_f) + s_i \cdot SMB + h_i \cdot HML + r_i \cdot RMW + c_i \cdot CMA + \varepsilon_i$$

关键点在于：**$\alpha_i$ 的大小完全依赖于你放了哪些因子进模型**。一只小盘价值股用 CAPM 算出的 alpha 可能高达 15%，用五因子模型算出来可能不显著。这就是为什么判断"有没有 alpha"必须先约定模型。

在 A 股实践中，除了上述因子还常加入：

- **动量/反转**：A 股的短期反转效应（1 个月）尤其显著，与美股的动量效应方向相反。
- **换手率/流动性**：低换手股票有溢价，高换手股票（投机性强）预期收益低。
- **波动率**：低波动异象在 A 股同样存在。

## 五、三个必须理解的风险指标

$$\mathrm{Sharpe}=\frac{\mathbb{E}[r_p-r_f]}{\sigma(r_p-r_f)}\sqrt{252}$$

$$\mathrm{IR}=\frac{\mathbb{E}[r_p-r_b]}{\sigma(r_p-r_b)}\sqrt{252} \quad (\text{信息比率，基准为 } b)$$

$$TE = \sigma(r_p - r_b)\sqrt{252} \quad (\text{跟踪误差})$$

三者的关系是：$IR = \frac{\text{超额收益}}{TE}$。对指增产品，IR 比 Sharpe 更重要——因为客户考核的是相对基准的超额。Grinold 的"主动管理基本定律"给出了 IR 的上界：

$$IR \approx IC \cdot \sqrt{BR}$$

其中 $IC$ 是预测能力（信息系数），$BR$ 是广度（每年独立预测的次数）。这个公式的实践价值极大：它说明**提高广度（增加标的数、提高频率）与提高 IC 同样重要**，这也是量化相对主观投资的结构性优势。

## 六、用平台做一次粗归因

```python
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import factor_long_only
from qd.factors import get_factor
from qd.factors.pipeline import zscore, winsorize, neutralize
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

# 策略净值
res = Backtest(md, factor_long_only(factor_name="mom_12_1", top_quantile=0.2),
               BacktestConfig(initial_cash=1_000_000)).run()
m = perf_report(res.equity, benchmark=md.close().mean(axis=1), rf=0.02)
print({k: round(v, 4) for k, v in m.flat().items()})

# 检查组合是否偷偷暴露在某个风格因子上
size = zscore(winsorize(get_factor("mom_12_1").compute(md), limits=0.01))
holdings = res.weights                        # 每日持仓权重（日期 × 标的）
exposure = (holdings * size).sum(axis=1)      # 组合在动量因子上的暴露时间序列
print("因子暴露均值:", round(exposure.mean(), 4), " 波动:", round(exposure.std(), 4))

# 若暴露显著不为 0，做一个中性化版本再回测，对比收益差异
f_neutral = neutralize(size, md, exposures=["mktcap", "industry"])  # 剔除市值与行业暴露
print(f_neutral.iloc[-1].describe())
```

归因的关键动作是**对比"原始版"与"中性化版"的收益差**：如果中性化后收益大幅下降，说明原来的收益有很大一部分来自你不想要的因子暴露，而不是选股能力。

## 七、归因的三种常见形式

| 形式 | 回答的问题 | 适用场景 |
| --- | --- | --- |
| 时间序列回归 | 收益中有多少来自市场/风格因子 | 判断策略是否为"伪装成 alpha 的 beta" |
| Brinson 归因 | 超额来自行业配置还是个股选择 | 公募/指增的定期报告 |
| 持仓法因子模型 | 组合的因子暴露与风险分解 | 事前风控与压力测试 |

## 常见坑

- **用错基准做归因**。一个全市场选股的组合拿沪深 300 做基准，会凭空产生巨大的"超额"，实际只是市值暴露。基准必须与选股池一致。
- **因子暴露时变却用全样本回归**。如果组合的 beta 在不同时期变化（趋势策略尤其如此），全样本回归会得到错误的平均暴露，应做滚动回归。
- **把残差当 alpha**。残差里包含运气和未被建模的风险，样本短时它与 alpha 无法区分。
- **忽略多重检验**。尝试了 100 个因子后挑出最显著的那个，其真实显著性远低于报告的 t 值。参见 [01-03-量化投研流程](./01-03-量化投研流程.md)。
