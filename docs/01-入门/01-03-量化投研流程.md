# 量化投研流程

## 一、为什么需要流程

量化研究最大的风险不是"想不出策略"，而是**在错误的路径上浪费大量时间，并且无法定位自己错在哪**。流程的作用是把研究切成可独立验证的环节，让失败发生在代价最小的地方：一个因子在单因子检验阶段就被否掉，成本是几小时；在实盘之后才被发现，成本是真金白银和信任。

## 二、8 步流程与交付物

| # | 步骤 | 交付物 | 最常见的失败模式 |
| --- | --- | --- | --- |
| 1 | 选题与假设 | 一句话假设 + 机制解释 + 可证伪的预期 | 只有"我试试看"，无先验逻辑，退化为数据挖掘 |
| 2 | 数据构造 | 干净、对齐、带版本号的面板数据 | 用了未复权价、用了未来数据、幸存者偏差 |
| 3 | 因子/信号 | `DataFrame(dates × symbols)` | 手误写成前视；横截面标准化时泄漏了当日收益 |
| 4 | 单因子检验 | IC/ICIR、分层单调性、换手率、衰减曲线 | 只看多空收益，不看分层单调与成本 |
| 5 | 组合构建 | 权重 $w_t$ + 约束条件 | 只做截面排名，忽略行业/市值中性化导致因子暴露混淆 |
| 6 | 回测与成本 | 净值、成交明细、成本敏感表 | 乐观撮合（用收盘价成交）、未处理涨跌停 |
| 7 | 风险评估 | 因子归因、压力测试、容量估计 | 只看夏普，不看过拟合概率与极端情景 |
| 8 | 上线与监控 | 实盘/模拟跟踪、偏离告警 | 实盘与回测不一致（数据/撮合/成本差异）却无人发现 |

### 第 1 步：先写假设，再写代码

一条合格的假设应该长这样：

> 假设：由于处置效应，过去 12 个月剔除最近 1 个月的动量（$mom_{12-1}$）在 A 股个股上能预测未来 20 日收益。**预期**：IC > 0，五分位分层收益单调。**证伪条件**：若月度 IC 均值 < 0.01 或 ICIR < 0.3，或分层不单调，则放弃。**机制**：投资者对利好反应不足、对利空反应过度，导致中期价格延续。

关键在"证伪条件"——提前写死它，可以防止你在看到结果后不断修改标准以迁就结果（这是过拟合的心理机制）。

### 第 2-3 步：数据与信号的边界

信号矩阵必须严格满足：**$t$ 行的值只能由 $t$ 日收盘时（或之前）已知的信息算出**。财报数据要用披露日而非报告期，指数成分要用调整生效日而非公告日。详见 [02-04-前视偏差](../02-数据与工具/02-04-前视偏差.md)。

### 第 4-5 步：从"因子有效"到"策略赚钱"

因子有效（IC 显著）不等于策略赚钱。中间还隔着三层：

$$\text{因子收益} \xrightarrow{- \text{交易成本}} \text{毛收益} \xrightarrow{- \text{约束/中性化代价}} \text{可用收益} \xrightarrow{\div \text{容量}} \text{可执行收益}$$

换手率是这三层里最容易被低估的：月度 IC 为 0.03 的因子，如果双边换手 200%、每边成本 0.15%，仅成本一项一年就吃掉约 3.6%。

### 第 6-7 步：回测要做的三件事

1. **成本敏感性**：把成本参数按 0/1×/2×/4× 跑四遍，看策略是在哪个成本倍数下失效的。
2. **样本外验证**：用 `walk_forward` 或 `purged_kfold`，不要用普通 K 折（相邻折的训练/测试样本在时间序列上重叠，会泄漏）。
3. **过拟合检验**：用 `deflated_sharpe` 评估在做了 N 次尝试之后，这个夏普比率还值不值钱。

## 三、用代码走一遍第 4、6、7 步

```python
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab
from qd.factors import get_factor
from qd.factors.pipeline import winsorize, zscore, neutralize
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import factor_long_only
from qd.metrics.perf import perf_report, deflated_sharpe
from qd.optimize import walk_forward

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

# --- 第 3 步：构造并清洗因子 ---
raw = get_factor("mom_12_1").compute(md)      # 原始因子面板
f = zscore(winsorize(raw, limits=0.01))        # 去极值 + 截面标准化
print(f.iloc[-1].sort_values(ascending=False).head(5))

# --- 第 4 步：单因子检验 ---
lab = FactorLab(md)
rep = lab.report("mom_12_1")
print({k: rep[k] for k in ("ic_mean", "icir", "turnover") if k in rep})

# --- 第 6 步：回测 ---
strategy = factor_long_only(factor_name="mom_12_1", top_quantile=0.2)
res = Backtest(md, strategy, BacktestConfig(initial_cash=1_000_000)).run()
print(res.metrics)

# --- 第 7 步：过拟合检验 ---
sharpe_obs = perf_report(res.equity, rf=0.02)["sharpe"]
n_trials = 50                                  # 诚实记录你一共试了多少组参数
print(deflated_sharpe(res.equity, n_trials=n_trials))

# --- 第 7 步：样本外验证 ---
oos = walk_forward(strategy, md, train_window=504, test_window=126)
print(oos)
```

## 四、研究日志：唯一不会被市场夺走的资产

每完成一次实验，立刻记录。一条记录至少包含：

| 字段 | 说明 | 例子 |
| --- | --- | --- |
| `exp_id` | 唯一编号 | `mom121-007` |
| `hypothesis` | 假设原文 | 处置效应导致中期动量 |
| `data_version` | 数据快照版本号 | `ashare-daily-v20240630` |
| `params` | 完整参数（含默认值） | `fast=20, slow=60, cost=3bp` |
| `result` | 核心指标 | `IC=0.028, ICIR=0.41, Sharpe=1.1` |
| `decision` | 采纳/放弃 + 原因 | 放弃：成本 2× 后 Sharpe < 0.3 |

为什么必须记"放弃的实验"？因为**过拟合最大的来源不是参数太多，而是尝试次数没有被记录**。记下 50 次失败，你才知道第 51 次的漂亮结果该打几折。日志不需要复杂，一个 Markdown 表格或一个 sqlite 表就够，关键是"每次都记、当场记"。

## 常见坑

- **跳步**：直接写回测，跳过单因子检验。结果是策略亏钱时你不知道是因子不行、权重不行还是成本不行。
- **反复改目标**：先看到结果再定义"这个策略算成功"。解决方法是第 1 步就把证伪条件写死。
- **参数在样本内反复调优**却只用一份样本外数据做最终验证——那一份样本外数据已经被你"看"过，不再独立。真正干净的做法是滚动式样本外（`walk_forward`），或者把最终数据锁起来只在上线前打开一次。
- **不记录失败**，导致半年后把同一条死路再走一遍。
