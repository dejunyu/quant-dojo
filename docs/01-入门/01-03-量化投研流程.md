# 量化投研流程

## 学完这一篇，你能做到

- 用自己的话说清量化研究为什么要"分步走"，而不是想到哪写到哪
- 说出从想法到上线的八个步骤，以及每一步必须交出什么东西
- 理解"研究日志"为什么是这行最值钱的资产，并会记一条
- 用平台跑一次单因子检验，亲眼看到"通过"并不等于"能赚钱"

## 本篇要点

- 流程的意义是**让失败发生在代价最小的地方**：因子阶段否掉只花几小时，实盘才发现要花真金白银
- 八步：假设 → 数据 → 信号 → 单因子检验 → 组合 → 回测与成本 → 风险 → 上线监控
- 每一步都有"必须产出"和"最常见的死法"，跳步等于把错误藏起来
- **研究日志是唯一不会被市场夺走的资产**：记下失败，才知道漂亮结果该打几折

## 一、从一次"停机"说起

1989 年 4 月，**吉姆·西蒙斯**（Jim Simons）的文艺复兴科技公司遇到了大麻烦。

他旗下的**大奖章基金**（Medallion Fund）回撤了大约 30%。西蒙斯不是交易员出身，他是个数学家——23 岁拿到伯克利博士，和陈省身一起创立了 Chern–Simons 理论，还曾为美国国家安全局破译过密码。1978 年他离开学界去做投资，招人时**刻意不招有华尔街经验的人**，而是请数学家、物理学家、统计学家和计算机科学家。

面对这次回撤，团队里出现了分歧。合伙人、代数学家 James Ax 认为模型早就预期到这种波动，应该继续跑；但作为大股东的西蒙斯主张**先停下来**。

最后西蒙斯占上风：基金暂停交易，请伯克利教授 Elwyn Berlekamp 用**六个月彻底重构**整套交易系统。

结果呢？重构之后，1990 年净收益 **+55.9%**（扣费后），1991 年 **+39.4%**，1992 年 **+34%**，1993 年 **+39.1%**。此后大奖章成为投资史上最传奇的基金之一。（[Wikipedia: Jim Simons](https://en.wikipedia.org/wiki/Jim_Simons)、[Renaissance Technologies](https://en.wikipedia.org/wiki/Renaissance_Technologies)）

> **这个故事真正的重点，不是"西蒙斯多聪明"，而是他在亏钱时做的那个动作：**
> **暂停 → 诊断 → 重构 → 再上线。**
>
> 他没有硬扛，没有"再等等看会不会回来"，更没有半夜偷偷改个参数让曲线好看一点。
> **一个清晰的流程，最大的价值就是在你最想乱动的时候，告诉你下一步该做什么。**

而"半夜改参数"这件事有多危险，2014 年有一篇论文把它算出来了。

### 一篇让整个行业难堪的论文

2014 年 5 月，美国数学学会（AMS）的 *Notices* 上刊登了一篇文章，标题很不客气：**《伪数学与金融江湖骗术：回测过拟合对样本外表现的影响》**（*Pseudo-Mathematics and Financial Charlatanism*）。作者包括 Marcos López de Prado 等人。

文章里有个场景：一位顾问用 20 年数据跑了几千个模拟组合，挑出夏普比率最高的那个来向你推销。

作者给出的结论让人后背发凉：

> **如果只有 5 年数据，只要试 45 个配置，就几乎必定能找到一个"样本内非常漂亮、样本外一塌糊涂"的策略。**

注意，是"必定"。这不是运气差，是数学规律——**试的次数够多，噪声里总能挑出一个看着像信号的**。原文甚至说："过拟合在金融业是病理性的"，"这很可能是大量系统性对冲基金达不到宣传预期的一大原因"。

他们开的药方只有两条，恰好都是本篇的主题：

1. **做样本外检验**（用模型没见过的数据验一遍）；
2. **老实公开"你一共试过多少个配置"**——而现实中，几乎没人愿意披露这个数字。

> 把这两件事合起来，就是一句能记一辈子的话：
> **回测的目的不是找出最漂亮的那条曲线，而是诚实回答"我一共试了多少次"。**

## 二、为什么需要流程

量化研究最大的风险，不是"想不出策略"，而是**在错误的路径上耗掉大量时间，还说不清自己错在哪**。

流程做的一件事，就是把研究切成能**独立验证**的环节。这样失败就能发生在代价最小的地方：

| 在哪一步发现问题 | 代价 |
| --- | --- |
| 单因子检验阶段就否掉 | 几小时 |
| 组合构建阶段 | 一两天 |
| 回测阶段 | 一周 |
| **上线之后** | 真金白银 + 别人的信任 |

所以流程不是官僚主义，它是**把昂贵的错误提前变成便宜的错误**。

> 这句话值得单独记住：**流程的核心不是"更严谨"，是"更早地知道自己错了"。**

## 三、八步流程，一步一步讲

下面这张表是整本书的骨架。后面很多章，都只是在把其中一格讲透。

| # | 步骤 | 必须交出的东西 | 最常见的死法 |
| --- | --- | --- | --- |
| 1 | 选题与假设 | 一句话假设 + 机制解释 + 证伪条件 | 只有"我试试看"，退化成数据挖掘 |
| 2 | 数据构造 | 干净、对齐、带版本号的面板数据 | 用了未复权价、未来数据、幸存者偏差 |
| 3 | 因子/信号 | 一张"日期 × 股票"的表 | 手误写成前视；标准化时泄漏了当日收益 |
| 4 | 单因子检验 | IC/ICIR、分层单调性、换手率、衰减 | 只看多空收益，不看分层和成本 |
| 5 | 组合构建 | 持仓权重 + 约束条件 | 忽略行业/市值中性化，暴露混淆 |
| 6 | 回测与成本 | 净值、成交明细、成本敏感表 | 用收盘价成交、没处理涨跌停 |
| 7 | 风险评估 | 归因、压力测试、容量估计 | 只看夏普，不看过拟合概率 |
| 8 | 上线与监控 | 跟踪、偏离告警 | 实盘与回测不一致却没人发现 |

### 第 1 步：先写假设，再写代码（单独讲透）

这是八步里最容易被跳过、也最不该跳过的一步。一条合格的假设长这样：

> **假设**：由于处置效应，过去 12 个月剔除最近 1 个月的动量，在 A 股个股上能预测未来 20 日收益。
> **预期**：IC > 0，五分位分层收益单调。
> **证伪条件**：若月度 IC 均值 < 0.01 或 ICIR < 0.3，或分层不单调，就放弃。
> **机制**：投资者对利好反应不足、对利空反应过度，导致中期价格延续。

请特别注意那个**证伪条件**——**在看到结果之前，就把"什么算失败"写死**。

为什么这么重要？因为人有个根深蒂固的毛病：看到结果不如意，会不自觉地放宽标准（"IC 0.008 也差不多吧""这次数据特殊"），直到结果"看起来还行"。这不是作弊，是自欺，而且几乎每个人都中招。**提前写死标准，是唯一能挡住它的机制。**

> 这跟前面那篇 AMS 论文是同一件事：**不给自己事后解释的余地**。
> 论文要求披露"试了多少次"，这里要求提前写"什么算输"——两个都是把诚实**制度化**，而不是指望自己有毅力。

### 第 2-3 步：数据与信号的边界

一句话规矩：**某一行的信号值，只能由那一行当天收盘时（或更早）已经知道的信息算出来。**

听着像废话，但坑全在细节里：

- 财报数据要用**披露日**，不是报告期（公司 3 月才公布年报，你不能假装 1 月就知道）；
- 指数成分要用**调整生效日**，不是公告日；
- 停牌、退市的股票要老老实实留在样本里，不能只挑活到今天的。

详见 [02-04 前视偏差](../02-数据与工具/02-04-前视偏差.md) 与 [02-05 幸存者偏差](../02-数据与工具/02-05-幸存者偏差.md)。

### 第 4-5 步：从"因子有效"到"策略赚钱"隔着三层

这是新手最需要建立的一个认知：**因子有预测力（IC 显著），跟策略能赚钱，完全是两回事。**

中间要过三道关：

```
因子收益 → 扣掉交易成本 → 扣掉约束/中性化的代价 → 除以容量 → 真正能拿到手的钱
```

最容易被低估的是**换手率**。举个能自己算的例子：一个因子月度 IC 是 0.03（已经算不错了），但如果双边换手 200%、每边成本 0.15%，那么光成本一项，一年就吃掉约 **3.6%**。一个微弱但真实的信号，很容易被交易摩擦吃干净。

这也解释了 01-01 里那个双均线策略：它不是完全没抓到东西，是**8418 笔交易把利润全交了手续费**。

### 第 6-7 步：回测必须做的三件事

1. **成本敏感性**：把成本参数按 0 / 1 倍 / 2 倍 / 4 倍各跑一遍，看策略在哪个倍数下开始失效。一个 2 倍成本就归零的策略，实盘几乎没有生存空间。
2. **样本外验证**：用 `walk_forward`（滚动前推）或 `purged_kfold`（净化交叉验证），**别用普通 K 折**——时间序列里相邻两份样本会重叠，等于偷偷泄漏。
3. **过拟合检验**：用 `deflated_sharpe`，把"你一共试了 N 次"直接算进结论里。试 9 次和试 900 次，同一个夏普比率的可信度天差地别。

> 补一个圈内常识：**Deflated Sharpe（DSR，折减夏普）** 读法不重要，意思很朴素——
> **"扣掉你瞎试的运气之后，还剩下多少真本事？"**
> 平台每次参数搜索都会强制给这个数，就是在替你做那篇 AMS 论文要求的事。

## 四、用平台亲眼看看："通过"不等于"能赚钱"

按 [00-开始之前](00-开始之前.md) 装好环境，把下面这段存成文件跑一次。它只做第 4 步——单因子检验：

```python
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab

# 还是合成数据（假股市），用来学方法，不代表真实收益
md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)

lab = FactorLab(md)
rep = lab.report("mom_12_1")
print("检验结论:", rep["verdict"])
for r in rep["reasons"]:
    print("  -", r)
```

我实际跑出来的结果：

```
检验结论: 通过：可以考虑进入组合（仍需样本外验证）
  - |IC|=0.029，达到可用水平
  - 分组单调性 -1.00 差，可能是少数极端股票驱动的假象
```

**请仔细看这两行，它们是矛盾的。** 系统说"通过"，但第二条理由已经在警告你：分层单调性很差，这个结果可能是几只极端股票撑起来的假象。

> 这就是本篇最想让你看到的一课：
> **自动化工具给你的是"信号"，不是"结论"。**
> 一个"通过"的标签背后可能藏着一条反对意见，而判断是否采纳，是人的责任。

顺带说两个术语常识，以后会反复用到：

- **IC（信息系数）**：因子值和未来收益的相关性，衡量"预测准不准"。0.03 左右已经算不错，负值就是反向指标。
- **分层单调性**：把股票按因子值分成 5 组，如果第 1 组到第 5 组收益依次递减（或递增），说明关系稳定；如果忽高忽低，多半是少数极端股在捣乱。

## 五、研究日志：唯一不会被市场夺走的资产

每做完一次实验，**当场**记一条。最少要有这几个字段：

| 字段 | 意思 | 例子 |
| --- | --- | --- |
| `exp_id` | 唯一编号 | `mom121-007` |
| `hypothesis` | 假设原文 | 处置效应导致中期动量 |
| `data_version` | 数据快照版本 | `ashare-daily-v20240630` |
| `params` | 完整参数（含默认值） | `fast=20, slow=60, cost=3bp` |
| `result` | 核心指标 | `IC=0.028, ICIR=0.41, Sharpe=1.1` |
| `decision` | 采纳/放弃 + 原因 | 放弃：成本 2 倍后 Sharpe < 0.3 |

**为什么连"放弃的实验"也必须记？**

> 因为**过拟合最大的来源不是参数太多，而是"尝试次数"没有被记录**。
> 记下 50 次失败，你才知道第 51 次那个漂亮结果该打几折；
> 不记，你会真心觉得第 51 次是天赋。

这正好是西蒙斯和那篇 AMS 论文的交汇点：**他们赢在把"诚实"变成了流程，而不是变成美德**。日志不需要复杂，一个 Markdown 表格或一个 sqlite 表就够，关键是**每次都记、当场记**。

> 德鲁克有句被管理界引用了几十年的话：
> **"你无法管理你无法衡量的东西。"**
> 在量化里可以改一个字：**你无法改进你没有记录的实验。**

## 六、把这一篇串起来

回到 1989 年那次停机。

西蒙斯后来被问到大奖章为什么能长期成功，答案从来不是某个神秘公式，而是：他们**先把数据攒干净，再让一群不信华尔街故事的人，用可复现的方法一遍遍检验、推翻、重来**。

八步流程里的每一步，其实都在回答同一个问题：**我怎么才能更早、更便宜地知道自己错了？**

| 故事里的动作 | 对应流程 |
| --- | --- |
| 回撤 30% 时停机，而不是硬扛 | 第 7-8 步：风险评估与监控 |
| 花六个月彻底重构系统 | 第 2-6 步：回到数据与假设重走 |
| 招数学家而非交易员，只信数据 | 第 1 步：先写可证伪的假设 |
| 2014 年论文要求披露"试了多少次" | 研究日志：把诚实制度化 |

> 最后送你一句和开头呼应的话，来自那篇 AMS 论文的精神：
> **一个策略最危险的时候，不是它亏钱的时候，而是它"看起来太漂亮"的时候。**
> 亏钱会让你停下来检查，漂亮会让你想赶紧上线——而后者往往才是过拟合。

## 动手练习

- 跑一遍上面的代码，把 `"mom_12_1"` 换成 `"bp"`（账面市值比）和 `"amihud_illiquidity"`，看检验结论怎么变。**先猜，再跑。**
- 给某个因子写一条"合格假设"（四要素：假设、预期、证伪条件、机制），**先写下来再跑代码**——体会一下"提前写死标准"是什么感觉。
- 建一份研究日志，认真记 5 次实验，其中至少 2 次是"放弃"的。半年后你会感谢自己。
