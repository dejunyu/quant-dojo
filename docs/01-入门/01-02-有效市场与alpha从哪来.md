# 有效市场与alpha从哪来

## 一、有效市场假说（EMH）的三种形式

尤金·法马（Eugene Fama）在 1970 年的综述中把"有效市场"定义为**价格能够充分反映可得信息的市场**，并划分为三个层次：

| 形式 | 已反映的信息 | 直接推论 |
| --- | --- | --- |
| 弱式有效 | 全部历史价格与成交量 | 技术分析长期无法获得超额收益 |
| 半强式有效 | 所有公开信息（财报、公告、宏观） | 基本面分析无法持续获得超额收益 |
| 强式有效 | 所有信息，含未公开的内幕信息 | 连内幕交易也无法获得超额收益 |

理解 EMH 的一个关键点是：**它从来不是说"价格永远正确"，而是说"错误定价无法被稳定地利用"**。因此它天然伴随"联合假设问题"（joint hypothesis problem）：任何"市场无效"的检验结果，都可能是用错了资产定价模型（比如用 CAPM 算出的 alpha 其实只是市值、价值因子暴露），而不是真的发现了对市场的有效反驳。这一点在归因时极其重要，参见 [01-05-收益分解与风险因子](./01-05-收益分解与风险因子.md)。

## 二、现实：市场"足够有效"，但不完全有效

如果市场完全有效，量化行业就不该存在。它存在，说明存在持续的、可被捕获的错误定价。这些定价错误的来源大致有五类：

1. **行为偏差**：散户与机构都会系统性犯错，如处置效应（过早卖出盈利股、长期持有亏损股）、追涨杀跌、锚定、彩票偏好。
2. **机构约束与代理问题**：基金经理面临排名压力、回撤约束、风格漂移考核，被迫在错误时点做错误的交易。
3. **流动性供给的报酬**：在别人急于成交时提供对手方，赚的是买卖价差与冲击补偿。
4. **信息处理的不对称**：谁能更快、更便宜地解析公告、新闻、产业链数据，谁就有优势。
5. **结构性/制度性摩擦**：涨跌停、T+1、指数成分调整、打新制度等会制造可预测的价格压力。

前两类对应"慢 alpha"（月度、季度频率，容量大），第三、四类对应"快 alpha"（日内、高频，容量小），第五类是 A 股特有的重要来源。

## 三、alpha 为什么会衰减

alpha 不是静态矿藏，而是会被开采殆尽的。衰减链条通常是：

$$\text{规律被发现} \rightarrow \text{资金涌入} \rightarrow \text{拥挤度上升} \rightarrow \text{错误定价被修正} \rightarrow \text{收益下降}$$

这条链有三个容易忽略的细节：

- **衰减速度取决于容量**。交易越快的信号，能被套利的资金越少，衰减越快但可能长期存在（因为大资金进不来）；越慢的信号容量越大，一旦被发现，衰减得越彻底。
- **拥挤度不只是"收益变少"，更是"风险变大"**。当同一个因子上有大量同质化杠杆持仓时，一旦出现外部冲击，所有人同时平仓会造成踩踏。2007 年 8 月的 Quant Quake 是典型案例：基本面没有变化，但多只量化基金同时被迫减仓，动量与价值因子单周出现极端回撤。
- **拥挤度是可以被观测的**。常用代理指标包括：因子多空组合的估值价差（value spread）、因子暴露的相关性、同类策略收益的相关性、以及换手率与成交占比。

## 四、用平台观察因子收益的时间变化

```python
from qd.data.synthetic import generate_demo_market
from qd.research.lab import FactorLab
from qd.factors import list_factors

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
print([f for f in list_factors()][:10])

lab = FactorLab(md)

# IC 序列：因子值与未来 20 日收益的截面相关性
ic = lab.ic("mom_12_1", horizon=20)

# 按年分组看 IC 均值，观察强弱是否随时间变化
yearly = ic.groupby(ic.index.year).mean()
print(yearly.round(4))

# IC 衰减：预测期拉长后 IC 如何下降，反映信号的"有效半衰期"
print(lab.ic_decay("mom_12_1").round(4))

# 分层回测：五分位组合的收益是否单调，单调性比单看多空收益更可靠
print(lab.quantile_backtest("mom_12_1", n_quantiles=5))
```

如果 IC 在某些年份接近 0 甚至为负，这本身就是最重要的结论：**因子不是常数，它有周期性**。做因子配置的人必须接受"某个因子连续两三年不赚钱"是常态，而不是模型失效的证据。

## 五、一个务实的态度

对做实盘的人来说，EMH 之争的实践结论可以浓缩成三句话：

1. 市场足够有效，所以**任何超额收益都需要付出代价**——这个代价可能是承担风险、提供流动性、做别人不愿做的枯燥工作，或者比别人更早处理信息。
2. 市场不完全有效，所以**超额收益确实存在**，但它集中在少数地方、容量有限、且会随时间衰减。
3. 因此量化工作的重点不是"找到一个永远有效的圣杯"，而是**建立一个能持续生产、检验、淘汰假设的体系**，并严格管理拥挤度与回撤。

## 注意事项

- **不要把"历史有效"等同于"未来有效"**。任何因子都要有先验的逻辑支撑（行为、制度、风险补偿），纯数据挖掘出来的规律衰减最快。
- **警惕叙事陷阱**。"散户占比高所以 A 股容易赚钱"这类说法听起来合理，但它既无法证伪、也不能直接交易；真正有用的是把它拆成可计算的信号。
- **区分统计显著与经济显著**。样本足够大时，一个 IC 只有 0.01 的因子也可能统计显著，但扣掉双边千分之几的交易成本后可能毫无价值。
- **有效市场不等于不可预测**。波动率、相关性、交易量这些二阶量可预测性远高于收益率本身，这也是波动率目标类策略能够长期存在的原因。
