# 新手学习路线图

## 一、三条原则

1. **先跑通链路，再追求收益**。前 4 周做出来的策略几乎一定不赚钱，这很正常。目标是让"数据 → 因子 → 回测 → 评价"这条链路变得熟练，之后你才能把精力放在真正重要的地方。
2. **每个阶段都要有可交付物**。看完一本书没有交付物；跑出一个可复现的回测脚本、写出一份研究日志，才算交付。
3. **尽早接触真实数据与真实规则**。合成数据是学习工具，不是结论来源。第 5 周起就应该切到真实行情，你会立刻撞上停牌、复权、涨跌停这些真实的麻烦——这些麻烦本身就是必修课。

## 二、12 周路径

| 周 | 主题 | 任务 | 交付物 | 检验标准 |
| --- | --- | --- | --- | --- |
| 1 | 环境与数据 | 装好环境；跑通 `generate_demo_market`；理解 `md.close()/open()/volume()/returns()` 的形状 | 一个打印面板形状与基本统计的脚本 | 能说出 DataFrame 的行列含义与 `dates × symbols` 方向 |
| 2 | 收益与复利 | 学 [04-01-收益率与复利](../04-统计与建模/04-01-收益率与复利.md)；算对数收益、年化、最大回撤 | 一个手写的 `perf_report` 迷你实现 | 与平台 `perf_report` 结果一致（误差 < 1e-6） |
| 3 | 第一个策略 | 双均线金叉死叉；对比 `buy_and_hold` | 回测脚本 + 绩效对比表 | 能解释为什么双均线扣费后不赚钱 |
| 4 | 回测机制 | 读懂成交明细；理解 T+1、涨跌停不可成交、撮合价假设 | 一份成交明细的检查报告 | 找出至少一处"回测过于乐观"的假设 |
| 5 | 真实数据 | 用 `AkshareFeed` 拉真实 A 股行情；处理缺失值与停牌 | 真实数据的清洗脚本 | 能画出缺失率随时间的分布 |
| 6 | 数据陷阱 | 学 [02-03-复权停牌与异常处理](../02-数据与工具/02-03-复权停牌与异常处理.md)、[02-04-前视偏差](../02-数据与工具/02-04-前视偏差.md)、[02-05-幸存者偏差](../02-数据与工具/02-05-幸存者偏差.md) | 一份"我的数据里有哪些坑"清单 | 至少发现自己数据中的 3 个真实问题 |
| 7 | 因子构造 | 用 pandas 写 3 个因子：动量、反转、波动率 | 三个 `DataFrame(dates × symbols)` | 因子面板无 NaN 爆炸、无未来函数 |
| 8 | 因子处理 | winsorize / zscore / neutralize / rank / combine | 处理前后 IC 对比表 | 能解释中性化改变了什么 |
| 9 | 因子检验 | IC、ICIR、ic_decay、分层回测 | 一份因子研究报告 | 分层收益单调，且能说出换手率 |
| 10 | 组合与风控 | 波动率目标、风险平价、行业/市值约束 | 三种权重方案的对比 | 能说出每种方案降低了哪种风险 |
| 11 | 成本与容量 | 学 [03-04-交易成本分解](../03-市场与交易规则/03-04-交易成本分解.md)、[03-05-流动性与冲击成本](../03-市场与交易规则/03-05-流动性与冲击成本.md) | 成本敏感性表（0/1×/2×/4×） | 能给出"这个策略能容纳多少钱"的估计 |
| 12 | 样本外与报告 | `walk_forward` + `purged_kfold` + `deflated_sharpe` | 完整的策略研究报告 | 样本外 Sharpe > 0.5 且机制可解释 |

## 三、每周的时间分配建议

- **读**（30%）：教材与论文，但只读与本周任务直接相关的部分。
- **写**（50%）：代码与数据。量化是手艺活，读十遍不如写一遍。
- **复盘**（20%）：写研究日志、对比结果与预期、记录失败。

如果时间有限，优先压缩"读"，绝不压缩"写"和"复盘"。

## 五、第 1 周与第 12 周的示例代码

```python
# ---------- 第 1 周：熟悉数据结构 ----------
from qd.data.synthetic import generate_demo_market
from qd.utils.calendar import trading_days

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, ret = md.close(), md.returns()
print(close.shape, len(md.symbols), len(md.dates))
print(ret.describe().iloc[:, :3])

# 切片：只用 2022 年之后的数据
sub = md.slice("2022-01-01", "2024-12-31")
print(sub.close().shape, trading_days("2024-01-01", "2024-12-31", market="A")[:3])

# ---------- 第 12 周：样本外验证 ----------
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.optimize import grid_search, walk_forward, purged_kfold
from qd.metrics.perf import deflated_sharpe

# 参数网格：诚实记录一共试了多少组
grid = {"fast": [10, 20, 30], "slow": [60, 90, 120]}
best = grid_search(sma_cross, md, grid, metric="sharpe")
print("样本内最优:", best)

# 滚动样本外：每次只用在训练窗调出来的参数去跑下一个测试窗
oos = walk_forward(sma_cross, md, train_window=504, test_window=126)
print(oos)

# 净化交叉验证：在训练/测试之间留出禁飞区（embargo），避免标签重叠泄漏
cv = purged_kfold(md, n_splits=5, horizon=20, embargo=20)
print(cv)

res = Backtest(md, sma_cross(fast=20, slow=60),
               BacktestConfig(initial_cash=1_000_000)).run()
print("deflated:", deflated_sharpe(res.equity, n_trials=9))
```

对比 `grid_search` 的最优结果与 `walk_forward` 的结果，是这门课最重要的一课：**两者差距越大，说明过拟合越严重**。一个健康的策略，样本外 Sharpe 通常只有样本内的 30%~60%。

## 六、几个容易走偏的地方

- **过早追求高夏普**。初学者花大量时间调参数把 Sharpe 从 1.2 提到 2.0，但那只是在样本内拟合噪声。正确做法是增加样本、减少参数、提高机制的说服力。
- **沉迷机器学习**。在没有扎实的数据处理与因子检验能力之前上模型，只会更快、更隐蔽地过拟合。机器学习的正确位置是第 12 周之后。
- **频繁更换方向**。一个月换三个策略方向的人，一年后仍然在第 3 周。选定一个方向至少做完 4 周再评估。
- **只看教程不碰真实数据**。合成数据里没有停牌、没有退市、没有涨跌停，这些才是实盘真正的杀手。

## 注意事项

- 本路线假设每周可投入 8~12 小时。若时间减半，把 12 周拉成 24 周，**不要压缩第 5-6 周（数据陷阱）**，那是最容易被跳过、代价最高的一段。
- 所有回测结果都要用固定随机种子（`seed=7` 之类）保证可复现，否则你无法判断结果变化来自代码改动还是数据抖动。
- 教程与书籍的选择以"能否立即上手"为标准，不要追求体系完整。

## 七、用一行公式记住全流程

整条学习路径最终收敛到这一个式子：

$$\underbrace{w_t}_{\text{第 7-10 周}} = f(\underbrace{X_t}_{\text{第 1-6 周}};\ \underbrace{\theta}_{\text{第 11-12 周}})$$

第 1~6 周解决"能不能拿到干净、无偏的 $X_t$"，第 7~10 周解决"给定 $X_t$ 怎么得到合理的 $w_t$"，第 11~12 周解决"$\theta$ 是不是真的"。**任何一个环节缺失，后面做出来的东西都不可信**——这也是为什么本路线坚持顺序推进而不允许跳步。
