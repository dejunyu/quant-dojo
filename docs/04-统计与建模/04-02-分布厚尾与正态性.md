# 分布厚尾与正态性

## 一、为什么要在意分布形状

大量金融模型默认收益服从正态分布：$r_t \sim \mathcal{N}(\mu, \sigma^2)$。这个假设的吸引力在于只需两个参数（均值、方差），且线性组合仍为正态，组合风险的计算极其简单。

但如果分布假设错了，基于它算出的所有风险数字都是错的，而且错的方向总是"过于乐观"。

## 二、金融收益的实际形态

实证上，个股与市场指数的日收益普遍呈现：

1. **尖峰（leptokurtic）**：峰度远大于正态分布的 3，即"超额峰度 > 0"。日频数据的超额峰度常在 3~10 之间，极端行情期间更高。
2. **厚尾（fat tails）**：极端事件（±5%、±10% 的日内波动）的频率远高于正态分布的预测。
3. **负偏（negative skew）**：大跌的日子更集中、更极端。股票市场的典型特征是"涨得慢、跌得快"。

三者的统计量定义（对样本 $r_1,\dots,r_n$，$s$ 为样本标准差）：

$$\text{偏度 } S = \frac{1}{n}\sum_{i}\left(\frac{r_i-\bar r}{s}\right)^3, \qquad \text{峰度 } K = \frac{1}{n}\sum_{i}\left(\frac{r_i-\bar r}{s}\right)^4$$

正态分布的 $S = 0$、$K = 3$，因此常用**超额峰度** $K - 3$。

一个直觉：正态分布下，$|r| > 4\sigma$ 的概率约为 $6.3\times10^{-5}$，约 1.6 万年一次（按 252 天/年）。而实际市场中"4 个标准差以上的日波动"每隔几年就出现——1987 年 10 月 19 日美股单日跌幅（若按当时日波动率估计）远超 20 个标准差。这类事件在正态世界里根本不该发生。

## 三、厚尾的成因

1. **信息到达不均匀**：重大消息离散到达（财报、政策、黑天鹅），不是连续的高斯噪声。
2. **杠杆与强制平仓**：下跌触发保证金追缴 → 强制卖出 → 进一步下跌，形成正反馈。
3. **流动性的非线性消失**：正常时候买卖价差很小，危机时做市商撤出，价差瞬间扩大数倍。
4. **羊群与拥挤交易**：同质化策略同时平仓（见 [01-02-有效市场与alpha从哪来](../01-入门/01-02-有效市场与alpha从哪来.md)）。
5. **波动率聚集**：大波动之后倾向出现大波动（GARCH 效应的经验基础），极端值成簇出现。

第 5 点说明**收益不是独立同分布的**：即使边际分布是正态，波动率聚集也会产生厚尾（方差混合）。这也解释了为什么聚合到月频后峰度会下降——极端日被平均掉了，但月频仍非正态。

## 四、检验方法

### Jarque-Bera 检验

基于偏度与峰度的联合检验，统计量：

$$JB = \frac{n}{6}\left(S^2 + \frac{(K-3)^2}{4}\right)$$

在原假设"样本来自正态分布"下，$JB \sim \chi^2(2)$。日频金融数据几乎总是得到极大的 JB 值（几百到几万），p 值趋近于 0，强烈拒绝正态。

### Kolmogorov-Smirnov 检验

比较样本经验分布函数与参考分布：$D = \sup_x |F_n(x) - F_0(x)|$。KS 对整体形状敏感，但对尾部不敏感（尾部概率质量小）。因此**KS 通过不代表尾部安全**；关心尾部应配合 Anderson-Darling 检验或直接检验尾指数。

### QQ 图（分位数-分位数图）

最直观的工具：把样本分位数画在理论正态分位数上。若数据来自正态，点应落在 45° 直线上。金融收益的 QQ 图典型形态是**两端偏离直线、向外侧张开**（厚尾），且**下端偏离更多**（负偏）。

## 五、正态假设的危险后果

### 1. VaR 被严重低估

正态假设下的 VaR：$\text{VaR}_{1-\alpha} = -\left(\mu + z_{\alpha}\sigma\right)$，其中 $z_{\alpha}$ 是标准正态的 $\alpha$ 分位数（99% 时 $z = -2.326$）。

在厚尾下，真实的 99% 分位数可能是 $-3.5\sigma$ 甚至更极端。用 $-2.33\sigma$ 估计会低估约 50% 的潜在损失。越高的置信度，低估越严重——因为差距集中在尾部。

改进方法：

- **历史模拟法**：直接用历史分位数，不做分布假设。缺点是对样本期敏感。
- **Cornish-Fisher 展开**：用偏度、峰度修正分位数（见下方代码）。
- **t 分布 / 广义帕累托分布（GPD）**：显式建模厚尾，GPD 常用于极值理论（EVT）拟合超阈值尾部。

### 2. 夏普比率不可靠

夏普比率的分母是标准差，而标准差在厚尾下会低估"投资者真正关心的风险"（风险集中在少数几天）。厚尾 + 负偏的策略常有"高夏普 + 偶尔巨亏"的特征——这是"卖保险型"策略（卖出期权、某些套利）的典型形态：常态化小赚、偶发巨亏。

识别方法：看**最大回撤与夏普的匹配度**。夏普 2.0 但最大回撤 40% 的策略，几乎一定有隐藏的尾部风险。

### 3. 参数检验失效

t 检验、F 检验、线性回归的显著性推断都依赖正态（或大样本的渐近正态）。厚尾下**样本均值的收敛速度变慢**，小样本的 t 值不可靠；尾指数很低时（如 $\alpha < 2$，方差本身可能不存在），标准误的估计可能是错的。

## 六、用平台检验

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report, max_drawdown
from qd.optimize import monte_carlo

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
ret = md.returns()
port = ret.mean(axis=1).dropna()          # 等权组合日收益

# 1) 描述统计
def moments(x):
    x = np.asarray(x, dtype=float)
    n = len(x); s = x.std(ddof=1)
    S = ((x - x.mean()) ** 3).mean() / s ** 3
    K = ((x - x.mean()) ** 4).mean() / s ** 4
    JB = n / 6 * (S ** 2 + (K - 3) ** 2 / 4)
    return {"mean": x.mean(), "std": s, "skew": S, "kurt": K,
            "excess_kurt": K - 3, "JB": JB}

m = moments(port)
print({k: round(v, 4) for k, v in m.items()})
# JB 远大于 chi2(2) 的临界值（99% 时为 9.21）→ 强烈拒绝正态

# 2) 尾部频率：正态分布下的期望次数 vs 实际次数
from scipy.stats import norm
sigma = port.std()
for k in [2, 3, 4, 5]:
    actual = int((port.abs() > k * sigma).sum())
    expected = len(port) * 2 * (1 - norm.cdf(k))
    print(f"|r| > {k}σ: 实际 {actual:4d} 次, 正态期望 {expected:6.2f} 次")

# 3) VaR 三种算法对比（99%）
from scipy import stats
var_norm = -(port.mean() + stats.norm.ppf(0.01) * sigma)
var_hist = -np.percentile(port, 1)
z = stats.norm.ppf(0.01)
S, K = m["skew"], m["kurt"]
z_cf = (z + (z**2 - 1) * S / 6 + (z**3 - 3*z) * (K - 3) / 24 - (2*z**3 - 5*z) * S**2 / 36)
var_cf = -(port.mean() + z_cf * sigma)
print(f"正态 VaR {var_norm:.4%} | 历史 VaR {var_hist:.4%} | Cornish-Fisher {var_cf:.4%}")

# 4) 聚合到月频：峰度应下降，但仍非正态
monthly = (1 + port).resample("ME").prod() - 1
print("月频:", {k: round(v, 3) for k, v in moments(monthly).items()})

# 5) 用蒙特卡洛做非参数情景（重抽样，不依赖正态假设）
boot = monte_carlo(port, n_sims=2000, method="block", block=20)   # 区块重抽样，保留波动聚集
print("模拟终值分位数:", np.round(np.percentile(boot["finals"], [1, 5, 50]), 4))
print("亏损概率:", round(boot["prob_loss"], 3))

print("最大回撤:", round(max_drawdown((1 + port).cumprod()), 4))
```

第 2 步的输出最具说服力：正态分布下 $|r|>4\sigma$ 应该几乎不发生，而实际样本里会有若干次。这个对比是把"厚尾"从概念变成可感知事实的最快方式。

## 七、实务建议

1. **先用历史分位数，再用参数模型**。参数模型只作补充与情景分析工具。
2. **同时报告多个指标**：夏普 + 最大回撤 + CVaR + 最差 N 天的平均损失。单一指标必然被钻空子。
3. **CVaR（expected shortfall）优于 VaR**：$\text{CVaR}_\alpha = \mathbb{E}[r \mid r \leq -\text{VaR}_\alpha]$，它度量"尾部发生时的平均损失"，且是**一致性风险度量**（满足次可加性），而 VaR 不是。
4. **做压力测试而非只做统计估计**：把历史上最差的几天施加到当前组合，看会亏多少。
5. **对尾部做专门监控**：设置波动率、相关性、杠杆的阈值告警，不要等亏损发生后再反应。

## 常见坑

- **用 KS 检验通过就认为安全**。KS 对尾部不敏感，日频数据也可能"通过"整体检验却有极端尾部。
- **只看夏普不看回撤与尾部**。卖保险型策略（卖出期权、某些套利）在爆仓前夏普可以是 3.0。
- **用正态 VaR 做风控限额**。99% 置信度下误差可达数十个百分点。
- **用全样本标准差估计风险**。波动率聚集意味着当前风险状态可能远偏离历史均值，应使用滚动/条件波动率模型。
- **假设极端事件独立**。危机中相关性上升，分散化在最需要的时候失效。
- **样本太短就下结论**。厚尾特征需要长样本才能稳定估计，5 年数据的 99% 分位数噪声极大。
