# 分布厚尾与正态性

## 学完这一篇，你能做到

- 用自己的话说清"为什么金融市场不能假设正态分布"
- 理解偏度、峰度、Jarque-Bera 各自在测什么
- 亲眼看到"4 倍标准差事件"在真实数据里比理论频繁得多
- 知道正态假设会怎样低估风险，以及该换用什么工具

## 本篇要点

- 金融日收益的典型形态：**尖峰、厚尾、负偏**——"涨得慢、跌得快"
- 正态分布下 $|r|>4\sigma$ 约 1.6 万年一遇，现实里每隔几年就有一次
- **正态假设错的方向永远是"过于乐观"**：所有风险数字都被低估
- 尾部风险要用历史分位数、CVaR、压力测试，不能只靠一个标准差

---

## 一、从"1.6 万年一遇"说起

1987 年 10 月 19 日，美股单日下跌 **22.6%**（道指 -508.32 点，见 [03-05](../03-市场与交易规则/03-05-流动性与冲击成本.md)）。若按当时的日波动率折算，这是一个**超过 20 个标准差**的事件。

在正态分布的世界里，20σ 事件的概率小到什么程度？**小到宇宙年龄内都不该发生一次。** 可它就在那个周一发生了，而且此后类似的"不可能"事件反复出现。

更早指出这件事的人，是**本华·曼德博**（Benoit Mandelbrot）——分形几何之父。他在 1960 年代研究棉花价格时发现：**价格变化的分布，尾巴比正态分布"胖"得多**，极端波动出现的频率远高于高斯模型的预测。他后来写了《市场的行为不当》（*The (Mis)Behavior of Markets*）系统批判金融里的正态假设。（[Wikipedia: Benoit Mandelbrot](https://en.wikipedia.org/wiki/Benoit_Mandelbrot)）

> **"1.6 万年一遇"这句话，本身就是问题所在。**
> 正态分布说 4σ 事件约 $6.3\times10^{-5}$ 概率、按 252 天/年折合 1.6 万年一次；
> 而真实市场里，"4 个标准差以上的日波动"**每隔几年就来一次**。
>
> 塔勒布后来把这类事件叫**黑天鹅**（[Wikipedia: Black swan theory](https://en.wikipedia.org/wiki/Black_swan_theory)）。
> 但本篇想强调的重点不是"黑天鹅多吓人"，而是一个更朴素、更要命的事实：
> **不是模型偶尔失手，是模型从根上就用错了分布。**

> 前面 01-01 结尾那只火鸡，在这里可以换个说法：
> **火鸡被喂了 1000 天，每天更确信"世界是温和的"；第 1001 天不是因为它运气差，是因为它假设了错误的分布。**

## 二、为什么大家还是爱用正态（先把对手讲明白）

大量金融模型默认：

$$r_t \sim \mathcal{N}(\mu, \sigma^2)$$

逐个拆：$r_t$ 是 t 期收益，$\mathcal{N}$ 表示正态分布，$\mu$ 是均值、$\sigma^2$ 是方差。

**它的诱惑力很实在**：只要两个数（均值、方差）就描述完整个分布，而且正态变量线性组合后还是正态——**组合风险的计算极其简单**。03-05 的平方根冲击、08 章的均值方差、04-01 的波动率年化，全靠这个便利。

> **但便利不等于正确。** 如果分布形状假设错了，基于它算出的**所有**风险数字都是错的，
> 而且错的方向**总是过于乐观**——因为厚尾意味着"极端亏钱的概率比模型以为的大"。
> **一个永远往乐观方向错的模型，比一个偶尔出错的模型危险得多**：它不会报警，只会发奖。

## 三、金融收益实际长什么样（逐个讲透）

实证上，个股与市场指数的日收益普遍呈现三个特征：

| 特征 | 叫什么 | 白话 |
| --- | --- | --- |
| **尖峰** | leptokurtic / 超额峰度 > 0 | 中间特别尖（小波动的日子特别多） |
| **厚尾** | fat tails | 两端特别胖（极端日子也特别多） |
| **负偏** | negative skew | **大跌比大涨更猛、更集中**——"涨得慢、跌得快" |

度量它们的两个统计量：

$$S = \frac{1}{n}\sum_i\left(\frac{r_i-\bar r}{s}\right)^3, \qquad K = \frac{1}{n}\sum_i\left(\frac{r_i-\bar r}{s}\right)^4$$

| 符号 | 意思 | 为什么是 3 次方 / 4 次方 |
| --- | --- | --- |
| $r_i-\bar r$ | 每期收益偏离均值多少 | 先去掉中心 |
| $s$ | 标准差 | 除以它，变成"几个标准差" |
| $S$（偏度） | 3 次方，**保留正负号** | 负的极端值 3 次方还是负 → 测"哪边尾巴更长" |
| $K$（峰度） | 4 次方，**全是正的** | 大偏离被 4 次方急剧放大 → 测"极端值多不多" |

正态分布下 $S=0$、$K=3$，所以常用**超额峰度** $K-3$：日频金融数据常在 **3~10**，极端行情更高。

> **记住这个"两头都多"的形状**：正态分布以为"大部分日子温和、极端几乎没有"；
> 现实是"**温和的日子更多，但极端的日子也更多**"——中间被掏空，两头鼓起来。
> 所以用"平均波动"去想风险，会同时低估两件事：平静有多平静，以及崩溃有多崩溃。

### 为什么会有厚尾

1. **信息不是连续到达的**：财报、政策、事故是**一堆一堆**来的，不是均匀的高斯噪声；
2. **杠杆与强平**：下跌 → 追缴保证金 → 强制卖出 → 再跌（03-06 的反馈环）；
3. **流动性非线性消失**：平时价差很小，危机时做市商撤出，价差瞬间扩大（03-05）；
4. **拥挤交易**：同质化策略同时平仓（01-02）；
5. **波动率聚集**：大波动之后倾向再来大波动（GARCH 的经验基础），极端值**成簇**出现。

> 第 5 点特别重要：**收益不是独立同分布的**。即使单日边际分布是正态，
> "波动率时高时低"这个混合本身也会造出厚尾。
> 这也解释了为什么把数据聚合到**月频**后峰度会下降——极端日被平均掉了——
> **但月频仍然不是正态**。

## 四、怎么检验（逐个讲透）

### Jarque-Bera 检验

$$JB = \frac{n}{6}\left(S^2 + \frac{(K-3)^2}{4}\right)$$

| 符号 | 白话 |
| --- | --- |
| $n$ | 样本数 |
| $S^2$ | 偏度离 0 有多远（平方后不分正负） |
| $(K-3)^2/4$ | 峰度离 3 有多远 |
| 整体 | **"这份数据离正态总共偏了多少"** |

原假设"来自正态"下，$JB \sim \chi^2(2)$，99% 临界值约 **9.21**。日频金融数据常常得到几百到几万的 JB，**p 值趋近 0，强烈拒绝正态**。

### QQ 图（最直观，不用记公式）

把样本分位数画在理论正态分位数上。若真是正态，点落在 **45° 直线**上。金融收益的典型形态是：**两端向外张开**（厚尾），且**下端偏得更多**（负偏）。

### KS 检验的陷阱

KS 比较整体分布形状（$D = \sup_x|F_n(x)-F_0(x)|$），但**对尾部不敏感**——尾部概率质量太小，差一点也测不出来。

> ⚠️ **KS 通过 ≠ 尾部安全**。日频数据完全可能"整体检验通过"却藏着极端尾部。
> 关心尾部要用 Anderson-Darling、或直接估尾指数 / 看历史分位数。

## 五、正态假设的三个危险后果（单独讲透）

### 1. VaR 被严重低估

正态假设下：

$$\text{VaR}_{1-\alpha} = -\left(\mu + z_{\alpha}\sigma\right)$$

$z_\alpha$ 是标准正态分位数（99% 时 $z = -2.326$）。而厚尾下真实的 99% 分位数可能是 $-3.5\sigma$ 甚至更极端——**用 -2.33σ 估计会低估约 50% 的潜在损失**，且置信度越高、低估越严重（差距全集中在尾部）。

改进：**历史模拟法**（直接取历史分位数，不假设分布）、**Cornish-Fisher 展开**（用偏度峰度修正分位数）、**t 分布 / GPD 极值理论**（显式建模厚尾）。

### 2. 夏普比率不可靠

夏普的分母是标准差，而标准差**在厚尾下会低估"投资者真正关心的风险"**（风险集中在少数几天）。于是出现一类危险策略：

> **"常态化小赚、偶发巨亏"**——卖期权、某些套利。
> 爆仓前夏普可以是 3.0。**识别方法：看夏普和最大回撤匹不匹配。**
> 夏普 2.0 却最大回撤 40%，几乎一定有隐藏尾部风险。

### 3. 参数检验失效

t 检验、F 检验、回归显著性都依赖正态（或大样本渐近正态）。厚尾下样本均值收敛变慢，小样本 t 值不可靠；尾指数很低时（$\alpha<2$）**方差本身可能不存在**，标准误估计都是错的。

> 一句话：**厚尾世界里，"统计显著"这四个字要比你以为的更难拿到。**
> 这跟 01-03 的 AMS 论文、06 章的多重检验是同一条警告链。

## 六、用平台亲眼看到厚尾

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import numpy as np
from scipy import stats
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import max_drawdown
from qd.optimize import monte_carlo

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
port = md.returns().mean(axis=1).dropna()      # 等权组合日收益

# 1) 描述统计
x = np.asarray(port, dtype=float)
s = x.std(ddof=1)
S = ((x - x.mean()) ** 3).mean() / s ** 3
K = ((x - x.mean()) ** 4).mean() / s ** 4
JB = len(x) / 6 * (S ** 2 + (K - 3) ** 2 / 4)
print({"skew": round(S, 4), "kurt": round(K, 4),
       "excess_kurt": round(K - 3, 4), "JB": round(JB, 2)})

# 2) 尾部频率：正态期望 vs 实际
sigma = port.std()
for k in [2, 3, 4, 5]:
    actual = int((port.abs() > k * sigma).sum())
    expected = len(port) * 2 * (1 - stats.norm.cdf(k))
    print(f"|r| > {k}σ: 实际 {actual:4d} 次, 正态期望 {expected:6.2f} 次")

# 3) VaR 三种算法对比（99%）
var_norm = -(port.mean() + stats.norm.ppf(0.01) * sigma)
var_hist = -np.percentile(port, 1)
z = stats.norm.ppf(0.01)
z_cf = (z + (z**2 - 1) * S / 6 + (z**3 - 3*z) * (K - 3) / 24
        - (2*z**3 - 5*z) * S**2 / 36)
var_cf = -(port.mean() + z_cf * sigma)
print(f"正态 VaR {var_norm:.4%} | 历史 VaR {var_hist:.4%} | Cornish-Fisher {var_cf:.4%}")

# 4) 蒙特卡洛：区块重抽样，不依赖正态假设
boot = monte_carlo(port, n_sims=2000, method="block", block=20)
print("模拟终值 1% 分位:", round(float(np.percentile(boot["finals"], 1)), 4))
print("亏损概率:", round(boot["prob_loss"], 3))
print("最大回撤:", round(max_drawdown((1 + port).cumprod()), 4))
```

我实跑的结果：

```
{'skew': 0.1486, 'kurt': 3.4024, 'excess_kurt': 0.4024, 'JB': 19.05}
|r| > 2σ: 实际   73 次, 正态期望  83.08 次
|r| > 3σ: 实际    4 次, 正态期望   4.93 次
|r| > 4σ: 实际    1 次, 正态期望   0.12 次
|r| > 5σ: 实际    1 次, 正态期望   0.00 次
正态 VaR 2.3676% | 历史 VaR 2.3420% | Cornish-Fisher 2.3432%
亏损概率: 0.324
最大回撤: -0.4399
```

**请盯住 `|r| > 4σ` 那一行：实际 1 次，正态期望 0.12 次——多了 8 倍。**
`> 5σ` 更直接：正态期望 **0.00 次**，实际 **1 次**。

> 这就是把"厚尾"从概念变成可感知事实的最快方式。
> 注意这份是**合成数据**（生成器刻意植入了涨跌停等极端行为），
> 真实市场的厚尾通常**比这更严重**。JB = 19.05 也已超过 99% 临界值 9.21，拒绝正态。

三种 VaR 这次很接近（2.37% / 2.34% / 2.34%），因为合成数据的超额峰度只有 0.40，不算极端。**别因此得出"正态 VaR 够用"的结论**——真实危机里偏度峰度会飙升，那时差距会成倍拉开。

## 七、实务建议

1. **先用历史分位数，再用参数模型**：参数模型只作补充与情景分析。
2. **同时报告多个指标**：夏普 + 最大回撤 + CVaR + 最差 N 天平均损失。**单一指标必然被钻空子。**
3. **CVaR 优于 VaR**：$\text{CVaR}_\alpha = \mathbb{E}[r \mid r \le -\text{VaR}_\alpha]$，度量"尾部真发生时平均亏多少"，且是**一致性风险度量**（满足次可加性），VaR 不是。
4. **做压力测试，而不只是统计估计**：把历史上最差的几天直接施加到当前组合。
5. **对尾部设专门告警**：波动率、相关性、杠杆阈值，别等亏了再反应。

> 补两个常识：
> - **CVaR** 也叫 expected shortfall（期望短缺），08 章会专门讲。
> - **"一致性风险度量"** 里最关键的一条叫**次可加性**：合并两个组合的风险不应大于各自风险之和。VaR 违反它，所以用它做分散化决策会得出荒谬结论。

## 八、把这一篇串起来

回到曼德博。

他当年看棉花价格，看到的不是"噪声太多"，而是**钟形曲线根本画错了形状**。整个行业花了很久才承认这一点，而代价是一连串"模型说不可能、市场偏偏发生了"的事故：1987、1998、2008、2020……

> 这和 03-05 的黑色星期一、03-06 的轧空、01-01 的火鸡是同一件事的不同切面：
> **把"没见过"当成"不会发生"，是这个行业最贵的一个假设。**

> 一句话收尾：
> **标准差描述的是"平常日子"，而杀死你的是"不平常的那几天"。**
> 正态分布的错，不在于它算错了平均值，
> **在于它把尾部削平了——而风险全住在尾部。**
