# 收益率与复利

## 学完这一篇，你能做到

- 用自己的话说清"赚 50% 再亏 40%，为什么最后是亏的"
- 分清简单收益与对数收益，知道各该用在哪
- 理解**波动率拖累**：为什么"波动本身"会吃掉你的钱
- 会算年化，并知道 A 股不该硬套 252 天

## 本篇要点

- 简单收益在**资产维度**可加，对数收益在**时间维度**可加
- 几何平均（CAGR）才是"实际拿到的钱"，算术平均只是"单期期望"
- **波动越大，两者差距越大**——这一课值很多钱
- 年化交易日数要用真实的（A 股约 242~244，不是 252）

---

## 一、从一个"平均赚 5%，实际亏 5%"的账说起

先做一道小学算术题。

假设你的账户第一年**赚 50%**，第二年**亏 40%**。

算术平均是：$\frac{50\% - 40\%}{2} = +5\%$。听起来还不错，对吧？

但拿 100 万真金白银走一遍：

```
100 万 × 1.5 = 150 万
150 万 × 0.6 =  90 万   ← 两年后只剩 90 万
```

**平均每年"赚 5%"，两年下来却亏了 10 万。** 实际年化是 **-5.13%**。

> **这不是计算错误，是复利的本质：**
> **亏 40% 之后，需要涨 66.7% 才能回到原点**（$1/0.6 = 1.667$），
> 而赚 50% 之后的回撤，需要的涨幅比你想的大得多。
> **涨跌是不对称的，亏损对复利的伤害，永远大于同等幅度盈利的帮助。**

这个不对称有个正式名字，叫 **波动率拖累**（volatility drag，也叫 variance drain / volatility tax；该术语由 Rick Ashburn 2003 年提出、Mark Spitznagel 后来系统化，见 [Wikipedia: Volatility tax](https://en.wikipedia.org/wiki/Volatility_tax)）。

> 爱因斯坦常被（多半是误传地）引作说"复利是世界第八大奇迹"。
> 但复利有正反两面：**它让稳定的小收益滚成大雪球，也让剧烈波动把雪球震碎。**
> 这一篇讲的，就是后一面。

---

## 二、两种收益率（逐个讲透）

设 $P_t$ 是 t 时刻价格——**必须用复权价**（见 [02-03 复权停牌](../02-数据与工具/02-03-复权停牌与异常处理.md)），否则除权日的假暴跌会毁掉一切。

**简单收益**：

$$r_t = \frac{P_t}{P_{t-1}} - 1$$

**对数收益**：

$$R_t = \ln\frac{P_t}{P_{t-1}} = \ln(1 + r_t)$$

| 符号 | 白话 |
| --- | --- |
| $P_t$ | 今天（复权）收盘价 |
| $r_t$ | 简单收益：涨跌了百分之几 |
| $R_t$ | 对数收益：取自然对数后的涨跌 |
| $\ln$ | 自然对数，可理解为"把乘法变成加法的工具" |

**为什么要有两种？** 一句话：

> **对数收益在时间上可加，简单收益在资产上可加。**

$$\ln\frac{P_T}{P_0} = \sum_{t=1}^{T} R_t \qquad\qquad r_{p,t} = \sum_i w_{i,t}\, r_{i,t}$$

逐个拆：

- 左边：把每天的对数收益**加起来**，正好等于"最终价 ÷ 初始价"再取对数 → **算多期累计用对数收益**；
- 右边：组合收益 = 各资产简单收益按权重 $w_{i,t}$ 加权 → **算组合用简单收益**。

> ⚠️ **两个最常见的混用错误**：
> ① 把各资产的**对数**收益按权重加权，当成组合收益；
> ② 把每日**简单**收益直接相加，当成累计收益。
> 两者都错。**记住那句"时间用对数、资产用简单"，就不会搞反。**

当收益很小（日频通常 <5%）时，两者几乎一样：$r=5\%$ 时 $R=4.88\%$，差 12 bp；但 $r=-50\%$ 时 $R=-69.3\%$，差得离谱。**所以做高频/日频研究用对数收益很方便，做业绩汇报必须用简单收益导出的几何平均。**

## 三、年化与复利（逐个讲透）

一段时期共 $n$ 个交易日，累计简单收益 $r_{\text{cum}}$，年化（CAGR）为：

$$r_{\text{ann}} = (1 + r_{\text{cum}})^{252/n} - 1$$

| 符号 | 白话 |
| --- | --- |
| $r_{\text{cum}}$ | 整段下来总共赚了多少（比例） |
| $n$ | 这段有多少个交易日 |
| $252/n$ | 把这段"放大"到一年的倍数 |
| $-1$ | 把"变成几倍"还原成"赚了百分之几" |

**注意那个 252**：它是**美股**一年的近似交易日数。A 股一年约 **242~244** 天。平台里 `trading_days("2024-01-01","2024-12-31", market="A")` 实跑返回 **262**（含该口径下的全部交易日）。硬套 252 会造成约 4% 的相对误差——不大，但足以毁掉严格的对比。**年化要用真实交易日数。**

波动率的年化则不同，按**时间平方根**缩放：

$$\sigma_{\text{ann}} = \sigma_{\text{daily}} \cdot \sqrt{252}$$

> **为什么收益乘 252、波动乘 $\sqrt{252}$？**
> 因为收益是**累加**的（$n$ 天加 $n$ 次），而独立的随机变量相加时，**方差**累加、标准差按 $\sqrt{n}$ 增长。
> 这个区别是 04-02 和 08 章很多内容的地基。

## 四、波动率拖累：本篇最值钱的一节（单独讲透）

设一串单期收益 $r_1,\dots,r_T$：

- **算术平均** $\bar{r}_A = \frac{1}{T}\sum r_t$：单期收益的**期望**；
- **几何平均** $\bar{r}_G = \left(\prod_t(1+r_t)\right)^{1/T} - 1$：实际实现的**复合增长率**（CAGR）。

两者的近似关系（二阶展开）：

$$\bar{r}_G \approx \bar{r}_A - \frac{\sigma^2}{2}$$

| 符号 | 白话 |
| --- | --- |
| $\bar{r}_A$ | 你以为的"平均收益" |
| $\bar{r}_G$ | 账户真正拿到的复合收益 |
| $\sigma^2$ | 收益的方差（波动的平方） |
| $-\sigma^2/2$ | **被波动吃掉的那部分** |

> **整句话：波动越大，你实际拿到手的越少。**
> 而且注意是 **$\sigma^2$（平方）**——波动翻 2 倍，拖累变 **4 倍**。
> 这解释了三件在别处会再遇到的事：
>
> 1. **汇报业绩必须用几何平均（CAGR）**，用算术平均会系统性高估高波动策略；
> 2. **杠杆会放大拖累**：2 倍杠杆下波动翻倍，拖累变 4 倍——这正是"2 倍杠杆指数基金长期跑输 2 倍无杠杆收益"的数学原因（03-06 提过）；
> 3. **降低波动本身就能提高复合收益**：这是 `vol_target` 波动率目标策略的经济学基础，也呼应 01-05 的低波动异象。

> 补个常识：**CAGR** = Compound Annual Growth Rate，复合年增长率。
> 基金业绩报告、招募说明书里的"近五年年化"指的都是它，**不是**把五年收益除以五。

## 五、用平台亲眼验证

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.utils.calendar import trading_days

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
px = md.close()
logret = np.log(px).diff()

# 1) 时间可加性：对数收益从第 2 行起求和 = 首尾价格比的对数
lhs = np.log(px.iloc[-1] / px.iloc[1])
rhs = logret.iloc[2:].sum()
print("时间可加性误差:", float((lhs - rhs).abs().max()))

# 2) 算术平均 vs 几何平均（波动率拖累）
eq = px.mean(axis=1)
r_daily = eq.pct_change().dropna()
arith = r_daily.mean() * 252
geo = (eq.iloc[-1] / eq.iloc[0]) ** (252 / len(r_daily)) - 1
sigma = r_daily.std() * np.sqrt(252)
print(f"算术 {arith:.4f} | 几何 {geo:.4f} | 差 {arith-geo:.4f} | σ²/2 预测 {sigma**2/2:.4f}")

# 3) 经典对照：+50% 然后 -40%
r = np.array([0.5, -0.4])
print("算术平均:", round(r.mean(), 4))
print("实际复合:", round((np.prod(1 + r)) ** (1/2) - 1, 4))
print("2024 交易日数:", len(trading_days("2024-01-01", "2024-12-31", market="A")))
```

我实跑的结果：

```
时间可加性误差: 8.05e-16
算术 0.1055 | 几何 0.0960 | 差 0.0095 | σ²/2 预测 0.0138
算术平均: 0.05
实际复合: -0.0513
2024 交易日数: 262
```

**三行，三个结论：**

- 第一行 `8e-16` 是浮点精度误差，等于 **0** → 对数收益确实**时间可加**；
- 第二行：算术年化 **10.55%**，实际几何只有 **9.60%**，差 **0.95 个百分点**被波动吃掉；$\sigma^2/2$ 预测 1.38%，量级一致（近似式有偏度误差，不会完全相等）。**波动是真金白银的成本。**
- 第三行就是开头那道题：**算术 +5%，实际 -5.13%**。

> **别小看那 0.95 个百分点。** 一个年化 10% 的策略，
> 少掉将近 1 个点，二十年复利下来会差出一大笔钱。
> **这正是 03-04 讲成本、03-05 讲冲击之后，第三种"安静漏钱"的方式。**

## 六、常见换算速查

| 想要什么 | 从什么出发 | 怎么算 |
| --- | --- | --- |
| 日 → 年（收益） | 日均简单收益 $\bar r$ | $(1+\bar r)^{252}-1$，或 $252\bar r$ 近似 |
| 日 → 年（波动） | 日标准差 $\sigma_d$ | $\sigma_d\sqrt{252}$ |
| 年 → 日（波动） | 年标准差 $\sigma_a$ | $\sigma_a/\sqrt{252}$ |
| 累计 → 年化 | 累计 $r_c$，共 $n$ 日 | $(1+r_c)^{252/n}-1$ |
| 名义 → 实际（扣通胀） | 名义 $r$、通胀 $\pi$ | $\frac{1+r}{1+\pi}-1$ |

## 七、把这一篇串起来

回到那道"+50% 再 -40%"的题。

它之所以反直觉，是因为人脑习惯**把百分比相加**，而钱是**相乘**的。整个量化行业里，从 03-04 的交易成本、03-05 的冲击，到本篇的波动率拖累，都是同一类东西：

> **单次看着很小、乘上次数之后很大，而且方向永远对你不利。**

> 一句话收尾：
> **收益是乘出来的，不是加出来的；风险也是。**
> 所以评价一个策略，"平均每天赚多少"几乎没用，
> **"一路乘下来最后剩多少"才是唯一算数的数字。**
