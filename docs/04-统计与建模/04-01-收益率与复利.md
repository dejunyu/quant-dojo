# 收益率与复利

## 一、两种收益率的定义

设 $P_t$ 为 $t$ 时刻的价格（**必须是复权价**，见 [02-03-复权停牌与异常处理](../02-数据与工具/02-03-复权停牌与异常处理.md)）。

**简单收益（simple / arithmetic return）**：

$$r_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1$$

**对数收益（log / continuously compounded return）**：

$$R_t = \ln\frac{P_t}{P_{t-1}} = \ln(1 + r_t)$$

两者的关系与近似：

$$R_t \approx r_t - \frac{r_t^2}{2}, \quad r_t \approx e^{R_t} - 1$$

当 $|r_t|$ 很小时（如日内或日频个股通常 <5%），两者差异极小（$r=5\%$ 时 $R=4.88\%$，差 12 bp）；但当收益很大时差异显著（$r=-50\%$ 时 $R=-69.3\%$）。

## 二、为什么需要两种

| 场景 | 用哪种 | 原因 |
| --- | --- | --- |
| 多期累计收益 | **对数** | 可加：$\sum R_t = \ln(P_T/P_0)$ |
| 组合（多资产）加权收益 | **简单** | 可加：组合收益 = 各资产收益按权重加权 |
| 与价格/金额相关的计算 | **简单** | 现金流的实际比例是简单收益 |
| 统计建模、正态性假设 | **对数** | 更接近正态，且时间可加 |
| 汇报业绩（CAGR） | 由简单收益导出 | 投资者关心实际拿到多少钱 |

核心区别一句话：**对数收益在时间维度上可加，简单收益在资产维度上可加**。

$$\underbrace{\ln\frac{P_T}{P_0} = \sum_{t=1}^{T} R_t}_{\text{时间可加}} \qquad \underbrace{r_{p,t} = \sum_i w_{i,t} r_{i,t}}_{\text{资产可加}}$$

常见的错误是混用：把各资产的对数收益按权重加权得到"组合对数收益"，或者把简单收益直接相加得到"累计收益"。两者都是错的。

## 三、复利与年化

若一段时期共 $n$ 个交易日，累计简单收益为 $r_{\text{cum}}$，则年化收益（CAGR）：

$$r_{\text{ann}} = (1 + r_{\text{cum}})^{252/n} - 1$$

用对数收益则更简洁（设 $\bar{R}$ 为日均对数收益）：

$$R_{\text{ann}} = 252 \cdot \bar{R}, \quad r_{\text{ann}} = e^{R_{\text{ann}}} - 1$$

反过来，若已知年化目标，日均为 $r_{\text{ann}} / 252$ 的简单近似只在收益很小时成立；严格应使用 $(1+r_{\text{ann}})^{1/252} - 1$。

**注意 252 这个数字**：它是美股一年的近似交易日数。A 股一年约 242~244 个交易日。**年化时应使用实际的交易日数**，可用 `trading_days` 获取。用错数字会造成约 4% 的相对误差（$252/242$），虽然不大但足以影响严格的对比。

波动率的年化则不同——它按时间平方根缩放：

$$\sigma_{\text{ann}} = \sigma_{\text{daily}} \cdot \sqrt{252}$$

## 四、几何平均 vs 算术平均：波动率拖累

这是本章最重要的一节。设一系列单期收益 $r_1, \dots, r_T$，则：

- **算术平均**：$\bar{r}_A = \frac{1}{T}\sum r_t$ —— 单期收益的**期望**。
- **几何平均**：$\bar{r}_G = \left(\prod_{t}(1+r_t)\right)^{1/T} - 1$ —— 实际实现的**复合增长率**。

两者近似关系（二阶展开）：

$$\bar{r}_G \approx \bar{r}_A - \frac{\sigma^2}{2}$$

这就是**波动率拖累（volatility drag / variance drag）**：波动越大，你实际拿到手的复合收益越低。

举例：一个组合单期收益交替为 +50% 和 -40%：

- 算术平均：$\frac{50\% - 40\%}{2} = +5\%$。
- 实际：$(1.5 \times 0.6)^{1/2} - 1 = \sqrt{0.9} - 1 = -5.13\%$。

**算术平均是 +5%，实际是每年亏 5.13%**。这不是计算错误，而是复利的本质：亏损 40% 后需要上涨 66.7% 才能回到原点。

实践意义：

1. **汇报业绩必须用几何平均（CAGR）**，用算术平均会系统性高估。这在评价高波动策略时差距极大（波动率 40% 时，$\sigma^2/2 = 8\%$/年）。
2. **杠杆会放大波动率拖累**。2 倍杠杆下，波动率翻倍，拖累变为 4 倍：$\sigma^2/2 \to (2\sigma)^2/2 = 2\sigma^2$。这就是为什么"2 倍杠杆的指数基金"长期表现往往不如 2 倍的无杠杆收益（还有融资成本与日内再平衡损耗）。
3. **降低波动本身就能提高复合收益**。这是波动率目标策略（`vol_target`）的经济学基础，也与 [01-05-收益分解与风险因子](../01-入门/01-05-收益分解与风险因子.md) 中的低波动异象相呼应。

## 五、代码：两种收益的计算与验证

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import perf_report, annual_return
from qd.utils.calendar import trading_days

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
px = md.close()

# 1) 两种收益
simple = px.pct_change()
logret = np.log(px).diff()
print("最大差异:", float((simple - logret).abs().max().max()))

# 2) 验证对数收益的时间可加性
first, last = px.index[1], px.index[-1]
lhs = np.log(px.loc[last] / px.loc[first])
rhs = logret.loc[first:last].sum()
print("时间可加性误差:", float((lhs - rhs).abs().max()))

# 3) 年化：用真实交易日数，不用固定 252
n_days = len(md.dates)
cum = px.iloc[-1] / px.iloc[0] - 1
ann_geo = (1 + cum) ** (252 / n_days) - 1
print("几何年化均值:", round(float(ann_geo.mean()), 4))
print("算术年化均值:", round(float(simple.mean().mean() * 252), 4))

# 4) 波动率拖累的验证
eq = px.mean(axis=1)
r_daily = eq.pct_change().dropna()
arith = r_daily.mean() * 252
geo = (eq.iloc[-1] / eq.iloc[0]) ** (252 / len(r_daily)) - 1
sigma = r_daily.std() * np.sqrt(252)
print(f"算术 {arith:.4f} | 几何 {geo:.4f} | 差 {arith-geo:.4f} | σ²/2 预测 {sigma**2/2:.4f}")

# 5) 用平台函数核对
equity = (1 + r_daily).cumprod()
print({k: round(v, 4) for k, v in perf_report(equity, rf=0.02).flat().items()})
print("年化:", round(annual_return(equity), 4))
print("2024 交易日数:", len(trading_days("2024-01-01", "2024-12-31", market="A")))
```

第 4 步的输出值得反复看：`arith - geo` 与 $\sigma^2/2$ 应该在同一量级（不会完全相等，因为二阶近似有误差，且真实分布有偏度）。这个实验能让你直观理解"低波动为什么值钱"。

## 六、常见换算速查

| 想要什么 | 从什么出发 | 公式 |
| --- | --- | --- |
| 日 → 年（收益） | 日均简单收益 $\bar r$ | $(1+\bar r)^{252}-1$ 或 $252\bar r$（近似） |
| 日 → 年（波动） | 日标准差 $\sigma_d$ | $\sigma_d\sqrt{252}$ |
| 年 → 日（波动） | 年标准差 $\sigma_a$ | $\sigma_a/\sqrt{252}$ |
| 月 → 年 | 月收益 $r_m$ | $(1+r_m)^{12}-1$ |
| 累计 → 年化 | 累计 $r_c$，共 $n$ 日 | $(1+r_c)^{252/n}-1$ |
| 名义 → 实际（扣通胀） | 名义 $r$、通胀 $\pi$ | $\frac{1+r}{1+\pi}-1$ |

## 常见坑

- **直接用不复权价算收益**，在除权日产生假跌幅（见 [02-03-复权停牌与异常处理](../02-数据与工具/02-03-复权停牌与异常处理.md)）。
- **把对数收益按权重加总**得到组合收益，或者把简单收益逐日相加得到累计收益。
- **固定用 252 年化 A 股数据**，造成约 4% 的相对偏差。
- **用算术平均汇报业绩**，系统性高估高波动策略。
- **对含零或负价格的数据取对数**。（价格不会为负，但价差、某些衍生品价格可能，需先处理。）
- **把 $\sigma^2/2$ 当成"成本"直接从收益里减**。它是复合效应的近似，严格计算应直接用几何平均。
