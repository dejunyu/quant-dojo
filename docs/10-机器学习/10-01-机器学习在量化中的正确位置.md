# 机器学习在量化中的正确位置

机器学习在量化投资中被过度宣传，也被过度贬低。本节给出一个冷静的定位：**它是工具箱里的一把好工具，但不是一个能凭空创造 alpha 的黑箱**。理解它能做什么、不能做什么，比学会调用某个库重要得多。

## 一、信噪比：一切讨论的起点

量化预测的本质是估计条件期望：

$$\mathbb{E}[r_{i,t+1}\mid x_{i,t}] = f(x_{i,t})$$

问题在于 $r_{i,t+1}$ 的绝大部分是噪声。用日频个股收益做回归，单因子的截面 $R^2$ 通常在 **0.5%~2%** 的量级。这意味着：

- 即使 $f$ 完全正确，你能解释的方差也只有 1%。
- 剩下的 99% 是真正的随机性，**任何模型都无法消除**。
- 一个 $R^2=1\%$ 的因子如果对应的 IC 约 0.03，在足够大样本下是统计显著的，也是经济上有价值的——但它的"显著"与图像识别里 $R^2=95\%$ 的显著完全是两回事。

信噪比低带来三条直接推论：

1. **模型的方差比偏差更致命**。在 $\text{MSE}=\text{Bias}^2+\text{Var}+\sigma^2_{\text{noise}}$ 里，$\sigma^2_{\text{noise}}$ 占绝对主导，任何增加模型方差的做法（更多参数、更深树、更少正则）都会迅速被噪声吞没。
2. **样本量不是"行数"**。5000 只股票 × 2500 个交易日 = 1250 万行，但**独立观测远少于此**：同一天所有股票共享市场因子，同一只股票相邻日高度相关。有效样本量更接近于"独立的时间段数"（几百个）乘以"独立的截面分组数"（几十个）。
3. **过拟合的收益是即时的，代价是延迟的**。过拟合的模型在样本内一定漂亮，在样本外一定崩塌，而崩塌要等上线后才发现。

学界对这一点有明确证据。Gu、Kelly 与 Xiu (2020) 在 *Journal of Financial Economics* 上用美股近 60 年数据系统比较了大量方法，结论是：机器学习方法（尤其是树模型与神经网络）相对线性模型确实有稳定的样本外改进，但**改进幅度远小于样本内差异**——样本内 $R^2$ 差异可以是百分之几，样本外只有零点几个百分点。而且收益主要集中在**非线性与交互项**上， univariate 的线性部分两者差别不大。

## 二、ML 能做什么

在信噪比低的约束下，ML 真正创造价值的地方是**函数形式**：

| 能力 | 说明 | 例子 |
| --- | --- | --- |
| **非线性** | 因子与收益的关系不是单调线性的 | 动量因子在中段最强，两端弱；估值因子的 U 型 |
| **交互作用** | 因子的效果依赖于其它因子的状态 | 价值因子在小市值股票上更强；动量在高质量股上更强 |
| **状态依赖** | 因子效果随宏观/波动率区制变化 | 高波动期反转因子更强 |
| **高维处理** | 数十到数百个弱因子需要正则化聚合 | 用 Lasso/GBDT 组合弱信号 |
| **非结构化数据** | 文本、公告、新闻、卫星图像 | NLP 情绪因子 |
| **组合构建** | 端到端优化权重而非预测收益 | 强化学习、直接优化夏普 |

注意前四项都是"更好地利用**已有的**信息"，而不是"发现**新的**信息"。这是理解 ML 定位的关键：**它是信号处理器，不是信号发生器**。

## 三、ML 不能做什么

1. **不能凭空制造 alpha**。如果输入特征里没有预测信息，再复杂的模型也学不出来。垃圾进、垃圾出（garbage in, garbage out）在金融里格外残酷。
2. **不能摆脱统计显著性的约束**。深度网络在小样本上拟合噪声的能力极强，这是**劣势**不是优势。
3. **不能替代因果与经济学逻辑**。纯数据挖掘出的模式往往是一次性的（data snooping），缺乏机制支撑的模式在下一次样本外就失效。Harvey、Liu 与 Zhu (2016) 在研究数百个已发表因子后指出，考虑多重检验后，大部分"显著因子"的 t 值门槛应提高到 3.0 以上而非 2.0。
4. **不能保证稳定**。金融是非平稳的：市场结构、参与者、监管都在变，训练期学到的映射在预测期可能已经改变（见 [模型漂移与监控](10-05-过拟合可解释与模型监控.md)）。
5. **不能跳过成本**。ML 模型通常给出更频繁、更大幅度的调仓信号，若不考虑 [成本与换手](../09-执行与成本/09-04-换手率控制.md)，回测的漂亮曲线在实盘会消失。

## 四、与计量经济学方法的分工

| 维度 | 计量/统计方法 | 机器学习 |
| --- | --- | --- |
| 目标 | **推断**：这个因子是否真实、效应多大 | **预测**：下期收益是多少 |
| 关注 | 系数估计、标准误、显著性 | 样本外预测误差 |
| 假设 | 强（线性、独立同分布、外生性） | 弱（只需函数可学习） |
| 可解释性 | 高 | 低（需 SHAP 等后处理） |
| 过拟合风险 | 低（参数少） | 高（需严格正则与验证） |
| 样本需求 | 小 | 大 |

正确的分工是**两段式**：

1. **用计量方法做因子发现与验证**：检验因子是否显著、是否已被已知因子解释、是否稳健（见 [单因子检验IC与ICIR](../05-因子/05-05-单因子检验IC与ICIR.md)）。这一步要的是"可信"。
2. **用 ML 做因子聚合与非线性增强**：把已验证的多个弱因子组合成一个预测。这一步要的是"精度"。

反过来用（用 ML 挖掘因子、用线性回归验证组合）通常会两头落空。

## 五、实践建议

- **先建立线性基准**。任何 ML 模型都必须先跑赢一个带交叉验证的岭回归/Lasso。跑不赢就说明模型没有增量。
- **把复杂度当作需要证明的成本**。每增加一个超参数，都要用样本外收益来证明它值得。
- **正则化要偏强**。金融的噪声水平支持"欠拟合一点"的策略。
- **特征比模型重要**。在有信号的特征上用简单模型，胜过在噪声特征上用复杂模型。见 [特征工程与标签构造](10-02-特征工程与标签构造.md)。
- **验证方案比模型重要**。[随机 K 折在金融上失效](10-03-金融数据的交叉验证.md)，用错验证方案的复杂模型一定输给用对验证方案的简单模型。

## 六、代码示例

```python
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor, list_factors
from qd.factors.pipeline import zscore, combine
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=100, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

# 1) 计量视角：单因子的 IC / ICIR，回答"这个因子真实吗"
ic = lab.ic("mom_12_1", horizon=20)
print("IC 均值 %.4f  IC 标准差 %.4f  ICIR %.3f"
      % (ic.mean(), ic.std(), ic.mean() / ic.std()))

# 2) 衰减检查：信号能活多久，决定调仓频率上限
print(lab.ic_decay("mom_12_1").head(10))

# 3) 线性基准：把已验证的弱因子用 z-score 等权聚合
names = list_factors()[:5]
frames = [zscore(get_factor(n).compute(md)) for n in names]
composite = combine(frames, method="mean")

# 4) 分位数组合回测：ML 模型上线前必须先跑赢这个基准
print(lab.quantile_backtest("mom_12_1", n_quantiles=5))
print(lab.report("mom_12_1"))
```

## 常见坑

- **用图像/CV 的直觉做金融**：那里信噪比 90%+，这里 1%。参数量、数据量、训练轮数的经验完全不适用。
- **只在样本内评估**：金融 ML 论文里 $R^2$ 提升 3% 的结果，样本外往往只有 0.3%。
- **忽视多重检验**：试了 200 个模型配置，选最好的那个，等于做了 200 次检验。必须用 [deflated Sharpe](../08-组合与风险/08-06-风险指标VaR与CVaR.md) 一类修正。
- **特征里混入了未来信息**：这是金融 ML 最常见的致命错误，见 [数据泄漏](10-03-金融数据的交叉验证.md)。
- **把 ML 输出当概率**：GBDT 的输出不是校准过的概率，用于仓位 sizing 前必须做校准。
