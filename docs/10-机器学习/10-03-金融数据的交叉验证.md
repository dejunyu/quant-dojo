# 金融数据的交叉验证

交叉验证是机器学习的标准工具，但**标准的随机 K 折在金融数据上是错的**，而且错得隐蔽——它会让你相信一个毫无预测力的模型有很高的样本外收益。本节讲清楚为什么错，以及正确的替代方案。

## 一、为什么随机 K 折失效

标准 K 折假设样本**独立同分布（i.i.d.）**。金融数据违反这一假设的方式有三种：

### 1. 标签重叠（horizon overlap）

你的标签是未来 $h$ 日收益：

$$y_{i,t} = \frac{P_{i,t+h}}{P_{i,t}}-1$$

那么样本 $(i,t)$ 的标签区间是 $[t, t+h]$，样本 $(i,t+1)$ 的标签区间是 $[t+1,t+1+h]$——**两者重叠 $h-1$ 天**。随机 K 折把 $(i,t)$ 放进训练集、$(i,t+1)$ 放进测试集，测试样本的标签信息就通过重叠区间泄漏到了训练集。

这是最直接的泄漏路径，危害随 $h$ 增大而增大。若 $h=20$，每个测试样本周围有 19 个"亲戚"在训练集里。

### 2. 序列相关与特征重叠

即使 $h=1$，特征本身也常包含历史窗口（如 20 日动量），训练样本的特征窗口与测试样本的特征窗口重叠。同时，个股收益存在自相关（波动率聚集、反转效应），使得相邻样本不独立。

### 3. 截面相关

同一天所有股票共享市场因子。训练集中某天的股票与测试集中另一天的股票，若处在同一个宏观区制内，也共享信息。这使"独立样本数"远少于行数。

**净效果**：随机 K 折得到的"样本外"分数是**乐观偏差**的，偏差大小与信噪比成反比——而金融的信噪比极低，所以偏差相对巨大。López de Prado 指出，这正是大量金融 ML 论文结果无法复现的技术原因之一。

## 二、净化（Purging）

**净化**的思路最简单：**把所有标签区间与测试期重叠的训练样本删掉**。

形式化：设测试期索引集合为 $\mathcal{T}$（时间区间 $[t_{start}, t_{end}]$），训练样本 $s$ 的标签区间为 $[t_s, t_s+h]$。若

$$[t_s,\ t_s+h] \cap [t_{start},\ t_{end}] \ne \varnothing$$

则从训练集中剔除 $s$。

注意净化是**双向**的：不只是"测试期之前的训练样本会泄漏"（向前看），测试期**之后**的样本若其特征窗口覆盖测试期，也可能泄漏（取决于特征构造）。完整实现应对两者都做检查。

## 三、禁运（Embargo）

净化处理的是标签重叠，**禁运**处理的是**序列相关的信息回流**。

即便净化了，测试期结束后的紧邻样本与测试期样本高度相关（同一个市场状态、同一波资金流）。若这些紧邻样本在训练集里，模型仍能"闻到"测试期的信息。

禁运的做法：在测试期**之后**再留出一段长度为 $e$ 的禁运期，这段样本也从训练集中剔除。经验取值：

$$e \approx 0.01 \times T \quad \text{或} \quad e \approx h$$

其中 $T$ 是总样本期数，$h$ 是标签持有期。日频数据常用 $e=5\sim20$ 个交易日。

## 四、两种正确的切分方案

### 方案 1：净化 K 折（Purged K-Fold with Embargo）

保留 K 折的结构（每折都能做测试，样本利用率高），但每段做：

1. 划分测试期 $\mathcal{T}_k$。
2. 从训练集中**净化**所有与 $\mathcal{T}_k$ 标签区间重叠的样本。
3. 从训练集中**禁运**$\mathcal{T}_k$ 之后 $e$ 期内的样本。
4. 训练、评估，记录该折分数。
5. 汇总各折分数（注意各折的测试期不重叠，分数可平均但标准误会被低估，因为折间仍相关）。

适用于：样本有限、希望充分利用数据做超参数选择。

### 方案 2：Walk-Forward（滚动前向）

更贴近实盘的做法：

```
[========= 训练 =========][== 测试 ==]
        [========= 训练 =========][== 测试 ==]
                [========= 训练 =========][== 测试 ==]
```

两种变体：

- **扩展窗口（expanding）**：训练起点固定，终点前移。样本越来越多，但早期数据可能与当前市场结构不符。
- **滚动窗口（rolling）**：训练窗口长度固定，整体前移。更适应非平稳性，但每次训练样本少。

Walk-forward 的优点是**天然时序、无需净化**（当然仍建议做禁运），且直接给出一条样本外收益曲线（相关讨论见 [样本内外与滚动前推](../06-回测/06-06-样本内外与滚动前推.md)），可以计算 [夏普与回撤](../08-组合与风险/08-06-风险指标VaR与CVaR.md)。缺点是只能做一次，评估方差较大。

| 方案 | 前视风险 | 样本利用率 | 计算成本 | 适用 |
| --- | --- | --- | --- | --- |
| 随机 K 折 | **高（不可用）** | 高 | 低 | 非时序数据 |
| 时序 K 折（无净化） | 中 | 高 | 低 | 粗筛 |
| 净化 K 折 + 禁运 | 低 | 中 | 中 | **超参数选择** |
| Walk-forward | 最低 | 低 | 高 | **最终评估** |

## 五、其它泄漏来源（比交叉验证更容易被忽略）

1. **特征里用全样本统计量**：用全样本的均值/标准差做标准化 → 前视。必须只用训练期或滚动窗口。
2. **幸存者偏差**：用当前存续的股票池做历史回测，剔除了已退市/被 ST 的标的。
3. **使用修订后的数据**：财务数据在发布后会被修正（restatement），回测中使用的是"最终版"而非当时可得的版本。
4. **未来函数**：用 $t$ 日收盘价计算信号却假设按 $t$ 日收盘价成交。
5. **超参数在测试集上调**：反复看测试结果调参数，等于把测试集变成了训练集。正确做法是嵌套交叉验证（nested CV）。

## 六、代码示例

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.optimize import purged_kfold_indices
from qd.factors import get_factor
from qd.factors.pipeline import zscore, winsorize

md = generate_demo_market(n_symbols=80, start="2018-01-01", end="2024-12-31", seed=7)
rets = md.returns().dropna()
T = len(rets)
h, e = 20, 5                                   # 标签持有期、禁运期

# ---- 1. 净化 K 折 ----
folds = purged_kfold_indices(T, n_splits=5, horizon=h, embargo=e)   # -> [(train_idx, test_idx), ...]
for k, (tr, te) in enumerate(folds):
    print("第 %d 折: 训练 %d 期, 测试 %d 期, 测试区间 [%d, %d]"
          % (k + 1, len(tr), len(te), te.min(), te.max()))

# ---- 2. 自检：训练样本的标签区间不得与测试区间相交，且不得落在禁运期内 ----
for tr, te in folds:
    t0, t1 = te.min(), te.max()
    overlap = [s for s in tr if not (s + h < t0 or s > t1)]
    in_embargo = [s for s in tr if t1 < s <= t1 + e]
    assert not overlap and not in_embargo, "净化/禁运不彻底"
print("检查通过：无标签重叠、无禁运期违规")

# ---- 3. Walk-forward：最终评估（最简模型：按训练期 IC 符号持仓）----
mom = zscore(winsorize(get_factor("mom_12_1").compute(md))).reindex(rets.index)

def train_predict(train_idx, test_idx):
    tr_ret, tr_sig = rets.iloc[train_idx], mom.iloc[train_idx]
    ic = (tr_sig.shift(1) * tr_ret).sum(axis=1).mean()      # 训练期平均 IC
    sign = np.sign(ic)
    return (sign * mom.iloc[test_idx].shift(1) * rets.iloc[test_idx]).sum(axis=1)

# 时间序列折：每折的测试段是连续的未来区间，训练集已做净化 + 禁运
splits = purged_kfold_indices(T, n_splits=5, horizon=h, embargo=e)
pnl = pd.concat([train_predict(tr, te) for tr, te in splits])
print("样本外日收益: 均值 %.5f  年化夏普 %.2f"
      % (pnl.mean(), pnl.mean() / pnl.std() * np.sqrt(252)))
```

## 常见坑

- **只净化不禁运**：序列相关仍会泄漏，尤其是波动率聚集导致的相邻样本相关。
- **忘了特征窗口的泄漏**：若特征用 60 日窗口，净化应按 $\max(h, \text{窗口长度})$ 计算重叠。
- **折间分数当成独立样本算标准误**：相邻折的测试期仍相关，标准误会被低估，t 值被高估。
- **在测试集反复调参**：应使用嵌套 CV——内层做超参数选择，外层做评估。
- **用 walk-forward 的某一段最好结果汇报**：应报告全部样本外区间的完整曲线与统计。
- **数据本身的泄漏**：财务数据修正、退市股剔除、指数成分调整，都会让"干净的切分"仍然泄漏。
