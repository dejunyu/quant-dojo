# 特征工程与标签构造

在 [信噪比极低的金融数据](10-01-机器学习在量化中的正确位置.md) 上，**特征与标签的质量远比模型结构重要**。同一个 GBDT，喂入经过中性化与标准化的特征，与喂入原始价格衍生量，结果可以是一个赚钱一个亏钱。本节讲这两件事的标准做法。

## 一、特征：从原始数据到可学习变量

### 四类特征

| 类别 | 构造方式 | 例子 |
| --- | --- | --- |
| **因子化特征** | 把经济学量纲转成横截面可比的分位数/rank | 价值、动量、质量、成长、盈利能力 |
| **时序特征** | 对同一标的的历史序列做统计 | 过去 20 日波动率、成交量变化率、价格与均线的偏离 |
| **交互特征** | 两个因子的乘积或条件组合 | 价值 × 质量、动量 × 波动率倒数 |
| **原始行情量** | 收益率、成交量、换手率、振幅 | 需先做标准化与滞后 |

关键原则：**特征必须在时间上严格滞后**。任何使用 $t$ 日收盘信息构造、用于预测 $t+1$ 日收益的特征，在实盘中都无法在 $t$ 日收盘前获得（除非你能在收盘集合竞价成交，这是不可靠的假设）。

### 截面标准化：为什么必须做

金融数据有两个方向的异质性：

1. **跨期**：不同日期的市场波动率、整体估值水平差异巨大。2020 年 3 月的波动率数据是平时的 3 倍。
2. **跨标的**：不同股票的波动率、市值、价格量级差异巨大。

因此对每个交易日 $t$ 独立做**截面标准化**：

$$z_{i,t} = \frac{x_{i,t} - \text{mean}_t(x)}{\text{std}_t(x)}$$

或者更稳健的**截面排序**：

$$r_{i,t} = \frac{\text{rank}_t(x_i)}{N_t} \in (0,1]$$

排序的优点是对极端值免疫、分布恒定，是实务中最常用的形式。平台提供了 `qd.factors.pipeline` 中的 `winsorize`、`zscore`、`rank`、`neutralize` 等算子。

### 三步标准处理流程

1. **去极值（winsorize）**：把上下 $\alpha\%$（通常 1%~5%）分位之外的极端值截断到分位值。防止单一异常值主导标准化。
2. **标准化（zscore / rank）**：截面标准化。
3. **中性化（neutralize）**：对行业与市值做回归取残差：

$$z_{i,t} = \alpha_t + \beta_1 \ln(\text{mktcap}_{i,t}) + \sum_k \beta_k \mathbb{1}[\text{industry}_k] + \varepsilon_{i,t},\quad \tilde z_{i,t}=\varepsilon_{i,t}$$

中性化的意义：剔除你**不想要**的暴露。如果你做选股，行业与市值 beta 往往不是你想赌的（或者是你想单独控制的），中性化后剩下的才是真正的选股能力。

## 二、标签：定义"什么算好"

### 1. 未来收益（回归标签）

$$y_{i,t} = \frac{P_{i,t+h}}{P_{i,t}} - 1$$

$h$ 为持有期。直接、可微分，但**信噪比最低**（日度个股收益波动 2%~4%，信号只有几个基点）。

### 2. 三分类 / 排序标签

$$y_{i,t} = \begin{cases} +1, & r_{i,t:t+h} \text{ 处于截面前 } 30\% \\ 0, & \text{中间 } 40\% \\ -1, & \text{后 } 30\% \end{cases}$$

优点：把回归问题转成分类，**降低了对噪声精度的要求**（你不需要预测准确的收益率，只需预测相对排序）。缺点：丢失了幅度信息，且类别边界是人为的。

### 3. 超额收益标签（推荐）

$$y_{i,t} = r_{i,t:t+h} - r^{bench}_{t:t+h}$$

或用因子模型剔除共同因子：

$$y_{i,t} = r_{i,t} - \big(\alpha + \beta_{mkt} r^{mkt}_t + \beta_{size} SMB_t + \beta_{value} HML_t\big)$$

这是**最重要的一个改进**：原始收益里绝大部分是市场 beta，它对所有股票都一样，**不构成可学习的截面差异**，却贡献了绝大部分方差。剔除它之后，信噪比会显著提升。

### 标签的四个设计原则

| 原则 | 说明 |
| --- | --- |
| **期限匹配** | 标签的持有期必须与你实际能持有的期限一致。用 5 日标签训练却持有 20 日，模型学到的是错的 |
| **剔市场** | 用超额收益或因子残差，而非原始收益 |
| **对齐执行** | 标签应从 $t+1$ 日（而非 $t$ 日）的收益算起，与 [T+1 成交假设](../09-执行与成本/09-06-实盘延迟与系统.md) 一致 |
| **稳健化** | 收益用对数收益或 winsorize 后的收益，避免极端值主导损失 |

## 三、样本权重

金融样本不是等价的，三类权重最常用：

1. **时间衰减权重**：近期样本更能反映当前市场结构。
   $$w_t = \lambda^{T-t},\quad \lambda\in[0.99, 0.999]\ \text{(日度)}$$
   或按年衰减（半衰期 2~5 年是常见选择）。

2. **波动率倒数权重**：高波动期的样本噪声大，降权。
   $$w_t \propto \frac{1}{\sigma_t^2}$$

3. **类别平衡 / 重要性权重**：三分类标签中，极端类别样本少但价值高，可提高其权重。

使用样本权重时要注意：**它等价于改变损失函数的加权方式**，会影响交叉验证的切分逻辑——权重本身也必须只用训练期信息确定，否则引入前视。

## 四、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor, list_factors
from qd.factors.pipeline import winsorize, zscore, neutralize, rank, combine
from qd.research.lab import FactorLab

md = generate_demo_market(n_symbols=100, start="2018-01-01", end="2024-12-31", seed=7)

# ---- 1. 特征处理三步曲：去极值 -> 标准化 -> 中性化 ----
mom = get_factor("mom_12_1").compute(md)
mom_w = winsorize(mom, lower=0.01, upper=0.99)     # 去极值
mom_z = zscore(mom_w)                               # 截面标准化
mom_n = neutralize(mom_z, md, by=["mktcap", "industry"])  # 剔除市值与行业
mom_r = rank(mom_n)                                 # 截面排序（对异常值最鲁棒）

# ---- 2. 多因子合成（线性基准；GBDT 应以它为对手）----
names = list_factors()[:6]
feats = [rank(zscore(winsorize(get_factor(n).compute(md)))) for n in names]
X = combine(feats, method="mean")                   # 等权 z-score 合成

# ---- 3. 标签构造：未来 h 日超额收益（相对截面均值，即剔除市场 beta）----
close = md.close()
h = 20
fwd_ret = close.pct_change(h).shift(-h)          # 从 t+1 起算 h 日收益
bench = fwd_ret.mean(axis=1)                     # 截面等权基准
label = fwd_ret.sub(bench, axis=0)               # 超额收益标签
label_rank = label.rank(axis=1, pct=True)        # 转成分位数标签 [0,1]
label_cls = (label_rank > 0.7).astype(int) - (label_rank < 0.3).astype(int)  # 三分类

# ---- 4. 样本权重：时间衰减 + 波动率倒数 ----
T = len(label)
age = np.arange(T)
w_time = 0.995 ** (T - age)                      # 时间衰减（日度）
vol = md.returns().std(axis=1).replace(0, np.nan)
w_vol = 1.0 / (vol ** 2)
w = (w_time * w_vol.reindex(label.index).bfill().fillna(1.0)).values

# ---- 5. 用 FactorLab 检验处理后的因子是否变好 ----
lab = FactorLab(md)
print("原始动量 IC :", round(float(lab.ic("mom_12_1", horizon=h).mean()), 4))
print("标签 IC 检验:", round(float(lab.ic("mom_12_1", horizon=h).mean() /
                            lab.ic("mom_12_1", horizon=h).std()), 3), "(ICIR)")
```

## 常见坑

- **用全样本均值做标准化**：必须用**截面**（同一天横着）标准化，用时间序列的滚动均值会引入前视。
- **标签用了 t 日收益**：若你在 $t$ 日收盘才能算信号，$t$ 日的收益已经实现，无法捕捉。标签必须从 $t+1$ 日起算。
- **忘记 shift(-h) 的对齐**：`pct_change(h).shift(-h)` 中的 `shift(-h)` 把未来收益搬到当前行，方向容易搞反，务必抽查几行验证。
- **中性化变量本身有前视**：用未来市值做中性化是常见错误，市值必须用 $t$ 日的。
- **类别标签的边界是人为的**：30/70 分位的切点应做敏感性测试，不该只报一个数字。
- **样本权重用了全样本波动率**：必须用滚动或训练期内的估计。
- **特征数量远超样本**：见 [金融数据的交叉验证](10-03-金融数据的交叉验证.md)，高维小样本必须用净化切分。
