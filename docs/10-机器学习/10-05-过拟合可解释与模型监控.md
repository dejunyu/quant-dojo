# 过拟合可解释与模型监控

一个量化模型的生命周期里，**训练它只占 20% 的工作量，判断它是不是真的有效、以及什么时候该下线，占剩下的 80%**。本节处理这三件事：识别过拟合、解释模型、监控与下线。

## 一、过拟合的识别

### 1. 样本内外落差

最直接的指标。设样本内年化夏普 $SR_{in}$，[净化交叉验证](10-03-金融数据的交叉验证.md) 或 walk-forward 得到的样本外 $SR_{out}$，定义**衰减率**：

$$\text{decay} = 1 - \frac{SR_{out}}{SR_{in}}$$

经验阈值（日频股票策略）：

| 衰减率 | 判断 |
| --- | --- |
| < 30% | 正常 |
| 30%~50% | 可疑，需要检查 |
| > 50% | 高度可能过拟合 |
| > 80% | 基本可以断定是噪声拟合 |

注意：**样本内夏普本身没有参考价值**，只有它与样本外的比值才有意义。

### 2. 多重检验修正

如果你试了 $N$ 组参数/特征组合，选了最好的那个，你实际上做了 $N$ 次检验。在零假设（全部无效）下，最大 t 值的期望约为

$$\mathbb{E}[\max t] \approx \sqrt{2\ln N} - \frac{\ln\ln N + \ln(4\pi)}{2\sqrt{2\ln N}}$$

对 $N=100$，$\mathbb{E}[\max t]\approx 2.5$——**即使所有策略都无效，你也会看到一个 t 值 2.5 的"显著"策略**。

正确做法：

- **Deflated Sharpe Ratio（DSR）**：Bailey & López de Prado 提出，把观测夏普转换为"在考虑了试验次数、样本长度、收益分布的偏度与峰度之后的概率陈述"。
  $$\text{DSR} = P\big(SR > SR_0 \mid \text{已试 } N \text{ 次}\big)$$
- **提高门槛**：Harvey、Liu 与 Zhu (2016) 建议在考虑既往研究后，新因子的 t 值门槛应提到 **3.0** 而非 2.0（另见 [过拟合与多重检验](../06-回测/06-05-过拟合与多重检验.md)）。

平台提供了 `qd.metrics.perf.deflated_sharpe` 与 `probabilistic_sharpe`，应作为策略上线的强制检查项。

### 3. 参数敏感性（参数高原 vs 参数尖峰）

绘制"参数 vs 样本外表现"的曲面：

- **高原（plateau）**：一大片参数区域表现都好 → 稳健。
- **尖峰（spike）**：只有孤立的一个点好，周围立刻变差 → 过拟合。

这是最实用也最容易被跳过的检查。**只报单点最优结果而不给参数敏感性的策略，一律视为不可信**。

### 4. 其它红旗

- 换手率异常高（扣成本后收益消失）。
- 收益集中在少数几天/几只股票。
- 模型在样本外的**错误方向**上持续犯错。
- 特征重要性在相邻折之间大幅变动（说明模型不稳定）。

## 二、模型可解释性

### 三类方法

| 方法 | 回答什么 | 优点 | 局限 |
| --- | --- | --- | --- |
| **特征重要性（gain/split）** | 哪些特征被用得多 | 快、内置 | 偏向高基数，非因果 |
| **置换重要性** | 打乱某特征后损失恶化多少 | 与模型无关、可在样本外算 | 相关特征会互相掩盖 |
| **SHAP** | 单个预测中每个特征贡献多少 | 有理论保证（Shapley 值）、可做个体归因 | 计算慢，相关特征下解释需谨慎 |

SHAP 的核心思想是把预测值 $f(x)$ 分解为各特征的贡献之和：

$$f(x) = \phi_0 + \sum_{j=1}^{M}\phi_j$$

其中 $\phi_0$ 是基线（训练集平均预测），$\phi_j$ 是特征 $j$ 的 Shapley 值——它是该特征在所有可能特征子集上的平均边际贡献。SHAP 满足效率性、对称性、可加性、虚设性四条公理，是目前理论最扎实的解释方法。

实务用途：

1. **组合层归因**：把组合收益分解到各因子的 SHAP 贡献，看钱是哪个因子赚的。
2. **异常单笔诊断**：某个持仓的预测为什么高？看它的 SHAP 分解。
3. **符号一致性检验**：SHAP 值的方向是否符合经济学预期？若一个价值因子的 SHAP 显示"估值越贵预测收益越高"，那就要怀疑数据或标签有问题。

### 解释的边界

必须明确：**解释工具给出的是"关联"而非"因果"**。要回答"如果我改变因子 $X$，收益会怎样"，需要因果推断工具（双重差分、工具变量、随机实验），不是 SHAP。在观察性金融数据上，这几乎是做不到的——所以对因子保持经济学先验的约束，比事后解释更重要。

## 三、模型漂移监控与下线标准

金融是非平稳的：市场结构、参与者构成、监管规则、交易成本都在变。模型上线后的性能衰减是**常态**，不是异常。因此必须有监控系统与**预先写死的下线标准**。

### 三层监控

**第一层：输入漂移（feature drift）**

监控特征分布是否变化。常用指标：

- **PSI（Population Stability Index）**：
  $$\text{PSI} = \sum_{b=1}^{B}(p_b^{new} - p_b^{ref})\ln\frac{p_b^{new}}{p_b^{ref}}$$
  经验阈值：< 0.1 稳定；0.1~0.25 需关注；> 0.25 显著漂移。
- **KS 统计量**：两样本分布的最大累积差。
- 特征缺失率、极值比例。

**第二层：输出漂移（prediction drift）**

监控预测值的均值、标准差、分位数。若分散度突然下降，往往意味着输入已进入训练分布之外的区域。

**第三层：实盘表现（performance）**

- 滚动 IC / ICIR（如 60 日滚动）。
- 实盘净值与回测净值的偏离度。
- 最大回撤、当前回撤持续时间。
- 换手率、成交额是否异常。

### 下线标准（必须预先写死）

示例（可按策略类型调整）：

| 触发条件 | 动作 |
| --- | --- |
| 滚动 60 日 IC < 0 且 ICIR < 0 | 减仓至 50%，告警 |
| 滚动 60 日 IC 低于历史均值 2 个标准差 | 减仓至 50% |
| 实盘回撤 > 1.5 × 回测历史最大回撤 | 减仓至 25%（见 [回撤熔断](../08-组合与风险/08-05-止损与回撤控制.md)） |
| 任一核心特征 PSI > 0.25 持续 10 日 | 暂停开新仓 |
| 实盘与回测净值偏离 > 20% | 人工复核（可能是成本或执行问题） |
| 数据管道连续 3 日异常 | 停止交易 |

**关键原则**：下线标准必须在**上线之前**写好，并由独立于策略的进程执行。事中由人判断，一定会被"再等等看会不会反弹"拖住，这正是毁灭性亏损的典型路径。

### 下线不等于永久放弃

区分三种情形：

1. **因子失效（结构性）**：经济学机制被套利掉了或制度变了 → 永久下线。
2. **区制切换（周期性）**：价值因子在成长股行情中连亏三年是常态 → 降仓观察，不要永久下线。
3. **实现问题（操作性）**：数据错误、执行退化 → 修复后重新上线。

判断的关键是有没有**经济学解释**。有解释的衰减（如"当前是流动性驱动行情，价值因子失效合理"）可以等；没有解释的衰减应当立即下线。

## 四、代码示例

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor
from qd.factors.pipeline import winsorize, zscore, rank
from qd.research.lab import FactorLab
from qd.metrics.perf import deflated_sharpe, probabilistic_sharpe, sharpe

md = generate_demo_market(n_symbols=100, start="2018-01-01", end="2024-12-31", seed=7)
lab = FactorLab(md)

# ---- 1. 过拟合检查：样本内外落差 ----
full = md.returns().dropna()
cut = int(len(full) * 0.7)
in_sample, out_sample = full.iloc[:cut], full.iloc[cut:]
sig = rank(zscore(winsorize(get_factor("mom_12_1").compute(md)))).reindex(full.index)
pnl_in = (sig.iloc[:cut].shift(1) * in_sample).sum(axis=1)
pnl_out = (sig.iloc[cut:].shift(1) * out_sample).sum(axis=1)
sr_in, sr_out = sharpe(pnl_in.values), sharpe(pnl_out.values)
print("样本内夏普 %.2f  样本外夏普 %.2f  衰减 %.1f%%"
      % (sr_in, sr_out, 100 * (1 - sr_out / sr_in) if sr_in > 0 else np.nan))

# ---- 2. 多重检验修正：试了 50 组参数后的 deflated Sharpe ----
n_trials = 50
sr_obs = np.array([sr_out] * 3)                      # 观测到的若干夏普
n_obs = len(pnl_out)
skew = float(pd.Series(pnl_out).skew())
kurt = float(pd.Series(pnl_out).kurt())
dsr = deflated_sharpe(sr_obs, n_trials=n_trials, n_obs=n_obs,
                      skew=skew, kurt=kurt)
psr = probabilistic_sharpe(sr_out, n_obs=n_obs, skew=skew, kurt=kurt)
print("Deflated Sharpe:", np.round(dsr, 3), " Probabilistic Sharpe:", round(psr, 3))

# ---- 3. 输入漂移监控：PSI ----
def psi(ref, new, bins=10):
    qs = np.quantile(ref, np.linspace(0, 1, bins + 1))
    qs[0], qs[-1] = -np.inf, np.inf
    qs = np.unique(qs)
    p = np.histogram(ref, bins=qs)[0] / len(ref)
    q = np.histogram(new, bins=qs)[0] / len(new)
    p = np.clip(p, 1e-6, None); q = np.clip(q, 1e-6, None)
    return float(np.sum((q - p) * np.log(q / p)))

sig_series = sig.stack().dropna()
n = len(sig_series) // 2
print("因子 PSI(前/后半期) = %.3f" % psi(sig_series.values[:n], sig_series.values[n:]))

# ---- 4. 实盘表现监控：滚动 IC ----
ic = lab.ic("mom_12_1", horizon=20)
roll_ic = ic.rolling(60).mean()
print("最近滚动 60 期 IC 均值 %.4f（历史 %.4f）" % (roll_ic.iloc[-1], ic.mean()))
```

## 常见坑

- **只用样本外一次切分**：一次切分的结果方差很大。应该用 [净化 K 折](10-03-金融数据的交叉验证.md) 或 walk-forward 得到分布。
- **把 deflated Sharpe 当夏普**：它是一个概率陈述，不是收益指标。
- **SHAP 值当因果**：SHAP 分解的是模型的预测，不是真实世界的因果。
- **监控阈值拍脑袋**：阈值应基于策略历史表现的分布（如历史 IC 的 2 个标准差），而不是整数。
- **只有表现监控没有输入监控**：等到收益掉下来才发现，已经亏了钱。输入漂移通常领先表现 1~3 个月。
- **下线标准留给人工判断**：必须在上线前写死并自动化执行。
- **忘了记录试验次数**：事后无法计算 deflated Sharpe。应建立策略实验台账，记录每次尝试。
