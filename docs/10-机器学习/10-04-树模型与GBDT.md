# 树模型与GBDT

在 [信噪比极低](10-01-机器学习在量化中的正确位置.md) 的金融表格数据上，**梯度提升树（GBDT）** 是实践中表现最稳的一类模型。Gu、Kelly 与 Xiu (2020) 的大规模比较中，树模型是表现最好的几类方法之一。本节讲它的原理、参数、与传统线性模型的对比。

## 一、原理：逐级拟合残差

给定损失函数 $L(y, F(x))$（回归用平方误差，排序用 LambdaRank 类损失），GBDT 逐步构建：

$$F_m(x) = F_{m-1}(x) + \nu\cdot h_m(x),\qquad m=1,\dots,M$$

第 $m$ 步的树 $h_m$ 拟合的是**当前模型的负梯度（伪残差）**：

$$h_m \approx \arg\min_{h}\sum_i \Big(-\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\Big|_{F=F_{m-1}} - h(x_i)\Big)^2$$

三个核心超参数的含义：

| 参数 | 含义 | 作用 |
| --- | --- | --- |
| $M$（n_estimators） | 树的数量 | 太多过拟合，配合早停 |
| $\nu$（learning_rate） | 学习率/收缩 | 越小越需要更多树，但泛化更好 |
| 树深度 / num_leaves | 单棵树的复杂度 | **控制交互阶数的关键** |

关键洞察：**树的深度决定了能学到几阶交互**。深度为 $d$ 的树最多能表达 $d$ 阶交互。金融中的交互通常只有 2~3 阶（如"价值 × 质量"），所以**浅树（深度 3~6，或 num_leaves 15~63）往往就够了**——这也是为什么 GBDT 在金融上不需要很深。

### 为什么树模型适合金融表格数据

1. **无需标准化与单调变换**：树对特征的单调整变换不变（用的是切点），省去了大量预处理。
2. **自动处理交互**：不需要人工构造 $x_1\times x_2$。
3. **能处理缺失值**：XGBoost/LightGBM 有默认的缺失值分配方向。
4. **对异常值鲁棒**：切点只依赖排序，不依赖数值大小。
5. **能拟合非单调关系**：这是它相对线性模型最大的增量。

### 为什么需要强正则

树模型的方差很大，而 [金融的噪声主导](../10-机器学习/10-01-机器学习在量化中的正确位置.md)。必须：

- 限制树深（num_leaves ≤ 63，深度 ≤ 6）
- 降低学习率（0.01~0.05）
- 子采样（`bagging_fraction` / `subsample` 0.6~0.8，`feature_fraction` 0.3~0.8）
- 提高分裂最小样本数（`min_child_samples` ≥ 100，日频截面数据应更大）
- **用早停（early stopping）**：在验证集上监控，连续 N 轮无改善则停止

## 二、在选股中的应用

典型流程：

1. **样本构造**：每行为 (股票 $i$, 日期 $t$)，特征为 $t$ 日的截面标准化因子，标签为 $t+1$ 日起的超额收益（见 [特征与标签](10-02-特征工程与标签构造.md)）。
2. **切分**：用 [净化 K 折](10-03-金融数据的交叉验证.md) 或 walk-forward，**绝不用随机 K 折**。
3. **训练目标**：三种常见选择
   - 回归：`objective='regression'`，直接用超额收益。
   - 排序：`objective='lambdarank'`（LightGBM 支持），直接优化截面排序，与选股目标最一致，**推荐**。
   - 分类：把标签离散成三分类，用 `multiclass`。
4. **预测与组合**：用 $t$ 日模型输出预测 $t+1$ 日收益，按预测排序取前 $K$ 只做多（或与 [均值方差](../08-组合与风险/08-01-马科维茨均值方差.md) 一类的优化器对接）。
5. **评估**：用 IC、ICIR、分位数组合收益，而不是只看 MSE。

## 三、关键参数与调参顺序

以 LightGBM 为例（XGBoost 有对应参数）：

| 参数 | 建议范围 | 说明 |
| --- | --- | --- |
| `num_leaves` | 15~63 | 主要复杂度旋钮，先调这个 |
| `learning_rate` | 0.01~0.05 | 与 `n_estimators` 反向联动 |
| `n_estimators` | 100~1000（配合早停） | 用 `early_stopping_rounds=50` |
| `min_child_samples` | 100~1000 | 数据量大时应增大 |
| `feature_fraction` | 0.3~0.8 | 特征子采样，降方差、防共线 |
| `bagging_fraction` | 0.6~0.9 | 样本子采样 |
| `lambda_l2` | 1~100 | L2 正则 |
| `max_depth` | 3~6（或 -1 由 leaves 决定） | 限制交互阶数 |

**调参顺序**（由粗到细）：

1. 先固定 `learning_rate=0.05`，调 `num_leaves`（从 15 到 63）。
2. 调 `min_child_samples` 与 `feature_fraction`（防过拟合的主力）。
3. 调 `lambda_l2`、`bagging_fraction`。
4. 最后降 `learning_rate` 并增加树数（通常能小幅改善）。

**必须用嵌套交叉验证**：内层用净化 K 折选超参数，外层评估。否则超参数本身就是在测试集上调出来的。

## 四、特征重要性：怎么读、怎么不读

LightGBM/XGBoost 提供三种重要性：

| 类型 | 定义 | 偏向 |
| --- | --- | --- |
| `split` (weight) | 该特征被用作分裂点的次数 | 偏向取值多的特征 |
| `gain` | 该特征带来的总损失下降 | **最常用**，偏向早期分裂 |
| `cover` / `total_gain` | 覆盖的样本量 | 辅助参考 |

注意事项（非常重要）：

1. **重要性不等于因果性**。特征重要只说明"模型用它降低了损失"，不说明改变它会导致收益变化。
2. **相关性特征的重要性会被分摊**。两个几乎相同的因子，重要性各占一半，看起来都不重要。
3. **偏向高基数与连续特征**。离散特征（如行业）即使有用，split 数也少。
4. **过拟合模型的重要性不可信**。在噪声上拟合出的"重要特征"是随机的。
5. 更可靠的解释工具是 **SHAP 值**与**置换重要性（permutation importance）**，见 [可解释与监控](10-05-过拟合可解释与模型监控.md)。

## 五、与线性模型的对比

| 维度 | 线性模型（岭/Lasso） | GBDT |
| --- | --- | --- |
| 函数形式 | 线性、可加 | 任意（分段常数） |
| 交互 | 需人工构造 | 自动 |
| 外推能力 | 强（趋势外推合理） | **无**（超出训练范围输出常数） |
| 可解释性 | 系数直接可读 | 需 SHAP |
| 小样本表现 | 好（方差小） | 差（易过拟合） |
| 大样本表现 | 中等 | **好** |
| 训练速度 | 快 | 中等（LightGBM 很快） |
| 对单调变换 | 敏感（需预处理） | 不敏感 |
| 超参数 | 1 个（$\lambda$） | 8+ 个 |

**外推能力的差异是金融上的关键区别**：如果预测期出现了训练期从未见过的极端因子值（如 2020 年 3 月的波动率），线性模型会外推，GBDT 会给出一个常数——后者更安全，前者可能给出荒谬的预测。这也是树模型的优势之一。

实务建议：**永远先跑线性基准**。若 GBDT 在净化交叉验证下不能显著跑赢带正则的线性模型，就说明数据里没有可利用的非线性，用线性模型更省心、更稳、更好解释。

## 六、代码示例

```python
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.factors import get_factor, list_factors
from qd.factors.pipeline import winsorize, zscore, rank
from qd.optimize import purged_kfold

md = generate_demo_market(n_symbols=100, start="2018-01-01", end="2024-12-31", seed=7)
rets = md.returns().dropna()

# ---- 1. 特征矩阵：每个因子做去极值 + 标准化 + 截面排序 ----
names = list_factors()[:8]
feats = {n: rank(zscore(winsorize(get_factor(n).compute(md)))) for n in names}
X = pd.concat(feats, axis=1).reindex(rets.index)

# ---- 2. 标签：未来 20 日超额收益（相对当日截面均值）----
h = 20
fwd = md.close().pct_change(h).shift(-h)
y = fwd.sub(fwd.mean(axis=1), axis=0).reindex(rets.index)

# ---- 3. 摊平成 (date, symbol) 长表 ----
frame = pd.concat([y.stack().rename("y")] +
                  [X[n].stack().rename(n) for n in names], axis=1).dropna()

# ---- 4. 按"日期"做净化 K 折（同一日期的所有股票必须在同一侧）----
uniq_dates = pd.Index(sorted(set(frame.index.get_level_values(0))))
date_pos = frame.index.get_level_values(0).map({d: i for i, d in enumerate(uniq_dates)}).values

folds = purged_kfold(len(uniq_dates), n_splits=5, horizon=h, embargo=5)
for k, (tr_d, te_d) in enumerate(folds):
    tr, te = np.isin(date_pos, tr_d), np.isin(date_pos, te_d)
    Xtr, ytr = frame.loc[tr, names], frame.loc[tr, "y"]
    Xte, yte = frame.loc[te, names], frame.loc[te, "y"]

    # 线性基准：岭回归（收缩系数 1e-2 * I）
    beta = np.linalg.solve(Xtr.values.T @ Xtr.values + 1e-2 * np.eye(len(names)),
                           Xtr.values.T @ ytr.values)
    ic_lin = float(np.corrcoef(Xte.values @ beta, yte.values)[0, 1])

    # GBDT（需自行 pip install lightgbm；未安装时跳过）
    try:
        import lightgbm as lgb
        dtrain = lgb.Dataset(Xtr, label=ytr)
        dvalid = lgb.Dataset(Xte, label=yte, reference=dtrain)
        params = dict(objective="regression", learning_rate=0.05,
                      num_leaves=31, min_child_samples=500,
                      feature_fraction=0.6, bagging_fraction=0.8,
                      bagging_freq=1, lambda_l2=10.0, verbose=-1)
        model = lgb.train(params, dtrain, num_boost_round=400, valid_sets=[dvalid],
                          callbacks=[lgb.early_stopping(50), lgb.log_evaluation(0)])
        ic_gbdt = float(np.corrcoef(model.predict(Xte), yte.values)[0, 1])
        gain = pd.Series(model.feature_importance("gain"), index=names).sort_values(ascending=False)
    except ImportError:
        ic_gbdt, gain = float("nan"), None

    print("第 %d 折  线性 IC=%.4f  GBDT IC=%.4f" % (k + 1, ic_lin, ic_gbdt))
    if gain is not None:
        print("   特征重要性(gain) 前 3:", dict(gain.head(3).round(1)))
```

## 常见坑

- **用随机 K 折调 LightGBM**：这是金融 ML 最常见的错误，结果必然虚高。
- **num_leaves 设成几百**：在噪声数据上等于拟合噪声。金融数据建议 ≤ 63。
- **只看 MSE 不看 IC**：MSE 被极端收益主导，IC 才是选股真正关心的。
- **忘记成本**：GBDT 输出的信号波动更大，换手更高，必须扣 [成本](../09-执行与成本/09-04-换手率控制.md) 后再比较。
- **用默认参数**：默认参数是为通用场景设的，对金融数据过于激进。
- **训练集包含未来的截面标准化参数**：必须用滚动或训练期内的分位数。
- **相信 gain 重要性做因子筛选**：做筛选应该用置换重要性，并且要在样本外验证。
