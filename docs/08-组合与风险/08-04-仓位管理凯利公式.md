# 仓位管理凯利公式

凯利公式回答的是一个非常实际的问题：**在已知优势的赌局上，每次应该押上总资金的百分之多少？** 1956 年 John Kelly 在贝尔实验室用信息论的语言给出答案；它被 Ed Thorp 带进二十一点与华尔街，成为量化交易的仓位管理基石。

## 一、推导：最大化长期增长率

设每期押注比例 $f$，剩余放无风险资产。单期组合收益近似正态，超额收益 $\mu$，方差 $\sigma^2$。令 $W_T$ 为 $T$ 期后的财富，对数财富的期望增长率为（用 $\ln(1+x)\approx x-x^2/2$）：

$$g(f)=\mathbb{E}\big[\ln(1+f r)\big] \approx f\mu - \frac{1}{2}f^2\sigma^2$$

对 $f$ 求导并令其为 0：

$$g'(f)=\mu-f\sigma^2=0 \quad\Longrightarrow\quad \boxed{f^\*=\frac{\mu}{\sigma^2}}$$

若计入无风险利率，则 $f^\*=\frac{\mu-r_f}{\sigma^2}$。这就是**连续凯利公式**。观察其性质：

- $g(f)$ 是关于 $f$ 的开口向下的抛物线，$f^\*$ 处取最大值 $g_{\max}=\frac{\mu^2}{2\sigma^2}=\frac{1}{2}SR^2$。
- $g(f^\*)=g(0)$ 不成立；$g(f)$ 在 $f=2f^\*$ 处回到 0——**下注超过两倍凯利，长期增长率归零**。
- 超过 $2f^\*$ 之后 $g<0$，长期必然亏损。
- $g$ 在 $f^\*$ 附近是**平坦**的（二阶导为 $-\sigma^2$），所以略低于 $f^\*$ 损失很小，略高于 $f^\*$ 损失开始加速。这个不对称性是"半凯利"的理论基础。

离散二项情形（赢的概率 $p$，净赔率 $b$，输则损失全部赌注）：

$$f^\*=\frac{bp-q}{b}=p-\frac{q}{b},\quad q=1-p$$

例如胜率 55%、赔率 1:1（$b=1$）：$f^\*=0.55-0.45=10\%$。优势只有 5 个百分点，凯利仓位却只有 10%——很多人第一次算出来都觉得"太保守"，这正是凯利的价值。

## 二、为什么必须"分数凯利"

教科书凯利是**满凯利**，实务几乎一律只用其一部分 $f=\kappa f^\*$，$\kappa\in[0.2,0.5]$。理由有三：

1. **估计误差**。$f^\*$ 对 $\mu$ 是一阶敏感、对 $\sigma$ 是二阶敏感。若 $\hat\mu = \mu+\epsilon$，则 $\hat f^\* = f^\* + \epsilon/\sigma^2$。而 $\mu$ 的标准误约 $\sigma/\sqrt{T}$，所以仓位误差约 $\frac{1}{\sigma\sqrt T}$——样本少、波动低时，误差可以轻易吞掉整个仓位。$\mu$ 高估一倍，仓位就翻一倍，而 $g$ 在右侧下降极快。
2. **效用函数不是对数**。对数效用（$U=\ln W$）意味着完全不在乎路径波动，只看长期复利。真实投资者在乎回撤、在乎中途被迫平仓、在乎心理状态，这对应更凹的效用，最优 $f$ 更小。
3. **现实约束**：保证金、流动性、冲击成本、以及"你以为的正态其实有厚尾"。厚尾会引入破产概率，而连续凯利在扩散近似下破产概率为 0。

Thorp 在实务中建议"半凯利"或更低；很多机构把 $\kappa=0.25$ 作为默认值。半凯利保留约 75% 的渐近增长率，但波动率只有满凯利的一半——这是性价比极高的交换。

## 三、多资产与策略层凯利

多个策略/资产时，若各策略独立，最优杠杆向量为

$$f^\* = \Sigma^{-1}\mu$$

形式与 [均值方差](08-01-马科维茨均值方差.md) 的无约束解完全一致，只是 $\lambda=1$。这解释了为什么凯利组合"看起来像均值方差但更激进"：它的隐含风险厌恶系数固定为 1，而不是一个可调参数。若策略之间相关（必然相关），$\Sigma^{-1}$ 会进一步放大差异——因此多策略凯利**必须**配合协方差 [收缩](08-02-协方差估计与收缩.md) 和仓位上限。

实务分层：

| 层级 | 做法 |
| --- | --- |
| 单策略 | 用策略样本外夏普反推 $f^\*$，乘 $\kappa=0.25\sim0.5$ |
| 多策略组合 | 先算各策略凯利，再在策略层面做相关性调整与总杠杆上限 |
| 组合层面 | 用波动率目标封顶，例如总杠杆不超过"目标年化波动 15% ÷ 组合波动" |

## 四、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import kelly_fraction
from qd.metrics.perf import sharpe, max_drawdown, annual_return

md = generate_demo_market(n_symbols=30, start="2018-01-01", end="2024-12-31", seed=7)
X = md.returns().dropna()
cut = int(len(X) * 0.7)
train, test = X.iloc[:cut], X.iloc[cut:]

mu = float(train.mean().mean() * 252)        # 年化预期超额收益
sd = float(train.std().mean() * np.sqrt(252))
f_star = kelly_fraction(mu, sd ** 2)         # 连续凯利
print("年化 mu=%.2f%%  波动=%.2f%%  满凯利 f*=%.2f" % (mu*100, sd*100, f_star))

base = test.values.mean(axis=1)              # 等权组合日收益，作为策略代理
for k in [0.25, 0.5, 1.0, 1.5, 2.0]:
    lev = k * f_star
    r = lev * base + (1 - lev) * 0.02 / 252  # 剩余资金放无风险
    print("kappa=%.2f 杠杆=%.2f 年化=%6.2f%% 夏普=%.2f 回撤=%6.2f%%"
          % (k, lev, annual_return(r)*100, sharpe(r), max_drawdown(r)*100))
```

注意示例中 `kelly_fraction(mu, variance)` 的第二个参数是**方差**。多资产情形请直接传入协方差矩阵，再自行乘以 $\kappa$ 与总杠杆上限。

## 常见坑

- **用样本内夏普估 $\mu$**：回测夏普通常被过度优化抬高，代入凯利会给出荒谬的杠杆。务必用样本外、或至少做过 [deflated Sharpe](08-06-风险指标VaR与CVaR.md) 修正的数字。
- **把凯利当目标杠杆而非上限**：凯利是渐近理论，短期路径风险完全没有体现。把它当上限用更安全。
- **假设 $\sigma$ 恒定**：波动率聚集（见 GARCH 类模型）意味着在高波动期凯利仓位会自动超限，必须用滚动波动率动态调仓（见 `qd.strategy.builtin.vol_target`）。
- **忽略破产不可逆性**：连续凯利假设可以无限分割下注、永不爆仓；真实市场有跳空、有 [强平](08-07-杠杆与爆仓.md)，一旦归零就没有"长期"了。
- **多策略直接相加**：策略间相关会让总杠杆远超预期，务必在策略层面统一求解。
