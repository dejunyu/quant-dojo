# 仓位管理凯利公式

## 学完这一篇，你能做到

- 说清凯利公式回答的到底是哪个问题
- 从"最大化长期增长率"推出 $f^*=\mu/\sigma^2$，并讲清每一项
- 理解为什么实务中**几乎没人用满凯利**
- 用平台亲手跑一遍"半凯利/满凯利/两倍凯利"

## 本篇要点

- 凯利公式回答：**"已知有优势时，每次该押多少"**
- 连续近似：$f^* = \mu/\sigma^2$（$\mu$ 是超额收益、$\sigma^2$ 是方差）
- **长期增长率在 $f = 2f^*$ 处归零**——押两倍就白干
- 实务标准是**分数凯利**（四分之一到一半），因为 $\mu$ 估不准

---

## 一、从一个贝尔实验室的电话线问题说起

1956 年，贝尔实验室的科学家 **John L. Kelly Jr.** 在《贝尔系统技术期刊》发表了一篇论文，题目叫《信息速率的一种新解释》。

他研究的是**信息论**问题：一条有噪声的电话线上，信息最多能以多快的速率可靠传输？但他用了一个非常妙的类比——**把"通信"换成"下注"**：

> 每收到一点信息，你对"哪个结果会发生"的判断就更准一点；
> 那么你应该**押上资产的多少比例**，才能让长期财富增长最快？

答案是那个著名的式子。这就是**凯利公式**（Kelly criterion）。（*Bell System Technical Journal* 35(4): 917–926, 1956）

> **这个故事最值得注意的地方是：它根本不是金融论文。**
> 凯利研究的是电话线，不是股票。
> **而恰恰因为它讨论的是"信息 → 下注"的一般问题，后来才被搬进了赌场和华尔街。**
>
> 这也解释了这个公式为什么这么"硬"：**它不依赖任何市场假设，只依赖"你有优势，且优势可以被量化"。**

后来**爱德华·索普**（01-01 讲过他在赌场记牌的故事）把它用于二十一点，再带进对冲基金——**这也是 01-01 那三根支柱里"只在有优势时下注"的数学原型**。

## 二、推导：最大化长期增长率（逐个讲透）

设每期押注比例 $f$，剩下的钱放无风险资产。单期超额收益 $\mu$、方差 $\sigma^2$。$T$ 期后的财富是 $W_T$。

我们关心的不是"期末平均有多少钱"，而是**"长期下来每年增长多少"**——也就是对数财富的期望增长率（04-01 讲过：几何平均才代表实际拿到的钱）：

$$ g(f) = \mathbb{E}[\ln(1 + f r)] \approx f\mu - \frac{1}{2}f^2\sigma^2 $$

| 符号 | 白话 |
| --- | --- |
| $f$ | **押多少比例**（决策变量） |
| $\mu$ | 每期平均能赚多少（超额） |
| $\sigma^2$ | 收益的方差（抖得多厉害） |
| $f\mu$ | 押得越多，赚得越多（**线性**） |
| $-\frac{1}{2}f^2\sigma^2$ | 押得越多，波动拖累越大（**平方**） |

> **这个式子就是 04-01 那个"波动率拖累"的完整版。**
> 前一项线性涨，后一项平方涨——**所以一定存在一个最优点，再往上押就开始亏。**

对 $f$ 求导、令其为零，得到：

$$ f^* = \frac{\mu}{\sigma^2} $$

**就这一步。** 最优押注比例 = 平均超额收益 ÷ 方差。

> **注意分母是方差（$\sigma^2$），不是标准差。**
> 这个区别很重要：**波动翻倍，最优仓位变成原来的四分之一**（因为分母是平方）。

### 最反直觉的一条：押两倍等于白干

把 $f^*$ 代回增长率式子，可以算出：**当你押 $f = 2f^*$ 时，长期增长率恰好归零。**

$$ g(2f^*) = 0 $$

> **这句话的意思是：**
> **你不但没赚，还承担了比最优仓位高一倍的风险，最后的长期收益是 0。**
> 而如果你继续加码（$f > 2f^*$），**长期增长率变成负数**——明明每期都有正优势，你却会稳定地亏钱。
>
> **这就是"过度下注"的数学本质：它不是"赚得少一点"，是"把正期望变成负复利"。**
> 04-01 讲过的"亏 40% 需要涨 66.7% 才回本"，在这里有了它的仓位版本。

## 三、为什么实务中几乎没人用满凯利（单独讲透）

$f^* = \mu/\sigma^2$ 看着很美，但问题出在 **$\mu$ 永远估不准**。

| 麻烦 | 后果 |
| --- | --- |
| $\mu$ 的估计误差极大 | $\mu$ 高估 20%，仓位就高 20%，而 $f$ 的容错空间很小 |
| $\mu$ 会随时间变 | 历史均值不代表未来（05-07 的衰减） |
| 真正的 $\mu$ 可能是 0 | 那 $f^*$ 也应该是 0，而你还在满仓 |

> **凯利公式对 $\mu$ 的敏感度是线性的，但对"押过头"的惩罚是平方的。**
> 换句话说：**低估 $\mu$ 你少赚一点，高估 $\mu$ 你可能归零。**
> 这个不对称，就是"分数凯利"（fractional Kelly）存在的全部理由。

**实务标准**：

| 倍率 | 用途 |
| --- | --- |
| **0.25 ~ 0.5 倍凯利** | **最常见**，留足误差空间 |
| 1.0 倍（满凯利） | 理论上最优，实践上极危险 |
| > 1 倍 | 自杀 |

> 这也是 01-01 索普那三根支柱的第三层的实操版：
> **他记牌时只在优势明显时加注，而不是每把都按理论最优下注。**

### 一个让人后背发凉的实验

2016 年，**Victor Haghani**（LTCM 前合伙人）与 **Richard Dewey** 做了一个实验：

> 邀请 **61 名**受过量化训练的金融从业者，每人给 **25 美元**、玩 **30 分钟**掷硬币游戏，
> **胜率 60%**（明显有优势），让他们自己决定每次押多少。

结果：**约 30% 的人把钱全输光了。**

（工作论文见 [arXiv:1701.01427](https://arxiv.org/abs/1701.01427)；期刊版卷期待确认。）

> **这个实验最扎心的地方是：参与者都懂凯利公式。**
> 他们知道"押 20% 是最优"，但他们**做不到**——
> 因为赢了想加码、输了想翻本，而这正是凯利公式最反对的两件事。
>
> **所以"知道公式"和"能执行公式"之间，隔着的不只是知识，是人性。**
> 这也是为什么实务里要用"**分数凯利**"——把公式和人性之间留出缓冲。

## 四、用平台跑一遍（含真实数字）

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.optimize import kelly_fraction
from qd.metrics.perf import sharpe, max_drawdown, annual_return

md = generate_demo_market(n_symbols=30, start="2018-01-01", end="2024-12-31", seed=7)
X = md.returns().dropna()
cut = int(len(X) * 0.7)
train, test = X.iloc[:cut], X.iloc[cut:]

# kelly_fraction 吃的是「收益序列」，不是 (mu, sigma) 两个数
base_train = train.mean(axis=1)
f_star = kelly_fraction(base_train)
print("满凯利 f* =", round(f_star, 2))

base = test.values.mean(axis=1)
rf_daily = 0.02 / 252
for k in [0.25, 0.5, 1.0, 1.5, 2.0]:
    lev = k * f_star
    r = lev * base + (1 - lev) * rf_daily
    nav = (1 + pd.Series(r)).cumprod()      # 先转净值，再算年化/回撤
    print("kappa=%.2f 杠杆=%.2f 年化=%7.2f%% 夏普=%.2f 回撤=%7.2f%%"
          % (k, lev, annual_return(nav) * 100, sharpe(r), max_drawdown(nav) * 100))
```

我实跑的结果：

```
满凯利 f* = 0.75
kappa=0.25 杠杆=0.19 年化=   7.13% 夏普=2.01 回撤=  -3.44%
kappa=0.50 杠杆=0.38 年化=  12.35% 夏普=1.73 回撤=  -7.62%
kappa=1.00 杠杆=0.75 年化=  23.12% 夏普=1.58 回撤= -15.56%
kappa=1.50 杠杆=1.13 年化=  34.26% 夏普=1.54 回撤= -22.95%
kappa=2.00 杠杆=1.51 年化=  45.70% 夏普=1.51 回撤= -29.81%
```

**这张表最漂亮的地方，是它同时演示了两件事：**

**第一，杠杆放大收益**：$0.19 \to 1.51$ 倍杠杆，年化从 **7.13%** 涨到 **45.70%**。

**第二，但风险调整后收益在变差**：夏普从 **2.01** 一路降到 **1.51**，回撤从 **-3.44%** 扩到 **-29.81%**。

> **这不是矛盾，这正是凯利的全部张力：**
> **它最大化的是"长期增长率"，不是"夏普比率"。**
> 凯利会说"应该押 0.75 倍"，因为那样长期财富最大；
> 而风险部门会说"押 0.19 倍就好"，因为回撤只有 -3.4%。
>
> **两者都对，因为它们优化的目标不同。**
> 而"选哪个"取决于一个公式永远回答不了的问题：**你能承受多大回撤？**

> ⚠️ 这份是**样本外**（后 30% 数据）的数字，所以已经避开了一部分过拟合。
> 但请注意：$f^*$ 是**用训练集估的**——这正是正确做法。
> 若用全样本估 $f^*$ 再回测全样本，就是 02-04 讲的前视偏差。

## 五、凯利的三个前提（它什么时候会害你）

| 前提 | 不满足时会怎样 |
| --- | --- |
| **优势是稳定的** | $\mu$ 会衰减（05-07），昨天的 $f^*$ 今天不成立 |
| **可以无限细分** | 现实有最小交易单位（03-01 的 100 股）、有融资上限 |
| **不会被迫离场** | 一旦爆仓出局，再高的长期增长率也没意义（03-06 的轧空） |

> **第三条最要命。**
> 凯利公式优化的是"**无限期**的长期增长率"，它默认你能一直玩下去。
> 而现实中，**一次爆仓就终止了游戏**——你的 0.75 倍凯利，可能在第 3 年就把你清零。
>
> 这就是 03-06 讲 GameStop、01-04 讲 LTCM 的核心：
> **"长期最优"只有在"能活到长期"的前提下才成立。**

## 六、把这一篇串起来

回到 1956 年那篇电话线论文。

凯利提出的问题极其纯粹：**"有优势时，押多少？"** 这个问题的答案，在赌场、在电话线、在股票市场里**是同一个式子**。

> 而它给这个行业留下的最重要一课，可能不是公式本身，而是那个不对称：
> **押少了，你少赚一点；押多了，你归零。**
>
> 所以 01-01 里索普的三根支柱，第三根"只在有优势时下注"，
> 在这里有了精确的形状：**不是"有优势就满仓"，而是"有优势，也只押一小部分"。**

> 一句话收尾：
> **凯利公式告诉你"最优点在哪"，但它更重要的贡献，是告诉你"越过去会发生什么"。**
> 而大多数人不是死于没找到最优点，**是死于找到了还嫌不够。**
