# 杠杆与爆仓

## 学完这一篇，你能做到

- 用巴林银行的故事说清"杠杆 + 不止损"能有多贵
- 理解保证金与强平的机制，知道爆仓是怎么一步步发生的
- 用 04-01 的波动率税，算清"杠杆到底放大了什么"
- 知道什么时候该加杠杆、什么时候绝对不该

## 本篇要点

- 杠杆**放大收益，也放大拖累**，而拖累是**平方级**的
- 存在一个**凯利临界杠杆** $L^*$，超过它长期增长率为负
- 强平的可怕在于：**它发生在最差的时点，且不问你同不同意**
- 杠杆不改变策略的期望，只改变**你能不能活到兑现**

---

## 一、从"一个人搞垮一家两百年银行"说起

1995 年 2 月，英国最古老的商业银行之一——**巴林银行**（Barings Bank）——宣告破产。

它成立于 1762 年，曾为美国购买路易斯安那、为拿破仑战争融资，英国女王是它的客户。**而拖垮它的，是一个 28 岁的交易员：尼克·里森**（Nick Leeson）。

里森当时被派到新加坡，负责巴林期货（新加坡）的交易。他做的是**日经 225 股指期货**，一开始做"套利"（利用大阪和新加坡两个市场的小价差）。但为了掩盖早期的交易亏损，他开了一个**秘密账户**（账号 88888），把亏损藏在里面。

接下来是经典的下坡路：

> **亏了 → 想赚回来 → 加大仓位 → 亏更多 → 再加仓……**

到 1995 年初，他已经持有了巨量的日经期货多头。**1995 年 1 月 17 日，阪神大地震**，日经指数暴跌，他的头寸彻底穿仓。

最终亏损 **8.27 亿英镑**（约合当时 14 亿美元），**超过巴林银行全部可交易资本的两倍**。银行以 1 英镑的象征性价格被荷兰国际集团（ING）收购。（[Wikipedia: Barings Bank](https://en.wikipedia.org/wiki/Barings_Bank)、[Nick Leeson](https://en.wikipedia.org/wiki/Nick_Leeson)）

> **这个故事里，"杠杆"甚至不是最吓人的部分。**
> 最吓人的是：**一个交易员能同时控制交易和后台结算**——
> 他既在下单，又在记账。于是亏损可以被"藏起来"，藏在 88888 账户里，
> 直到它大到谁都藏不住。
>
> **这是一个关于"风控失效"的故事，而杠杆只是放大器。**
> 这也是 06-07 Knight Capital 的另一面：
> **Knight 死于部署失误，巴林死于职责不分——两者的共同点是，问题都不在模型里。**

## 二、杠杆到底放大了什么（数学上讲透）

杠杆 $L$ 意味着：用 1 份本金，持有 $L$ 份资产。

- 收益被放大 $L$ 倍；
- **波动也被放大 $L$ 倍**；
- 但**波动率拖累被放大 $L^2$ 倍**（04-01 的 $\sigma^2/2$，方差是平方的）。

于是长期增长率变成：

$$ g(L) = L\mu - \frac{L^2\sigma^2}{2} - (L-1)r_b $$

| 符号 | 白话 |
| --- | --- |
| $L\mu$ | 放大后的收益（线性） |
| $-\frac{L^2\sigma^2}{2}$ | **放大后的波动率税（平方）** |
| $-(L-1)r_b$ | 借钱要付的利息 |

**对 $L$ 求导、令其为零**，得到**凯利临界杠杆**：

$$ L^* = \frac{\mu - r_b}{\sigma^2} $$

> **这个式子的形状和 08-04 的 $f^*=\mu/\sigma^2$ 一模一样**——因为它们是同一个公式：
> **凯利公式回答"押多少"，杠杆回答"借多少钱去押"，本质是一回事。**
>
> 而 $L > 2L^*$ 时，$g(L)$ 也会变成负数。
> **换句话说：杠杆加到一定程度，你不是"赚得少"，是"稳定地亏"。**

## 三、用平台看"杠杆加到多少开始反噬"

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import annual_return, max_drawdown, sharpe, calmar

md = generate_demo_market(n_symbols=40, start="2018-01-01", end="2024-12-31", seed=7)
base = md.returns().dropna().mean(axis=1).values

mu = base.mean() * 252
sd = base.std() * np.sqrt(252)
print("年化 %.2f%%  波动 %.2f%%  凯利临界杠杆 L*=%.2f" % (mu*100, sd*100, mu/sd**2))

rb = 0.06 / 252                                     # 融资年化 6%，按日计
for L in [1.0, 1.5, 2.0, 3.0, 5.0]:
    r = L * base - (L - 1) * rb
    eq = np.cumprod(1 + r)
    print("L=%.1f 年化(几何)=%7.2f%% 夏普=%.2f 最大回撤=%6.2f%% Calmar=%.2f"
          % (L, annual_return(eq)*100, sharpe(r), max_drawdown(eq)*100, calmar(eq)))

# 波动率税：算术 vs 几何
for L in [1.0, 3.0, 5.0]:
    g = L*mu - L**2 * sd**2 / 2
    print("L=%.1f 算术 %.2f%%  几何(含波动率税) %.2f%%  税收 %.2f%%"
          % (L, L*mu*100, g*100, (L*mu - g)*100))
```

我实跑的结果：

```
年化 9.37%  波动 17.08%  凯利临界杠杆 L*=3.21

L=1.0 年化(几何)=   8.31% 夏普=0.55 最大回撤=-45.38% Calmar= 0.18
L=1.5 年化(几何)=   8.20% 夏普=0.43 最大回撤=-62.19% Calmar= 0.13
L=2.0 年化(几何)=   7.30% 夏普=0.37 最大回撤=-74.12% Calmar= 0.10
L=3.0 年化(几何)=   3.26% 夏普=0.31 最大回撤=-88.27% Calmar= 0.04
L=5.0 年化(几何)= -12.40% 夏普=0.27 最大回撤=-97.90% Calmar=-0.13
```

**这张表是全书里最"教科书"的一张——它把杠杆的真相一次说完：**

| 杠杆 | 年化 | 夏普 | 回撤 |
| --- | --- | --- | --- |
| 1.0 | **8.31%** | **0.55** | -45.4% |
| 2.0 | 7.30% | 0.37 | -74.1% |
| 5.0 | **-12.40%** | 0.27 | **-97.9%** |

> **请注意：从 1 倍加到 5 倍，年化从 +8.31% 变成 -12.40%。**
> 你的策略一点没变、期望收益一点没变，
> **只是多借了钱，就把一个赚钱的策略做成了亏钱的。**
>
> 而看夏普那一列更清楚：**从 0.55 一路降到 0.27，单调变差。**
> **杠杆从来没"提高"过风险调整后收益，它只在放大赌注。**

再看最后那三行"波动率税"，这是最直观的：

```
L=1.0 算术 9.37%  几何(含波动率税) 7.91%   税收 1.46%
L=3.0 算术 28.11% 几何(含波动率税) 14.99%  税收 13.13%
L=5.0 算术 46.86% 几何(含波动率税) 10.39%  税收 36.47%
```

> **杠杆 5 倍时，算术收益 46.86%，但税吃掉了 36.47%——你可以说"我赚了 46%"，
> 但你实际只拿到 10.39%。**
> 而且这还是**没扣融资利息**的乐观版本。

## 四、保证金与强平：为什么会"一夜之间"

| 概念 | 说明 |
| --- | --- |
| **保证金** | 你押在券商那里的抵押品 |
| **维持担保比例** | 账户资产 ÷ 负债，低于线就危险 |
| **强平（margin call）** | 券商**不问你同意**就卖你的持仓 |

> **强平的三个可怕之处：**
> ① 它发生在**最差的时点**（价格已经跌到平仓线）；
> ② 它**不听你解释**（"马上就会反弹"这种话没用）；
> ③ 它**可能连锁**（强平制造更多卖压，把价格推得更低，让更多人被强平）。
>
> 第三条就是 03-06 讲的轧空的反向版本——**"下跌螺旋"**。

**A 股的相关约束**（03-06 讲过）：融券券源少、成本高；融资有维持担保比例要求。所以 A 股个人投资者"上高杠杆"的路径，通常比美股窄。

## 五、什么时候该加杠杆（以及绝对不该）

| 情况 | 该不该加 |
| --- | --- |
| 策略波动**低且稳定**（如市场中性、低波因子） | ✅ 可以考虑，但要算 $L^*$ |
| 策略波动**高或有厚尾**（04-02） | ❌ 绝对不该 |
| 你**无法实时监控**（比如要睡觉） | ❌ 不该 |
| 你的 $\mu$ 是**从回测估的、样本外未验证** | ❌ 不该 |
| 你已经有**大幅回撤**，想靠加杠杆赚回来 | ❌ **这是里森做的事** |

> **最后一行是所有杠杆悲剧的共同起点。**
> 里森不是一开始就想赌命的——他只是**想弥补亏损**。
> 而"弥补亏损"这个动机，几乎必然导致"加仓"，
> 而"加仓"在亏损时，等于**在最差的时点放大赌注**。

> 一个真正专业的做法，反而是 08-04 说的：
> **用波动率目标来"动态调杠杆"**——波动低时自动多承担，波动高时自动降下来。
> 这比"固定 2 倍杠杆"安全得多，因为**它会在危险时自己缩手**。

## 六、把这一篇串起来

回到 1995 年那家 233 年的银行。

巴林倒下的直接原因是日经暴跌，但**真正的死因是三层叠加**：一个能同时管交易和记账的交易员、一个藏亏损的秘密账户、和一个"亏了就加仓"的人性。

> 而这一篇的数学部分告诉我们：
> **杠杆的危险不是"可能亏得多"，而是"它会把正期望变成负复利"。**
> 这不是概率问题，是算术问题——**$L^2$ 那一项，迟早会追上 $L$ 那一项。**

> 一句话收尾：
> **杠杆不改变你的期望，它只改变"你能不能活到兑现的那天"。**
> 而所有因为杠杆而死掉的账户，都不是因为看错了方向——
> **是因为在方向对之前，就已经不在场上了。**
