# 杠杆与爆仓

杠杆是量化交易中最容易被低估的危险。它把一个年化 8%、回撤 10% 的策略，"看起来"变成年化 24%、回撤 30%——但真实结果往往比这个线性外推差得多，甚至归零。

## 一、杠杆放大了什么

设策略单利期望年化超额收益 $\mu$、年化波动 $\sigma$，使用杠杆 $L$（$L=1$ 为无杠杆）。若不考虑融资成本，组合的算术期望收益与波动率为：

$$\mu_L = L\mu,\qquad \sigma_L = L\sigma$$

夏普比率不变（$SR_L = L\mu/L\sigma = SR$），这是"杠杆中性"的一面。但**几何（复利）收益不是线性的**：

$$g(L) = L\mu - \frac{L^2\sigma^2}{2}$$

第二项就是**波动率税（volatility drag / variance drag）**，它随 $L^2$ 增长。两个例子：

| 策略 | $\mu$ | $\sigma$ | $L=1$ 时 $g$ | $L=3$ 时 $g$ |
| --- | --- | --- | --- | --- |
| 低波动 | 6% | 8% | 5.68% | 15.1% |
| 高波动 | 12% | 25% | 8.88% | **2.6%** |

高波动策略加 3 倍杠杆，算术期望 36%，几何收益却掉到 2.6%——因为 $-\frac{3^2\times0.25^2}{2}=-28.1\%$ 的波动率税几乎吃掉了全部收益。$g(L)$ 的极大值在 $L^\*=\mu/\sigma^2$，正是 [凯利公式](08-04-仓位管理凯利公式.md) 给出的最优杠杆；$g$ 在 $L=2L^\*$ 处归零。

除了波动率税，杠杆还放大：

- **回撤**：最大回撤大致按 $L$ 线性放大，但**回撤恢复时间按超线性增长**（亏 50% 需涨 100%）。
- **破产/强平概率**：一旦净值触及维持担保比例，就被强制平仓，此后的反弹与你无关。这是不可逆的。
- **融资成本**：融资利率 $r_b$ 会直接扣减 $\mu_L = L\mu - (L-1)r_b$，把临界杠杆向左推。
- **尾部与跳空**：隔夜跳空 8% 在 3 倍杠杆下就是 24%，一次就足以触平。

## 二、保证金机制与强平

以 A股融资融券为例（具体比例以券商与交易所当期规则为准，此处仅说明结构）：

- **保证金比例**：买入证券时投资者需自有资金的比例。若初始保证金比例 100%（即保证金比例系数 1），则"保证金比例 80%"对应约 1.25 倍杠杆。
- **维持担保比例**：
  $$\text{维持担保比例}=\frac{\text{现金}+\text{证券市值}}{\text{融资买入金额}+\text{利息费用}}$$
  通常警戒线 150%、平仓线 130%。跌破警戒线会收到追加保证金通知（margin call）；跌破平仓线且未按时补足，券商有权**强制平仓**。
- **折算率**：证券作为担保品时按市值打折（如 70%），所以"看起来够"的担保品在下跌时会双重缩水。
- **集中度与标的限制**：单票集中度上限、标的池限制、ST 股不可融资等。
- **T+1 与不可当日对冲**：融券卖出有额外的提价规则约束。

关键认知：**爆仓不等于净值归零，而是"在最坏的时刻被强制卖出"**。你的策略逻辑可能是对的，但因为无法承受中途的回撤而在底部被清出局，之后市场反弹与你无关。这就是"路径依赖风险"——它不出现在任何均值/方差的统计量里。

期货的保证金机制不同：交易所收的是**初始保证金 + 维持保证金**，按逐日盯市（mark-to-market）结算，日内浮亏就会消耗可用资金；且期货是线性杠杆工具，1 手合约对应名义价值固定，亏损可以**超过本金**（穿仓），因此期货爆仓比股票融资更凶险。

## 三、什么时候该加杠杆

加杠杆的正当理由只有两类：

1. **策略本身夏普高但波动低**。例如市场中性、套利、多因子对冲组合，$\sigma$ 只有 3%~6%，波动率税极小，此时 3~5 倍杠杆是行业标准做法（风险平价基金对债券加杠杆同理）。
2. **作为风险预算工具而非收益放大工具**。用波动率目标（vol targeting）把组合波动稳定在预设水平，低波动期加杠杆、高波动期降杠杆，这实际上是**逆周期**操作，比固定杠杆更优。

不该加杠杆的情形：

- 策略有**未验证的尾部风险**（卖期权式收益曲线、裸空、事件驱动）。
- 流动性差、存在跳空风险、或标的可能停牌。
- 你的回测没有包含融资利息、冲击成本与 [强平逻辑](08-05-止损与回撤控制.md)。
- 心理与资金层面无法承受 2 倍于历史最大回撤的回撤。

## 四、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.metrics.perf import annual_return, max_drawdown, sharpe, calmar

md = generate_demo_market(n_symbols=40, start="2018-01-01", end="2024-12-31", seed=7)
base = md.returns().dropna().mean(axis=1).values    # 等权组合日收益，策略代理

mu = base.mean() * 252
sd = base.std() * np.sqrt(252)
print("年化 %.2f%%  波动 %.2f%%  凯利临界杠杆 L*=%.2f" % (mu*100, sd*100, mu/sd**2))

rb = 0.06 / 252                                     # 融资年化 6%，按日计
for L in [1.0, 1.5, 2.0, 3.0, 5.0]:
    r = L * base - (L - 1) * rb                     # 扣掉融资成本
    eq = np.cumprod(1 + r)
    print("L=%.1f 年化(几何)=%7.2f%% 夏普=%.2f 最大回撤=%6.2f%% Calmar=%.2f"
          % (L, annual_return(r)*100, sharpe(r), max_drawdown(eq)*100, calmar(r)))

# 波动率税：算术 vs 几何
for L in [1.0, 3.0, 5.0]:
    g = L*mu - L**2 * sd**2 / 2
    print("L=%.1f 算术 %.2f%%  几何(含波动率税) %.2f%%  税收 %.2f%%"
          % (L, L*mu*100, g*100, (L*mu - g)*100))
```

## 常见坑

- **用"年化 ÷ 最大回撤"线性外推**：忽略了波动率税与强平的非线性。
- **忘记融资利息**：它使盈亏平衡点上移，且在高杠杆时是净收益的主要扣减项。
- **回测里不建模维持担保比例**：真实爆仓发生在触及平仓线的那一天，而不是净值归零。
- **用日频数据评估杠杆的尾部风险**：日内跳空与连续跌停会让实际损失远超日频模型。
- **把所有资金押在一个杠杆账户**：应做资金分层，保留"备用金"以备补仓，避免被迫强平。
- **忽视相关性上升**：[危机时相关性趋 1](08-02-协方差估计与收缩.md)，杠杆组合的实际波动会高于历史估计。
