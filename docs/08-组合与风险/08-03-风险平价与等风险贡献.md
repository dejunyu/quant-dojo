# 风险平价与等风险贡献

## 学完这一篇，你能做到

- 说清"等权"和"等风险"为什么不是一回事，差在哪
- 理解**风险贡献**的定义，以及它为什么不是权重
- 会算 ERC（等风险贡献）权重，并检验它是否真的"等风险"
- 知道风险平价的适用环境与局限

## 本篇要点

- 60/40 组合里，股票贡献的风险常年在 **90% 以上**——**权重分散不等于风险分散**
- 风险贡献 $RC_i = w_i \cdot (\Sigma w)_i / \sigma_p$，**它不是权重**
- ERC 的目标：让所有资产的 $RC_i$ 相等
- 代价：低波动资产要**加杠杆**，而杠杆有成本也有风险（08-07）

---

## 一、从"60/40 其实没那么分散"说起

最经典的投资组合是 **60% 股票 + 40% 债券**。它看起来挺分散：两类资产、一个进攻一个防守。

但如果你真的去算**风险贡献**，会看到一个刺眼的数字。

钱恩（Edward Qian）在 2005 年那份风险平价白皮书里给出了一个具体测算：假设股票波动 **15%**、债券波动 **5%**（方差比 9:1），在 60/40 组合里——

> **股票贡献了约 93% 的风险，债券只有 7%。**

（Qian, *Risk Parity Portfolios: Efficient Portfolios Through True Diversification*, PanAgora, 2005；样本期 1983–2004，用 Russell 1000 的波动率约 15.1%。）

为什么？因为股票的波动率通常是债券的好几倍。假设股票年化波动 18%、债券 5%：

- 股票：$0.6 \times 18\% = 10.8\%$
- 债券：$0.4 \times 5\% = 2.0\%$

**权重是 60:40，风险的"毛贡献"却接近 84:16。** 再算上相关性，真实比例往往更极端。

> **这就是"权重分散 ≠ 风险分散"的最直观例子。**
> 你以为自己配了 40% 的"防守资产"，**其实它只贡献了 10% 左右的保护**。
>
> 2008 年、2020 年 3 月、2022 年那种"股债双杀"的年份，
> 60/40 组合的持有者会突然发现：**自己以为有两根柱子，其实只有一根。**

**风险平价**（Risk Parity）就是针对这件事设计的：

> **不去配"钱"，去配"风险"。每个资产贡献同样多的风险。**

（07-06 从达里奥 1971 年看错市场的故事讲过风险平价的哲学起点，这一篇讲它的数学。）

---

## 二、风险贡献：为什么它不是权重（逐个讲透）

先把定义写清楚：

$$ RC_i = w_i \cdot \frac{(\Sigma w)_i}{\sigma_p},\qquad \sigma_p = \sqrt{w^\top \Sigma w} $$

| 符号 | 白话 |
| --- | --- |
| $w_i$ | 第 i 个资产的**权重** |
| $(\Sigma w)_i$ | 第 i 个资产对组合风险的**边际影响** |
| $\sigma_p$ | 组合总风险 |
| $RC_i$ | 第 i 个资产**贡献了多少风险**（各项加起来 = 1） |

> **关键在那个乘积：$w_i \times (\Sigma w)_i$。**
> **权重只决定"你买了多少"，边际影响才决定"它多能折腾"。**
>
> 一个波动极低的资产，哪怕权重很大，$(\Sigma w)_i$ 也很小，
> **它对总风险的贡献可能微乎其微**——这就是 60/40 里债券的处境。

**ERC 的目标**就是让所有 $RC_i$ 相等：

$$ RC_1 = RC_2 = \dots = RC_N = \frac{1}{N} $$

> 这个式子没有解析解（除了特殊情形），只能用数值方法解（08-03 的 `risk_parity_weights` 就是干这个的）。
> **但它的直觉极简单：不问你买了多少，只问你各自承担了多少。**

**一个特例**：当所有资产**两两不相关**时，ERC 解就退化成**逆波动率**：

$$ w_i \propto \frac{1}{\sigma_i} $$

> **为什么是倒数？** 波动越大，你该买越少——**这样"权重 × 波动"才相等。**
> 这个式子特别值得记住，因为它是风险平价最容易被理解的形式：
> **"按波动的倒数分配资金"**。

## 三、用平台验证"到底谁更分散"

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import risk_parity_weights
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import risk_parity
from qd.metrics.perf import perf_report

md = generate_demo_market(n_symbols=40, start="2018-01-01", end="2024-12-31", seed=7)
X = md.returns().dropna()
Sigma = X.cov().values * 252

w_rp = risk_parity_weights(Sigma)
sd = np.sqrt(np.diag(Sigma))
w_iv = (1 / sd) / (1 / sd).sum()          # 逆波动率：不相关时的特例
w_eq = np.repeat(1 / len(sd), len(sd))

def risk_contrib(w, S):
    sp = np.sqrt(w @ S @ w)
    rc = w * (S @ w) / sp
    return rc / rc.sum()

for name, w in [("等权", w_eq), ("逆波动率", w_iv), ("风险平价", w_rp)]:
    rc = risk_contrib(w, Sigma)
    print("%-8s 风险贡献 max/min = %.2f  组合年化波动 %.2f%%"
          % (name, rc.max() / rc.min(), np.sqrt(w @ Sigma @ w) * 100))

res = Backtest(md, risk_parity(lookback=126),
               BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003,
                              slippage_bp=5, stamp_duty=0.0005)).run()
print("夏普:", round(perf_report(res.equity, rf=0.02)["sharpe"], 2))
```

我实跑的结果：

```
等权       风险贡献 max/min = 1.86  组合年化波动 17.09%
逆波动率   风险贡献 max/min = 1.78  组合年化波动 16.94%
风险平价   风险贡献 max/min = 2.25  组合年化波动 16.09%
夏普: 0.58
```

**这张表有一个非常反直觉的结果：风险平价的 max/min 是 2.25，反而比等权（1.86）更差。**

> **如果风险平价真的"等风险"，max/min 应该接近 1.0。为什么是 2.25？**
>
> 三个可能，而且都值得知道：
>
> ① **求解精度问题**：ERC 只有数值解，迭代没收敛到足够精度；
> ② **样本协方差噪声**：08-02 讲过，当 $N$ 与 $T$ 接近时，$\Sigma$ 本身就不可信，
>    **优化器在一个错误的 $\Sigma$ 上求"等风险"，结果自然不"等"**；
> ③ **`risk_parity_weights` 的目标函数**可能不是严格的 RC 相等（比如用对数障碍法近似）。
>
> **第一条和第二条合起来，正好是本篇最该记住的教训：**
> **优化器的输出质量，永远不超过输入的估计质量。**
> 你在一个噪声矩阵上求"最优"，得到的是"噪声的最优"，不是"现实的最优"。

再看波动率那一列：等权 17.09% → 逆波动率 16.94% → 风险平价 16.09%。**三种方式波动差不多**，差异不到 1 个百分点。

> **为什么？因为这份合成数据里，40 只股票的波动率差异不大。**
> 风险平价的价值，恰恰要在"**资产波动率差异巨大**"时才显现——
> 比如股票（18%）配债券（5%），逆波动率权重会是 1/18 : 1/5 ≈ **1 : 3.6**，
> 而等权是 1 : 1。**那才是风险平价真正改变结构的地方。**

而 `夏普 0.58` 这个数字，可以和 07-06 的 `risk_parity 夏普 0.35` 对照——同一个策略类，不同参数/窗口，结果差不少，**再次说明单点结论不可靠**（06-06）。

## 四、风险平价的适用环境与代价

**适合**：

| 条件 | 为什么 |
| --- | --- |
| 资产**类别差异大**（股/债/商品/黄金） | 波动率差异大，才需要"按风险配" |
| 资产之间**低相关** | 分散才有意义 |
| 你能接受**低杠杆下的低收益** | 否则会想加杠杆（08-07） |
| 长期持有、能忍受**牛市跑输** | 07-06 讲过 |

**代价**：

| 代价 | 说明 |
| --- | --- |
| **需要杠杆** | 要让债券贡献同样风险，就得给它加杠杆；杠杆有利息、有强平 |
| **牛市跑输** | 降波动 = 降仓位，牛市里必然落后 |
| **危机中相关性上升** | 股债同时下跌时，分散失效（04-02） |
| **对 $\Sigma$ 依然敏感** | 还是要估协方差（08-02） |

> **最后一条常被忽略**：风险平价经常被宣传成"不需要预测收益"，
> 这是真的——**它不需要 $\mu$**。
> **但它仍然需要 $\Sigma$，而 $\Sigma$ 一样估不准。**
> **所谓"不用预测"，只是换了个更难估的东西。**

## 五、把这一篇串起来

回到 60/40 那个"90% 风险来自股票"的事实。

它说明了一件很朴素、但很少被认真对待的事：**你配置的"比例"，和你实际承担的风险，是两回事。**

> 08-01 讲"组合风险来自协方差"，
> 08-02 讲"协方差估不准"，
> 这一篇讲"**就算估准了，你也不该按钱分配，而该按风险分配**"。
>
> 三步走下来，组合优化的核心问题越来越清楚：
> **不是"买什么"，而是"你想承担什么样的风险结构"。**

> 一句话收尾：
> **等权分散的是钱，风险平价分散的是风险。**
> 前者只需要除法，后者需要估计——**而这正是它更强、也更脆的原因。**
