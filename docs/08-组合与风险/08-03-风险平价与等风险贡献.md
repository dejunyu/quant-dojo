# 风险平价与等风险贡献

[均值方差优化](08-01-马科维茨均值方差.md) 之所以脆弱，一半原因是它依赖预期收益 $\mu$。如果干脆不用 $\mu$，只要求"每只股票贡献的风险一样多"，就得到了**风险平价（Risk Parity）**，也叫**等风险贡献（Equal Risk Contribution, ERC）**。

## 一、从边际风险贡献到 ERC

组合波动率 $\sigma_p=\sqrt{w^\top\Sigma w}$。对 $w_i$ 求偏导：

$$\frac{\partial\sigma_p}{\partial w_i}=\frac{(\Sigma w)_i}{\sigma_p}\equiv MRC_i$$

由欧拉齐次定理，$\sigma_p=\sum_i w_i MRC_i$，于是定义**风险贡献**：

$$RC_i = w_i\cdot MRC_i = \frac{w_i(\Sigma w)_i}{\sigma_p},\qquad \sum_i RC_i=\sigma_p$$

风险贡献天然满足加总等于总风险，因此可以做百分比归因。

- **等权组合**：$w_i=1/N$ 相等，但 $MRC_i$ 差异很大。低波动股票的风险贡献通常只占个位数百分比，高波动股票可能占 3~4 倍。结果是名义分散、实际集中。
- **市值加权**：权重与经济规模挂钩，风险贡献更集中，且它本质上是一个"市场组合"，不是风险分散最优化的结果。
- **风险平价**：要求 $RC_1=RC_2=\cdots=RC_N=\sigma_p/N$。

ERC 的一阶条件可写成：对任意 $i,j$，

$$w_i(\Sigma w)_i = w_j(\Sigma w)_j,\qquad \sum_i w_i = 1,\quad w_i\ge 0$$

这是一个非线性方程组，一般没有闭式解。Maillard、Roncalli 与 Teïletche（2010）证明在 $w>0$ 且 $\Sigma$ 正定时解存在且唯一。

## 二、三种求解思路

1. **不动点迭代**（最常用，代码最短）：从当前 $w$ 出发，令 $\sigma_i^2$ 为"若只持 $i$ 的风险贡献"，迭代
   $$w_i \leftarrow \frac{\sigma_p/N}{MRC_i}$$
   然后归一化，重复几十次收敛。
2. **转化为无约束凸优化**（Roncalli 等）：
   $$\min_{w>0}\ \frac{1}{2}w^\top\Sigma w - \theta\sum_i \ln w_i,\quad \theta>0$$
   目标函数严格凸，任何 $\theta$ 给出的解都满足 ERC 条件（$\theta$ 只影响归一化尺度）。这一形式便于加约束。
3. **序列二次规划 / 数值求根**：需要加行业上限、换手限制时使用。

当 $\Sigma$ 是对角阵（资产互不相关）时，风险平价退化为 $w_i\propto 1/\sigma_i$，即**逆波动率加权**——这是理解风险平价直觉最简的入口：波动率高的资产权重低。

## 三、与等权、市值加权的对比

| 维度 | 等权 $1/N$ | 市值加权 | 风险平价 |
| --- | --- | --- | --- |
| 是否用 $\mu$ | 否 | 否 | 否 |
| 是否用 $\Sigma$ | 否 | 否 | 是 |
| 权重倾斜方向 | 无 | 大市值 | 低波动、低相关 |
| 风险集中度 | 高波动票主导 | 大市值票主导 | 最分散 |
| 对小市值/低波动因子暴露 | 偏高（小票权重被抬高） | 低 | 中等偏高 |
| 换手 | 低（但需定期再平衡） | 极低 | 低至中等 |

学界最系统的比较来自 DeMiguel、Garlappi 与 Uppal（2009）：在多个数据集上，$1/N$ 在样本外夏普、回撤上都胜过绝大多数需要估 $\mu$ 的优化器，而只需要估 $\Sigma$ 的最小方差/风险平价类方法表现更稳定。**这说明"少估一个输入"本身就是巨大的优势。**

## 四、适用环境与局限

适用：

- 多资产配置（股/债/商品/黄金），各资产波动率量级差异大，逆波动率倾斜非常有效。
- 你对 $\mu$ 毫无把握（绝大多数时候的真实情况）。
- 希望风险归因清晰、可接受。

局限：

- **不是收益最优**。它完全忽略预期收益，如果某资产确实有更高风险调整收益，风险平价会系统性地低配。
- **相关性上升时失效**。风险平价假设"分散化有效"，危机时相关性向 1 收敛，各资产同时下跌，再加上风险平价通常对债券加了杠杆，损失会被放大。2020 年 3 月就是典型案例。
- **低波动环境里债券权重高、久期风险集中**。所谓"风险平价本质上是加杠杆的债券组合"这一批评，在利率上行周期中确实成立。
- **仍是 $O(N^2)$ 的估计问题**。股票层面做风险平价，需要配合 [协方差收缩](08-02-协方差估计与收缩.md)。

## 五、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import risk_parity_weights
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import risk_parity
from qd.metrics.perf import perf_report, sharpe

md = generate_demo_market(n_symbols=40, start="2018-01-01", end="2024-12-31", seed=7)
X = md.returns().dropna()
Sigma = X.cov().values * 252

w_rp = risk_parity_weights(Sigma)
sd = np.sqrt(np.diag(Sigma))
w_iv = (1 / sd) / (1 / sd).sum()          # 逆波动率：不相关时的特例
w_eq = np.repeat(1 / len(sd), len(sd))

def risk_contrib(w, S):
    sp = np.sqrt(w @ S @ w)
    rc = w * (S @ w) / sp
    return rc / rc.sum()                   # 归一化成占比

for name, w in [("等权", w_eq), ("逆波动率", w_iv), ("风险平价", w_rp)]:
    rc = risk_contrib(w, Sigma)
    print("%-6s 风险贡献 max/min = %.2f  组合年化波动 %.2f%%"
          % (name, rc.max() / rc.min(), np.sqrt(w @ Sigma @ w) * 100))

bt = Backtest(md, risk_parity(lookback=126),
              BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003,
                             slippage_bps=5, stamp_tax=0.0005))
res = bt.run()
print(perf_report(res.equity))
print("夏普:", round(sharpe(res.equity.pct_change().dropna().values), 2))
```

## 常见坑

- **把风险平价当 alpha 来源**：它只是风险配置规则，收益来自低波动/低相关的因子暴露和再平衡，不是选股能力。
- **用原始样本协方差直接求**：$N$ 大时先做 [收缩](08-02-协方差估计与收缩.md) 或用因子协方差，否则权重对噪声极敏感。
- **股票层面直接做，忽略流动性**：风险平价倾向于给低波动的大票更高权重，但也可能把权重压到流动性差的小票上，需要叠加成交额下限。
- **忘记再平衡**：风险贡献会随波动率变化漂移，需要按 [再平衡节奏](08-08-再平衡与调仓节奏.md) 定期拉回。
- **把"风险贡献相等"当成"风险小"**：总风险由杠杆决定，风险平价解决的是**结构**问题不是**总量**问题。
