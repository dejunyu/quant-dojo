# 协方差估计与收缩

[均值方差优化](08-01-马科维茨均值方差.md) 的第二个输入是协方差矩阵。它的估计质量直接决定组合风险是否可控。糟糕的是，协方差是高维对象：$N$ 只股票需要估计 $N(N+1)/2$ 个参数，100 只股票就是 5050 个。

## 一、样本协方差的噪声有多大

用 $T$ 期收益样本估计：

$$\hat\Sigma = \frac{1}{T-1}\sum_{t=1}^{T}(r_t-\bar r)(r_t-\bar r)^\top$$

其元素的标准误约为 $\sigma_i\sigma_j/\sqrt{T}$。所以信噪比取决于 **$N/T$** 而非 $T$ 本身。随机矩阵理论给出了精确刻画：若 $N,T\to\infty$ 且 $N/T=q$，样本协方差的特征值分布在

$$\lambda \in \Big[\sigma^2(1-\sqrt q)^2,\ \sigma^2(1+\sqrt q)^2\Big]$$

（Marchenko-Pastur 分布）。当 $q=0.5$（例如 100 只股票、200 天数据）时，最大特征值约为真实值的 2.9 倍，最小约为 0.09 倍。而最小特征值出现在 $\Sigma^{-1}$ 的分母上——**组合优化会精确地把权重压到估计最差的方向上**。

三条经验法则：

| 情形 | 现象 | 后果 |
| --- | --- | --- |
| $T\gg N$（如 5 年 × 10 只） | 估计尚可 | 优化基本可用 |
| $T\approx N$ | 特征值严重偏离 | 最小方差组合权重剧烈跳动 |
| $T<N$ | $\hat\Sigma$ 奇异、不可逆 | 必须降维或收缩 |

## 二、Ledoit-Wolf 收缩

思路很朴素：把样本协方差 $S$ 与一个结构极简、几乎无噪声的目标矩阵 $F$ 做凸组合：

$$\hat\Sigma_{shrunk} = \delta F + (1-\delta)S,\quad \delta\in[0,1]$$

$\delta$ 是收缩强度，由数据自适应决定：噪声越大，$\delta$ 越大。Ledoit 与 Wolf（2003）以**单因子（市场）模型**为目标给出了解析解；Ledoit 与 Wolf（2004）以**等方差 + 等相关的常数相关矩阵**为目标给出了更常用的版本。

常用目标矩阵：

- **单位阵乘常数** $F=\bar\sigma^2 I$：只收缩方差，最保守。
- **常数相关矩阵**：所有相关系数取样本平均 $\bar\rho$，$F_{ij}=\bar\rho\sigma_i\sigma_j$（$i\ne j$），对角为 $\sigma_i^2$。这是实务中最常见的选择。
- **单因子/多因子结构** $F=\beta\beta^\top\sigma_m^2+D$：既收缩又保留真实经济结构。

收缩的效果是：把过大的特征值拉小、过小的特征值拉大，矩阵条件数改善，逆矩阵稳定，优化权重不再剧烈震荡。代价是引入偏差——这在统计上是标准的**偏差-方差权衡**，而且总体均方误差一定下降。

## 三、因子协方差模型

当 $N$ 很大（全市场数千只股票）时，直接估 $N\times N$ 矩阵已经无望。行业标准做法是结构化建模（BARRA 一类风险模型）：

$$\Sigma = B\Sigma_f B^\top + D$$

其中 $B$ 是 $N\times K$ 的因子暴露矩阵（市值、价值、动量、波动率、行业哑变量……），$\Sigma_f$ 是 $K\times K$ 的因子协方差（$K$ 只有几十个，估计精度高），$D$ 是对角的特质方差矩阵（假设特质收益之间不相关）。参数量从 $N^2/2$ 降到 $NK+N$，且每个参数的经济含义清楚，风险归因也变得可行。

需要注意：把 $D$ 设为对角是一个**强假设**。同一行业、同一供应链、同一控股股东的股票，特质收益往往正相关。常见补丁是在 $D$ 之外再加行业/主题块结构。

## 四、相关系数的陷阱

1. **相关性不是常数，而且方向最坏**。市场大跌时，截面平均相关系数会显著上升（"危机时相关性趋于 1"）。分散化在最需要它的时候消失，这正是 [风险平价](08-03-风险平价与等风险贡献.md) 组合在 2020 年 3 月一类行情中同时下跌的原因。
2. **线性相关只刻画椭圆分布**。金融资产收益有厚尾与偏态，两个变量可以线性相关很弱却在尾部几乎同涨同跌。度量尾部依赖需要 Copula 或直接用分位数回归。
3. **相关性非因果**。共同因子驱动会造成伪相关；用中性化（见 `qd.factors.pipeline.neutralize`）剔除共同因子后的"残差相关"才有意义。
4. **窗口选择的两难**：窗口太短噪声大，太长则无法反映状态切换。实务常用半衰期指数加权（如 RiskMetrics 的 $\lambda=0.94$ 日度 EWMA），或引入区制（regime）模型。

## 五、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import mean_variance
from qd.metrics.perf import annual_return, max_drawdown

md = generate_demo_market(n_symbols=60, start="2018-01-01", end="2024-12-31", seed=7)
X = md.returns().dropna().values
T, N = X.shape
S = np.cov(X, rowvar=False) * 252              # 样本协方差（年化）

# ---- Ledoit-Wolf 常数相关目标收缩 ----
var = np.diag(S)
sd = np.sqrt(var)
C = S / np.outer(sd, sd)                        # 相关系数矩阵
rbar = (C.sum() - N) / (N * (N - 1))            # 平均相关系数
F = rbar * np.outer(sd, sd)
np.fill_diagonal(F, var)

# 收缩强度：delta = (估计的噪声量) / (噪声量 + 偏离量)
phi = 0.0
for t in range(T):
    Y = np.outer(X[t], X[t])
    phi += np.sum((Y - S / 252) ** 2)
phi /= T
gamma = np.sum((F - S) ** 2)
delta = max(0.0, min(1.0, phi / gamma / T if gamma > 0 else 0.0))
Sigma_shrunk = delta * F + (1 - delta) * S
print("收缩强度 delta =", round(delta, 3))

mu = X.mean(axis=0) * 252
w_raw = mean_variance(mu, S, risk_aversion=10.0, allow_short=False)
w_shr = mean_variance(mu, Sigma_shrunk, risk_aversion=10.0, allow_short=False)
print("有效持仓数：原始 %.1f  收缩 %.1f" % (1/np.sum(w_raw**2), 1/np.sum(w_shr**2)))
```

## 常见坑

- **用价格算协方差**：必须用收益率，价格序列的非平稳性会让协方差被趋势主导。
- **不同频率混用**：日频估出的协方差乘 252 年化，与直接用月频估的结果会有差异（尤其在自相关存在时），不要用年化值去做日内风险判断。
- **收缩后忘记检查正定性**：收缩到正定目标上可以保证正定，但如果目标矩阵本身构造有误（如平均相关系数为负且幅度过大），仍可能出问题。
- **把因子模型的 $D$ 当零**：特质风险恰恰是主动组合的主要风险来源，忽略它会低估跟踪误差。
- **用全样本协方差做样本外**：至少要用 [净化与禁运](../10-机器学习/10-03-金融数据的交叉验证.md) 的思路保证没有前视。
