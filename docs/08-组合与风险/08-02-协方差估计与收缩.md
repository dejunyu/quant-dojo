# 协方差估计与收缩

## 学完这一篇，你能做到

- 理解为什么"样本协方差"在资产多、样本短时几乎不可用
- 说清收缩估计在做什么：**把噪声大的估计，往一个稳定的靶子上拉**
- 会算 Ledoit-Wolf 收缩强度，并看懂它为什么卡在 0 和 1 之间
- 知道因子协方差模型是另一条路，以及它的代价

## 本篇要点

- 要估的参数是 $N(N+1)/2$ 个，$N=50$ 就是 1275 个——**比你以为的多得多**
- 样本协方差**在极值附近极不稳定**，求逆会放大误差（08-01 的 $w\propto\Sigma^{-1}\mu$）
- 收缩：$\Sigma = \delta F + (1-\delta)S$，$F$ 是"结构化靶子"，$\delta$ 是收缩强度
- **$\delta$ 越接近 1，说明你的样本越不可信**

---

## 一、从"要估多少个参数"说起

08-01 说均值方差的解要用 $\Sigma^{-1}$。但先算一笔账：

> 一个 $N \times N$ 的协方差矩阵，因为对称，独立参数有 **$N(N+1)/2$** 个。

| $N$ | 要估的参数 |
| --- | --- |
| 10 | 55 |
| **50** | **1275** |
| 100 | 5050 |
| 500 | 125250 |

**这就是问题的规模。**

再看样本：如果你有 5 年日频数据，约 1250 个交易日。

> **50 只股票要估 1275 个参数，而只有 1250 个观测。**
> **参数比样本还多。**
>
> 这不是"估得不准"，这是**矩阵接近奇异**——$\Sigma^{-1}$ 会把误差放大到失去意义。

这就是 08-01 那个脆弱点的量化来源：**优化器不是在用信息，是在用噪声。**

---

## 二、收缩估计：把估计"往稳的地方拉"

**Ledoit-Wolf 收缩**的核心想法，一句话就能说清：

> **既然样本协方差噪声太大，那就把它"往一个结构简单、稳定的靶子上拉一点"。**

$$ \Sigma_{\text{shrunk}} = \delta F + (1-\delta) S $$

| 符号 | 白话 |
| --- | --- |
| $S$ | **样本协方差**（数据说的，但吵） |
| $F$ | **结构化靶子**（结构简单，稳） |
| $\delta$ | **收缩强度**（0~1）：$F$ 占多少 |
| $\Sigma_{\text{shrunk}}$ | 拉完之后的估计 |

**最常用的靶子是"常数相关"**：假设所有资产两两的相关系数都等于平均值 $\bar r$。

$$ F = \bar r \cdot s s^\top,\quad \text{对角线用各自方差} $$

（$s$ 是各资产的标准差向量。）这样 $F$ 只有 $N+1$ 个参数，比 $S$ 的 1275 个简单得多——**所以它稳。**

> **收缩的本质，是一次"用偏差换方差"的交换：**
> - $\delta=0$：完全信样本 → 偏差小、**方差大**（噪声大）
> - $\delta=1$：完全信靶子 → 方差小、**偏差大**（假设太强）
> - 最优 $\delta$：在两者之间找平衡
>
> **这跟 05-03 的去极值、05-04 的中性化是同一种思路：**
> **不是"让估计更准"，而是"让估计更不容易被极端情况毁掉"。**

**$\delta$ 怎么估**（Ledoit-Wolf 的贡献）：用"噪声量 ÷ 目标偏离量"，两者必须在**同一量纲**上算，否则会差 252 倍（年度化 vs 日频）。

## 三、用平台算一次收缩

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import mean_variance

md = generate_demo_market(n_symbols=60, start="2018-01-01", end="2024-12-31", seed=7)
X = md.returns().dropna().values
T, N = X.shape
S = np.cov(X, rowvar=False) * 252              # 年化样本协方差

# ---- Ledoit-Wolf 常数相关目标收缩 ----
var = np.diag(S); sd = np.sqrt(var)
C = S / np.outer(sd, sd)
rbar = (C.sum() - N) / (N * (N - 1))           # 平均相关系数
F = rbar * np.outer(sd, sd)
np.fill_diagonal(F, var)

# 关键：pi 与 gamma 必须在同一量纲（这里都用日频），否则会差 252 倍
S_d = np.cov(X, rowvar=False)
var_d = np.diag(S_d); sd_d = np.sqrt(var_d)
C_d = S_d / np.outer(sd_d, sd_d)
rbar_d = (C_d.sum() - N) / (N * (N - 1))
F_d = rbar_d * np.outer(sd_d, sd_d)
np.fill_diagonal(F_d, var_d)

pi = 0.0
for t in range(T):
    Y = np.outer(X[t], X[t])
    pi += np.sum((Y - S_d) ** 2)
pi /= T
gamma = np.sum((F_d - S_d) ** 2)
delta = float(np.clip(pi / gamma / T if gamma > 0 else 0.0, 0.0, 1.0))
Sigma_shrunk = delta * F + (1 - delta) * S

print("平均相关系数 rbar =", round(float(rbar), 3))
print("收缩强度 delta =", round(delta, 3))

# 对比：收缩前后求出的组合分散程度
mu = X.mean(axis=0) * 252
for name, Sig in [("原始", S), ("收缩", Sigma_shrunk)]:
    w = mean_variance(mu, Sig, risk_aversion=10.0, allow_short=False)
    n_eff = 1.0 / np.sum(w ** 2)
    print(f"{name}: 有效持仓数 {n_eff:.1f}")
```

我实跑的结果：

```
平均相关系数 rbar = 0.197
收缩强度 delta = 0.339
有效持仓数：原始 8.1  收缩 7.9
```

**三个读点：**

**第一，`rbar = 0.197`** ——这 60 只股票两两平均相关约 0.2，不高，说明这份合成数据里资产比较独立。

**第二，`delta = 0.339`** ——收缩强度约三分之一。也就是说，**最优估计里，有三分之一来自"结构化假设"，三分之二来自样本**。

> **这个数字本身就是一份"诊断报告"：**
> $\delta$ 越大，说明样本越不可信（噪声占比越高）；
> $\delta$ 接近 0，说明样本够用、不需要收缩。
> **它是"我这份数据的信噪比"的量化指标**——比任何主观判断都实用。

**第三，有效持仓数 8.1 → 7.9**，几乎没变。

> **为什么几乎没变？** 因为在 $N=60$、$T=1826$ 这个比例下（样本比参数多得多），
> 样本协方差其实**没那么糟**，收缩的作用有限。
>
> **收缩真正救命的地方，是 $N$ 接近或超过 $T$ 的时候**——
> 比如 500 只股票、只有 250 个交易日。
> **那时候不做收缩，$\Sigma$ 可能根本求不了逆。**
>
> 这也是为什么很多量化研究在"小股票池 + 长样本"上做实验：
> **问题被无意中回避了，于是上线到"大股票池 + 短样本"时才爆。**

## 四、另一条路：因子协方差模型

除了收缩，还有一条路（05 章讲过它的思想）：**不直接估协方差，而是假设收益由少数因子驱动。**

$$ \Sigma = B \, \Sigma_f \, B^\top + D $$

| 符号 | 白话 |
| --- | --- |
| $B$ | 各资产在因子上的**暴露矩阵**（$N \times K$） |
| $\Sigma_f$ | 因子之间的协方差（$K \times K$，$K$ 很小） |
| $D$ | 每个资产**特有**的方差（对角阵） |

**要估的参数从 $N(N+1)/2$ 降到 $NK + K(K+1)/2 + N$**。$N=500$、$K=10$ 时，从 12.5 万降到约 5500。

> **这就是 BARRA 那类风险模型的数学骨架**（05-04 讲过 Rosenberg）。
> **代价是：你得先相信"收益由这 K 个因子驱动"这个假设。**
> 假设错了，结构再简洁也没用——**这又是"用偏差换方差"。**

---

## 五、相关系数的陷阱

| 陷阱 | 说明 |
| --- | --- |
| **危机中相关性上升** | 平时 0.2，危机时可能 0.8（04-02 提过） |
| **相关性不稳定** | 用全样本估一个平均相关系数，会掩盖剧烈变化 |
| **伪相关** | 两个都受第三个因素驱动（比如都是小盘股） |

> **第一条是致命的。** 风险模型通常假设"相关性在样本期是稳定的"，
> 而现实中，**你最需要分散的那个时刻，恰恰是分散失效的时刻**。
>
> 03-05 讲 1987 年黑色星期一、04-02 讲厚尾，说的都是这个：
> **模型在平静期校准，在危机期失效。**

---

## 六、把这一篇串起来

回到"1275 个参数 vs 1250 个观测"这笔账。

它揭示了一件事：**08-01 那个漂亮的最优化，前提是你知道协方差矩阵；而这个前提在实战中基本不成立。**

> 于是整个量化风险管理，变成了一门"**在估计不准时怎么还能做出决策**"的手艺。
> 收缩是其中一种回答：**别信样本，也别全信假设，找个折中。**
> 因子模型是另一种回答：**别估那么多参数，先假设结构。**

> 一句话收尾：
> **样本协方差告诉你"过去它们怎么一起动"，但你要的是"未来它们怎么一起动"。**
> 收缩的全部意义，是承认这两者之间的距离，并且**为这个距离留出余量**。
