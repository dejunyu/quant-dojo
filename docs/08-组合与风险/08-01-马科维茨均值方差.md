# 马科维茨均值方差

1952 年 Harry Markowitz 在 *Journal of Finance* 发表《Portfolio Selection》，第一次把"分散化"写成了一个可求解的优化问题。此后七十年，几乎所有机构组合管理软件的底层都跑着它的某个变体。理解它，既要会解，也要知道它为什么在实盘里经常"优化出一个最差的结果"。

## 一、目标函数与三种等价写法

设 $N$ 个资产的预期收益向量 $\mu\in\mathbb{R}^N$，协方差矩阵 $\Sigma\in\mathbb{R}^{N\times N}$，权重 $w$。风险厌恶系数 $\lambda>0$。最常用的是**效用最大化形式**：

$$\max_{w}\; w^\top\mu - \frac{\lambda}{2}w^\top\Sigma w \quad \text{s.t.}\quad \mathbf{1}^\top w = 1$$

三项含义：$w^\top\mu$ 是组合预期收益；$w^\top\Sigma w$ 是组合方差（波动率的平方）；$\lambda$ 是你在二者之间的兑换比价——$\lambda$ 越大越保守。

另外两种写法在数学上等价，只是取有效前沿上不同的点：

| 形式 | 约束 | 适用场景 |
| --- | --- | --- |
| 最小化方差 | $\min w^\top\Sigma w$，s.t. $w^\top\mu=\bar{\mu}$，$\mathbf{1}^\top w=1$ | 有明确收益目标（如负债成本） |
| 最大化夏普 | $\max \frac{w^\top\mu-r_f}{\sqrt{w^\top\Sigma w}}$ | 之后用现金调节总风险 |
| 效用最大化 | $\max w^\top\mu-\frac{\lambda}{2}w^\top\Sigma w$ | 参数少、数值最稳定 |

## 二、有效前沿与两基金分离

对每个目标收益解一次最小方差问题，把 $(\sigma_p,\mu_p)$ 画出来，就是**有效前沿**：一条双曲线，其上半支是有效集。加入无风险资产后前沿变成一条直线（资本市场线），切点组合即市场组合，任何投资者的最优解都只是"市场组合 + 无风险资产"的线性组合——这就是**两基金分离定理**。它的重要推论是：如果你只关心均值方差效率，那么被动持有市场组合并不比主动优化差多少。

## 三、无卖空约束下的解

忽略预算约束，一阶条件直接给出闭式解：

$$w^\* = \frac{1}{\lambda}\Sigma^{-1}\mu$$

问题全在这个 $\Sigma^{-1}$ 上。$\Sigma$ 的最小特征值对应的特征向量方向，代表"风险最小的组合方向"，取逆后该方向的权重被放大 $1/\lambda_{\min}$ 倍。而样本协方差的最小特征值恰恰是估计最不准的。

加上 $w\ge 0$（A股绝大多数账户不允许卖空）后，解常常落在**角点**上——一批权重被压到 0，剩下的股票集中度很高。表面看"优化后更分散"，实际可能只有七八只票，这种行为被称为"优化器的角点解偏好"。

## 四、输入敏感性：均值方差的阿喀琉斯之踵

均值方差优化器有两个输入，而它们的估计精度是天差地别的：

- $\hat{\mu}$ 的标准误约为 $\sigma/\sqrt{T}$。用 5 年日频数据（$T\approx1200$），单只股票年化波动 30%，则年化 $\hat\mu$ 的标准误约 $30\%\times\sqrt{252/1200}\approx 13.7\%$。而真实预期收益的差异可能只有几个百分点——**噪声比信号大好几倍**。
- $\hat\Sigma$ 的元素标准误约为 $\sigma_i\sigma_j/\sqrt{T}$，虽然也大，但它是"平均意义"上的量，估计误差在加总时部分抵消。

Chopra 与 Ziemba（1993）用现金等价损失度量后给出的经典结论是：**预期收益的估计误差造成的效用损失，大约是协方差误差的 10 倍量级，是方差误差的 20 倍量级**。Michaud（1989）把这种现象叫做"误差最大化器"（error maximization）：优化器会系统性地把权重压到那些恰好在样本内收益高、波动小的股票上，而这些"好"往往是抽样噪声。

## 五、怎么补救

1. **不要用原始样本均值**。实践中最常见的做法是直接把 $\mu$ 换成某个有先验支撑的估计：因子预期收益、风险溢价假设、或者干脆假设所有股票 $\mu$ 相同（此时均值方差退化为全局最小方差组合）。
2. **收缩协方差**。见 [协方差估计与收缩](08-02-协方差估计与收缩.md)。
3. **加约束**。Jagannathan & Ma（2003）证明：无卖空约束等价于隐式地降低了协方差估计的极端值，即"加错误的约束反而有帮助"。单票上限、行业中性、换手上限都属于这一类。
4. **重采样**。Michaud 的 Resampled Efficiency：对 $(\mu,\Sigma)$ 做 bootstrap，每次解一个权重，最后取平均，能有效抑制角点解。
5. **换基准**。DeMiguel、Garlappi 与 Uppal（2009）比较了多种优化器与朴素 $1/N$ 组合，结论是：在样本外，绝大多数优化器都跑不赢等权。把等权或 [风险平价](08-03-风险平价与等风险贡献.md) 作为默认基准，优化只作为"有信息优势时的增量"。

## 六、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import mean_variance
from qd.metrics.perf import sharpe, max_drawdown, annual_return

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
rets = md.returns().dropna()

cut = int(len(rets) * 0.7)          # 前 70% 训练，后 30% 检验
train, test = rets.iloc[:cut], rets.iloc[cut:]

mu = train.mean().values * 252      # 年化预期收益
Sigma = train.cov().values * 252    # 年化协方差

w_mv = mean_variance(mu, Sigma, risk_aversion=10.0, allow_short=False)
w_eq = np.repeat(1.0 / rets.shape[1], rets.shape[1])   # 等权基准

oos_mv = test.values @ w_mv
oos_eq = test.values @ w_eq
print("均值方差  夏普 %.2f  年化 %.2f%%  回撤 %.2f%%"
      % (sharpe(oos_mv), annual_return(oos_mv) * 100, max_drawdown(oos_mv) * 100))
print("等权      夏普 %.2f  年化 %.2f%%  回撤 %.2f%%"
      % (sharpe(oos_eq), annual_return(oos_eq) * 100, max_drawdown(oos_eq) * 100))
print("有效持仓数 N_eff =", round(1.0 / np.sum(w_mv ** 2), 1))
```

有效持仓数 $N_{\text{eff}}=1/\sum w_i^2$ 是判断优化器是否"假分散"的快捷指标：名义 50 只票，若 $N_{\text{eff}}<10$，说明权重高度集中。

## 常见坑

- **用历史均值当 $\mu$**：这是最常见的错误，也是均值方差名声不好的主因。历史收益对未来的预测力极弱。
- **忽略预算约束的调仓成本**：优化出来的权重变化往往很大，[换手率控制](../09-执行与成本/09-04-换手率控制.md) 会吃掉大半收益。
- **$\lambda$ 拍脑袋**：不同 $\lambda$ 给出的组合差异极大。建议固定组合波动率目标（如年化 15%），而不是固定 $\lambda$。
- **样本内回测看不出问题**：优化器在样本内一定漂亮，必须用严格的前向切分（见 [金融数据的交叉验证](../10-机器学习/10-03-金融数据的交叉验证.md)）评估。
- **协方差不满秩**：$T<N$ 时 $\Sigma$ 奇异，$\Sigma^{-1}$ 不存在，必须先收缩或降维。
