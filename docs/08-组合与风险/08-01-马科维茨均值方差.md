# 马科维茨均值方差

## 学完这一篇，你能做到

- 说清"分散化"为什么是数学上的免费午餐，而不只是"别把鸡蛋放一个篮子"
- 读懂均值方差优化的目标函数，知道每一项在权衡什么
- 理解这个"教科书最优解"在实战中为什么脆弱
- 用平台跑一次样本内优化、样本外检验，看它到底能不能用

## 本篇要点

- 优化的本质：**在给定风险下最大化收益**，或者反过来
- 关键在**协方差**：资产之间不同步，才有分散化的价值
- 无约束解 $w \propto \Sigma^{-1}\mu$，但 $\Sigma$ 估不准、$\mu$ 更估不准
- **实战里它常常输给等权**（1/N），原因是估计误差

---

## 一、从一篇"把风险变成数学"的论文说起

1952 年，一个 25 岁的芝加哥大学研究生 **哈里·马科维茨**（Harry Markowitz）在《金融学杂志》发表了一篇论文：《投资组合选择》（*Journal of Finance* 7(1): 77–91）。

在他之前，"怎么选股票"是**描述性**的：你研究公司、看财报、听消息，然后决定买什么。马科维茨做了一件当时很少见的事：

> **他把"投资组合"变成了一个可以求最优化的问题。**

核心洞见只有一句，但极其深刻：

> **决定组合风险的，不是单只股票各自的波动，而是它们"一起动"的程度。**

具体说：如果两只股票**总是同涨同跌**，那把它们放在一起**完全没有降低风险**——你只是把同一个赌注买了两遍。只有当它们**不同步**时，组合的波动才会小于各自波动的平均。

> **这就是"分散化是免费午餐"的数学版本：**
> **你可以在不降低预期收益的前提下降低风险——前提是这些资产不同步。**

这个洞见让马科维茨在 1990 年获得诺贝尔经济学奖（与 Merton Miller、William Sharpe 共同获奖），也被公认为**现代组合理论的起点**。

**这里有个特别诚实的注脚。** 1997 年，财经记者 Jason Zweig 采访马科维茨，问他自己的退休金怎么配的。马科维茨说，他 1950 年代中期第一次向退休账户缴款时，**把股票和债券各放一半**——而不是去跑一遍他刚发明的优化。

他的原话大意是：

> **"我本该去算历史协方差……但我脑子里浮现的是：如果股市大涨而我不在场，或者股市大跌而我全在里面，我会多难受。**
> **我想做的是最小化我未来的后悔。"**

（来源是 Zweig 1997 年末的采访，刊于 *Money* 杂志 1998 年 1 月号；马科维茨在 2009 年另一次问答中说明，那是 1952 年的做法，**"现在我不这么做了"**。）

> ⚠️ **网上对这个轶事有大量误传**，三种常见错误版本：
> ① 说成"他用 1/N 等权配 N 个资产"（其实是**股/债两类各半**）；
> ② 说成"1987 年股灾后他才这么做"（实际是 1950 年代中期）；
> ③ 说成"他至今仍这么配"（他本人已澄清不是了）。
>
> **但这个故事仍然是本篇最好的入口，因为它说出了一个真问题：**
> **发明这套方法的数学家自己，用的是"最小化后悔"，不是"最大化夏普"。**
> 这正是本篇后半段要回答的。

## 二、目标函数（逐个讲透）

均值方差优化，目标是在**给定风险**下最大化收益：

$$ \max_{w}\ \ w^\top \mu - \frac{\lambda}{2}\, w^\top \Sigma w $$

| 符号 | 白话 |
| --- | --- |
| $w$ | 各资产的权重向量（决策变量） |
| $\mu$ | 各资产的**预期收益** |
| $\Sigma$ | **协方差矩阵**（谁和谁一起动、动多少） |
| $w^\top\mu$ | 组合的预期收益 |
| $w^\top\Sigma w$ | 组合的**方差**（风险） |
| $\lambda$ | **风险厌恶系数**：越大越怕风险 |

**整句话：收益减掉"风险的惩罚"，让这个差最大。**

> 注意 $w^\top\Sigma w$ 这一项——**它不是各资产方差的简单加权，而是包含了所有两两协方差**。
> 这就是"协方差才是关键"的数学体现：
> **如果所有资产完全同步（相关系数=1），这一项就等于加权平均，分散化毫无作用。**

**无约束解**（允许做空、无其他限制）可以解析求出：

$$ w^* = \frac{1}{\lambda}\Sigma^{-1}\mu $$

| 符号 | 白话 |
| --- | --- |
| $\Sigma^{-1}$ | 协方差矩阵的**逆** |
| $\mu$ | 预期收益 |
| $1/\lambda$ | 风险厌恶的倒数（越怕风险，仓位整体越小） |

> **这个式子已经暴露了它最大的脆弱点：**
> **它要求 $\Sigma$ 可逆。**
> 而真实的协方差矩阵，在资产数量接近或超过样本长度时，**是接近奇异的**——
> 一求逆，误差被放大得离谱。这就是 08-02 要用"收缩估计"的原因。

## 三、为什么它在实战中很脆弱（单独讲透）

| 脆弱点 | 为什么致命 |
| --- | --- |
| **$\mu$ 估不准** | 预期收益是最难估的量，误差远大于波动率 |
| **$\Sigma$ 估不准** | 需要估 $N(N+1)/2$ 个参数，$N=50$ 就是 1275 个 |
| **对输入极度敏感** | $\mu$ 变一点，权重可能天翻地覆 |
| **解常集中在少数资产** | "角点解"，看着不像"分散" |

> **最反直觉的一条是：优化器会"过度自信"。**
> 它会**重仓那些历史收益看起来最高的资产**——而那些往往也是历史波动最幸运的。
> 这就是 01-03 讲的过拟合，在最优化框架里的具体形态。

**所以实战中的常见补救**：

| 手段 | 作用 |
| --- | --- |
| **收缩估计**（08-02） | 让 $\Sigma$ 更稳、可逆 |
| **加约束**：单票上限、行业中性 | 防止过度集中 |
| **降低对 $\mu$ 的依赖** | 用历史均值或等权，比"预测 $\mu$"更稳 |
| **等权（1/N）当基准** | 一个"零估计"的对照 |

> **最后一条特别重要。** 有研究（DeMiguel, Garlappi, Uppal 2009）比较过 14 种优化模型，
> 结论是：**在扣除估计误差后，很多复杂优化并不显著优于简单的 1/N 等权。**
> **这不是说优化没用，而是说：估计误差吃掉了优化的全部优势。**

## 四、用平台跑一次"样本内优化、样本外检验"

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
import pandas as pd
from qd.data.synthetic import generate_demo_market
from qd.optimize import mean_variance
from qd.metrics.perf import sharpe, max_drawdown, annual_return

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
rets = md.returns().dropna()

cut = int(len(rets) * 0.7)          # 前 70% 训练，后 30% 检验
train, test = rets.iloc[:cut], rets.iloc[cut:]

mu = train.mean().values * 252      # 年化预期收益
Sigma = train.cov().values * 252    # 年化协方差

w_mv = mean_variance(mu, Sigma, risk_aversion=10.0, allow_short=False)
w_eq = np.repeat(1.0 / rets.shape[1], rets.shape[1])

oos_mv = test.values @ w_mv
oos_eq = test.values @ w_eq

# 注意：annual_return / max_drawdown 吃的是**净值序列**，不是收益率序列。
nav_mv = (1 + pd.Series(oos_mv, index=test.index)).cumprod()
nav_eq = (1 + pd.Series(oos_eq, index=test.index)).cumprod()

print("均值方差  夏普 %.2f  年化 %.2f%%  回撤 %.2f%%"
      % (sharpe(oos_mv), annual_return(nav_mv) * 100, max_drawdown(nav_mv) * 100))
print("等权      夏普 %.2f  年化 %.2f%%  回撤 %.2f%%"
      % (sharpe(oos_eq), annual_return(nav_eq) * 100, max_drawdown(nav_eq) * 100))
print("有效持仓数 N_eff =", round(1.0 / np.sum(w_mv ** 2), 1))
```

我实跑的结果：

```
均值方差  夏普 1.55  年化 29.75%  回撤 -15.82%
等权      夏普 1.21  年化 20.10%  回撤 -22.12%
有效持仓数 N_eff = 7.2
```

**在这份数据上，优化赢了：夏普 1.55 vs 1.21，回撤 -15.82% vs -22.12%。**

> **但请别急着下结论说"优化更好"。** 三个理由：
>
> ① **这是合成数据**，资产之间的相关结构相对稳定（真实市场会变）；
> ② **只做了一个切分**（前 70%/后 30%），换个切点结论可能翻转（06-06 讲过）；
> ③ **`N_eff = 7.2`** ——50 只股票，有效持仓只有 7 只左右。
> 这叫"**名义分散、实际集中**"：你以为分散在 50 只，其实命脉系于 7 只。

> **第 ③ 点是最该记住的**：
> **有效持仓数 $N_{eff} = 1/\sum w_i^2$**，它衡量"你到底分散在几只股票上"。
> 等权 50 只是 50，而优化出来是 7.2——**优化器把 43 只的权重压到了接近 0。**
> 这就是 08-02 要用收缩、08-03 要用风险平价的原因：
> **它们都在试图解决"优化器太集中"这个问题。**

## 五、均值方差还值得学吗

值得，但要知道它的定位：

| 它擅长 | 它不擅长 |
| --- | --- |
| 提供**思考框架**（收益 vs 风险的权衡） | 直接给出可交易的权重 |
| 定义**有效前沿**的概念 | 预测 $\mu$ |
| 作为其他方法的**基准** | 处理厚尾（04-02） |

> **把它当成"一个思考框架"，而不是"一个求解器"。**
> 它教给你的是：**任何组合决策，都是"预期收益"和"协方差结构"之间的权衡。**
> 这个框架在 08-02（估得更准）、08-03（换个目标函数）里都还在用。

## 六、把这一篇串起来

回到 1952 年那篇论文。

马科维茨做的事，用一句话概括就是：**把"别把鸡蛋放在一个篮子里"这句老话，变成了一个可以求导的式子。** 而一旦变成式子，人们就发现：**这句老话的数学版本，有一个巨大的漏洞——它需要你准确知道每个鸡蛋会怎么动。**

> 而"准确知道"这件事，恰恰是金融市场里最难的（02-01 的数据口径、05-05 的 IC 波动、
> 06-05 的过拟合，全是同一个困难的变体）。
>
> **所以这一整章（08）的走向很清楚：**
> 08-01 给定目标函数 → 08-02 修协方差 → 08-03 换目标函数（风险平价）
> → 08-04 谈仓位上限 → 08-05~07 处理极端情况
> **全部都在回答同一个问题："当估计不准时，怎么还能做出稳健的组合？"**

> 一句话收尾：
> **马科维茨教会我们"组合的风险来自协方差"，**
> **但实战教会我们"协方差本身也估不准"。**
> 前者是理论的地基，后者是工程的全部。
