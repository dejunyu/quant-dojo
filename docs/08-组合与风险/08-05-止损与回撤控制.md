# 止损与回撤控制

止损是散户最熟悉、误解最深的风控工具。"截断亏损，让利润奔跑"这句话被引用了上百年，但它成立是有前提的。本节把止损拆成数学、实证与工程三层来看。

## 一、止损的数学：它到底改变了什么

设价格服从无漂移随机游走，你在 $P_0$ 买入，设定止损价 $P_0(1-s)$、止盈价 $P_0(1+t)$。对无漂移鞅而言：

$$\mathbb{E}[P_T-P_0]=0$$

由**可选停时定理**（Optional Stopping Theorem），在合理的可积性条件下，任意停时 $\tau$（无论止损、止盈还是二者的组合）都有

$$\mathbb{E}[P_\tau-P_0]=0$$

也就是说：**对随机游走，任何止损止盈规则都不改变期望收益，只改变收益分布形状**。止损把左尾截断（少亏），代价是把一部分本会反弹的小亏变成已实现亏损，并且频繁触发带来交易成本。净效果通常是**负的**。

那为什么止损在实盘中仍有价值？因为它改变的不是 $\mathbb{E}[R]$ 而是别的东西：

1. **降低破产概率与尾部风险**。截断左尾会降低 [VaR/CVaR](08-06-风险指标VaR与CVaR.md) 与极端回撤。
2. **释放资金并提高资金周转效率**。被套死的仓位无法参与新信号。
3. **配合有正期望且序列相关的信号**。这是止损真正产生 alpha 的唯一途径：如果入场信号有效且收益序列存在**趋势（正相关）**，则"亏损"本身是坏消息，止损能提前剔除坏路径；反之如果序列是**均值回复（负相关）**，止损会系统性卖在最低点附近，是负贡献。

这就给出一条可操作的判据：**趋势/动量策略适合止损；均值回复/网格策略不适合止损，反而应该加仓或死扛。** 这一结论与 Kaminski & Lo（2014）对技术规则的大规模实证一致：止损规则在趋势跟随类信号上有增量，在反转类信号上损害收益。

## 二、四类止损规则

| 类型 | 规则 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 固定百分比 | 亏损达 $s\%$ 平仓 | 简单、可回测 | 与波动率脱钩，高波动标的频繁被打掉 |
| ATR 止损 | 跌破 $P_{entry}-k\cdot ATR$ | 自适应波动率 | 参数 $k$ 需按持仓周期调 |
| 时间止损 | 持有 $N$ 天未达目标即平 | 控制机会成本、提高周转 | 与价格无关，可能卖在起飞前 |
| 跟踪止损 | 从最高价回撤 $s\%$ 平仓 | 保护浮盈、让利润奔跑 | 震荡市反复被扫 |

实务经验值：日频股票策略常用 $2\sim3$ 倍 ATR（约 6%~10%），或固定 8%~10%；持仓周期越长，止损应越宽。止损宽度与胜率、$[持仓周期]$ 的关系大致是：$s\approx k\cdot\sigma\sqrt{H}$，$H$ 为持仓天数。

## 三、组合层回撤熔断

单票止损只截断个股尾部，真正决定生死的是组合净值。回撤熔断是分层响应的规则：

| 组合回撤 | 动作 |
| --- | --- |
| < 5% | 正常运行 |
| 5%~10% | 降低单票上限、停止新增开仓 |
| 10%~15% | 整体仓位降至 50% |
| > 15%~20% | 降至 25% 或清仓，进入人工复核 |

熔断的关键设计细节：

- **用收盘价还是盘中价触发**：盘中价触发更灵敏但容易被插针打掉；收盘价触发更稳但可能慢一天。
- **恢复条件要写清楚**：是"净值回到前高"还是"连续 N 天无新低"，否则会出现反复减仓-加仓的震荡损耗。
- **熔断本身有成本**：减仓后再加仓，会错过反弹。因此熔断阈值必须结合策略的历史回撤分布设定，通常取历史最大回撤的 1.2~1.5 倍。

## 四、交易所规则约束（A股）

- **涨跌停板**：A股主板 ±10%、ST ±5%、创业板/科创板 ±20%。涨停封板时无法买入，跌停封板时**止损单无法成交**——这是止损最致命的执行风险，必须在回测里建模。
- **T+1**：当日买入不能当日卖出，日内止损不可行。
- **最小变动价位与价格笼子**：科创板/创业板的限价申报有"价格笼子"约束（买入申报价不得高于基准价的 102% 等），止损单报价需在其内。
- **停牌与熔断**：个股停牌期间无法交易，2016 年初沪深 300 曾实施过指数熔断（已暂停），但规则本身说明"市场层面可能禁止交易"。
- **不许卖空**：止损即卖出，不存在反向止损单。

在 `qd.backtest` 里，这些约束通过 `BacktestConfig(allow_short=False, t_plus_1=True)` 表达；涨跌停不可成交需要数据侧提供涨跌停标记。

## 五、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.metrics.perf import max_drawdown, annual_return, ulcer_index

md = generate_demo_market(n_symbols=30, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003,
                     slippage_bps=5, stamp_tax=0.0005,
                     allow_short=False, t_plus_1=True)

def apply_stop(equity, stop):
    """对净值序列施加组合层回撤熔断：跌破阈值后按日收益清零处理（保守近似）。"""
    r = equity.pct_change().fillna(0.0).values.copy()
    peak, halted = 1.0, False
    out = np.zeros_like(r)
    for i, x in enumerate(r):
        if halted:                       # 熔断后空仓，收益记 0
            out[i] = 0.0
            peak = max(peak, 1.0)
            continue
        out[i] = x
        peak = peak * (1 + x)
        if peak < 1 - stop:              # 回撤超过阈值，触发熔断
            halted = True
    return np.cumprod(1 + out)

bt = Backtest(md, sma_cross(fast=10, slow=60), cfg)   # 趋势类信号，适合止损
res = bt.run()
eq = res.equity

for stop in [None, 0.10, 0.15, 0.20]:
    curve = eq.values if stop is None else apply_stop(eq, stop)
    print("回撤熔断=%-5s 年化=%6.2f%% 最大回撤=%6.2f%% Ulcer=%5.2f"
          % (stop, annual_return(curve) * 100,
             max_drawdown(curve) * 100, ulcer_index(curve)))
```

注意 `stop=None` 这一行必须保留作为基准——**没有基准就无法判断止损是帮忙还是添乱**。

## 常见坑

- **用样本内最优止损**：止损参数极易过拟合。用 [净化交叉验证](../10-机器学习/10-03-金融数据的交叉验证.md) 或直接固定一个保守值。
- **回测里假设止损一定成交**：跌停、跳空、流动性枯竭时止损单不会成交。回测应按"下一根 K 线开盘价 ± 滑点"成交，并对一字板情形做不可成交判断。
- **把止损当成仓位管理的替代品**：真正控制总风险的是仓位（见 [凯利公式](08-04-仓位管理凯利公式.md)），止损只是二级工具。
- **均值回复策略乱加止损**：布林带回归（`qd.strategy.builtin.bollinger_reversion`）一类策略加止损会显著伤害收益，因为它靠"跌下去买更多"赚钱。
- **止损后不设禁止再入场期**：会造成同一标的高频反复进出，成本极快累积。
