# 止损与回撤控制

## 学完这一篇，你能做到

- 说清止损在数学上到底改变了什么（以及不改变什么）
- 分清四类止损规则，知道各自适合什么
- 理解"回撤熔断"和"单笔止损"的层级差异
- 用平台跑一次熔断对比，看懂"降回撤"的代价

## 本篇要点

- 止损**不提高期望收益**，它改变的是**收益分布的形状**（砍掉左尾）
- 代价是：**你会被正常的波动扫出去**
- 组合层**回撤熔断**比单笔止损更实用，因为它管的是"整体失控"
- **A 股有硬约束**：跌停卖不出（03-01），止损可能根本不执行

---

## 一、先说一个反直觉的结论

很多人认为：**"止损可以降低风险，所以应该提高风险调整后收益。"**

这句话**一半对一半错**：

| 说法 | 对不对 |
| --- | --- |
| 止损**降低**单笔最大亏损 | ✅ 对 |
| 止损**降低**回撤 | ✅ 对（多数情况下） |
| 止损**提高**期望收益 | ❌ **不一定**，常常是降低 |
| 止损**提高**夏普 | ❌ 不一定 |

> **为什么？因为止损是一笔交易，而交易有成本。**
> 你在 -5% 卖出，等它涨回来再买（或者不买），这中间的价差 + 手续费就是成本。
> **只有当"下跌有延续性"时，止损才划算**——你砍在 -5%，避免了后面跌到 -30%。
> 如果下跌只是噪声（很快反弹），止损就是**纯粹地把你扫出去**。

> 所以止损的本质是一个**判断**：
> **"这次下跌，是趋势的开始，还是噪声？"**
>
> 而这个判断，和 07-01（趋势）与 07-02（均值回归）的分歧是同一个问题——
> **你赌延续，还是赌回归？**

这三件事可以用一个式子写清楚。带止损的收益分布，是在原分布上做了一次**截断**：

$$ \mathbb{E}[r_{\text{stop}}] = \mathbb{E}[r] - \underbrace{P(\text{触发})\cdot \mathbb{E}[\text{止损成本} \mid \text{触发}]}_{\text{被砍掉的左尾，但付了成本}} - \underbrace{\text{手续费}}_{\text{每次触发都付}} $$

| 符号 | 白话 |
| --- | --- |
| $\mathbb{E}[r]$ | 不止损时的平均收益 |
| $P(\text{触发})$ | 有多少比例的日子会触发止损 |
| $\mathbb{E}[\text{止损成本} \mid \text{触发}]$ | 触发时，你实际损失了多少 |
| 手续费 | **每次触发都要付**，触发越多付越多 |

> **这个式子的关键，是它有两个减号。**
> 止损**救回**了一部分（避免继续跌），但也**付出了两笔成本**：被扫出去的价差、和手续费。
> **只有当"救回的"大于"付出的"，止损才真的提高了收益。**
> 而这取决于**下跌是否延续**——也就是你赌趋势还是赌回归。

**学术上对此有专门研究**：Kaminski 与 Lo 在《何时止损》（*Journal of Financial Markets* 18: 234–254, 2014）中系统检验了止损规则。

结论是**有条件的**：在某些收益过程下，较慢采样频率的止损规则可以**同时降低波动、提高期望收益**；但换一种收益过程（比如均值回归的），同样的规则就可能有害。

（具体结论以原文为准，DOI 10.1016/j.finmar.2013.07.001。这一点也解释了为什么 07-01 要宽止损、07-02 要硬止损——**两者的收益过程假设相反**。）

## 二、四类止损规则（逐个说清）

| 类型 | 规则 | 适合 | 风险 |
| --- | --- | --- | --- |
| **固定百分比** | 跌 X% 就卖 | 入门、单一标的 | X 太紧会被噪声扫 |
| **波动率调整（ATR）** | 跌 n 倍 ATR 就卖 | 波动差异大的组合 | 参数难定 |
| **时间止损** | 持有 N 天不涨就卖 | 短线、事件驱动 | 可能错过慢趋势 |
| **组合回撤熔断** | 总回撤超 X% 就降仓/空仓 | **整体风控** | 可能砍在底部 |

> **前三种是"单笔层面"，最后一种是"组合层面"。**
> 这个区别特别重要：
> **单笔止损保护的是"这一笔亏太多"，组合熔断保护的是"整个账户失控"。**
>
> 而真正让账户爆掉的，几乎总是后者——**因为多笔同时亏损时，单笔止损根本挡不住**（04-02 讲过危机中相关性上升）。

## 三、用平台跑一次熔断对比

按 [00-开始之前](../01-入门/00-开始之前.md) 装好环境，把下面这段存成文件跑一次：

```python
import warnings
warnings.filterwarnings("ignore")
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import sma_cross
from qd.metrics.perf import max_drawdown, annual_return, ulcer_index

md = generate_demo_market(n_symbols=30, start="2018-01-01", end="2024-12-31", seed=7)
cfg = BacktestConfig(initial_cash=1_000_000, commission_rate=0.0003,
                     slippage_bp=5, stamp_duty=0.0005)

def apply_stop(equity, stop):
    """组合层回撤熔断：跌破阈值后空仓（收益记 0），保守近似。"""
    r = equity.pct_change().fillna(0.0).values.copy()
    peak, halted = 1.0, False
    out = np.zeros_like(r)
    for i, x in enumerate(r):
        if halted:
            out[i] = 0.0
            continue
        out[i] = x
        peak = peak * (1 + x)
        if peak < 1 - stop:
            halted = True
    return np.cumprod(1 + out)

res = Backtest(md, sma_cross(fast=10, slow=60), cfg).run()

for stop in (None, 0.10, 0.15, 0.20):
    eq = res.equity if stop is None else apply_stop(res.equity, stop)
    print("熔断阈值=%-5s 年化=%7.2f%% 最大回撤=%7.2f%% Ulcer=%.2f"
          % (stop, annual_return(eq)*100, max_drawdown(eq)*100, ulcer_index(eq)))
```

我实跑的结果：

```
熔断阈值=None  年化=  -0.13% 最大回撤= -49.60% Ulcer=31.72
熔断阈值=0.10  年化=  -1.65% 最大回撤= -16.80% Ulcer=16.22
熔断阈值=0.15  年化=  -2.35% 最大回撤= -20.99% Ulcer=20.22
熔断阈值=0.20  年化=  -3.20% 最大回撤= -25.89% Ulcer=24.85
```

**这张表把止损的全部矛盾摊开了：**

| 熔断阈值 | 年化 | 最大回撤 | Ulcer |
| --- | --- | --- | --- |
| 不熔断 | **-0.13%** | **-49.60%** | 31.72 |
| 10% | -1.65% | **-16.80%** | **16.22** |
| 15% | -2.35% | -20.99% | 20.22 |
| 20% | -3.20% | -25.89% | 24.85 |

**读法一：回撤确实被砍下来了。** 从 -49.60% 降到 -16.80%（10% 阈值），**降了近三分之二**。

**读法二：代价是收益更差了。** 年化从 -0.13% 变成 -1.65%——**本来就微亏，现在亏更多**。

> **这就是止损的真相：它买的是"睡得着"，付的是"少赚（或多亏）"。**
>
> 请注意 Ulcer 那一列（04-02 提过，它对回撤深度和持续时间双重惩罚）：
> **从 31.72 降到 16.22，几乎减半**。这个改善是真实的、可感知的。
>
> **所以"止损好不好"这个问题，没有统一答案——它取决于你更怕什么：**
> **怕是"账户腰斩"，还是怕"少赚一点"。**

> ⚠️ 一个技术细节：**10% 那个阈值之所以回撤最小，是因为它最早熔断、最久空仓**。
> 但"空仓"在实盘里不是免费的——你还要决定**什么时候重新进场**，
> 而这个决策模型里没有（它一旦熔断就永久空仓）。
> **所以这张表在"恢复"这一点上是偏乐观的**：真实策略需要一套"何时复启"的规则。

## 四、A 股的硬约束：止损可能根本不执行

03-01 讲过这一条，这里必须重复，因为它能让所有止损设计失效：

> **跌停板上卖不掉。**

一个"跌 5% 就止损"的策略，在连续跌停时：
- 第一天跌停：卖不出；
- 第二天继续跌停：还是卖不出；
- 等到能卖出时，可能已经跌了 30%。

| 约束 | 后果 |
| --- | --- |
| **跌停不可卖**（03-01） | 止损在最需要时失效 |
| **T+1**（03-01） | 当天买的不能当天卖 |
| **流动性不足**（03-05） | 小盘股可能没有对手方 |
| **停牌**（02-03） | 直接无法交易 |

> **所以"A 股策略要不要止损"，答案不是"要"或"不要"，
> 而是"你要设计一个**在卖不掉的时候也成立**的风控"。**
>
> 现实做法通常是：**降低单票权重 + 分散**，而不是依赖"到点就砍"。
> **因为分散是事前生效的，止损是事后生效的**——而事后那一下，可能根本做不到。

## 五、回撤熔断的设计要点

| 要点 | 建议 |
| --- | --- |
| **阈值** | 别太紧（10% 就行，5% 会被噪声反复触发） |
| **降仓而非清仓** | 清仓后"何时回来"是个更难的问题 |
| **分层** | 回撤 10% 降半仓、20% 降更多，而不是一刀切 |
| **书面化** | 事先写死规则，避免"这次不一样"（06-07） |
| **考虑执行** | 熔断时正好是流动性最差的时候（03-05） |

> **最后一条特别残酷**：你要卖出的时刻，往往正是"所有人都在卖"的时刻。
> **回撤熔断和踩踏是同一个动作**——这既是它有效的原因，也是它危险的原因。

## 六、把这一篇串起来

回到那个反直觉的结论：**止损不提高期望，它改变分布形状。**

这个说法值得再品一次。它意味着：

> **买止损，买的不是"更好的收益"，是"更小的左尾"。**
> 你和市场做了一笔交换：**用一部分期望收益，换一部分尾部安心。**

> 而 07-01（趋势，要宽止损）与 07-02（均值回归，要硬止损）的分歧，
> 在这里得到了统一解释：
> **止损的好坏，取决于"下跌会不会延续"——而这正是那两个策略的核心假设。**
> **止损从来不是一个独立的技术，它是你对市场结构判断的下注。**

> 一句话收尾：
> **止损不能让你赚得更多，它只能让你亏得更少——而且只在"下跌会延续"时才成立。**
> **它的全部价值，取决于你有没有搞对那个前提。**
