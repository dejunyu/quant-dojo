# 换手率控制

换手率是连接策略与成本的桥梁：**毛收益来自信号，净收益来自毛收益减去换手成本**。很多策略在学术上显著、在实盘中无利可图，原因就是换手率过高。本节讲换手率的度量、约束与降低手段。

## 一、换手率的定义与口径

给定第 $t$ 期与 $t-1$ 期的权重向量 $w^{new}, w^{old}$（均归一化到和为 1）：

$$\text{Turnover}_t = \frac{1}{2}\sum_{i=1}^{N}\big|w_i^{new} - w_i^{old}\big|$$

除以 2 是因为每笔卖出必然对应一笔买入，**单边换手率**只统计一侧；不除以 2 则为**双边换手率**。两种口径文献中都在用，比较数字时必须确认口径一致。

换算：

- 若每月调仓一次，月单边换手 20%，则**年化单边换手约 240%**（不严格，因为权重漂移会叠加，实际应逐期累加）。
- 更准确的年化做法是 $\text{TO}_{annual}=\sum_{t=1}^{12}\text{TO}_t$。
- 名义成交额：单边换手率 $\times$ 组合市值。年化 240% 换手、1 亿规模，年成交额 2.4 亿。

**成本换算**：

$$C_{annual} = \text{TO}_{annual}^{one-side} \times 2 \times \Big(\text{佣金} + \text{印花税} + \text{滑点} + \text{冲击}\Big)$$

A股典型参数：佣金 3 bps（万三，双边）、印花税 50 bps（仅卖出，即单边 25 bps 摊到双边）、滑点 + 冲击 10~50 bps。取合计单边 30 bps，则年化 240% 换手的成本为：

$$2.4 \times 2 \times 0.003 = 1.44\% \quad\text{（双边计法）}$$

或按单边口径 $2.4\times 0.003 = 0.72\%$。**一个年化毛收益 8% 的策略，若换手 1000%，成本会吃掉 3% 以上**——这是很多高换手策略实盘失效的直接原因。

## 二、换手从哪来

把换手拆开看，通常只有一小部分是"信号真正变了"：

1. **信号换手（必要）**：因子排序变化导致的真实调仓。
2. **噪声换手（可优化）**：因子值微小抖动导致排名在第 20 名与第 21 名之间反复穿越，持仓反复互换。
3. **权重漂移换手（可优化）**：价格上涨使权重超出目标，被动拉回。
4. **约束触发换手**：风控、行业上限、停牌复牌等。

经验法则：**在一个月频 20 只持仓的选股组合里，第 2 类噪声换手通常占总换手的 30%~50%**。这就是换手控制的用武之地。

## 三、三种控制手段

### 1. 目标换手约束（硬约束）

在优化问题中显式加入：

$$\max_w\ w^\top\mu - \frac{\lambda}{2}w^\top\Sigma w \quad \text{s.t.}\quad \|w-w^{old}\|_1 \le 2\,\tau,\ \ \mathbf{1}^\top w=1,\ w\ge0$$

其中 $\tau$ 是单边换手上限。硬约束的优点是**可控性强**（组合经理可以明确承诺换手不超过多少）；缺点是约束紧时优化器退化为只动少数头寸，可能偏离目标组合很远。

### 2. 换手惩罚（软约束）

把 $\ell_1$ 惩罚放进目标函数：

$$\max_w\ w^\top\mu - \frac{\lambda}{2}w^\top\Sigma w - \underbrace{\gamma\|w-w^{old}\|_1}_{\text{换手成本}}$$

$\gamma$ 应**直接标定为真实交易成本**（含冲击），这样优化器自己在"新信息的价值"与"交易成本"之间权衡。这是实务中最优雅的做法——它把成本内生化了，且不需要人为设阈值。

$\ell_1$ 惩罚的一个好性质：它产生**稀疏的调整**，即只对偏离足够大的头寸调仓，小漂移自动不动。这与缓冲带的效果一致，但更平滑。

### 3. 缓冲带（buffer / no-trade zone）

定义一个容忍区间，只有偏离超过阈值才调整：

$$w_i^{new} = \begin{cases} w_i^{target}, & \big|w_i^{old}-w_i^{target}\big| > \delta\ \text{或}\ \big|\frac{w_i^{old}}{w_i^{target}}-1\big| > \delta_{rel} \\ w_i^{old}, & \text{否则} \end{cases}$$

常用 $\delta_{rel}=20\%\sim25\%$。缓冲带的优点是实现极简、效果显著（典型可降换手 30%~50% 而几乎不损失 alpha）；缺点是需要重新归一化，且当很多头寸同时被锁住时，目标组合与实际的偏离会累积。

三者对比：

| 手段 | 换手降幅 | alpha 损失 | 实现难度 | 可控性 |
| --- | --- | --- | --- | --- |
| 硬约束 $\tau$ | 大 | 可能大 | 中 | 最高 |
| $\ell_1$ 惩罚 | 中 | 小 | 中 | 中（靠 $\gamma$） |
| 缓冲带 | 中 | 很小 | 低 | 中 |

## 四、成本-收益平衡：最优换手

设毛 alpha 随换手率增大而上升但边际递减，常用形式 $A(T)=A_\infty(1-e^{-T/T_0})$，成本 $C(T)=cT$ 线性。净收益 $N(T)=A(T)-cT$，最优解：

$$N'(T)=\frac{A_\infty}{T_0}e^{-T/T_0}-c=0\quad\Longrightarrow\quad T^\*=T_0\ln\frac{A_\infty}{cT_0}$$

结论：**成本 $c$ 越高，最优换手越低，且是"对数"下降**——成本翻倍，最优换手减少一个常数，而不是减半。这也说明：高换手策略对成本极其敏感，规模一大就必须降频。

实务建议：

1. 先测策略的**毛收益 vs 换手曲线**，找到饱和点（超过该换手后 alpha 不再增长）。
2. 用真实成本参数（含冲击）标定，看净收益曲线的峰值在哪。
3. 把峰值附近设为默认换手，并留出 30% 安全边际。

## 五、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.optimize import grid_search
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import factor_long_only
from qd.metrics.perf import sharpe, annual_return

md = generate_demo_market(n_symbols=80, start="2018-01-01", end="2024-12-31", seed=7)

def buffer_weights(target, current, delta_rel=0.20):
    """缓冲带再平衡：相对偏离小于 delta_rel 的头寸不动。"""
    t = np.asarray(target, dtype=float)
    c = np.asarray(current, dtype=float)
    w = c.copy()
    with np.errstate(divide="ignore", invalid="ignore"):
        dev = np.where(t > 0, np.abs(c / np.where(t > 0, t, 1.0) - 1.0), np.inf)
    w[dev > delta_rel] = t[dev > delta_rel]
    if w.sum() <= 0:
        return t
    return w / w.sum()

def turnover(old, new):
    """单边换手率。"""
    return 0.5 * float(np.abs(np.asarray(new) - np.asarray(old)).sum())

def run(delta_rel):
    strat = factor_long_only(factors=["mom_12_1"], top_k=20, rebalance="1M")
    cfg = BacktestConfig(initial_cash=10_000_000, commission_rate=0.0003,
                         slippage_bps=20, stamp_tax=0.0005,
                         allow_short=False, t_plus_1=True)
    res = Backtest(md, strat, cfg).run()
    r = res.equity.pct_change().dropna().values
    return dict(delta_rel=delta_rel, sharpe=sharpe(r), annual=annual_return(r),
                n_trades=len(res.trades))

grid = grid_search(run, {"delta_rel": [0.0, 0.10, 0.20, 0.35, 0.50]})
for row in grid:
    print("缓冲带=%4.2f 夏普=%.2f 年化=%6.2f%% 交易笔数=%d"
          % (row["delta_rel"], row["sharpe"], row["annual"]*100, row["n_trades"]))
```

## 常见坑

- **口径不一致**：与同行或文献比较换手率时，先确认是单边还是双边、是月频还是年化。
- **忘记权重漂移**：只在调仓日算换手，忽略了中间因价格波动产生的被动偏离（这正是缓冲带要解决的部分）。
- **成本参数拍脑袋**：用 [冲击成本模型](09-03-冲击成本模型.md) 按规模动态估算，不要永远用 5bps。
- **缓冲带不设强制对齐日**：长期不调整会累计成很大的跟踪误差。建议每季度做一次全量对齐。
- **把换手当越低越好**：换手降到 0 就是买入持有，alpha 也没了。目标是**净收益最大**而非换手最小。
- **忽略税收与红利税**：A股持股不足 1 个月按 20% 征收股息红利税，高换手会额外损失。
