# 冲击成本模型

买卖价差是小额交易的显性成本，而**冲击成本（market impact）**是大额交易的隐性成本——它不出现在任何账单上，却往往是机构交易成本的最大组成部分。本节讲清楚它的结构、经典模型与实务估算方法。

## 一、成本分解

一笔交易的总成本可分为：

$$C_{total} = \underbrace{\frac{\text{spread}}{2}}_{\text{价差成本}} + \underbrace{I_{perm}}_{\text{永久冲击}} + \underbrace{I_{temp}}_{\text{暂时冲击}} + \underbrace{\text{佣金}+\text{税}}_{\text{显性费用}}$$

- **价差成本**：被动挂单可以避免，主动吃单必须支付。
- **永久冲击**：交易本身改变了市场对资产价值的判断（信息效应），价格**不会回来**。它是真实的经济成本，全额计入。
- **暂时冲击**：消耗了订单簿的即时流动性，价格会在几分钟到几天内**部分回复**。如果你不急于反向交易，实际承担的成本小于名义值。
- **显性费用**：佣金（万三左右）、印花税（A股卖出 0.05%）、过户费等。

Almgren 等人的实证分解显示，典型机构大单中，**永久冲击约占 2/3，暂时冲击约占 1/3**。所以估算总成本时不能只算价差。

## 二、线性 vs 平方根模型

### 线性模型

$$\frac{\Delta P}{P} = \eta\cdot\frac{Q}{V}$$

含义：每单位参与率造成固定比例的价格移动。形式简单，但**与实证严重不符**：它预测"下 10 倍的单造成 10 倍冲击"，而真实数据远低于此。

### 平方根模型（经典）

$$\boxed{\ \frac{\Delta P}{P} = \eta\cdot\sigma\cdot\sqrt{\frac{Q}{V}}\ }$$

其中 $\sigma$ 是标的日波动率，$Q$ 是订单量，$V$ 是同期市场成交量，$\eta$ 为无量纲常数（经验值约 1，依市场与样本不同而变）。

这一形式有多个独立来源：

- **理论**：Kyle (1985) 的序贯交易模型与 Glosten-Milgrom 模型都导出价格影响与交易量的平方根关系；微观结构中的"订单簿是分形/稀疏堆积"论证也支持它。
- **实证**：Almgren、Thum、Hauptmann 与 Li (2005) 用美银美林的机构大单数据，拟合出幂指数约 0.6，接近 0.5；Torre 与 Ferrari、Bouchaud 等人的研究给出 0.3~0.7 的区间。
- **业界**：Bloomberg/Axioma 等商业冲击模型的默认形式都是 $\sigma\sqrt{Q/V}$。

最著名的经验规律是 **"square-root law"**：把订单量翻倍，成本只增加约 41%（$\sqrt2$），而不是 100%。

### 幂律的一般形式

$$\frac{\Delta P}{P} = \eta\,\sigma\left(\frac{Q}{V}\right)^{\beta},\qquad \beta\in[0.3,0.7]$$

$\beta$ 因市场结构而异：订单驱动、散户占比高、盘口薄的市场 $\beta$ 偏大（更接近线性）。

## 三、用参与率估算成本

实务中最方便的做法是直接以**参与率 $\rho = Q/ADV$** 为自变量（ADV = 日均成交量，常用 20 日均值）：

$$\text{cost(bps)} \approx 10^4\cdot\eta\cdot\sigma_{daily}\cdot\sqrt{\rho}$$

举例：某股票日波动率 2%，单笔订单占 ADV 的 5%，$\eta=1$：

$$\text{cost} = 10^4\times 1\times 0.02\times\sqrt{0.05} = 447\ \text{bps} \approx 4.5\%$$

这个数字听起来吓人，但它是"一次性全部成交"的成本。这正是为什么大单必须拆单：**把订单拆成 10 份、每份占 ADV 0.5%，每份成本 $10^4\times0.02\times\sqrt{0.005}=141$ bps，合计约 141 bps（因为总量不变时拆分使总冲击按 $\sqrt{}$ 结构下降）**——拆单把成本从 447bps 降到约 141bps，节省近七成。

| 参与率 $Q/ADV$ | $\sigma=1\%$ | $\sigma=2\%$ | $\sigma=4\%$ |
| --- | --- | --- | --- |
| 0.1% | 32 bps | 63 bps | 126 bps |
| 1% | 100 bps | 200 bps | 400 bps |
| 5% | 224 bps | 447 bps | 894 bps |
| 20% | 447 bps | 894 bps | 1789 bps |

（按 $\eta=1$、$\text{cost}=10^4\sigma\sqrt\rho$ 计算）

**容量（capacity）的反推**：若你能接受的成本上限是 50 bps，标的是 $\sigma=2\%$，则

$$\rho^\* = \left(\frac{50}{10^4\times0.02}\right)^2 = 0.0625\%$$

即单日只能交易 ADV 的 0.06%。若策略日换手 10%，则可管理规模 $\approx 0.0625\%/10\% \times ADV$，即约 0.6% 的 ADV 名义。这就是"容量估算"的标准做法。

## 四、其它影响因素

- **价差**：小盘股价差可达 50~100 bps，本身就是主要成本。
- **波动率状态**：用全样本 $\sigma$ 会低估高波动期成本，建议用滚动 20 日波动率。
- **方向**：买入冲击通常大于卖出（订单簿上买盘更薄），且下跌日冲击更大。
- **隐蔽性**：[冰山单](09-01-订单类型.md)、暗池能降低成本，但成交概率下降。
- **相关性**：同时交易一篮子高度相关的股票，冲击会叠加（netting 很重要）。

## 五、代码示例

```python
import numpy as np
from qd.data.synthetic import generate_demo_market
from qd.backtest import Backtest, BacktestConfig
from qd.strategy.builtin import factor_long_only

md = generate_demo_market(n_symbols=50, start="2018-01-01", end="2024-12-31", seed=7)
close, vol, ret = md.close(), md.volume(), md.returns()

def impact_bps(sigma_daily, participation, eta=1.0):
    """平方根冲击模型：返回单边成本（bps）。"""
    return 1e4 * eta * sigma_daily * np.sqrt(participation)

sym = md.symbols[0]
adv = vol[sym].rolling(20).mean().dropna()          # 20 日均量
sig = ret[sym].rolling(20).std().dropna()           # 滚动日波动率

for rho in [0.001, 0.01, 0.05, 0.20]:
    print("参与率 %5.2f%%  估计冲击 %6.1f bps" % (rho*100, impact_bps(float(sig.iloc[-1]), rho)))

# 单笔名义金额 -> 参与率 -> 冲击 -> 换算成回测滑点
notional = 2_000_000
price = float(close[sym].dropna().iloc[-1])
shares = notional / price
rho = shares / float(adv.iloc[-1])
print("名义 %d 元 约占 ADV %.2f%%  冲击 %.1f bps" % (notional, rho*100, impact_bps(float(sig.iloc[-1]), rho)))

# 把冲击换算成 BacktestConfig.slippage_bps（双边则乘 2）
cfg = BacktestConfig(initial_cash=50_000_000, commission_rate=0.0003,
                     slippage_bps=int(2 * impact_bps(float(sig.iloc[-1]), rho)),
                     stamp_tax=0.0005, allow_short=False, t_plus_1=True)
res = Backtest(md, factor_long_only(factors=["mom_12_1"], top_k=20, rebalance="1M"), cfg).run()
print(res.summary())
```

## 常见坑

- **回测用固定 5bps 滑点**：对大资金完全不成立。滑点必须随参与率、波动率、市值动态变化。
- **只算单边成本**：建仓和平仓各一次，除非长期持有，否则应算双边。
- **用日成交量而非 ADV**：个股成交量自相关很强，单日放量不代表常态。
- **忽略暂时冲击的回复**：若你是长期持有者，暂时冲击部分可以少计；若是日内高频，全额计入。
- **忘记 netting**：同时买入 A 卖出 B，实际只需交易净额，成本应按净额计算。
- **在涨跌停/停牌日估算容量**：这些日子的 ADV 不代表可执行流动性。
