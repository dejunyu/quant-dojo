# 真实 A 股数据端到端示例：动量因子从拉数据到样本外检验

> 这份示例回答一个尖锐的问题：**「你这平台在合成数据上跑得欢，换成真股票还行吗？」**
>
> 答案分两层：**流程完全一样，一行都不用改**（这是设计使然）；但**结论必须诚实**——
> 下面的数字只说明「流程通了」，**不代表这个策略能赚钱**。原因在文末，每一条都是
> 真实研究里会咬人的坑。

## 运行前提

```bash
pip install akshare          # 社区接口，可能变更或限流
python examples/real_a_share.py
```

需要联网。拉取的数据会缓存在 `storage/cache/`（已加入 .gitignore，不会上传）。

## 示例脚本

[`real_a_share.py`](real_a_share.py) 做了六件事：

1. 用 akshare 拉取 **10 只真实 A 股** 2021–2024 年的前复权日线
   （贵州茅台、五粮液、中国平安、招商银行、宁德时代、恒瑞医药、
   万科A、海天味业、长江电力、伊利股份——覆盖消费/金融/新能源/医药/公用事业）
2. 组装成 `MarketData`（与合成数据完全同一接口）
3. 对 3 个经典因子（动量、价值、低波）做 IC 检验
4. 跑双动量策略的**样本外**回测（前 70% 训练选参，后 30% 检验）
5. 对比**日频 vs 月频**调仓的成本影响
6. **如实打印本示例的所有局限**

## 样本外的意义

前 70% 的数据用来选参数（比如 lookback 用 60 还是 120），后 30% 完全不参与任何决策，
只用来检验「选出来的参数在没见过的数据上还行不行」。**没有这一步，任何回测数字都可以
被参数搜索雕成艺术品。**见课程 [06-06 样本内外与滚动前推](../docs/06-回测/06-06-样本内外与滚动前推.md)。

## 本示例的局限（读结果前必看）

| 局限 | 影响 | 严重程度 |
|---|---|---|
| **幸存者偏差**：这 10 只股票是 2026 年的知名公司。2021 年时你未必会选它们——退市的、暴雷的不在名单里 | 收益被系统性高估 | 🔴 高 |
| **样本极小**：10 只股票撑不起横截面统计。正经因子研究需要全市场几千只 | IC 与分层结果噪声极大 | 🔴 高 |
| **无行业/市值中性化**：因子暴露可能只是行业暴露的替身 | 因子「有效」可能只是「押对了行业」 | 🟡 中 |
| **固定样本期**：2021–2024 含一轮完整牛熊，但没有覆盖 2015、2018 级别的极端行情 | 回撤被低估 | 🟡 中 |
| **成本假设是默认值**：实际佣金、冲击成本因人而异 | 净收益偏差 | 🟡 中 |
| **单一策略单一参数**：没有做完整的参数稳健性检验 | 结论脆弱 | 🟡 中 |

**正因为有这些局限，这个示例的价值不在数字本身，而在流程**：换数据、换因子、换策略，
检验流程是不变的。当你把样本扩到全市场、补上中性化和更长的历史，同一套代码就是
正经研究的起点。

## 实测结果（2026-10-22 运行，10 只标的 / 969 个交易日 / 13.9s 拉取）

### 因子 IC（真实数据，horizon=20）

```
因子        IC均值     ICIR    t统计    IC>0占比   判定
mom_12_1   +0.0525   +0.14    +3.70     56.4%    可疑（有信号但不稳）
rev_20d    -0.0346   -0.09    -2.85     44.1%    通过（反向有效）
vol_60d    +0.0002   +0.00    +0.02     50.4%    不通过（无信号）
```

### 样本外回测（前 70% 选参，后 30% 检验）

```
样本外区间              选出参数                      夏普
2022-05 ~ 2023-08      lookback=120, top_k=3        -1.83
2023-08 ~ 2024-12      lookback=120, top_k=3        +0.13
─────────────────────────────────────────────────────
样本外拼接              夏普 -0.647   年化 -12.4%   回撤 -38.0%
```

### 调仓频率的成本影响（真实数据）

```
daily     年化 -19.94%   成交 821 笔   成本 31.0 万元
monthly   年化  -0.09%   成交 119 笔   成本  8.8 万元
```

### 三组数字，三个教训（都来自真实市场）

1. **因子在真实数据上弱且不稳。** 合成数据里植入的动量 IC≈0.03 且 ICIR 很高；
   真实 10 只样本上动量 IC=0.05 但 ICIR 只有 0.14——**平均看有信号，逐月看忽正忽负**。
   这就是为什么单看「平均 IC」会骗人，必须看 [ICIR 与 t 统计](../docs/05-因子/05-05-单因子检验IC与ICIR.md)。

2. **样本外衰减是常态。** 滚动前推的两段：-1.83 和 +0.13。参数是同一段数据选出来的，
   样本外表现却在两个世界之间摇摆。**样本内 +0.41 的「最优参数」到了样本外就是 -0.65。**
   这不是 bug，是金融数据 2~3 年一变的真实节奏（regime shift）。

3. **成本在真实数据上同样致命。** 日频比月频多亏 19.9 个百分点，多花 22 万元交易成本。
   10 只股票、每天调仓，一年就能烧掉一个首付款。

**注意：这 10 只是 2026 年的知名公司——本身就是幸存者偏差样本。**
真实收益比这里显示的还要差。

## 常见问题

**Q：为什么不用全市场几千只股票？**
可以，但 akshare 逐只拉取有速率限制，全市场要数小时。示例取 10 只是让你 5 分钟内
跑通全流程。扩展到全市场只需改 `SYMBOLS` 列表并容忍更长的下载时间。

**Q：为什么用前复权？**
横截面因子研究的标准做法——让不同时点的价格可比。但它也有副作用：前复权价格
在除权日会"改写历史"，做事件研究时要用不复权数据。见
[02-03 复权停牌与异常处理](../docs/02-数据与工具/02-03-复权停牌与异常处理.md)。

**Q：为什么我的数字和你不一样？**
akshare 接口的数据可能被修正（复权因子更新、财务重述），且示例固定了随机种子
之外的一切都会随时间漂移。**数字会变，流程不变。**
